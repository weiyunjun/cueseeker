# Chronicle

Status: Draft

This directory records reasoning provenance for explicitly started Socratic
architecture alignment sessions.

Chronicle entries explain why an implementation idea, risk, proposal direction,
or engineering rule candidate emerged from a question path. They are not a
replacement for proposals, ADRs, changelog entries, or Git commits.

Use a chronicle entry when:

- The user explicitly starts a Socratic architecture alignment session.
- The conversation narrows from broad uncertainty into a meaningful technical
  concern or implementation direction.
- The user asks to record or update the process summary.

Naming format:

```text
YYYY-MM-DD-topic-name.md
```

Recommended sections:

```text
Context
Question Path
Evidence Surfaced
Emerging Insight
Open Questions
Next Update Trigger
```
