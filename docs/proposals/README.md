# Proposals

Status: Draft

This directory contains proposed product, architecture, data model, playback, storage, networking, and workflow changes before they become stable project rules.

Use a proposal when a change:

- Adds a significant feature.
- Changes a core user flow.
- Changes the database structure.
- Replaces or significantly changes playback, indexing, storage, or networking.
- Introduces a new external service or macOS system capability.

Naming format:

```text
YYYY-MM-topic-name.md
```

Accepted proposal conclusions must be merged into the relevant product or engineering documents. Proposal files remain as historical context.
