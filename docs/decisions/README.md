# Architecture Decision Records

Status: Draft

This directory contains Architecture Decision Records for major product or engineering decisions that are expensive to reverse.

Use an ADR for decisions such as:

- Native macOS rewrite direction.
- Playback engine selection.
- Sandboxing strategy.
- Signing and notarization strategy.
- Major database schema changes.
- Direct compatibility with the archived Flutter database.
- Raising the minimum supported macOS version.

Naming format:

```text
ADR-0001-topic-name.md
```

Recommended sections:

```text
Background
Decision
Rationale
Tradeoffs
Alternatives considered
Status
```

Stable conclusions from accepted ADRs must be reflected in the relevant product or engineering documents.
