# 需求描述

1. **应用启动与窗口展示时的焦点激活**：
   - 应用启动并展示主窗口（含开发环境直接运行与正式打包运行）时，主窗口应正常获得系统焦点（左上角红绿灯亮起彩色），窗口内所有界面元素的 `Hover` 效果、指针样式及弹出菜单交互立即可用。

2. **窗口内点击交互（含左键与右键）同步激活窗口焦点**：
   - 当主窗口或独立设置窗口处于未聚焦状态（左上角红绿灯为灰色）时，若用户在该窗口内按下鼠标左键或右键（例如直接点击页面控件，或直接在表格行、封面卡片上点击右键唤起右键菜单），窗口应立即切换为当前活跃聚焦窗口（红绿灯亮起彩色）。
   - 右键唤起菜单或窗口内任意菜单处于打开状态期间，菜单项的 `Hover` 高亮与二级菜单悬停展开均正常响应，不得出现一级菜单已弹出但无法触发 `Hover` 或无法展开二级菜单的情况。

# 验收标准

1. **启动即聚焦**：修改代码并重新编译启动应用后，主窗口弹出时左上角红绿灯正常亮起彩色，移动鼠标经过侧边栏、顶栏、卡片或表格行时立即显示 `Hover` 效果，打开任意包含子菜单的菜单并悬停在父菜单项上时正常弹出二级菜单。
2. **未聚焦状态下点击左键或右键立即聚焦并响应交互**：当焦点在其他应用（或另一窗口）导致目标窗口左上角红绿灯呈灰色时，直接在目标窗口内点击左键，或在表格行、卡片上直接点击右键弹出菜单，目标窗口左上角红绿灯立即亮起彩色，弹出的右键菜单可正常显示 `Hover` 高亮并悬停展开二级菜单。
