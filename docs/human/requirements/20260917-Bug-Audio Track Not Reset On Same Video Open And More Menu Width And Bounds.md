# 需求描述

## 1. 音频源

1. 在播放页打开任何条目时，当前音频源都取该视频的默认音频源，打开的是正在播放的同一视频时也一样。入口包括：Command Panel 的 Recent Videos、Recent Excerpt Lists 与搜索，Playlist，上一个与下一个，自动切换到下一条，Deep Link。
2. Repeat（重播当前字幕）不改变当前音频源。

## 2. 按钮位置

1. 底栏最右侧的全屏按钮与 More 按钮互换位置：全屏按钮在最右，More 按钮在它左侧。

## 3. 菜单宽度

1. More 菜单的宽度跟随菜单项内容，不再与倍速菜单相同。
2. 音轨二级菜单的宽度取以下三者中最小的：自然宽度、宽度上限、展开一侧的可用宽度。名称超出宽度时换行。宽度上限在 App 内验收时确定。
3. 二级菜单出现滚动条时加宽，但加宽后整体仍不超出可用宽度。

## 4. 菜单显示范围

1. 倍速菜单、More 菜单及其二级菜单不盖住顶栏，也不盖住底栏按钮区域；下边与一级菜单一样停在按钮上方。
2. 二级菜单不盖住一级菜单：默认向右展开，右侧不够时向左，两侧都不够时向较宽的一侧。
3. 高度不够时，菜单降低高度并出现滚动条。

# 验收

1. 在播放页修改当前音频源或默认音频源后，从第 1 节所列入口打开同一视频的条目，播放的音轨与 More 菜单的勾选都是默认音频源；按 Repeat 后当前音频源不变。
2. 中文与英文界面下，More 菜单的文字完整显示，不被截断。
3. 音轨二级菜单的宽度随名称变化，长名称到上限时换行；窗口变窄时二级菜单随之变窄，不盖住一级菜单。
4. 窗口高度不够时，二级菜单不盖住顶栏与底栏按钮，并出现滚动条。
5. 全屏按钮在底栏最右，More 按钮在它左侧。
6. 界面与音频由人工在 App 内验收；本次改动不新增任何自动化端到端用例或单元用例的失败。
