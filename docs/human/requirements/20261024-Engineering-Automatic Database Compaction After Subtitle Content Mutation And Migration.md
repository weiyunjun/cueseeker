# 需求描述

1. **数据库升级迁移时自动执行一次压缩整理**：
   - 升级数据库版本，在迁移过程中自动对现有数据库执行一次压缩整理，消除历史留存的搜索数据物理碎片并回收空闲空间。

2. **任务末尾按字幕台词数据变更自动压缩数据库**：
   - 在 `Index All`、`Index`、`Add Folder`、`Remove Folder` 四类任务的末尾，只要本次任务实际发生了字幕台词数据的增、删、改（含新增字幕、修改字幕、墓碑复活、删除字幕或移除文件夹内容），自动执行一次数据库压缩整理，保持搜索数据物理连续并回收空闲空间。
   - 当上述四类任务未发生任何字幕台词数据的增、删、改（如文件无变化的重扫、仅更新视频信息或同名视频绑定、仅生成或更新自动封面、仅回填文件详情的原始未清洗行数、添加或移除已被外层根目录覆盖的子文件夹、目标文件夹无有效可入库字幕，或任务在发布任何台词变更前失败/取消）时，不触发数据库压缩。
   - `Export to Anki`、`Rename Folder`、`Rename Files` 任务不触发数据库压缩。

# 验收标准

1. 现有数据库完成版本升级迁移后，搜索数据恢复物理连续且空闲空间被回收，`SearchBench --headless-cold` 冷启动搜索耗时恢复至基线水平。
2. 执行包含字幕台词增、删、改的 `Index All`、`Index`、`Add Folder`、`Remove Folder` 任务后，任务末尾自动完成数据库压缩，空闲空间归零且搜索数据保持连续；执行无字幕台词增、删、改的上述任务以及 `Export to Anki`、`Rename Folder`、`Rename Files` 任务时，不触发数据库压缩。
