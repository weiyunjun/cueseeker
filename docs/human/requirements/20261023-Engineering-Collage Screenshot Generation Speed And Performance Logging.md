# 需求描述

1. **视频抽帧仅读取画面数据并按分组交集中点复用底图**：
   - Collage 提取视频帧时仅读取目标时间点的视频画面，跳过音频、内封字幕、内封字体附件、章节信息及多余的流探测开销，消除含内封字幕或内封字体的视频在抽帧时的读取卡顿。
   - 同一 Collage 会话内，当分组新增或减少台词后计算出的分组交集中点时刻未发生变化（如勾选双语字幕的第二行）时，直接复用已抽取的无字幕原始视频底图，不再重复从视频抽帧；若分组交集中点时刻发生变化，则按新中点时刻抽取视频帧。

2. **外挂字幕会话内复用与无关内容剔除**：
   - 同一 Collage 会话内复用已加载的外挂字幕内容，新增或更新截图组时不再重复从磁盘读取外挂字幕文件。
   - 生成分组渲染字幕时，剔除外挂字幕中的注释行、制字幕软件工程垃圾段以及内嵌字体与图形段，仅保留样式定义与当前分组选中的台词事件（含被索引去重的多层渐变同源事件），并在完整还原多层渐变字幕的前提下避免对无关台词做全量重复扫描。

3. **长截图生成耗时本地日志记录**：
   - 每次进入 Collage 生成首图或勾选/取消勾选台词生成新截图组时，将耗时数据追加写入本地固定路径日志文件（`~/Library/Application Support/CueSeeker/logs/collage-performance.log`）。
   - 单条日志记录触发类型、视频与外挂字幕文件名、总分组数与新渲染分组数、目标台词序号与时间点、端到端总耗时，以及字幕准备、视频抽帧、字幕渲染叠字、长图拼接四个子阶段的耗时；日志文件大小超出上限时自动裁剪旧记录。

# 验收标准

1. 对含内封字幕与内封字体的视频（如《进击的巨人》第 1 季第 20 集）以及含大量注释与特效的大体积外挂字幕（如《It's MyGO!!!!!》第 05 集），进入 Collage 生成首图、依次往下勾选非同组台词以及勾选同组双语台词的生成耗时显著降低。
2. 普通台词、双语字幕及多层渐变特效字幕的 Collage 预览、复制与导出画面与改动前完全一致，不漏画多层渐变字幕，也不混入未选中的台词或注释。
3. 在打包后的 Release 版本中操作 Collage 时，本地日志文件实时记录每次截图组生成的总耗时与各环节拆解耗时。
