# 需求描述

1. **Search 与 Excerpt List 工具栏统一为两行布局**：
   - **第一行（封面区下方）**：从左到右依次为 `搜索框`、`筛选按钮`、`排序按钮`，搜索框宽度自适应并撑满整行剩余宽度。排序按钮与单选菜单复用 Library 一级界面排序控件样式（`funnel-simple` 图标 + 当前生效的排序名称，点击展开单选菜单并默认高亮首项）。
   - **第二行**：默认状态下左对齐显示结果数量（Search 为 `xx results`，未输入搜索词时不显示；Excerpt List 为 `xx excerpts`）。
   - **批量选择模式（Select Mode）**：Search 与 Excerpt List 统一为第一行的搜索框、筛选按钮、排序按钮整体禁用，第二行切换为左对齐的「退出选择」按钮与批量选择提示文案。

2. **Search 排序规则与行为**：
   - 排序选项依次为：
     - **默认排序**（英文：`Default Order`，默认选中）
     - **字符数最多**（英文：`Most Characters`）
     - **字符数最少**（英文：`Fewest Characters`）
   - **兜底规则**：当前排序规则下顺序相同时（如字符数相同），统一按**默认排序**作为二级兜底顺序；后续新增任何排序方式均以默认排序兜底。
   - **搜索中切换排序**：当搜索进行中修改排序时，立即打断当前搜索，并以当前关键词按新排序重新开始搜索。
   - **顺序固定与同步**：排序基于入库时已确定的属性，保证首屏结果与全量搜索完成后的顺序一致。Search 的筛选与排序跨重启持久化保留；Command Panel 本版本不增加筛选与排序按钮，但展示内容与顺序同 Search 保持一致。

3. **Excerpt List 排序规则与按列表独立状态**：
   - 排序选项依次为：
     - **添加日期最早**（英文：`Earliest Date Added`，默认选中）
     - **添加日期最晚**（英文：`Latest Date Added`）
     - **字符数最多**（英文：`Most Characters`）
     - **字符数最少**（英文：`Fewest Characters`）
   - **兜底规则**：当前排序规则下顺序相同时，统一按**添加日期最早**作为二级兜底顺序；后续新增任何排序方式均以添加日期最早兜底。
   - **搜索中切换排序**：当搜索进行中修改排序时，立即打断当前搜索，并以当前关键词按新排序重新开始搜索。
   - **独立状态与持久化**：每个 Excerpt List 的搜索词、筛选条件、排序方式彼此独立，切换列表互不共用；其中筛选条件与排序方式按列表跨重启持久化保留，搜索词在应用重启后不保留。

4. **搜索性能基准测试（Benchmark）**：
   - 修改代码前，在与上次基准测试相同的数据库上搜索日语 `の` 并记录各项耗时基线；改动完成后再次执行对比，确保本次改动不影响搜索性能。

# 验收标准

1. Search 与 Excerpt List 二级详情页工具栏统一为两行布局（第一行：搜索框 + 筛选 + 排序；第二行：左对齐结果数），批量选择模式下第一行禁用、第二行切换为退出选择与提示文案。
2. Search 与 Excerpt List 排序按钮、菜单选项顺序、中英文文案、兜底排序及播放队列顺序符合预期；搜索进行中切换排序可立即打断重搜，首屏与全量结果顺序一致。
3. 不同 Excerpt List 之间的搜索词、筛选、排序完全独立；Search 及各 Excerpt List 的筛选和排序在重启应用后保留，搜索词重启后清空；Command Panel 内容与 Search 一致。
4. 修改前后搜索日语 `の` 的各项 Benchmark 耗时无性能退化。
