# 需求描述

## 1. 表格序号列水平居中对齐
1. **表头居中**：Workbench 各表格（Search、Excerpt 等）的 `#` 列表头文本在 50px 列宽内**水平居中**对齐，移除原有的左侧固定内边距。
2. **内容居中**：表格各行的序号数字在 50px 列宽内**水平居中**对齐，视觉中心线与表头 `#` 及 Checkbox 严格对齐（中心线均为 X = 25px）。
3. **消除跳动**：鼠标悬停在行或进入批量选择时，序号切换为 Checkbox 不发生水平位置偏移。

## 2. 5 位数容量保障
1. **单行不换行**：序号文本保持单行渲染，不得折行。
2. **边距收敛**：序号在 50px 宽度内居中排版，确保 5 位数字（如 76817）完整显示并与列两侧各保持少量安全间距（约 6px）。

# 验收标准

1. 表头 `#` 与所有行的序号数字均水平居中显示。
2. 鼠标悬停行或表头时，序号/`#` 与 Checkbox 切换时水平中心位置完全一致，无跳动感。
3. 序号达到 5 位数时正常单行展示，不发生换行，左右保留可见间隙。
