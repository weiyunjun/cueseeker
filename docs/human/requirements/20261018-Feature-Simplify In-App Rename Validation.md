# 需求描述

1. **改名前冲突检测精简为仅做基础存在性与同路径重名校验（所见即所得）**：
   - **源存在性校验**：
     - **文件夹改名（`Rename Folder`）**：仅检测目标文件夹本身在磁盘上是否存在；不存在则拦截改名请求。
     - **文件改名（`Rename Files`）**：仅检测界面上当前这组已知配对文件（该视频及其已匹配的字幕）在磁盘上是否全部存在；只要有任意一个文件不存在，则整体拦截本次改名请求。
   - **同路径重名校验**：仅检测在当前所在的同一路径（同一父文件夹）下，改名后的目标名称是否已存在（仅大小写或 Unicode 规范化不同的自身改名除外）；已存在则拦截。不同路径下的同名情况不作限制。

2. **移除冗余的冲突检测规则**：
   - 不再检测涉及文件的文件大小与修改时间是否发生变化。
   - 不再扫描所在文件夹比对磁盘实时配对关系，也不再预演改名后是否会改变视频与字幕的配对关系（同文件夹下存在空白字幕或未索引文件时不影响改名）。
   - 不再拦截正在播放的视频，也不再拦截被排队中导出任务引用的文件。

# 验收标准

1. 当文件夹下存在空白字幕（如 `.blank.srt`）或未索引文件时，对该文件夹或其中已配对的视频与字幕执行改名均可正常完成，不再被拦截。
2. 执行 `Rename Files` 时，若该组已知配对文件在磁盘上全部存在且同路径下无重名，则全部一起改名；若其中至少有一个文件不存在，则拦截整个改名请求，其余文件保持原名不变。
3. 执行 `Rename Folder` 时，只要该文件夹本身在磁盘上存在且同路径下无重名，即可正常完成改名。
4. 同一父路径下已存在同名目标（非自身大小写变更）时拦截改名；不同路径下存在同名文件夹或文件时正常允许改名。
