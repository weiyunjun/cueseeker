# 需求描述

## 1. 移除无关加载与任务干扰

1. File 界面展现或停留期间，不触发 Library 媒体库的封面渲染或合集摘要计算，避免无关后台任务占用资源。
2. File 界面的数据加载保持独立，不受媒体库其他业务（如封面生成、播放历史变化）刷新信号的干扰或重置。

## 2. 文件夹下钻即时呈现（按需加载）

1. **二级界面（Subfolder 目录列表）**：点击一级根目录卡片下钻时，仅查询该根目录下的子文件夹列表；已入库内容应瞬时呈现，体感无延迟，不出现转菊花加载。
2. **三级界面（Files 文件流）**：点击二级子文件夹卡片下钻时，仅查询当前文件夹内的文件列表，瞬时呈现。
3. 保持现有重命名、删除、空状态及面包屑导航等既有交互功能完整可用。

# 验收

1. **下钻性能**：在大型已入库媒体目录下，点击根目录卡片进入二级子目录，卡片列表瞬时展现，无体感加载等待与转菊花。
2. **文件呈现**：点击二级子目录卡片进入三级文件流，音视频与字幕文件列表秒级呈现，文件大小与名称显示正确。
3. **操作完备性**：各级界面的重命名、删除操作，以及前进/后退历史导航与面包屑跳转均正常可用。
4. **测试要求**：
   - 视觉与端到端流畅度由所有者人工验收。
   - 数据按需提取逻辑与路由流转等由自动化测试覆盖且全部通过。
