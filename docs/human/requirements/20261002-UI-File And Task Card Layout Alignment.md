# 需求描述

## 1. 圆角图标底容器规范（File 与 Task 卡片统一）
1. 图标外部统一包裹圆角矩形底容器：尺寸 40×40px，圆角 `--radius-control`（8px），底色 `--color-bg-hover`。
2. 内部图标居中展示，尺寸微调为 24px，前景色统一为 `--color-text-secondary`，所有卡片保持一致的视觉表现，不按内容区分颜色。

## 2. 基准态几何对齐（标题 1 行 + 副标题/路径/时间 1 行）
1. 卡片内部基准边距为 $P$（`--spacing-4`，16px）。
2. 左边距（卡片左壁到图标底容器左壁）= $P$。
3. 图标到文字间距（图标底容器右壁到文字左壁）= $P$。
4. 上下边距（标准双行内容顶/底到卡片外框）= $P$。
5. 文字以上方 Cap 顶（大写字母/汉字顶缘）与图标底容器顶边水平平齐对齐，消除字体内置行空误差。
6. File 卡片右边距（最右侧操作按钮右壁到卡片右内壁）= $P$。
7. Task 卡片右侧无按钮，标准内边距为四边等距 $P$（视觉呈现左、上、下三边等宽）。

## 3. 扩展态顶部锁定（多行文本 / 进度条 / 错误信息）
1. 当路径或标题折行为多行、或 Task 卡片出现第 3 行进度条（In Progress，16px）/错误信息（Incomplete，16px）时，取消整卡片垂直居中。
2. 图标底容器与 File 卡片右侧按钮组的 Top 偏移量严格锁定在基准位置（Top = $P$），保持与标准两行态完全一致的 Y 轴落位。
3. 文字列及附属行仅向下方延展撑开卡片，卡片底部维持 $P$ 的内边距。

# 验收

1. **视觉一致性**：File 卡片与 Task 卡片左侧图标均统一为 40×40px 圆角底容器，图标颜色统一无色相差异。
2. **两行基准态对齐**：标准双行时，左边距、图标到文字间距、右边距、上下边距严格为 16px；文字 Cap 顶与图标底容器顶边齐平。
3. **多行与第 3 行展开态**：File 卡片长文本折行及 Task 卡片展示进度条/报错信息时，左侧圆角图标与右侧按钮保持 Top 偏移锁定，不发生垂直下沉。
