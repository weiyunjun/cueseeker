# 需求描述

## 1. 圆角图标底容器规范（File 与 Task 卡片统一）
1. 图标外部统一包裹圆角矩形底容器：尺寸 36×36px，圆角 `--radius-control`（8px），底色 `--color-bg-hover`。
2. 内部图标居中展示，尺寸为 20px（内部留白 8px），前景色统一为 `--color-text-secondary`，所有卡片保持一致的视觉表现，不按内容区分颜色。

## 2. 基准态几何对齐（标题 1 行 + 副标题/路径/时间 1 行）
1. 卡片内部基准边距为 $P$（`--spacing-4`，16px）。
2. 双行文本（标题 1 行 + 副标题/路径/时间 1 行）真实总高为 36px，以此确定基准卡片总高为 68px（上边距 16px + 双行文字 36px + 下边距 16px）。
3. 36×36px 图标底容器与双行文字 36px 绝对等高，卡片左边距、图标到文字间距、上边距、下边距严格相等，均为 $P$（16px）。
4. File 卡片右侧 40px 操作按钮在 68px 基准卡片内垂直居中（上下各 14px），右边距严格等于 $P$（16px）。
5. Task 卡片右侧无按钮，标准内边距为四边等距 $P$（视觉呈现左、上、下三边等宽）。

## 3. 扩展态顶部锁定（多行文本 / 进度条 / 错误信息）
1. 当路径或标题折行为多行、或 Task 卡片出现第 3 行进度条（In Progress，16px）/错误信息（Incomplete，16px）时，取消整卡片垂直居中。
2. 36×36px 图标底容器 Top 偏移量锁定在 16px，File 卡片右侧按钮组 Top 偏移量锁定在基准垂直居中位置（14px），保持与标准两行态完全一致的 Y 轴落位。
3. 文字列及附属行仅向下方延展撑开卡片，卡片底部维持 $P$（16px）的内边距。

# 验收

1. **视觉一致性**：File 卡片与 Task 卡片左侧图标均统一为 36×36px 圆角底容器，内部图标为 20px，图标颜色统一为 `--color-text-secondary`，无色相差异。
2. **两行基准态对齐**：标准双行时，卡片总高为 68px；图标底容器为 36×36px，左边距、图标到文字间距、上边距、下边距严格为 16px；右侧 40px 按钮垂直居中且右边距为 16px。
3. **多行与第 3 行展开态**：File 卡片长文本折行及 Task 卡片展示进度条/报错信息时，左侧圆角图标（Top 16px）与右侧按钮（Top 14px）保持基准位置锁定，不发生垂直下沉。
