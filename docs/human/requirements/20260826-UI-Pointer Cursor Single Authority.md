# 需求描述

## 1. 目标

手型指针当前只在字幕表格生效，其余位置写了却不显示，且菜单打开期间反而
出现。本需求将指针形状的判定收敛到唯一来源，并按下述规则修正实际表现。

## 2. 指针形状规则

1. 手型指针只出现在三处：表格内可播放字幕文本的点击区域、视频卡片
   （含库文件夹卡片）、Shiori 列表卡片。其中三张卡片的手型只在
   macOS 15 及以上生效；低于 macOS 15 时卡片使用系统默认箭头。
   表格内字幕文本的手型不受系统版本影响。
2. 其余界面一律箭头，包括 Icon Button、菜单项、表头触发、Command Panel、
   Playback Overlay 顶栏、封面编辑按钮、Recent 的 Shiori 续读行、
   搜索结果中的 Shiori 卡片。
3. 表格内可选文本保留 I 型指针，滚动条保留箭头。
4. 不可用或禁用的卡片与控件使用箭头，不使用禁止指针。

## 3. 判定归属

1. 指针形状只能由承载该界面的框架自身的指针机制决定：SwiftUI 界面用
   SwiftUI 的指针机制，AppKit 界面用 AppKit 的指针机制。
2. 禁止从承载框架之外压入或设置指针形状。这类做法会被框架在下一次
   鼠标移动时覆盖，表现为闪烁或完全不生效。
3. 现有分散的、随 Hover 压入与弹出指针的做法全部移除，不保留第二条
   可用路径。

## 4. 覆盖与冻结

1. 某层被更高层覆盖，或该层有菜单打开时，该层的指针保持箭头。
2. 覆盖与冻结沿用现有层级登记表回答，不新增判断来源。

## 5. 历史条目作废

`docs/human/requirements/20260615-Feature-UI Redesign.md` 中关于
Icon Button、表头触发、菜单项使用 pointer 的 Cursor 条目作废，以本需求为准。

## 6. 设计文档

本需求验收通过后，再将第 2、3、4 节规则补入关联设计文档，并在其中记录卡片手型的系统版本差异。

## 7. 已知限制

1. 卡片手型依赖 macOS 15 起提供的 SwiftUI 指针机制。低版本上没有
   不闪烁的实现方式，因此按默认箭头处理。
2. 若将来要在低版本上也支持卡片手型，需要把卡片改由接收鼠标命中的
   原生视图承载。这属于架构调整，不在本需求范围内，当前也没有必要性。

# 验收

1. 在 macOS 15 及以上：三处手型区域 Hover 显示手型，且鼠标在其上持续
   移动时手型保持不变，不回落为箭头。
2. 在 macOS 15 以下：三张卡片 Hover 为稳定的系统默认箭头，不得出现
   手型与箭头交替闪烁；表格内字幕文本仍显示手型。
3. 指针移出后恢复箭头。
4. 第 2 节第 2 条列出的界面 Hover 均为箭头。
5. 右键卡片打开菜单后，Hover 其他卡片为箭头。
6. 表格可选文本仍为 I 型，滚动条仍为箭头。
7. 现有自动化端到端与单元用例全部通过。
8. 指针形状本身由需求方人工验收。
