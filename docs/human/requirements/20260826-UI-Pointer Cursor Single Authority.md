# 需求描述

## 1. 目标

手型指针当前只在字幕表格生效，其余位置写了却不显示，且菜单打开期间反而
出现。本需求将指针形状的判定收敛到唯一来源，并按下述规则修正实际表现。

## 2. 指针形状规则

1. 手型指针只出现在三处：表格内可播放字幕文本的点击区域、视频卡片
   （含库文件夹卡片）、Shiori 列表卡片。
2. 其余界面一律箭头，包括 Icon Button、菜单项、表头触发、Command Panel、
   Playback Overlay 顶栏、封面编辑按钮、Recent 的 Shiori 续读行、
   搜索结果中的 Shiori 卡片。
3. 表格内可选文本保留 I 型指针，滚动条保留箭头。
4. 不可用或禁用的卡片与控件使用箭头，不使用禁止指针。

## 3. 判定唯一性

1. 全应用只有一份指针形状设置实现，且必须与系统在鼠标移动时的指针裁定
   同源，任何其他机制不得再设置指针形状。
2. 现有分散的、随 Hover 压入与弹出指针的做法全部移除，不保留第二条
   可用路径。

## 4. 覆盖与冻结

1. 某层被更高层覆盖，或该层有菜单打开时，该层的指针保持箭头。
2. 覆盖与冻结沿用现有层级登记表回答，不新增判断来源。

## 5. 历史条目作废

`docs/human/requirements/20260615-Feature-UI Redesign.md` 中关于
Icon Button、表头触发、菜单项使用 pointer 的 Cursor 条目作废，以本需求为准。

## 6. 设计文档

本需求验收通过后，再将第 2、3、4 节规则补入关联设计文档。

# 验收

1. 三处手型区域：Hover 显示手型，且鼠标在其上持续移动时手型保持不变，
   不回落为箭头。
2. 指针移出后恢复箭头。
3. 第 2 节第 2 条列出的界面 Hover 均为箭头。
4. 右键卡片打开菜单后，Hover 其他卡片为箭头。
5. 表格可选文本仍为 I 型，滚动条仍为箭头。
6. 现有自动化端到端与单元用例全部通过。
7. 指针形状本身由需求方人工验收。
