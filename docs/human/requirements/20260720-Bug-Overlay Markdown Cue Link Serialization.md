# 需求描述
1. 现状：在视频的Overlay界面按X复制markdown链接时，没有规范化的步骤，导致换行或其他情况，markdown链接异常。
2. 修改方案：1. 将 LF、CRLF、CR 和 Unicode 换行统一处理。2. 每个非空字幕行去掉首尾横向空白，再用一个普通空格连接。3. 使用 Markdown 反斜杠转义， \、[、]、<、>、*、_、反引号、~、&、|。4. 仅修改markdown链接，纯文本复制继续包含原始换行的完整字幕。5. 空白字幕生成可见回退标签，例如 Cue #<CueID>，而不是不可见链接。
