# 需求描述

## 1. 目标

菜单打开期间的模态改为在输入入口一处统一实现，使菜单之外的界面收不到任何输入，新增界面元素无需为菜单做任何适配。

## 2. 统一实现

1. 菜单打开期间，菜单之外的指针移动、hover、拖拽、滚轮、点击、键盘输入一律不送达界面；只有菜单本身、快捷键、独立窗口与系统菜单栏除外。
2. 该判断只允许存在于一处统一实现，禁止各界面、各控件自行判断菜单是否打开。
3. 每个菜单只声明自己的种类，滚动与键盘策略由统一实现按种类给出，对应关系与 `菜单模态` 的表格一致。

## 3. 焦点

1. 菜单打开的瞬间取消 App 内当前焦点，包括文本输入焦点与按钮焦点环。
2. 菜单存在期间禁止任何控件重新获得焦点。
3. 菜单关闭后不恢复焦点，需要用户重新点击。
4. 独立窗口（Settings）不受影响。

## 4. 选中文字

1. 菜单打开的瞬间清除 App 内已有的选中文字。
2. 选中文字菜单自身例外：打开时不清除，关闭时清除。

## 5. 指针

1. 菜单打开期间，菜单之外一律为箭头指针，包括文本输入控件的 I 型指针。
2. 由统一实现给出，禁止界面自行冻结指针形状。

## 6. Hover 与 selected 通用规则

适用于全部界面元素：

1. 鼠标右键点击 hover 判定区域，可以改变 hover / selected 到指针位置。
2. 只有菜单不存在时，鼠标移动可以改变 hover / selected 到指针位置。
3. 鼠标左键只有在非消极功能（目前只有取消已打开的菜单算消极功能）且位于 hover 判定区域时，可以改变 hover / selected 到指针位置。
4. 键盘方向键可以改变 hover / selected 到目标位置。
5. 菜单期间被丢弃的指针移动，不在菜单关闭后补发。

## 7. 保持不变

1. 菜单的键盘规则、关闭方式、层级归属、滚动禁止表均不变。
2. 菜单的外观与内容不变，不新增菜单种类。

## 8. 设计文档同步

本需求验收通过后再更新 `UI Application Rules.md`：菜单模态增加焦点取消与选中文字清除两条；hover / selected 改变规则写入通用规则。

# 验收

1. Search 页搜索框输入中点击筛选按钮：焦点取消，边框恢复未聚焦态，继续打字不进入搜索框；关闭菜单后需重新点击才能输入。
2. 表格行右键菜单打开时，指针移到搜索框上保持箭头。
3. 任意菜单打开期间，菜单之外的按钮、卡片、表格行、滚动条均无 hover 变化。
4. 菜单期间把指针移到别处，关闭菜单后原高亮不变，直到指针真实移动。
5. 表格中选中文字后打开筛选菜单，选中文字被清除；Playback Overlay 选中文字菜单打开时选中保留，关闭时清除。
6. Command Panel 中打开选中文字菜单后按 Esc，上下键仍可切换结果，Enter 可打开。
7. 播放倍速菜单行为不变：左右键仍传给播放页，不禁止滚动。
8. Settings 窗口的输入不受主窗口菜单影响。
9. 现有自动化端到端与单元用例全部通过。
