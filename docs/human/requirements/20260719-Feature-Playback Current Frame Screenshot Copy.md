# 需求描述
1. 在视频界面，新增截图功能，这个版本只做截图后写入剪贴板的功能，暂时不做导出为图片文件的功能。
2. 截图的快捷键是P（无修饰键）。会在播放器UI的字幕开关按钮左侧新增一个截图按钮，功能相同，图标用SF Symbol：photo。注意该图标不会有选中效果，整体比较接近Play按钮的样式，但是图标本身不会变化。这里需要检查UI.md看看直接复用哪个样式。
3. 截图会保存执行截图功能时，最后提交显示的帧的图片。应用视频显示方向后的原生视频像素尺寸。如果截图时开启了字幕显示，需要渲染字幕，如果关闭了字幕显示，就不需要渲染字幕。
4. Overlay界面，这个版本不要响应截图功能，避免不必要的麻烦。
5. 截图成功的提示，图标用SF Symbol：photo，文字是Screenshot Copied。
6. 截图过程不得启动 FFmpeg、不得 Seek、不得暂停播放。
7. 截图只包含视频和字幕，不包含黑边、播放器控制栏、Overlay、HUD。
8. 允许连续按P或者按截图按钮连续截图，这里不做显式限制，和其它播放器UI功能保持一致。
9. Timeline正在拖动时禁止截图，和其它播放器UI功能保持一致。
