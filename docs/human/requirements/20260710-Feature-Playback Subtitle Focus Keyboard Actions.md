# 需求描述
1. 修改字幕焦点窗口的交互。取消按下Enter键后的弹出菜单的交互，取消鼠标的hover效果和点击效果，相关UI代码可以删除，UI文档需要改动。
2. 恢复快捷键的功能交互，即：S键收藏字幕，C键复制字幕文本，空格键从这条字幕处开始播放。
3. 鼠标的功能交互下个版本再做（添加交互按钮点击执行操作），这个版本先不做。
4. 保留交互：方向上下键改变焦点字幕，鼠标滚轮滚动改变焦点字幕，拖拽滚动条改变焦点字幕。
5. 3个功能交互执行后需要调用已经有的动画反馈，即：1. 收藏字幕，Shiori Saved，Shiori Already Saved。2. 复制字幕文本，Subtitle Copied。3. 从这条字幕处开始播放，Play。
6. 收藏字幕或复制字幕文本执行完后，不要退出字幕焦点窗口。从这条字幕处开始播放，需要退出字幕焦点窗口并开始播放。
7. 移除播放器UI底栏的收藏字幕按钮和复制字幕文本按钮（这2个功能，现在开始与字幕焦点窗口耦合，从逻辑上讲，这是合理的，因为视频播放时，无法做到精确选中）。
8. 移除普通播放状态下对快捷键S和C的响应，移除普通播放状态下的后端的收藏字幕按钮和复制字幕文本功能。
9. 显示/隐藏字幕按钮改为圆形按钮。
10. 修改普通播放状态下，显示/隐藏字幕的快捷键为Q（更接近A和D，方便切换结果时显示/隐藏字幕，这实质上是一种功能优化）。
