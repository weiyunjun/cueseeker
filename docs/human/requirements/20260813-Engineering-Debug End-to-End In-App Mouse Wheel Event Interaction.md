main

# 需求描述

扩展现有 CueSeeker Debug E2E 控制器，增加应用内鼠标滚轮事件，使自动化端到端测试能够在完整界面的已知坐标执行真实滚动。

# 需求要求

1. 新增单次纵向滚轮命令，参数包含目标坐标、非零滚动量和当前 `sceneID`。
2. 坐标系沿用现有完整界面坐标；事件发送给该坐标下最前方的可见 CueSeeker 窗口。
3. 支持向上和向下滚动，并通过正常 AppKit 事件路径触发现有界面行为。
4. 成功后返回更新后的完整界面信息和新 `sceneID`。
5. `sceneID` 过期、坐标无效、滚动量无效、目标窗口不存在或事件创建失败时必须明确失败，且不得发送事件。
6. 不移动真实鼠标，不发送系统级全局事件，不申请 Accessibility 或 Input Monitoring 权限，不直接修改控件或业务滚动状态。
7. 本需求只包含离散鼠标滚轮事件；不包含触控板手势、惯性滚动、长按连续滚动或滚动条拖拽。连续滚动通过重复命令完成。
8. 该能力只在显式启用的 Debug E2E 流程中存在，Release App 不得包含或启用。
9. 更新 `docs/engineering/08_end_to_end_testing.md`，记录命令格式、坐标和滚动量语义、使用示例、失败条件及能力边界，使后续 AI 能直接发现并使用该能力。
10. 自动化测试覆盖命令解析、参数校验、前方窗口命中、双向滚动和现有 E2E 命令回归。

# 验收标准

1. 在真实 Debug E2E 流程中，可在已知滚动区域分别向上、向下滚动，并通过截图或界面状态确认结果。
2. 无效命令不会改变界面状态。
3. 现有 `inspect`、`capture`、`click` 和 `keyPress` 功能保持正常。
4. Release 隔离检查通过。
