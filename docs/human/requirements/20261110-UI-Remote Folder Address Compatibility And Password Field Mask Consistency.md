# 需求描述
## 1. 网络文件夹（`WebDAV` / `SMB` / `FTP` / `NFS`）地址输入兼容性统一
- **`WebDAV` 缺省协议头自动补全**：在 `WebDAV Folder` 弹窗 Step 1 的 `Address` 输入框中，若输入的地址未包含协议头（如直接输入 `192.168.1.100:5244/dav` 或 `nas.local/webdav`），点击 `Connect` 时在后台自动按 `http://` 协议补全并解析连接，且不直接修改输入框中的文本；若显式输入了 `http://` 或 `https://`，则按显式指定的协议解析连接。
- **4 种网络协议头大小写不敏感**：`WebDAV`（`http://` / `https://`）、`SMB`（`smb://`）、`FTP`（`ftp://`）、`NFS`（`nfs://`）均支持任意大小写形式的本协议前缀（如 `HTTP://`、`Https://`、`SMB://`、`FTP://`、`NFS://`），后台统一归一化为小写协议头；若显式输入了其他不匹配的协议头（如在 `WebDAV` 中输入 `smb://`，或在 `SMB` 中输入 `http://`），则在点击 `Connect` 时拦截并报错。
- **4 种网络协议地址解析与校验规则对齐**：`WebDAV`、`SMB`、`FTP`、`NFS` 统一支持以下地址兼容与合法性校验规则：
  - 支持未加方括号的纯 IPv6 地址（如 `fe80::1/share` 或 `2001:db8::1/dav`），后台自动识别并包裹为标准 `[IPv6]` 主机格式（若需为 IPv6 地址指定端口，则使用标准 `[IPv6]:port` 格式）。
  - 若地址主机前包含 `user@` 或 `user:pass@` 前缀，后台解析时自动剥离该前缀并正常提取主机、端口与路径（认证凭据统一以弹窗表单为准）。
  - 支持对整段地址（含主机与路径）中的百分号编码（如 `%20` 及中文百分号编码）进行解码归一化，并统一校验主机名、IPv4 地址段（拒绝如 `192.168.1.999` 等越界数字段）及端口范围（`1...65535`）；格式非法时在 Step 1 点击 `Connect` 即刻拦截并使 `Address` 输入框进入报错态。

## 2. 密码输入框聚焦与非聚焦态圆点掩码样式一致
- **掩码字符与视觉样式统一**：密码输入框（如 `WebDAV` / `SMB` / `FTP` 弹窗中的 `Password` 输入框）在获得焦点（Focused）与失去焦点（Unfocused）两种状态下，密码掩码圆点的字符形状、圆点大小、字间距及颜色保持完全一致。
- **聚焦切换零位移**：密码输入框在获得焦点与失去焦点切换时，掩码圆点的水平起始位置与垂直居中基线保持严格对齐（`0px` 跳动）。

# 验收标准
- [ ] 在 `WebDAV Folder` 弹窗 `Address` 中输入不带协议头的地址（如 `host:5244/dav`），点击 `Connect` 后输入框文本保持不变，后台自动补全 `http://` 并发起连接；显式输入 `http://` 或 `https://` 时按对应协议正常连接。
- [ ] 在 `WebDAV`、`SMB`、`FTP`、`NFS` 弹窗中输入大写或大小写混合的本协议前缀（如 `HTTP://`、`HTTPS://`、`SMB://`、`FTP://`、`NFS://`），点击 `Connect` 后均能正常识别并解析连接；输入非本弹窗对应的协议前缀时点击 `Connect` 被拦截并提示地址错误。
- [ ] 在 `WebDAV`、`SMB`、`FTP`、`NFS` 弹窗中，未加方括号的 IPv6 地址、带 `user@` 前缀的地址以及含百分号编码的地址均能按统一规则解析；非法主机名、越界 IPv4（如 `192.168.1.999`）或非法端口在点击 `Connect` 时立即拦截并报错。
- [ ] 在网络文件夹弹窗的 `Password` 输入框中输入密码后，对比输入框处于焦点中与点击空白处取消焦点后的显示效果，两种状态下的密码圆点大小、间距、垂直位置与水平位置完全一致，无大小变化或位置跳动。
