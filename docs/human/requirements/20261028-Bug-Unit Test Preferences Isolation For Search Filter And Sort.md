# 需求描述

1. **自动化单元测试与真实应用偏好配置完全隔离**：
   - 所有自动化单元测试在运行过程中必须使用独立的临时配置与临时数据空间，并在测试结束后自动清理，严禁读取或改写用户本机真实应用的偏好配置（如 Search 筛选条件、排序方式、工作台当前页面等）。

# 验收标准

1. 将真实应用的 Search 筛选条件清空、排序方式设为默认后，执行全量自动化单元测试，再次启动真实应用时，Search 筛选条件（如 `<1s`）与排序方式等用户偏好配置均保持原状，不被测试数据篡改。
