# 需求描述

## 1. 阴影由容器形状投射

1. 浮层的阴影由该浮层的容器形状投射，不由浮层整体投射。
2. 浮层内部的按钮、文字、图标不出现各自的阴影。
3. 适用于所有使用 `--shadow-popover` 的浮层。

## 2. `--shadow-popover` 改为双层收缩配方

1. `--shadow-popover` 由单层改为两层，两层均向内收缩：
   - 主层：Y 偏移 `10px`，模糊 `15px`，收缩 `-3px`
   - 接触层：Y 偏移 `4px`，模糊 `6px`，收缩 `-4px`
2. Light：两层颜色均为 `rgba(15,23,42,0.10)`。
3. Dark：两层颜色均为 `rgba(0,0,0,<待定>)`。
4. 收缩的含义是阴影形状在模糊前先按该数值向内缩小，使阴影只从容器下方漏出，上边缘不留可见阴影。
5. 该 token 的全部使用者一并变更。不新增只服务单个组件的阴影 token。

## 3. 数值记法与实现的关系

1. 本单数值采用设计文档现有的 CSS 记法。
2. 原生实现的模糊参数与该记法不是同一量纲，实现时以实际渲染结果校准，不直接照搬数字。
3. 是否达标由第 5 节验收判定，不以参数相等判定。

## 4. 保持不变

1. 浮层容器的背景、边框颜色、圆角不变。
2. Button 不带阴影的规定不变。
3. 各浮层的位置、尺寸、间距、交互不变。
4. `--shadow-player-overlay` 与 `--shadow-player-topbar-title` 不在本单范围内。

# 设计文档

验收通过后，更新 `docs/human/design/UI Design System.md`「Shadow」章节：

# 验收

1. Select 模式浮层内的四个按钮周围无阴影，「N selected」文字周围无阴影。
2. Select 模式浮层上边框之上无可见灰色，阴影只在下方与两侧下部可见。
3. Toast 内的文字与图标周围无阴影。
4. Menu、Tooltip、Dialog、Task Panel、播放命令面板、播放反馈的阴影与 Select 浮层一致，内部元素均无独立阴影。
5. Light 与 Dark 两个主题分别核对以上各项。
6. 阴影观感由需求方人工验收。
7. 本次改动不新增任何自动化端到端或单元用例的失败。
