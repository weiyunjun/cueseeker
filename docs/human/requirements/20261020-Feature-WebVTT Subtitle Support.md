# 需求描述

1. **支持 `.vtt`（WebVTT）字幕扫描、配对与默认排序**：
   - 本地、WebDAV 与 SMB 文件夹在执行 Index 时均支持扫描 `.vtt` 字幕文件并与同目录视频配对。
   - 当同一视频匹配到多条去掉最后 1 级后缀名后与视频同名的字幕时，排序优先级为 `ass > srt > vtt`。

2. **WebVTT 字幕解析与变化检测（归入非 ASS 字幕处理）**：
   - 忽略 `WEBVTT` 文件头及头部属性（不读取头部 `Language` 等声明，统一通过台词正文自动识别语言），并跳过 `NOTE`、`STYLE`、`REGION` 等非台词块。
   - 通过 `-->` 时间轴行提取每段台词，忽略时间轴上方的可选标识行与时间轴末尾附带的排版参数；时间戳同时支持 `时:分:秒.毫秒` 与省略小时位的 `分:秒.毫秒` 格式。
   - 移除台词文本中的 `<...>` 行内标签；其余清洗（去除首尾空白、排除时长小于 200ms 的台词、空文本过滤、同时间戳同文本去重）、单条独立 Cue Group 以及基于「时间戳 + 文字内容」二要素的变化检测，均按「非 ASS 字幕」规则处理。

3. **播放、导出与界面展示**：
   - `.vtt` 字幕在播放页画面渲染、字幕轨切换、截图与 Anki 导出、以及 File 文件详情展示中均正常支持，画面渲染样式与 SRT 一致。

# 验收标准

1. 将包含 `WEBVTT` 头部说明（如 `Kind`、`Language`）、含/不含小时位时间戳的 `.vtt` 字幕与同名视频放入资料库执行 Index，能够成功配对入库并自动识别语言，Search 搜索与筛选正常命中。
2. 台词中若包含 `<c>`、`<i>` 或 `<00:00:10.500>` 等行内标签，或时间轴末尾带有 `align:start` 等参数，入库后的台词文本与时间戳干净准确。
3. 播放匹配了 `.vtt` 字幕的视频时，画面字幕正常显示，字幕轨切换、台词定位跳转、收藏、截图与 Anki 导出功能正常。
