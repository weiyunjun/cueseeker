# 需求描述

1. **连续静态文本流作用域与阅读顺序连选**：
   - 在当前最上层可交互界面内，除可编辑输入框、表格与播放字幕流三类自包含组件外，同一逻辑承载面（主窗口当前工作台页面内容区、独立设置窗口右侧当前分类内容区、当前最上层模态对话框或任务面板、展开态 `Description Detail Popover`、`Playback Overlay` / `Command Panel` 非字幕流静态区）内部的可选展示文本（含 `I-beam` 纯静态文本与 `Grab` 可点击文本），统一归入该承载面的同一个连续静态文本流作用域；不同承载面之间及与表格、输入框、字幕流之间互不串连；
   - 同一连续静态文本流内严格按「纵向从上到下、同一水平行内从左到右」的视觉阅读顺序跨行、跨元素连续划选，起止位置之间夹杂的不可选控件（如按钮、进度条、图标等）自动跳过；
   - 本单先在当前已接入可选展示文本的承载面（`Cover Summary` 及其 `Description Detail Popover`、`Folder Info` / `File Info` / `Task Info` 已开放字段、`Rename`、`Confirmation`、工具栏统计与 `File` 顶部状态文字）打通并验证连续文本流交互。

2. **起点坐标折算、跨不可选区拖入起选与边缘自动滚屏**：
   - **阅读流上下边界折算**：在连续静态文本流中，纵向高于首行可选文本顶边的坐标统一折算至首行第 1 个字符之前，纵向低于末行可选文本底边的坐标统一折算至末行最后 1 个字符之后，不得在首尾行外侧留出截断行首/行尾文字的水平投影带；
   - **从空白或不可选控件拖入起选**：在全应用任意不承担自身原生拖拽手势的区域（页面/弹窗空白边距、左侧导航栏、面包屑、按钮/开关/分段控制器/`Filter Chip`、徽章标签、封面图与卡片等）按下鼠标左键并向外拖拽时，接触可选文本前不显示选区，一旦拖拽跨过可选展示文本使「最初按下位置」与「当前指针位置」形成非空选区，**立即以最初按下鼠标的位置折算起点激活选词**（不得用半途碰撞边缘的交点覆盖起点），拖选期间指针保持 `I-beam` 并立即取消起手点击控件的按下态，松开鼠标不触发原点击动作；
   - **原生拖拽组件豁免**：各窗口拖拽顶栏、可编辑文本输入框、滚动条、视频播放进度条与音量滑块、封面裁剪框（`Edit Cover`）以及 `Export to Anki` 卡片内可拖拽排序的数据胶囊保持自身原生拖拽职责，不触发跨区选词；
   - **视口边缘自动滚屏**：在任意可滚动视口内拖拽选词移至或超出上下边缘时，所属滚动容器自动连续平滑滚屏并实时扩展或收缩选区，直至松开左键。

3. **剪贴板序列化与全局单一选区生命周期**：
   - **复制格式**：同一水平行内左右并列的可选文本节点同时处于选区内时以单个制表符 `\t` 连接（仅选中单侧时不拼接 `\t`），纵向跨行/跨块之间以单个换行符 `\n` 连接；因行数或宽度限制显示省略号 `...` 的可选文本，在选区覆盖至可见末尾执行复制时提取未被截断的完整底层字符串；
   - **复制触发与选区互斥**：所有静态文本选区仅通过 `Cmd + C`（及系统菜单栏 `Edit -> Copy`）复制，右键不弹复制菜单；全应用（含主窗口与独立设置窗口）任意时刻最多仅保留 1 处活跃文字选区，在选区外按下左/右键、发起新选区、聚焦输入框、打开任意菜单/浮层/弹窗、进入表格 `Select Mode`、关闭所属弹窗或切换页面/标签页/分类时立即清除原选区。

# 验收标准

1. **连续跨行连选与斜拉起点准确**：在 `Library` / `Excerpt` 二级 `Cover Summary` 中，支持从主标题连续向下跨过统计行、本地路径/超长描述（`Grab` 可点击文本原地单击仍正常打开 Finder 或展开描述浮层，按住拖拽则连入选区且松手不误触点击）划选至进度文字；从左上角封面图、返回/侧边栏或空白处向右下斜拉穿过标题时，完整从主标题第 1 个字符起选，无漏选开头字符现象；从底部 `Play` 等按钮向上拖入文字时自动取消按钮按下态且松手不触发播放。
2. **边缘滚屏、省略号完整复制与互斥**：在 `Folder Info` / `File Info` / `Task Info` 或 `Description Detail Popover` 滚动区内跨多行拖至上下边缘时自动平滑滚屏更新选区；选中带 `...` 省略号的路径或台词预览按 `Cmd + C`（或 `Edit -> Copy`）粘贴可得完整未截断文本；点击外部、打开菜单/弹窗或切换页面时选区立即清除。
