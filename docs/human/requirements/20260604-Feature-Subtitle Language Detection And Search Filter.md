### 需求描述
1. 在index阶段，调用`Apple NaturalLanguage`框架里的`NLLanguageRecognizer`判断ASS字幕文件的[V4+ Styles]的不同Name的语言，判断SRT字幕文件的语言。
2. 判断语言的步骤，放在筛选完有效字幕文件后，写入数据库前，避免判断无效字幕文件的语言（例如某个字幕没有对应的视频，不会被检索到，那就没必要判断语言）。
3. 对于SRT字幕，将所有字幕合并为一个文本，然后全量判断所有字幕内容的语言。
4. 对于ASS字幕，只判断被调用的Name的语言。如果一个Name，定义了样式，但是后续没有调用，则不判断它的语言。与SRT字幕类似，对每个被调用的 Name，分别合并该 Name 下所有已清洗字幕文本，然后判断该 Name 的语言。
5. 对于SRT和ASS字幕，可能是单一语言，也可能是若干种语言，也可能是未知语言。基于后续检索的需要，例如只搜索日语，那么单一的ja，或者zh-hans+ja，都在搜索范围内。未知语言可以填unknown。
6. 对于SRT和ASS字幕，置信区间：大于等于0.9的情况下，判定为对应语言（中文特殊处理，见第8条）。低于0.9，判定为unknown。
7. 在设置项中，Appearance下面，新增Search的选项。图标用现在的Search图标。Search这个版本只添加一个选项：主要搜索语言（这里用英语），有一个下拉选择框，可以选择：All，日本語，English，中文，简体中文，繁体中文。（选项文字保持我说的这几个）默认选择All。选择对应语言后，搜索结果只会显示，包含该语言，或者unknown的字幕。
8. 对于中文，需要特殊处理。当且仅当，简体中文（zh-Hans）和繁体中文（zh-Hant）的置信值之和大于等于0.9，且简体中文置信值和繁体中文置信值均小于0.9，语言判定为中文（zh）。
9. 中文选项，会匹配中文或简体中文或繁体中文或unknown的结果。简体中文选项，会匹配中文或简体中文或unknown的结果。繁体中文选项，会匹配中文或繁体中文或unknown的结果。
10. 基于性能考虑，搜索语言设置本质上是一个筛选功能。搜索语言筛选作用于命中的字幕行；同时间戳多行可以合并展示，但不能把未命中行的语言用于匹配通过判断。首屏展示时就要做第一次筛选。后续分页、展开分组、导航、精确计数都在搜索层按同规则筛选。UI 只展示已经筛好的结果。
