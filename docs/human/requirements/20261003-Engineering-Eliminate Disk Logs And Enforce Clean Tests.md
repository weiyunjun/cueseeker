# 版本

main

# 需求目标

彻底移除应用运行时向磁盘写入搜索日志与调试文件的行为，消除隐私泄露与合规风险；规范所有测试用例的生命周期管理，确保单测与集成测试运行后零磁盘残留，保持系统环境清洁。

# 需求

1. **移除应用级搜索落盘日志**：
   - 彻底移除搜索过程向磁盘写入 JSONL / Log 文件的逻辑，严禁在本地持久化记录用户的搜索词（query）、文件夹路径及字幕内容样本。
   - 移除应用在运行时向源码目录或当前工作目录创建 `logs/` 文件夹的机制。
   - 移除偏好设置界面“开发者”分类中的“搜索 E2E 日志”开关、配置项及对应多语言本地化文案。
2. **规范测试配置清理**：
   - 单元测试与集成测试使用 `UserDefaults` 隔离配置时，必须在测试生命周期结束时物理删除对应的偏好设置文件（`~/Library/Preferences/<suiteName>.plist`），严禁在系统偏好设置目录下堆积空文件。
3. **规范测试临时数据库与目录清理**：
   - 测试生成的临时 SQLite 数据库，清理时必须连同 SQLite WAL 模式生成的辅助文件（`-wal`、`-shm`）一并彻底物理删除。
   - 集成测试在临时目录创建的测试子文件夹，必须在测试销毁（`tearDown`）阶段完整递归删除。

# 验收

1. 运行打包版本（Release）及 Debug 版本执行任意搜索，磁盘各处均不会生成任何包含用户搜索词或结果的 JSONL/Log 文件；偏好设置中不再包含搜索日志相关选项。
2. 执行完整单测与集成测试（`swift test`）后：
   - `~/Library/Preferences/` 下无任何新增的 `CueSeeker*.plist` 测试文件残留。
   - 系统临时目录（`$TMPDIR`）下无任何新增的测试 `.sqlite`、`-wal`、`-shm` 文件或测试目录残留。
   - 工程根目录 `logs/` 下无任何新增文件。
3. 既有所有单元测试与集成测试全部保持绿色通过。
