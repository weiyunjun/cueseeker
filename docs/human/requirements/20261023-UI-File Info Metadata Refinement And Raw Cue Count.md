# 需求描述

1. **视频详情（Video）展示调整与信息扩充**：
   - **分辨率（Resolution）**：仅展示宽高数值（如 `1920 × 1080`），移除末尾的宽高比括号（如 `(16:9)`）。
   - **新增「位深度（Bit Depth）」与「像素格式（Pixel Format）」**：在 Index 更新视频元数据时一并提取视频流的位深度（如 `8 bit`、`10 bit`）与像素格式（如 `yuv420p`、`yuv420p10le`）。
   - **展示顺序**：分辨率 → 帧率 → 编码格式 → 位深度 → 像素格式 → 码率 → 时长。

2. **音频详情（Audio #1, #2...）展示规范与信息扩充**：
   - **声道（Channels）**：统一为与播放界面音轨菜单一致的 `<N>ch` 格式（如 `1ch`、`2ch`、`6ch`、`8ch`），不再显示 `Stereo (2.0)`、`Mono (1.0)`。
   - **语言（Language）**：跟随当前 App 界面语言显示对应的语言名称（如中文界面显示 `英语`、`日语`，英文界面显示 `English`、`Japanese`），移除末尾的原始语言代码括号（如 `(eng)`）。
   - **新增「采样率（Sample Rate）」与「位深度（Bit Depth）」**：在 Index 更新视频元数据时一并提取每条音轨的采样率（带千分位分隔符，如 `48,000 Hz`）与位深度（如 `16 bit`、`24 bit`；有损音轨等无固定位深度信息时自动省略该行）。
   - **展示顺序（仅展示有效项）**：编码格式 → 声道 → 采样率 → 位深度 → 语言 → 音轨名称。

3. **字幕详情（Subtitle Specifications）行数拆分为两行**：
   - **原始行数（英文 `Raw Lines` / 简中 `原始行数` / 繁中 `原始行數`）**：统计未清理前的原始条目数（`.ass` / `.ssa` 字幕统计事件区以 `Dialogue:` 开头的行数量，不计 `Comment:`；`.srt` / `.vtt` 字幕统计包含时间轴箭头 `-->` 的行数量）。
   - **有效行数（英文 `Valid Lines` / 简中 `有效行数` / 繁中 `有效行數`）**：展示经清理与去重后实际入库的台词行数。
   - **展示顺序**：字符编码 → 原始行数 → 有效行数。

4. **Index 数据完整性检查与补齐**：
   - 已入库但尚未包含上述新增视频/音频元数据或字幕原始行数的数据，在执行 Index 时视为数据缺失并自动重新读取补齐。

# 验收标准

1. 视频「文件详情」中，分辨率显示为 `1920 × 1080`（无宽高比括号），并按顺序正确展示位深度（如 `8 bit`）与像素格式（如 `yuv420p`）。
2. 视频「文件详情」的各音轨卡片中，声道显示为 `2ch` 等统一格式，语言跟随当前 App 界面语言显示（无括号缩写），并正确展示采样率（如 `48,000 Hz`）与位深度（如 `24 bit`，无位深度的有损音轨自动省略该行）。
3. 字幕「文件详情」的字幕规格卡片中，按顺序展示字符编码、原始行数与有效行数，`.ass` / `.ssa` 与 `.srt` / `.vtt` 字幕的原始行数与有效行数均统计准确。
4. 对旧版本已索引的文件夹执行 Index 后，已有视频与字幕文件自动补齐上述新增详情信息。
