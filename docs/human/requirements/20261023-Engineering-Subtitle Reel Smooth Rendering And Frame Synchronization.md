# 需求描述

1. **字幕流排版与静态内容复用**：
   - 在所有使用字幕流的场景（Playback Overlay 的 `Current`、`Playlist`、`Collage Editor` 以及 `Command Panel` 的字幕搜索结果）中，单条字幕在文字内容与视口宽度不变的前提下，其断行排版、行高、字形边界及底部元数据布局仅计算一次并复用，滚动与颜色过渡期间不再逐帧重新排版测量。
   - 滚动过程中颜色未发生变化的字幕直接复用已渲染内容并仅更新纵向位置，每帧仅对正处于焦点淡入或淡出过程中的字幕更新颜色。

2. **屏幕垂直同步与导航即时起步**：
   - 字幕流的位置滚动与焦点颜色淡入淡出统一对齐显示器硬件刷新周期，消除软件定时步进不均造成的微抖动与跳帧。
   - 触发方向键或滚轮导航时当帧立即启动位移与颜色过渡，消除按键后的首帧起步延迟。

3. **保持既有排版与交互表现不变**：
   - 单行与多行可变高度字幕的锚定与间距、主台词/次台词/底部元数据三层同频颜色过渡、鼠标划词复制/搜索菜单、以及 Collage Editor 左侧勾选框与时间轴连接线等表现保持不变。

# 验收标准

1. 在 `Current`、`Playlist`、`Collage Editor` 及 `Command Panel` 字幕搜索结果中，单次按方向键、连按/长按方向键、滚轮/触控板滚动及拖动滚动条时，字幕滚动与焦点颜色淡入淡出均丝滑连贯，无起步粘滞感、掉帧或节奏微抖动。
2. 多行可变高度字幕排版、焦点防抖与淡入淡出时序、鼠标划词操作、快捷键即时响应及 Collage 勾选功能均正常，与既有设计规范完全一致。
