# 需求描述

1. **双层对话框叠加屏蔽与对话框内菜单联动规则（禁止硬编码与私自特殊实现）**：
   - **上层对话框完整屏蔽下层对话框**：当对话框发生叠加（如在 `Task` 面板之上弹出 `Confirmation` 二次确认框或 `Task Info` 任务详情框）时，被遮罩覆盖的下层对话框完全冻结，屏蔽一切鼠标点击、滚轮滚动、按钮/卡片 `Hover`、鼠标指针形状变化、文本选择、`Tooltip` 及滚动条交互；上层对话框关闭返回下层对话框时，立即解除冻结并按当前指针位置重新判定 `Hover` 与指针样式。
   - **单独弹出上层对话框与叠加弹出表现一致**：从工作台或播放界面直接弹出 `Confirmation` 二次确认框时，与在 `Task` 面板上叠加弹出遵循同一套下层界面冻结、焦点释放与关闭恢复规则。
   - **从对话框菜单打开上层对话框时保持悬停抑制**：在对话框内部通过卡片菜单或右键菜单触发打开上层新对话框（如在 `Task` 菜单中执行删除、移除或查看详情）时，旧菜单关闭不得清除新弹出对话框的初始 `Hover` 抑制——预先停留在新对话框控件（如右上角关闭按钮 `X`）位置的静止鼠标，在鼠标实际移动前不激活 `Hover`；未打开新对话框而单纯关闭菜单时，维持既有原地立即恢复重算 `Hover` 的表现不变。

2. **全界面悬停、菜单高亮与卡片高亮交互一致性保持（零回退约束）**：
   - 工作台、对话框、弹出菜单（含二级菜单斜向安全区滑入与键盘/手柄导航抑制）及播放界面的按钮、封面卡片、进度条悬停预览、滚轮 `300ms` 防抖及非焦点暴露窗口悬停响应均严格保持既有交互规范不变。

3. **设计文档同步安排**：
   - 本次改动使实际交互严格对齐现有 `UI Interaction Rules.md`；待视觉与交互验收完成后按需复核设计文档。

# 验收标准

1. **双层对话框叠加冻结验收**：
   - 打开 `Task` 面板，通过卡片右侧 `...` 或右键菜单选择删除/移除弹出 `Confirmation` 二次确认框，或选择 `Get Info` 弹出任务详情框：将鼠标移至上层弹窗外侧露出的下层 `Task` 面板区域（卡片、右上角 `X`、可选文本、滚动条）移动、点击、滚轮滚动并停留超过 `1s`，下层 `Task` 面板完全无 `Hover` 变化、不变指针样式、不滚动、不弹出 `Tooltip`。
2. **菜单联动初始悬停抑制与关闭恢复验收**：
   - 在 `Task` 面板打开卡片菜单后，提前将鼠标停在即将弹出的上层弹窗右上角 `X` 位置保持不动并触发打开上层弹窗：上层弹窗出现后在鼠标实际移动前，`X` 按钮不亮起 `Hover`；实际移动鼠标后正常亮起 `Hover`。
   - 关闭上层 `Confirmation` 或任务详情框回到 `Task` 面板，或直接按 `Esc` / 点击外部关闭 `Task` 卡片菜单而不打开新弹窗时，无需移动鼠标即按当前指针位置立即恢复 `Task` 面板对应元素的 `Hover` 与指针样式。
3. **卡片、弹出菜单与非焦点窗口悬停回归验收**：
   - 在 `Library` / `Excerpt` 封面卡片、弹出菜单及二级菜单中测试鼠标悬停、方向键移动高亮抑制鼠标悬停、移动鼠标恢复悬停，以及窗口失焦暴露状态下的悬停响应，均保持正常无退步。
