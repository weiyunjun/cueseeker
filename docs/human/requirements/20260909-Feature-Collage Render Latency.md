# 版本
main

# 需求描述
1. 现状：进入 Collage 后首图渲染偏慢。以 It's MyGO!!!!! 第 05 集（字幕约 12.7MB）为例，首图约 3.5 秒；字幕较小的第 10 集（约 56KB）约 1.3 秒。库内大字幕是常态，不是边界情况。
2. 目标：降低首图及每次勾选后的重绘耗时。不改变任何界面行为、交互和输出结果。
3. 取帧时刻必须继续是分组交集中点的那一帧，且必须保持精确到帧。已排除复用时间轴拖动预览的取帧能力，因为它取的是最近关键帧，实测该处关键帧距目标时刻可达 2.5 秒，会导致错帧。
4. Collage 的时间戳合并、排序、分组、中点计算和增量更新维持现状，本需求不修改，参考 20260730-Feature-Playback Current Collage Editor.md。

# 改动内容
1. 字幕扫描改为按字节处理。现在每渲染一组都要把整份字幕做多次全文替换、再逐行去空白并转小写；字幕解码入口在结构校验时还会再做一次同样的全文逐行扫描。改为按 UTF-8 字节切行、只比对行首关键字。筛选和校验结果必须与现状逐字节一致，包括 BOM、CRLF、大小写和首尾空白的处理。字幕解码入口是公共路径，字幕索引和播放打开字幕也经过它，改动需覆盖这些调用方的回归。
2. 取帧不再经过 PNG 中转。现在取帧会把画面压成 PNG 写入临时文件再读回，且因片源为 10-bit，中间文件是每通道 16 位、单张约 7.7MB。改为输出 8 位无压缩数据直接读入内存。Collage 最终输出的格式和画质不变，因为合成画布本来就是 8 位。

# 数据要求
1. 改动前先建立基准：以 It's MyGO!!!!! 第 05 集为基准样本，测量并记录首图总耗时，以及取帧、读入字幕、筛选、字幕渲染各环节的耗时。
2. 每完成一步改动，用同一样本、同一方法重新测量并记录同一组数据。
3. 全部完成后汇总，给出改动前、第一步后、第二步后的逐步对比。
4. 每次测量同时记录真实 App 中的首图耗时，操作路径为打开该集、回车选中字幕、按 P 进入 Collage。

# 修改流程
## 1. 记录改动前的基准数据
## 2. 字幕扫描改为按字节，回归筛选与校验结果，并记录数据
## 3. 取帧改为 8 位无压缩直读，回归 Collage 输出结果，并记录数据
## 4. 汇总三次测量，输出对比结论
