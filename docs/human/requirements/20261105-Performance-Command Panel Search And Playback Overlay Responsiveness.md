# 需求描述

1. **快捷命令面板（Command Panel）一级菜单实时计数减负与按需加载结果**：
   - 在快捷命令面板一级菜单输入搜索词（或打开面板自动填入当前聚焦台词）时，保留 `Search <搜索词>` 右侧的实时匹配数量展示，仅统计匹配的台词总条数，不在一级菜单打字阶段拉取和组装全量台词内容；
   - 在连续输入搜索词或按回车切入二级搜索结果页时，若前序输入词的统计或查询尚未完成，自动中止未完成的旧查询，消除前序短词查询对后续请求的排队阻塞；
   - 在一级菜单按回车或点击 `Search <搜索词>` 进入二级搜索结果页时，按需加载结果列表展示所需的台词内容，并保持退出播放页返回工作台 `Search` 页面时的搜索词、结果列表与计数同步一致。

2. **唤起快捷命令面板与打开字幕聚焦遮罩（Playback Overlay）时不阻塞主线程**：
   - 在播放页唤起快捷命令面板或打开字幕聚焦遮罩并自动暂停播放时，面板与遮罩立即弹出响应，观看进度保存与媒体库数据的同步不在弹出瞬间阻塞主线程。

3. **字幕聚焦遮罩与面板搜索结果的台词滚轴首帧渲染与内存优化**：
   - 打开字幕聚焦遮罩（`Current`、`Playlist` 字幕流、`Collage`）或切入快捷命令面板二级搜索结果页时，消除首屏列表的重复重绘，降低首帧渲染耗时与单次打开时的内存激增，同时保持台词滚轴排版样式、高亮定位、滚动流畅度及交互行为不变。

# 验收标准

1. **面板打字与搜索切页流畅无阻塞**：在播放页唤起快捷命令面板连续输入短词、高频词并按回车进入二级搜索结果页时，一级菜单右侧实时匹配数量正常显示，切入二级结果页不再因前序短词查询排队或全量数据组装与内存回收而引发主线程长时间卡顿。
2. **唤起面板与打开字幕遮罩即时响应**：无论从 `Search`、`Recent` 还是 `Library` 进入播放页（包含高分辨率视频及上千条字幕的剧集），按键或点击唤起快捷命令面板、打开字幕聚焦遮罩时首帧均流畅弹出，不再因观看进度落盘或列表首帧重绘产生明显卡顿与内存暴涨。
3. **跨页面搜索与播放记录状态一致**：在快捷命令面板内完成搜索或退出播放页回到工作台 `Search`、`Recent`、`Library` 时，搜索词、结果列表、精确计数及剧集观看进度均准确同步，视觉与交互行为无回退，自动化测试全部通过。
