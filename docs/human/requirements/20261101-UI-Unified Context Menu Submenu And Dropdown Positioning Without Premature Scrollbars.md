# 需求描述

1. **统一全局一级菜单与二级菜单的定位及限高优先级（`C-04.1 Menu`、`C-04.2 Submenu`）**：
   - 取消早期“菜单必须完整落在锚点单侧（鼠标或触发按钮上方/下方），单侧放不下即直接裁减菜单高度并出现滚动条”的规则，统一改为**优先保证菜单完整高度展示、不触发高度上限与内部滚动条**：
   - **一级右键菜单（Context Menu）**：
     - **垂直方向**：默认从鼠标落点向下展开；若下方空间不足且上方单侧空间充足，则向上翻转展开；**若鼠标上下单侧空间均不足以容纳完整菜单，但所属边界容器的总可用高度足以容纳，则保持菜单完整自然高度不变，将菜单沿垂直方向贴边平移（贴齐容器下边界或上边界），此时鼠标落点自然位于菜单侧边中间位置**。
     - **水平方向**：默认从鼠标落点向右展开；若右侧空间不足，则向左翻转或贴齐容器右边界展开。
   - **二级子菜单（Submenu）**：
     - **水平方向**：默认紧贴父菜单右侧展开；若右侧空间不足，则翻转至父菜单左侧展开。
     - **垂直方向**：默认顶边与父菜单触发项顶边对齐；若向下超出容器下边界，则**保持二级菜单完整高度向上平移至贴齐容器下边界**（此时父菜单触发项位于二级菜单侧边中间位置）。
   - **按钮触发的一级下拉菜单（Dropdown Menu）**：
     - 优先贴在触发按钮下沿向下展开；下方空间不足且上方单侧空间充足时，贴在触发按钮上沿向上展开；**若按钮位于垂直中间区域导致上下单侧空间均不足以容纳完整菜单，同样优先在容器边界内贴边平移以保持完整高度展示**。
   - **内部滚动条触发条件（最后兜底）**：
     - 无论是右键菜单、二级子菜单还是按钮触发菜单，**仅当菜单自然高度超出整个可用边界容器的总高度，或超出全局菜单最大高度上限（`--max-height-menu: 480px`）时**，才将菜单高度限制为可用高度（或 `480px`）并出现内部垂直滚动条。

2. **统一释放表格菜单的可用空间边界（`C-04.1 Menu`、`C-04.2 Submenu`）**：
   - 基于菜单打开期间整窗口禁止滚动的全局交互规则，移除 Workbench 表格（Search 与 Excerpt 二级详情页）行菜单及二级菜单“以表格正文区域为边界并裁剪”的早期限制。
   - Workbench 表格行右键菜单、行右侧 `...` 按钮菜单及其二级菜单，与工作台其余页面菜单统一**以当前工作台页面可视区域（顶栏下沿至窗口底边）作为可用空间边界**，允许菜单在空间需要时向上跨越表头、工具栏及摘录详情页顶部的封面简介区域完整展开。

# 验收标准

1. **中间区域右键不出滚动条**：在 Search 表格、Excerpt 二级详情页表格、Recent / Library / Excerpt 封面卡片网格、File 页面卡片及任务面板卡片的垂直中间区域点击右键时，只要页面可视区域总高度大于菜单自然高度，菜单即通过垂直贴边平移保持 100% 完整高度展示（鼠标位于菜单侧边中间），不出现内部滚动条。
2. **Excerpt 详情页带封面简介时菜单完整展示**：在默认窗口尺寸下进入 Excerpt 二级详情页（顶部显示封面简介），在表格任意行点击右键或点击行右侧 `...` 按钮并展开 `Move to ...` / `Duplicate to ...` 二级菜单时，一级菜单与二级菜单均可向上跨越表头与封面简介区域，在页面可视区边界内完整显示，不再被表头下沿截断或强行缩高出滚动条。
3. **靠边与角落翻转正常**：在靠近窗口底部、右侧边缘或右下角位置触发右键菜单、按钮菜单及二级菜单时，菜单自动向上翻转、向左翻转或贴边平移，始终完整落在可用边界内且不超出边界。
4. **极端情况滚动条兜底正常**：仅当菜单项极多（自然高度超过 `480px`）或窗口被缩至极矮（整个页面可用高度小于菜单自然高度）时，菜单才限制高度并正常显示内部垂直滚动条。
