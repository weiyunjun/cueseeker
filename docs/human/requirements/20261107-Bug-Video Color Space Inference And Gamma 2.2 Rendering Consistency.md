# 需求描述

1. **缺失色彩元数据视频的自动推断与 SDR Gamma 2.2 统一渲染（本地与远程）**：
   - **色彩矩阵、色域与量化范围推断**：当视频流已携带明确的色彩空间元数据时，按原片元数据解析；当色彩矩阵或色域缺失（未标记）时，按画面原始分辨率自动补齐行业标准（宽 `> 1280` 或高 `> 576` 的高清视频采用 `BT.709`，宽 `<= 1280` 且高 `<= 576` 的标清视频采用 `BT.601` 并按帧率区分 PAL 与 NTSC 色域）；当 YUV 视频缺失量化范围标记时，默认按有限范围（Limited Range）处理。
   - **SDR 明暗曲线统一为 Gamma 2.2（标准 sRGB）**：针对 SDR 视频（原片标记为 `BT.709`、`BT.601`、`sRGB` 或未标记传递曲线的视频），统一按 **Gamma 2.2（标准 sRGB）** 传递曲线交由系统色彩管理渲染，保持明暗对比度 1:1 透传并完成广色域屏幕（如 Display P3）的准确色域映射——既消除系统默认 `1.961` 曲线造成的画面泛白发灰，也避免暗部细节被过度压黑，同时保证硬件加速解码与软件解码下的画面色彩与明暗表现完全一致（HDR 视频保持原有 PQ / HLG 曲线不变）。

2. **播放画面与截图、拼图、缩略图的色彩表现对齐**：
   - 播放页当前画面截图（无字幕 / 带字幕）、台词拼图（Collage）、进度条悬停预览缩略图以及媒体库视频封面生成，在遇到缺失色彩元数据的视频时均遵循上述同一套色彩推断与 Gamma 2.2 标准，确保导出的图片、缩略图与播放窗口实际呈现的色彩和明暗一致。

# 验收标准

1. **无色彩标签的高清与标清 SDR 视频色彩及明暗准确**：
   - 打开未写入色彩元数据的 `1080p`（含 8-bit 与 10-bit）或 `720p` 高清番剧/影视视频时，播放画面按 `BT.709 + Gamma 2.2` 联合广色域映射正常渲染，肤色与暗部不偏红、画面不泛白发灰、暗部细节清晰通透，与配置为 `sRGB / Gamma 2.2` 模式的基准播放器画面一致。
   - 在设置中切换硬件加速解码（`Hardware`）与软件解码（`Software`）播放同一视频时，两种解码模式下的画面色彩与明暗对比度完全一致。
2. **有色彩标签视频与 HDR 视频保持正常**：
   - 打开已明确标记 `BT.709`、`BT.601` 或 `BT.2020`（HDR PQ / HLG）的视频时，色彩与明暗均正常还原，无偏色或过曝。
3. **截图、拼图与预览缩略图色彩一致**：
   - 对未标记色彩元数据的高清视频执行单帧截图、带字幕截图、台词拼图导出，以及查看进度条预览缩略图时，所得画面的色彩与播放窗口一致，无偏红或泛白现象。
