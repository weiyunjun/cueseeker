# 缺陷描述

## 1. 复现

1. 在 Workbench 表格区域右键打开行菜单，指针停在菜单某一行上。
2. 切换到其它应用，在其中移动指针，使指针离开菜单所在区域。
3. 切回本应用。

## 2. 现象

菜单高亮不再跟随指针，表格行、卡片、按钮、Scrollbar 也不再跟随指针。关闭菜单不恢复，重新打开新菜单不恢复，改变窗口大小不恢复，只有重启应用才恢复。

指针停在菜单上切走、不移动再切回不复现；指针不在菜单上时切走再切回不复现。

## 3. 期望

切回后菜单高亮照常跟随指针；关闭菜单后表格行、卡片、按钮、Scrollbar 恢复跟随指针。`20260826-UI-Menu Modality Input Barrier And Focus Cancellation.md` §2 的屏障行为不变。

## 4. 不在本单范围内

菜单在应用切换时保持打开不变，本单不改变任何菜单的开关时机。

# 验收

1. 按 §1 复现路径操作，切回后指针在菜单内移动，高亮跟随指针。
2. 承接第 1 条，菜单仍然打开。
3. 承接第 1 条，关闭菜单后表格行、卡片、按钮、Scrollbar 全部恢复跟随指针，手型与文本光标正常。
4. 菜单打开时，菜单之外的表格行、卡片、按钮、Scrollbar 仍然不跟随指针，光标形状不变。
5. 五个菜单行为一致。
