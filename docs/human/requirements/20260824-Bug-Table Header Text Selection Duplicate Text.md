# 需求描述

1. 本需求适用于 Search 与 Shiori 两个表格界面的表头文字选择。

2. 现象：拖选表头标题时，选中范围内出现两份标题文字——一份随选中底色一起绘制、比原标题整体偏上约 2.5 点，另一份是被不透明选中底色遮住、只在底色框下方露出下缘的原标题。视觉上表现为重影与错位。

3. 期望：表头处于选中状态时，标题文字只呈现一份，其位置、字号、字重、颜色与未选中时完全一致，不产生偏移、重影或残缺边缘。

4. 选中底色的颜色、透明度、覆盖的字符范围与几何表现保持现状，仅要求其与标题文字对齐正确。

5. 表头文字选择的交互不变：拖选起止、跨列选择、选中内容复制、选择清除时机均保持现状。

6. 未选中状态下的表头绘制不得改变。

7. 表格行内的文字选择与绘制不受影响。
