# 需求描述

1. **第一步：连接信息输入与检测（`L-06.4 WebDav Folder Dialog Layout`）**：
   - 弹窗保持中等宽度，移除原 `Name` 输入框，仅保留 `Address`、`Username`、`Password` 三项，底部右侧按钮为 `Cancel` 与 `Connect`（连接）。
   - 点击 `Connect` 后发起连接验证并读取所填地址下的目录内容：检测期间 3 个输入框均为 `Disabled`，`Connect` 按钮为 `Disabled` 且内部左侧显示旋转 `Spinner`（表现同筛选弹窗计算中按钮）。
   - 在成功加载初始目录列表前发生的任何错误（地址格式非法、网络异常、鉴权失败、目标不存在或非目录等），一律停留在第一步界面，恢复输入框与按钮可用，并在 `Password` 输入框下方预留行内显示红字报错。

2. **第二步：目录浏览、面包屑与单行卡片展示**：
   - 初始目录加载成功后切换为大尺寸弹窗，底部左侧为 `Back`（返回），右侧为 `Cancel` 与 `Add`（添加）。
   - **面包屑导航**：顶部常驻面包屑，以第一步所填地址对应的文件夹名称作为最左端起点（若为纯主机根地址则显示主机名），不允许向上进入该起点之前的父级目录；每双击打开一层子文件夹向右追加一级，点击任意上级节点可跳回对应层级。
   - **卡片列表与滚动条**：列表仅展示文件夹、视频文件与字幕文件，不提供排序功能，固定按文件夹在上、文件在下排列；垂直滚动条位于弹窗最右侧的留白通道内（同任务面板滚动条位置）。
   - **单行卡片样式**：文件夹与文件均采用单行卡片展示（文件夹为 `folder-webdav` 图标 + 名称 + 右侧 `caret-right` 箭头；视频与字幕文件为 `video` / `subtitles` 图标 + 名称，无右侧箭头）。文件卡片不可点击、无悬停变色，不做额外置灰。

3. **第二步交互：文件夹选择、层级切换与添加入队**：
   - **单击多选、选中态与悬停规则**：单击文件夹卡片切换选中/取消选中，支持同层级多选；选中时卡片背景变为封面卡片悬停的浅强调色（`--color-library-media-card-hover-bg`），外边框同步变为系统强调色（`--color-border-active`）；**仅未选中的文件夹卡片有 Hover 效果，被单击选中后的文件夹卡片无 Hover 效果**。
   - **双击打开与跨层级清空**：双击文件夹卡片进入下一级目录；双击进入子目录、点击面包屑切换层级或点击 `Back` 返回第一步时，此前选中的文件夹自动清空。
   - **返回与清空规则**：点击 `Back` 返回第一步时完整保留第一步已输入的 `Address`、`Username`、`Password` 内容；仅在关闭弹窗（点击 `Cancel`、右上角关闭按钮、按 `Esc` 或完成 `Add`）时清空输入框内容。
   - **子目录加载与 `Add` 按钮状态**：第二步切换目录加载期间，列表区域正中央显示 `Spinner`，`Add` 按钮为 `Disabled`；若加载失败，列表区域正中央显示错误提示文字，`Add` 按钮保持 `Disabled`；确认目录加载成功后，`Add` 按钮解除禁用变为可用。
   - **添加目标判定与任务队列**：
     - 当前层级未选中任何子文件夹时，点击 `Add` 直接添加当前所在的目录本身；
     - 当前层级选中了 1 个或多个子文件夹时，点击 `Add` 按列表从上到下的显示顺序，将所选文件夹依次拆分为独立的「添加文件夹」任务加入队列（首个任务立即 `进行中`，其余任务处于 `排队中` 依次执行）。

# 验收标准

1. 第一步仅显示 `Address`、`Username`、`Password` 及底部 `Cancel`、`Connect`；点击 `Connect` 检测期间输入框与主按钮禁用且按钮内显示 `Spinner`；进入第二步前的所有报错均在第一步 `Password` 下方显示红字提示。
2. 连接成功后进入第二步，面包屑以所填地址的文件夹名为起点且不显示更上层目录；列表仅展示单行文件夹、视频、字幕卡片，滚动条位于右侧留白通道内，文件卡片无悬停与点击效果。
3. 单击文件夹可切换选中并支持同层级多选，选中态为浅强调色背景加系统强调色边框，且**已选中的文件夹卡片无 Hover 效果**；双击文件夹进入下一级，切换层级或点击 `Back` 自动清空已选项，且点击 `Back` 保留第一步输入内容。
4. 第二步切换目录加载时居中显示 `Spinner` 且 `Add` 禁用，加载失败居中显示错误提示文字且 `Add` 禁用，加载成功后 `Add` 按钮可用。
5. 未选中子文件夹时点击 `Add` 直接添加当前所在目录；选中多个子文件夹时点击 `Add` 按界面显示顺序拆分为多个独立的「添加文件夹」任务依次排队执行。
