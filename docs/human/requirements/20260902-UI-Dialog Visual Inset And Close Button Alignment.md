# 需求描述

## 1. 范围

1. 四边视觉内边距：Confirmation Dialog、Edit Cover Dialog、Shiori List Editor Dialog。
2. 关闭按钮定位与尺寸：以上三个对话框，加任务面板。
3. 任务面板不适用四边视觉内边距，其 Tab 栏的横向内边距不变。

## 2. 视觉内边距

1. 新增 token `--inset-dialog`，取值 `20px`。三个对话框四边的视觉内边距均为该值。
2. 视觉内边距量到看得见的边，不量布局盒：文字的水平边取文本框边缘，不补偿字形侧边距；文字的上边取 cap 顶；文字的下边取基线；有边框或背景的控件取其可见边缘；纯图标按钮取图标字形的墨迹边缘，不取按钮盒。
3. 以下八段距离必须等于 `--inset-dialog`：标题文本框左缘到左边、正文文本框左缘到左边、正文折行边界到右边、最右侧底部按钮右缘到右边、最下方按钮下缘到底边、关闭按钮字形右缘到右边、标题 cap 顶到顶边、关闭按钮字形顶到顶边。
4. 容器的上内边距必须扣掉首行文字行盒顶到 cap 顶的距离，字形才落在 `--inset-dialog` 上。该扣减值由标题的字号与字重决定，字号或字重变化时必须重算。
5. 标题中的 h、b、l 等高小写字母，以及 S、O 等圆形字母，允许超出 cap 顶所在的那条线，不做压制。
6. 正文的右边指折行边界，不指某一行墨迹的右端。
7. 对话框内部间距不变：标题与正文之间、正文与按钮行之间保持现状。

## 3. 关闭按钮

1. `--size-dialog-close-icon` 由 `14px` 改为 `12px`，撤销 `docs/human/requirements/20260901-UI-Icon Button Color Weight And Hover Removal.md` 第 4.1 条的取值与其验收第 3 条。
2. 新增 token `--size-dialog-close-button`，取值 `24px`。关闭按钮的盒尺寸改用该 token，不再使用 `--size-icon-button`。
3. 关闭按钮移出 Header 的布局流，锚定对话框右上角，不再撑高标题所在的行。
4. 关闭按钮的定位按图标字形的墨迹边缘计算，不按按钮盒边缘。锚点偏移必须扣掉盒与字形之间的空白，该扣减值随图标尺寸或盒尺寸变化时必须重算。
5. 撤销 `docs/human/requirements/20260827-UI-Dialog Close Button.md` 第 2.1 条中「右边距等于对话框自身的内边距」的量法，改为本需求第 2.2 与 3.4 条。
6. 任务面板的关闭按钮适用本节第 1 至 4 条，其在 Tab 栏中的纵向位置与 Tab 栏本身的横向内边距不变。

## 4. 保持不变

1. 对话框宽度、标题字号与字重、正文字号、按钮高度与文案与顺序不变。
2. 关闭按钮的图标颜色、字重、Hover 缺省、Open 态、Disabled 态不变。
3. 焦点环的颜色、宽度与偏移不变。
4. 关闭按钮的动作、快捷键与可用性判定不变。
5. 对话框的压暗范围、输入屏蔽与叠加规则不变。

# 验收

1. 三个对话框中，第 2.3 条列出的八段距离逐段量取，两两之差不超过 1px。
2. 关闭按钮的字形右缘与最右侧底部按钮的右缘落在同一条竖线上。
3. 关闭按钮的字形顶与标题的 cap 顶落在同一条横线上。
4. 标题不再因关闭按钮而下移，对话框总高度较本需求前减小。
5. 关闭按钮的字形明显小于本需求前，命中区不小于 24×24。
6. 任务面板的关闭按钮字形与盒尺寸随本需求改变，Tab 栏的横向内边距与本需求前一致。
7. Light 与 Dark 两个主题分别核对以上各项。
8. 现有自动化端到端与单元用例全部通过。
