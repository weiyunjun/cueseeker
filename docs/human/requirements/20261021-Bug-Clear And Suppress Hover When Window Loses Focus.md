# 需求描述

1. **仅在当前聚焦窗口（Key Window）内产生与响应 `Hover`**：
   - 只有当 CueSeeker 处于前台激活状态，且组件所在的窗口（主窗口或独立设置窗口）为当前聚焦窗口时，窗口内的界面元素才允许产生和更新 `Hover` 效果及特殊指针样式（窗口左上角系统红绿灯保持系统原生行为不变）。
   - 当切换到其他应用、或焦点切换到应用内另一独立窗口时，失焦窗口处于后台期间，鼠标划过该窗口暴露在屏幕上的任何区域（含各类按钮、导航栏项、标签页、分段控件、筛选胶囊、复选框、封面卡片、菜单项、表头与表格行、自定义滚动条、台词长截图预览组、播放进度条、以及窄窗口展开的覆盖式侧边栏），一律不触发任何 `Hover` 效果、特殊指针样式或移出收起动作。

2. **窗口失去焦点时立即清空 `Hover`**：
   - 当应用切出或当前窗口失去焦点时，窗口内所有正处于 `Hover` 状态的组件（含 Search 与 Excerpt 二级界面的表头底色高亮与 `#` 列全选勾选框、各类按钮、封面卡片 `Hover` 底色与放大效果、菜单项 `Hover` 等）立即清除 `Hover` 效果，指针恢复默认箭头。
   - 例外保持：若窗口内已有菜单或上层弹窗打开导致下层处于冻结态，下层被菜单挂靠的高亮按菜单模态规则保持冻结；Playback 封面卡片与菜单项由键盘或默认维持的 `Select` 选中状态保持不变。

3. **窗口重获焦点时按当前鼠标位置立即重判 `Hover`**：
   - 当切回 CueSeeker 或点击窗口使其重新成为聚焦窗口时，若鼠标未隐藏、未处于滚轮滚动防抖期且当前界面层未被冻结，立即根据鼠标当前在窗口内的实际位置重新判定并恢复落点处组件的 `Hover` 效果与对应指针样式。

# 验收标准

1. **表头与组件失焦清理及恢复**：在 Search 或 Excerpt 二级界面将鼠标悬停在表头或按钮、封面卡片上（显示 `Hover` 效果及对应手型指针），按 `Cmd + Tab` 切换到其他应用、点击其他应用窗口或打开独立设置窗口后，原有的 `Hover` 效果立即消失、指针恢复默认箭头；切回主窗口时，若鼠标仍在原目标内则立即恢复 `Hover` 与对应指针，若鼠标已移出则保持无 `Hover`。
2. **后台窗口禁绝 `Hover` 交互**：当焦点在其他应用（或焦点在独立设置窗口而主窗口在后）时，移动鼠标划过后台窗口中露出的任意按钮（如 `Resume`、`...`、`Filter`、排序按钮、顶栏按钮、侧边栏导航项）、封面卡片、表格或滚动条，均不出现任何 `Hover` 视觉变化或特殊指针样式。
