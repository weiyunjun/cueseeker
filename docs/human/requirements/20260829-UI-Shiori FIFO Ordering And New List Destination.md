# 需求描述

## 1. 排序

1. Shiori 一级界面的列表卡片按创建时间正序排列，新建的列表排在最后。
2. Shiori 二级界面的表格按收藏时间正序排列，新收藏的字幕排在最下方，已有的所有列表一并生效。
3. 二级界面的搜索结果、筛选结果、导出、复制，以及由表格进入播放后的播放列表，都沿用该顺序；播放页在 Shiori 上下文中的上一条与下一条方向一致。
4. “第一个列表”指一级界面的第一张卡片，即最早创建的列表。从播放页收藏字幕时的默认目标列表随之改为该列表。
5. 新收藏加入后不自动滚动表格。

## 2. 子菜单新增 New List

1. `Move to ...` 与 `Duplicate to ...` 展开的子菜单，在列表项下方依次增加一条分隔线和 `New List` 项。
2. `New List` 项的三语文案与 Shiori 一级界面主按钮一致，不带图标。
3. 子菜单仍不显示当前所在的列表；键盘方向键可以走到 `New List` 项。
4. 废除 `20260723-Feature-Shiori Multi-List.md` 第 20 条“只剩当前一个列表时这两项禁用”。只要该行收藏本身可用，这两项即为可用；没有其他列表时，子菜单只显示 `New List` 项。
5. 失效或身份无法确认的收藏，仍然禁用这两项。

## 3. New List 的行为

1. 点击 `New List` 项，右键菜单与子菜单一并关闭，随后打开现有的新建列表界面，该界面本身不作任何改动。
2. 点击 Cancel 直接关闭，不执行移动或复制。
3. 创建成功后，立即以新建的列表为目标执行触发本次流程的 `Move to ...` 或 `Duplicate to ...`，结果提示沿用现有的 Shiori 提示场景，不新增提示。
4. 无论移动或复制成功与否，新建的列表都保留。
5. 创建成功后停留在当前列表，不跳转。

# 验收

1. 新建的列表出现在一级界面最后一张卡片；新收藏出现在二级界面表格最下方；每个已有列表打开后都是正序。
2. 从播放页收藏，默认进入一级界面第一张卡片对应的列表。
3. 两个子菜单的最下方都是分隔线加 `New List`。
4. 只剩一个列表时这两项可用，子菜单只有 `New List`。
5. 点击 `New List` 打开新建列表界面；取消后表格与列表均无变化。
6. 创建成功后该行被移动或复制到新列表，出现对应提示，新列表位于一级界面最后一张卡片。
7. 移动或复制失败时出现对应的失败提示，新列表仍然保留。
8. 失效收藏的这两项仍为禁用。
