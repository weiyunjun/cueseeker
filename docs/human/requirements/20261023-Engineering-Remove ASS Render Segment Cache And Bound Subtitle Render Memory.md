# 需求描述

1. **移除 ASS 字幕分段缓存及数据库存储**：
   - 索引流程不再生成和保存 ASS 字幕分段缓存。
   - 升级数据库版本并在迁移时清理已有的 ASS 字幕分段缓存数据与结构，释放数据库空间。

2. **播放时整轨加载 ASS 字幕并限制渲染缓存内存**：
   - 播放 ASS / SSA 字幕时直接加载完整字幕文件并在同一播放会话内复用，不再按时间段切分或重新加载字幕片段。
   - 限制字幕渲染器的图形与字形缓存上限，消除高密度动态特效字幕在连续播放时的跨帧内存累积膨胀，同时保持字幕画面视觉效果完全不变。

# 验收标准

1. 数据库完成迁移后，历史 ASS 字幕分段缓存数据与结构被彻底移除；新增或重索引字幕文件时不再生成分段缓存。
2. 播放含高密度特效的 ASS 字幕（如《It's MyGO!!!!!》第 05 集与《超时空辉夜姬》密集特效片段）时，画面渲染效果与改动前完全一致，且播放期间的内存峰值与平均内存占用优于或持平于改动前基线。
