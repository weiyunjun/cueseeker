# 需求描述

1. **各页面重现刷新严格以数据库实际内容变化（结果）为准**：
   - 在执行 `Index`、`Add Folder` 或 `Remove Folder` 后，若数据库中的已入库内容并未发生任何实质性增删改（例如执行 `Index` 时文件无变动、添加空文件夹、或移除空文件夹），`Search`、`Recent`、`Library`、`Excerpt`（一级与二级界面）以及 `File`（二级与三级界面）均保持原有状态不变，不在后台或重现时触发无意义的重新加载。
   - 仅当操作实际改变了数据库中的已入库内容时，相关页面才按既有规则在后台更新（若当前未停留）或待离开再重现时刷新（若当前正停留）。

2. **`Rename`（重命名文件夹或文件）作为原地替换更新，不触发 `Index` 式的重搜或延迟冻结**：
   - **`File` 界面**：用户在 `File` 一级、二级或三级界面完成重命名后，当前界面立即显示更新后的新名称，无需离开再重新进入。
   - **`Search` 界面**：重命名不改变台词内容与命中结果集合，因此不触发重新搜索；仅将当前已有搜索结果中的显示标题与路径、Filter 中的文件夹名称以及已勾选的文件夹筛选条件直接替换为新名称与新路径，保留原有结果列表、勾选状态与滚动位置。
   - **`Library`、`Recent` 与 `Excerpt` 界面**：同步将涉及的文件夹及剧集显示标题、路径更新为新名称；若 `Excerpt` 二级界面已勾选被重命名的文件夹筛选项，同步替换为新路径并保留勾选状态。

# 验收标准

1. **空文件夹添加/移除不触发多余刷新**：添加或移除一个不包含任何有效字幕的空文件夹后，切回 `Search`、`Recent`、`Library`、`Excerpt` 一/二级界面或 `File` 二/三级界面时，各页面保持原状，不发生重新查询或闪烁。
2. **`File` 二/三级界面重命名立即生效**：在 `File` 二级界面重命名子文件夹（如将 `Ave Mujica` 改为 `Bang Dream! Ave Mujica`），或在三级界面重命名剧集文件后，当前页面卡片标题立即更新为新名称。
3. **`Search` 界面重命名原地替换且保留筛选**：搜索出命中结果并勾选 `Filter` 中的 `Ave Mujica` 文件夹后，去 `File` 页将该文件夹（或其中命中的剧集文件）重命名，再返回 `Search` 页，不重新发起全文搜索，已有结果的标题及 `Filter` 中已勾选的文件夹名称直接更新为新名称，筛选勾选状态与结果条数保持不变。
4. **`Library`、`Recent`、`Excerpt` 重命名同步替换**：重命名文件夹或剧集后，进入 `Library`、`Recent`、`Excerpt` 一/二级界面，对应卡片与条目的显示标题均已更新为新名称，且 `Excerpt` 二级界面中已勾选的该文件夹筛选条件保持选中不丢失。
