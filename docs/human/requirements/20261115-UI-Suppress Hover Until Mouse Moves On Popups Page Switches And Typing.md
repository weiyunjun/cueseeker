# 需求描述

1. **统一静止指针下的悬停与指针形状抑制规则（扩展 `UI Interaction Rules.md` 与 `UI Design Rules.md`）**：
   - 延续现有滚动与键盘/手柄导航的悬停抑制原则，将“鼠标未发生真实移动前不激活悬停态”统一扩展至以下三类场景（全局共用同一套交互规则，严禁针对单个弹窗或单个控件编写私自特殊实现，所有规则须可表达于 `UI Interaction Rules.md` 与 `UI Design Rules.md`）：
     - **新打开局部弹层、面板与菜单**：新打开任意业务对话框、确认框、`Task Panel`、`Command Panel`、右键菜单、下拉菜单、弹出面板（如颜色选择弹层）以及展开子菜单时，即使新界面元素恰好生成在静止鼠标指针正下方，也不得激活 `Hover` 高亮或弹出悬停提示（`Tooltip`）；待鼠标发生真实移动后，再对指针所在元素恢复正常的 `Hover` 与指针形状响应。
     - **全窗口界面、层级、标签页、步骤与模式切换**：在主工作台切换一级页面、工作台与 `Playback` 播放页互切（`Workbench` ↔ `Playback`）、`Playback` 播放页与 `Playback Overlay` 互切（`Playback` ↔ `Playback Overlay`）、进出文件夹层级或摘录列表详情（含顶部历史前进/后退）、切换页面内或浮层/面板内标签页与分段（如 `Recent`、`File`、`Playback Overlay` 顶栏 `Current` / `Playlist` / `Collage`、`Task Panel` 标签切换）、在多步弹窗或面板内前进/返回切换内容层级（如 `Command Panel` 进入子级或点击返回、远程目录浏览切换目录层级）、展开或收起工作台左侧导航栏（`Sidebar`）、以及字幕表格进入或退出批量选择模式（`Select Mode`）时，立即清除原界面与目标界面的残留 `Hover`（全窗口跨界面切换不冻结保留下层旧 `Hover`）并进入悬停抑制，直至鼠标发生真实移动。
     - **输入框打字与文本编辑**：用户在任意搜索框、单行输入框或多行文本输入框中实际键入、删除或粘贴修改文本时（不含界面初始化或程序自动填入文本），立即清除当前界面已有的鼠标 `Hover` 高亮并进入悬停抑制，直至鼠标发生真实移动。
   - **主窗口与独立 `Settings` 窗口的指针形状表现**：
     - 主窗口进入上述悬停抑制状态且未处于鼠标拖拽选字过程中时，指针统一退回默认箭头（`arrow`），不因新渲染或新换入静止指针下方的可选中文本、输入框或拼贴预览条而提前变为文本光标（`I-beam`）或抓手（`grab`）；待鼠标发生真实移动后，再按指针下方元素恢复对应指针形状。
     - 独立 `Settings` 窗口在打开窗口、弹出内部弹层/菜单或切换左侧分类时，同样抑制按钮与列表行的 `Hover` 背景高亮，但窗口内输入框与可选中文本保持 macOS 原生文本光标（`I-beam`）表现不变。

2. **保持既有交互边界与零退步约束**：
   - **关闭局部弹层/菜单返回下层的即时重算保持不变**：关闭任意菜单、对话框、`Task Panel` 或 `Command Panel` 回到原先被冻结的下层界面（含在 `Playback Overlay` 之上关闭菜单、对话框或 `Command Panel` 回到 `Playback Overlay`）时（不含 `Workbench` ↔ `Playback` 及 `Playback` ↔ `Playback Overlay` 的全窗口跨界面切换），维持现有设计规则——解冻当下即按当前鼠标位置立即重算下层元素的 `Hover` 与指针形状，无需晃动鼠标；右键在菜单打开状态下直接换位弹出新菜单、以及通过方向键关闭子菜单回到父菜单时，保持各自既有交互表现不变。
   - **鼠标展开子菜单时的父菜单斜向移动保护**：当用户通过鼠标悬停父菜单项展开子菜单时，仅新弹出的子菜单自身抑制初始静止悬停，不得清除父菜单当前项的高亮，也不得影响鼠标从父菜单斜向滑入子菜单的安全区容错体验。
   - **播放页内切换剧集不误伤悬停预览**：已在 `Playback` 播放页内自动连播、点击上/下一集或从 `Command Panel` 选集切换视频时，不属于全窗口跨界面切换；若鼠标静止停留在播放进度条等控件上，不得清空正在展示的缩略图悬停预览，亦不得干扰局部弹层关闭后的下层即时重算。
   - **抑制期间原地点击不残留悬停态**：在悬停抑制生效期间（或点击按钮触发页面/步骤切换的瞬间），用户在未移动鼠标的情况下原地按下并松开按钮、列表行或菜单项后，松手不得在原控件或同位置新控件上卡死残留 `Hover` 高亮。

3. **设计文档同步安排**：
   - 关联 UI 设计文档（`UI Interaction Rules.md`、`UI Design Rules.md`）中的对应规则描述，待本次改动验收完成后再统一提交更新。

# 验收标准

1. **新开局部弹层与菜单无幽灵双高亮验收**：鼠标停留在窗口中部（例如 `Command Panel` 第 2 行位置）不移动，按快捷键打开 `Command Panel` 时，仅第 1 项显示默认键盘 `Select` 高亮，鼠标下方的第 2 项不亮起 `Hover`；轻微移动鼠标后，指针所在行立即亮起 `Hover` 且与第 1 项 `Select` 正常并存。打开各业务对话框、`Task Panel`、右键菜单、下拉菜单与子菜单时，静止指针下均无初始误亮，且父菜单斜向滑入子菜单顺畅不断开。
2. **全窗口跨界面及页面/层级/标签/步骤/侧边栏/批量模式切换与原地点击验收**：在 `Workbench` ↔ `Playback` 与 `Playback` ↔ `Playback Overlay` 全窗口进出切换（例如点击 `Recent` / `Library` 封面卡片或字幕表格行进入 `Playback` 后点左上角 `<` 返回且鼠标不动，或从 `Playback` 进出 `Playback Overlay` 后点左上角 `<` / 按 `Esc` 返回且鼠标不动）时，原界面不残留旧 `Hover` 高亮，新暴露界面在静止指针下方也不误亮 `Hover`（如左上角同位置 `<` 按钮不自动亮起）；通过快捷键或原地点击切换工作台页面、进出文件夹或摘录列表、切换 `Recent` / `File` / `Playback Overlay`（`Current`、`Playlist`、`Collage`）/ `Task Panel` 标签页、在 `Command Panel` 钻取或点击 `<` 返回、展开/收起左侧 `Sidebar`、以及字幕表格进出 `Select Mode` 时，静止指针下方新换入的行、卡片、按钮不误亮 `Hover`，落在文本或拼贴条上方时主窗口指针保持默认箭头直至移动鼠标；抑制期间原地点击任意按钮松手后不残留 `Hover` 背景。
3. **输入框打字抑制与独立 `Settings` 窗口验收**：鼠标停留在表格行、面板行或按钮上使其处于 `Hover` 状态时，直接在搜索框或表单输入框中打字/删字，原有 `Hover` 立即消失且主窗口指针退回箭头，移动鼠标后恢复；打开 `Settings` 窗口或切换左侧分类时，静止指针下方的按钮/行不误亮 `Hover`，同时 `Settings` 内输入框与可选中文本保持原生 `I-beam` 光标正常可用。
4. **关闭局部弹层即时重算与播放页内切集零退步验收**：鼠标停留在下层按钮、列表行或可选中文本位置且打开弹窗/菜单/`Command Panel`/`Task Panel` 期间未移动鼠标，按 `Esc` 关闭上层后，无需移动鼠标下层立即恢复 `Hover` 高亮与对应指针形状（如 `I-beam`）；在 `Playback` 播放页内切换上/下一集或自动连播时，静止停留在进度条上的缩略图悬停预览保持正常不消失。
