# 需求描述

1. **入口与弹窗层级（`L-06.9 Task Panel Layout`、`L-06.10 Task Card Layout`）**：
   - 任务面板（`Current`、`Completed`、`Incomplete` 三个标签页）所有任务卡片右侧 `...` 弹出菜单顶部新增 **「查看详情」（英：`Get Info` / 繁：`查看詳情`）**（Neutral，图标 `info`），下方保留原有的 `Remove Task` 或 `Delete Record`。
   - 当菜单打开期间任务状态改变导致原卡片离开当前标签页时，已打开的弹出菜单保持原位不消失；此时点击「查看详情」正常打开该任务的详情弹窗并展示其最新状态。
   - 「任务详情」作为二级模态弹窗叠加在「任务面板」之上（层级同二次确认弹窗），遮罩并屏蔽下层任务面板输入；支持点击右上角关闭按钮或按 `Esc` 关闭并回到任务面板。

2. **整体布局与排版规范（对齐 `L-06.8 File Detail Dialog Layout`）**：
   - 弹窗宽度（`--width-dialog-x-large`）、窗口安全高度约束与内部垂直滚动、四边视觉等距（`--inset-dialog`）、分组卡片样式、键值行与 `#1` 序号行排版、右侧多行文本折行后内部左对齐及数字等宽对齐规则均与「文件详情」一致。
   - **顶部标题栏**：左侧主标题为 **「任务详情」（英：`Task Info` / 繁：`任務詳情`）**，右上角为关闭按钮。
   - **任务标头行（Header Row）**：左侧为 `40×40px` 的任务类型专属同色深浅大图标，右侧（间距 `24px`）仅展示**纯任务类型名称**（`导出到 Anki`、`重命名文件夹`、`重命名文件`、`索引全部`、`索引`、`添加文件夹`、`移除文件夹`），不包含具体文件名或文件夹名。
   - **卡片分组顺序**：上方为各任务专属的**业务信息分组**，最下方固定为 **「任务状态」分组**。

3. **五类任务的业务信息分组（位于上方）**：
   - 所有数量字段（卡片数量、文件数量、文件夹数量、已索引字幕）统一仅显示纯阿拉伯数字。
   - **导出为 Anki**：
     - **「导出信息」**：`文件名称`（apkg 文件名）、`所在路径`（仅导出所在文件夹路径，不含文件名）、`卡片数量`。
   - **重命名文件夹**：
     - **「重命名信息」**：`原路径`（含原文件夹名称的完整路径）、`新路径`（含新文件夹名称的完整路径）。
   - **重命名文件**：
     - **「重命名信息」**：`所在路径`（所在文件夹完整路径）、`文件数量`。
     - **「修改前文件名」**：以 `#1`、`#2`... 序号列出该配对下全部视频与字幕修改前的完整文件名（含扩展名）。
     - **「修改后文件名」**：以 `#1`、`#2`... 序号列出该配对下全部视频与字幕修改后的完整文件名（含扩展名）。
   - **索引**：
     - **单文件夹索引**：**「索引信息」** 展示 `路径`（文件夹完整路径），以及仅在「已完成」状态下展示 `已索引字幕`。
     - **索引全部**：**「索引信息」** 展示 `文件夹数量`，以及仅在「已完成」状态下展示 `已索引字幕`；下方紧接 **「目标文件夹」** 分组，以 `#1`、`#2`... 序号列出全部目标根文件夹的完整路径。
   - **添加文件夹**：
     - **「文件夹信息」**：展示 `路径`（文件夹完整路径），以及仅在「已完成」状态下展示 `已索引字幕`。
   - **移除文件夹**：
     - **「文件夹信息」**：仅展示 `路径`（文件夹完整路径）。

4. **三种状态的「任务状态」分组（位于最下方）与实时同步**：
   - 时间字段格式统一为 `yyyy-MM-dd HH:mm:ss`；除处于「排队中」的任务外，所有任务均在 `创建时间` 下方展示 **`开始时间`**（任务实际进入执行状态的时间；若任务在排队期间未开始即被取消或中断而进入「未完成」，则 `开始时间` 显示 `-`）。
   - **进行中（`Current`）**：
     - **正在执行（`In Progress`）**：展示 `状态`（`正在执行`）、`当前阶段`（阶段与进度描述）、`进度`（右侧展示可视化胶囊进度条与百分比，仅移除文件夹无此行）、`创建时间`、`开始时间`。
     - **排队中（`Queued`）**：展示 `状态`（`排队中`）、`创建时间`。
   - **已完成（`Completed`）**：
     - 展示 `状态`（`已完成`）、`创建时间`、`开始时间`、`完成时间`。
   - **未完成（`Incomplete`）**：
     - 展示 `状态`（`未完成`）、`失败原因`（`--color-danger-text` 红色文字，多行完整折行展示，内部左对齐，不截断）、`创建时间`、`开始时间`、`终止时间`。
   - **实时局部刷新与状态流转同步**：
     - 详情弹窗打开期间，任务进度跳动仅局部刷新底部「任务状态」分组内的阶段与进度行，不重建弹窗其余区域。
     - 若任务在详情弹窗打开期间由「排队中」进入「正在执行」，或执行结束转入「已完成 / 未完成」，详情弹窗保持打开并实时更新底部「任务状态」分组内容（含补齐 `开始时间`、`完成时间` / `终止时间`，以及索引与添加文件夹完成时同步补齐上方分组的 `已索引字幕` 行），同时下层任务面板列表同步完成状态流转。

# 验收标准

1. 任务面板三个标签页的所有卡片 `...` 菜单首项均为带 `info` 图标的「查看详情」；点击后在任务面板上方叠加弹出「任务详情」弹窗，点击关闭按钮或按 `Esc` 仅关闭详情弹窗并回到任务面板。
2. 菜单打开期间若进行中任务结束导致原卡片离开当前标签页，菜单保持原位不消失，此时点击「查看详情」可正常打开该任务详情并展示最新状态。
3. 详情弹窗标头行右侧仅展示纯任务类型名称；上方业务分组与最下方「任务状态」分组的排列顺序、字段内容、纯阿拉伯数字计数、重命名文件前后完整含后缀文件名列表、以及长路径与长报错的多行左对齐折行均符合上述规范。
4. 除排队中的任务外，正在执行、已完成、未完成任务均在 `创建时间` 下方正确展示 `开始时间`（排队期间被取消或中断未开始的任务显示 `-`）。
5. 进行中任务在详情弹窗内实时局部刷新阶段文字与胶囊进度条；任务状态跨阶段或跨标签页流转时，详情弹窗与下层任务面板实时保持同步。
