# 需求描述

## 1. 搜索期间锁定数据库快照

1. 搜索开始的瞬间锁定数据库版本，首屏 100 行推送与后续全量结果推送均基于同一数据库快照。
2. 搜索进行期间，后台 Index、Add Folder 或 Remove Folder 任务的执行与写入不取消、不打断当前搜索。

## 2. 资料库任务完成后不刷新搜索界面

1. 除 File 一级界面外，Index、Add Folder 与 Remove Folder 完成后，不主动刷新搜索界面。
2. 搜索结果列表、总数、Facet 筛选快照与选中状态保持当前内容，不重新执行搜索。
3. 资料库文件夹列表变更不隐式清空或刷新当前搜索结果。

## 3. 失效内容交互处理

1. 搜索结果中若有条目因后台任务被移出资料库，界面保留该条目展示。
2. 点击播放已移出资料库的条目时，进入播放界面并保持黑屏，左上角显示报错横幅 `This item is no longer in the library`，持续 5 秒。
3. 播放列表中不展示已移出资料库的条目；上一个、下一个跳到列表中第一个有效项，若无有效项则播放页中央提示 1 秒 `No Available Results`。

## 4. 保持不变

1. Filter 对话框中的文件夹勾选规则不变：有勾选时新增文件夹为勾选，无勾选时为未勾选；全量搜索完成后修改勾选直接基于快照投影，不重新搜索。
2. 关键词修改时正常触发新搜索。

# 验收

1. 延迟模拟环境下，在 Index、Add Folder 或 Remove Folder 执行期间进行搜索：搜索正常展示首屏与全量结果，不被打断或取消。
2. 搜索完成后后台任务结束并写库：搜索结果无闪烁、不刷新，滚动位置与选中状态保持不变。
3. 点击已移出资料库条目的播放：进入播放界面保持黑屏，左上角显示报错横幅 `This item is no longer in the library`；播放列表不含失效项，上一个/下一个跳到第一个有效项（无有效项时中央提示 1 秒）。
4. 对 `大丈夫`、`今`、`の` 3 个基准词完成改动前后的性能对照，首屏与全量完成耗时无性能回退。
5. 单元测试与集成测试全部通过。
