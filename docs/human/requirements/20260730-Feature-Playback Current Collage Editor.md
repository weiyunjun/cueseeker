# 需求描述
1. 新增Collage功能，当且仅当位于Playback Current界面时提供入口和功能
2. 入口：界面顶栏位置左上角新增Collage按钮。快捷键P，也可以鼠标左键点击。
3. 功能逻辑，类似表格界面的Select，包含图标+文字，点击后，文字变为Exit。点击Exit，或按快捷键P，或按Esc键，退出Collage功能。
4. 在Collage状态，顶栏中间的标签页替换为编辑图标+Editing Collage的文字，禁用Tab切换Current和Playlist。从外观感觉和实际实现上，都要做到与这2个标签页隔离。
5. 进入Editing Collage后，顶栏下方页面变化，分为左右2个部分，右侧是字幕，复用reel界面的虚拟化表格和虚拟化滚动条。本质上这里就是将Current界面推到了右边，数据上继承过来。该界面增加一个鼠标点击选择/取消选择checkbox的交互功能（允许点击选中非焦点字幕），以及回车的选择/取消选择checkbox的交互功能。进入后，保持进入前的焦点并默认选中焦点字幕。退出Editing Collage后也要保留退出前焦点位置。
6. 字幕的大小不变和显示的内容不变，只是需要预留选中的checkbox的位置。选中字幕的checkbox样式参考Search筛选那里的圆形checkbox，宽度和高度要调整得大一些，适配该界面。checkbox的视觉锚点是Primary Cue。
7. 左侧显示实时预览，初始化时由于默认选中了焦点字幕，因此会显示包含该字幕的截图。
8. 每次选中或取消选中一个字幕，都会触发实时预览的计算和重绘。注意这里只做增量计算和重绘。只刷新必要的区域，管理好refresh scope。
9. 具体的Collage规则和当前代码有差异，参考# Collage生成
10. 左侧实时预览图下方还有加2个包含图标的按钮：Copy Collage（用Copy图标），Export Collage（用表格界面选择后导出Anki的那个图标）。前者会复制截图到剪贴板，后者会弹出一个文件管理器界面，命名和当前的表格界面的Collage的一致。
11. 左侧布局：第一行是标题：Collage Preview，第二行是图片，第三行是2个按钮。
12. 左侧要占据一半的窗口宽度，并且要让Collage图片尽量可以显示得更宽一些，Collage图片的宽度只需要比左侧部分的宽度稍微小一些就可以了。
13. Collage图片的高度超过了区域高度时，加滚动条。标题和按钮区域的位置不要滚动，固定在那里。

# Collage生成
1. 首先统计选中字幕的时间戳，合并完全相同的时间戳。
2. 将第1步处理后的时间戳，按照开始时间戳从小到大（如果开始时间戳相同，结束时间戳小的排在前面）排序。
3. 概念定义：一组时间戳，指的是对于若干个时间戳，任意2个时间戳有大于等于100ms的交集。
4. 接下来进入分组流程：检查前2个时间戳是否位于一组，分组判定成功则继续取下一个时间戳进行分组判定，分组判定失败首先将前一组固定下来，然后后一个时间戳继续对之后的时间戳进行分组判定。由于第2步得到的时间戳本身是严格递增的，因此该流程可以最终对选中的字幕的不重复的时间戳进行分组。
5. 此时Collage就变成了：处理单个时间戳的位于时间戳区间中间的时间戳的包含选中字幕的截图（不包括未选中字幕），以及一组时间戳的交集的中间的时间戳的包含选中字幕的截图（不包括未选中字幕）。
6. Collage只会选取第一组时间戳的完整截图，后续组的截图，只取包含字幕的部分的完整宽度的部分（具体实现，例如合并多字幕区域和高度数值，参考现在的代码）。整体表现上和当前实现一致。
7. 每次勾选或取消勾选，只需要对变化字幕的时间戳相邻部分做增量分组判定即可，不需要全局判定。
8. Collage的选中字幕，最多50条。当达到上限时，未选中的字幕进入disable状态，不可以选择，此时可以取消已经勾选的字幕。

# 修改流程

## 1. 实现 Collage 基础语义和渲染能力
完成时间戳合并、排序、分组、中点计算、50 条上限及增量更新；复用现有截图、字幕区域裁剪和纵向合成能力，只渲染选中字幕。

## 2. 实现 Editing Collage 模式
增加 Current 左上角入口、P 快捷键和 Exit 状态；将 Editing Collage 与 Current、Playlist Tab 隔离，处理 P、Esc、Tab 及其他 Playback 快捷键。

## 3. 实现字幕选择区域
复用 Current 的虚拟化 Reel、焦点交互、字幕渲染和虚拟化滚动条，将其移至右侧并继承、保留焦点位置；增加圆形 Checkbox，支持鼠标及回车选择或取消选择，默认选中焦点字幕并处理 50 条上限。

## 4. 实现所见即所得实时预览
完成左右等宽布局、固定标题和按钮区域、单一连续 Collage 画布及图片滚动；选择变化时只重新计算和渲染受影响分组，并处理过期异步任务。

## 5. 实现 Copy Collage 和 Export Collage
Copy、Export 与实时预览共用同一代合成结果；接入剪贴板、保存面板和现有 Collage 文件命名规则。

## 6. 完成刷新范围与整体收尾
检查 Checkbox、字幕列表、预览画布和 Playback Host 的刷新边界，完成相关回归、实施记录和必要的工程文档更新；不修改现有表格 Collage 和 Context 功能。
