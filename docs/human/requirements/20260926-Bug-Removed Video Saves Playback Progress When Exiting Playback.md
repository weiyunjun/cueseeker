# 需求描述

## 1. 现状

正在播放或已移除文件夹下的视频离开数据库后，退出播放时仍向数据库保存了播放进度与播放历史，导致数据库中生成了孤儿记录。重新添加该文件夹后，该视频播放进度未能归零，播放状态异常保持在 Watching，未能恢复初始状态。

## 2. 要求

1. 视频已离开数据库或所属目录已不在库中时，退出播放**严禁保存该视频的观看进度、播放历史与观看状态**，杜绝向数据库写入任何残留或孤儿记录。
2. 重新添加曾被移除的文件夹后，该文件夹下所有视频的播放进度必须为 0，播放状态必须为 **Unwatched**。

## 3. 保持不变

1. 20260925 需求单中当前视频离开数据库后继续播放、不退出播放页等既有逻辑保持不变。

# 验收

1. 播放已移除目录下的视频，移除完成后退出播放，再重新添加该目录：该视频播放进度归零，播放状态正确显示为 Unwatched。
2. 单元测试与集成测试覆盖“视频离开库后退出播放拒绝写库”及“数据库无污染”的断言。
3. 不为本需求新增 E2E 能力；第 1 条由人工验收。
