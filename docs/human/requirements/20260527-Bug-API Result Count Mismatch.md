### bug描述
1. 如图1所示，API请求chunks后，显示chunks的搜索结果数一直转圈，需要按方向键切换才会停止转圈。此处数据库搜索是非常快的，正常不可能一直转圈。
2. 如图2和图3所示，方向键切换以后，搜索结果数错误。例如图中实际有48个结果，但只显示有8个结果。
3. 方向键左右切换，同一chunks，搜索结果数的数量也会变化。
