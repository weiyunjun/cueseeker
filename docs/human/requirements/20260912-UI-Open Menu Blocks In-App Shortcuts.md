# 需求描述

## 1. 适用范围

菜单模态第 6 条表格中的全部菜单，含视频播放倍速菜单。

## 2. 键盘

菜单打开且未被更高层覆盖期间，主窗口内的按键按下表处理：

| 按键 | 处理 |
| --- | --- |
| ↑↓、回车、Esc | 归菜单 |
| ←→ | 归菜单：有二级菜单时展开与收起，没有时吞掉，无效果 |
| 打开该菜单的快捷键 | 归菜单，再按一次关闭它 |
| 其余 App 内功能：Settings / Shortcuts 中的全部功能，以及 Tab | 不响应，也不传给任何层 |
| ⌘ 组合键、被系统截留的按键 | 不受影响 |

1. 「不响应」按功能判定，与当前绑定的键位无关；手柄触发同一功能时同样不响应。
2. 独立窗口与系统菜单栏的输入不受影响。

## 3. 滚轮

1. 任何菜单打开期间，整窗口禁止滚动。
2. 指针位于菜单之上时，滚轮只作用于菜单本身；倍速菜单不可滚动，滚轮在它上面无效果。

## 4. 倍速菜单

除 Player UI 隐藏时一并关闭外，倍速菜单与其它菜单没有差别。取消以下三条：

1. 左右键传给播放页。
2. 不禁止滚动。
3. 切换到上一个或下一个结果、打开 Command Panel、打开 Playback Overlay 时关闭。这三个动作在菜单打开时已不响应，相关代码一并删除。

## 5. 保持不变

1. 鼠标：左键在菜单之外只关闭菜单，右键关闭并继续生效，中键不关闭。
2. 菜单之外的 Hover 冻结、焦点取消、选中文字清除、更高层界面冻结下层菜单。
3. Esc 只关闭菜单，不关闭菜单所属的界面。
4. 不新增、不修改任何 Token。

# 验收

1. 倍速菜单打开：Space、←→、↑↓、A、D、K、回车、F、Q、R、P、⇧,、⇧. 均不执行原功能；↑↓ 移动高亮，回车选中并关闭，Esc 关闭，音量与进度不变，Command Panel 与 Playback Overlay 不打开。
2. 倍速菜单打开：滚轮在窗口任意位置无效果。
3. Playback Overlay 的 Save to Shiori 菜单打开：Tab、C、X、P、K 不响应，模块不切换；S 关闭菜单。
4. Playback Overlay 与 Command Panel 的选中文字菜单打开：Tab、S、C、X、P、K 不响应；Esc 只关闭菜单。
5. 任一菜单打开时 ⌘Q、⌘,、⌘M 照常生效；Settings 窗口内输入不受影响。
6. Workbench 各菜单行为与改动前一致。
7. Player UI 隐藏时倍速菜单仍一并关闭。
8. 手柄：倍速菜单打开时上一个、下一个、播放暂停不响应。本条人工验收。
9. 其余使用现有 Debug E2E 控制器覆盖，不为本需求新增 E2E 能力；现有自动化用例无新增失败。
