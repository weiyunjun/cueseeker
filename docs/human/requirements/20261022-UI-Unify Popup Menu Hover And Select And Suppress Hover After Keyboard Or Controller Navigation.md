# 需求描述

1. **各界面 `Hover` 与 `Select` 的定位边界**：
   - **保留默认选中且区分 `Hover`（浅底）与 `Select`（深底）**：仅限 **Playback 界面的封面卡片**（Playback Overlay 视频播放列表默认选中当前播放剧集，Command Panel 的 `Recent Videos` 与 `Recent Excerpt Lists` 默认选中第 1 项）以及 **Command Panel 一级界面的选项**（默认选中第 1 项）。
   - **仅 `Hover` 无 `Select`**：**Workbench 界面的封面卡片**无默认选中项，也不设 `Select` 状态。
   - **弹出菜单取消默认选中，且将 `Hover` 与 `Select` 合二为一**：所有界面的弹出菜单（含下拉菜单、右键菜单、二级菜单、播放页倍速菜单、播放页更多菜单、摘录集目标菜单、设置页字体菜单等）打开时**均无默认选中项**；弹出菜单项不再区分 `Hover` 与 `Select`，鼠标悬停与键盘/手柄导航共用单一高亮状态，视觉样式统一采用现有的 `Hover` 样式。

2. **弹出菜单无默认高亮后的键盘/手柄导航与二级菜单规则**：
   - **无高亮项时的首次上下导航**：当当前激活的菜单（或已展开的二级菜单）内没有任何高亮项时：
     - 按 **上方向键 / 手柄十字上键 / 左摇杆上拨** $\rightarrow$ 高亮当前菜单**最下面（最后一个可用）**的菜单项，若未完整显示则自动滚动使其完整可见；
     - 按 **下方向键 / 手柄十字下键 / 左摇杆下拨** $\rightarrow$ 高亮当前菜单**最上面（第一个可用）**的菜单项，若未完整显示则自动滚动使其完整可见；
     - 按 **回车键** $\rightarrow$ 无高亮项时不执行任何动作。
   - **已有高亮项时的上下导航**：从当前高亮项向上或向下移动一格（到达首尾边界时停在原处，不循环），若目标项未完整显示则自动滚动使其完整可见。
   - **二级菜单的展开与收起**：
     - 无论通过鼠标移入/点击父菜单触发项，还是通过键盘右方向键 / 手柄十字右键 / 左摇杆右拨 / 回车键展开二级菜单，**二级菜单刚打开时内部均无任何默认高亮项**，父菜单中对应的触发项保持高亮底色。
     - 二级菜单展开期间，上下方向键、手柄上下与回车键作用于二级菜单；按 **左方向键 / 手柄十字左键 / 左摇杆左拨** 关闭二级菜单回到父菜单，父菜单原触发项保持高亮。

3. **鼠标指针 `Hover` 触发状态机与键盘/手柄导航抑制规则**：
   - **无法触发 `Hover` 的状态条件**：在以下任一期间，鼠标指针处于无法触发 `Hover` 的状态：
     1. 鼠标滚轮或触控板滚动开始至停止滚动后的 `300ms` 内；
     2. 在支持键盘/手柄导航的位置（Playback 封面卡片、Command Panel 一级界面选项、所有弹出菜单及二级菜单）通过键盘或手柄移动选中/高亮内容（含在首尾边界继续按键、开启或关闭二级菜单）后，且鼠标尚未发生真实移动前；
     3. 鼠标指针隐藏后，且鼠标尚未发生真实移动前；
     4. 窗口失焦期间。
   - **键盘/手柄导航瞬间清除同层级已有 `Hover`**：当通过键盘或手柄操作上述位置时，**立即清除当前鼠标在同层级其它项上的 `Hover` 效果**（如其它封面卡片的 `Hover` 及手型指针、Command Panel 一级界面其它选项的 `Hover`、菜单中其它菜单项的高亮），并进入「鼠标移动前无法触发 `Hover`」状态。
   - **恢复条件**：由键盘/手柄导航或指针隐藏进入的无法触发 `Hover` 状态，**仅在鼠标发生真实移动时才可退出**（期间若发生滚轮滚动，滚动停止满 `300ms` 后仍保持抑制，不唤醒鼠标 `Hover`）。

# 验收标准

1. **弹出菜单打开与合一高亮表现**：
   - 打开任意下拉菜单、右键菜单、播放页倍速/更多菜单或摘录集目标菜单：若鼠标指针不在菜单项上，菜单内没有任何高亮项（单选菜单的对勾 `✓` 正常显示）；鼠标移入某项或用方向键导航到某项时，统一显示 `Hover` 样式。
   - 弹出菜单无高亮项时，按下方向键（或手柄下）高亮第 1 个可用项，按上方向键（或手柄上）高亮最后 1 个可用项；随后移动鼠标到另一项，高亮直接切换到鼠标所在项。
2. **二级菜单交互表现**：
   - 用鼠标移入或按右方向键/回车展开二级菜单（如 `Save to Excerpt List` 或播放页 `More` 的音轨/字幕菜单）时，二级菜单内初始无高亮项，父菜单触发项保持高亮；此时按下键高亮二级菜单第 1 项，按上键高亮二级菜单最后 1 项，按左键关闭二级菜单且父菜单触发项维持高亮。
   - 当按右方向键/回车展开二级菜单且二级菜单恰好出现在静止的鼠标指针下方时，指针所在的二级菜单项不会触发高亮，直至移动鼠标。
3. **键盘/手柄导航清除并抑制鼠标 `Hover`**：
   - 在 Playback 封面卡片网格或 Command Panel 一级界面中，将鼠标停在非 `Select` 项上产生浅底 `Hover`（封面卡片同时显示手型指针），按下键盘方向键或手柄方向后：原鼠标所在项的 `Hover` 立即消失（指针恢复默认箭头），且即便页面自动滚动使新卡片滑到静止鼠标下方、或再使用滚轮滚动停稳满 `300ms`，也不会触发鼠标 `Hover`；晃动鼠标后，当前指针所在项立即恢复 `Hover`（及手型指针）。
