# 需求描述

1. **HDR 与杜比视界视频播放及 SDR 色彩表现（本地与远程）**
   - 全面支持主流高动态范围与广色域视频格式，涵盖 `HDR10`（含缺失静态亮度元数据的视频）、`HDR10+`、`HLG`（含播放中途由 SDR 动态切换为 `HLG` 的视频）以及杜比视界（`Dolby Vision Profile 5 / 8.1 / 8.4 / 10.1` 等配置）。
   - **播放流畅度与解码一致性**：硬件加速解码与软件解码下的画面色彩与明暗表现完全一致；高分辨率高帧率（如 4K 60fps）视频播放全程满帧流畅，画面进度与音频时钟、进度条时间戳严格同步；中途色彩动态切换无黑屏、无闪烁、无卡顿；带旋转方向或非正方形像素的视频按转正后的实际显示比例与朝向渲染。
   - **开启与关闭系统 HDR 下的播放画面对齐**：
     - 当显示器开启系统 HDR 时，完整还原视频的高动态范围明暗层次与广色域细节，高光不过曝、暗部纯正不偏色，整体视觉表现与同环境下 `Movist Pro` 的播放画面一致。
     - 当显示器关闭系统 HDR（或处于 SDR 显示环境）时，自动将高动态范围与杜比视界画面平滑映射至标准动态范围，日常场景明暗适中、高光自然滚降不死白、暗部黑位纯正无泛白灰雾，整体视觉表现与同环境下 `Movist Pro` 的播放画面一致。
   - **普通 SDR 视频表现保持不变**：普通 SDR 视频继续按标准 `sRGB (Gamma 2.2)` 传递曲线与缺失色彩元数据按分辨率自动推断规则渲染，不受影响。

2. **`Settings - General - Appearance` 新增 `HDR Screenshot` 开关与 5 处静态图片统一对齐**
   - **设置项布局与文案（`L-02.3` / `C-02.2`）**：在 `Settings` 窗口 `General` 分类的 `Appearance` 分组卡片内，于 `Appearance Mode` 行下方新增分隔线与设置行（英文：`HDR Screenshot`；简体中文：`HDR 截图`；繁体中文：`HDR 截圖`），右侧配置原生开关（`C-02.2 Switch`），**默认开启**，并纳入设置页无障碍焦点遍历顺序。
   - **5 处静态图片统一控制规则**：该开关统一控制应用内全部 **5 处静态图片**（① **播放页无字幕/带字幕实时截图**、② **播放页底部进度条鼠标悬停预览缩略图**、③ **台词拼图预览与导出长图**、④ **Anki 制卡导出配图**、⑤ **媒体库视频卡片自动提取封面**）在遇到 HDR 与杜比视界视频时的渲染输出效果，不依赖当前物理显示器是否支持或开启系统 HDR（普通 SDR 视频不受该开关影响）：
     1. **开启 `HDR Screenshot`（默认）**：5 处静态图片统一按 HDR 画面基准渲染输出标准 `sRGB` 图片，明暗与色彩对齐开启系统 HDR 时的视频播放画面及 `Movist Pro` 开启 HDR 模式下的内置截图。
     2. **关闭 `HDR Screenshot`**：5 处静态图片统一按 SDR 画面基准渲染输出标准 `sRGB` 图片，明暗与色彩对齐关闭系统 HDR（SDR 模式）时的视频播放画面及 `Movist Pro` 关闭 HDR 模式下的内置截图。
   - **开关切换生效边界**：切换开关后，实时截图与 Anki 导出立即按新状态输出；进度条悬停预览缩略图立即清空已缓存缩略图并按新状态重新生成，当前已打开的台词拼图预览同步刷新；媒体库自动提取封面在扫描添加文件夹生成自动封面时按当前开关状态渲染。

3. **`Debug` 模式专属播放与截图诊断日志**
   - 仅在 `Debug` 构建下向 `logs/debug/` 目录输出以下诊断日志（`Release` 正式构建不采集、不输出）：
     1. **视频色彩与管线状态日志**：打开视频、播放中途色彩切换或显示器 HDR 状态变更时，记录视频色彩空间、传输曲线、杜比视界配置、亮度元数据、解码方式、显示器 HDR 状态及状态切换耗时。
     2. **播放流畅度与音画同步心跳日志**：播放期间定期及暂停/跳转/停止时，汇总记录目标帧率与实际输出帧率、数据包读取/视频解码/画面渲染各阶段的平均与最大单帧耗时、丢帧数、音画时钟偏差及预读缓冲水位。
     3. **卡顿、掉帧与跳转耗时抓拍日志**：当单帧解码或渲染耗时超出帧间隔预算、出现掉帧、音画时钟偏差超标或画面时间戳推进滞后，以及执行跳转（Seek）时，记录具体慢阶段与分步耗时。
     4. **5 处静态图片耗时日志**：每次生成上述 5 处静态图片时，记录触发场景、`HDR Screenshot` 开关状态、源视频色彩格式、输出尺寸及取帧解码、画面渲染与图片编码的分阶段耗时。

# 验收标准

1. **设置项 UI 与交互验证**
   - 打开 `Settings -> General`，`Appearance` 分组卡片内 `Appearance Mode` 下方显示 `HDR Screenshot`（随界面语言切换为 `HDR 截图` / `HDR 截圖`）与原生开关，默认处于开启状态，支持鼠标点击与设置窗口无障碍焦点遍历切换。
2. **HDR 与杜比视界实时播放验证（本地与远程）**
   - 在开启与关闭系统 HDR 两种显示状态下，分别使用硬件加速解码与软件解码播放各类 `HDR10`（含无 `MaxCLL` 视频）、`HDR10+`、`HLG`（含中途由 SDR 切换为 `HLG` 的视频）及杜比视界（`Profile 5 / 8.1 / 8.4 / 10.1`，含带旋转方向的竖屏视频）以及普通 SDR 视频：
     - 4K 60fps 等高码率视频播放全程满帧流畅，进度条时间戳按真实时间 `1:1` 推进，音画严格同步；中途 `SDR -> HLG` 切换无黑屏或卡顿；竖屏与非正方形像素视频比例和朝向正确；
     - 开启与关闭系统 HDR 下的播放画面明暗、高光细节、暗部黑位与色彩饱和度，均分别与同显示状态下的 `Movist Pro` 播放画面一致；普通 SDR 视频保持原有 `Gamma 2.2` 正常色彩与对比度。
3. **5 处静态图片与 `HDR Screenshot` 开关联动验证**
   - **开启 `HDR Screenshot` 时**：即使当前显示器关闭系统 HDR，触发无字幕/带字幕实时截图、查看进度条悬停预览缩略图、查看并导出台词拼图、导出 Anki 配图以及重新添加文件夹生成媒体库自动封面，5 处图片的明暗与色彩彼此完全一致，且与开启系统 HDR 时的视频播放画面及 `Movist Pro` 开启 HDR 时的截图一致。
   - **关闭 `HDR Screenshot` 时**：上述 5 处图片的明暗与色彩彼此完全一致，且与关闭系统 HDR（SDR 模式）时的视频播放画面及 `Movist Pro` 关闭 HDR 时的截图一致；切换开关后，进度条预览缩略图与已打开的台词拼图无需重开视频即可按新状态刷新。
4. **`Debug` 诊断日志验证**
   - 在 `Debug` 模式下播放视频、跳转进度、切换设置并触发 5 处静态图片生成后，`logs/debug/` 日志文件中完整记录色彩识别与管线状态、定期帧率与分段耗时心跳、跳转与异常慢帧抓拍以及 5 处静态图片的分阶段耗时。
