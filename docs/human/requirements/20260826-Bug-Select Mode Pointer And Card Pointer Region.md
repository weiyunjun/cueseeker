# 需求描述

## 1. 多选模式指针

表格进入多选模式后，整行任何位置都不显示手型指针，一律使用默认箭头。该模式下点击执行的是勾选而非播放，因此不属于「表格内可播放字幕文本」。退出多选模式后，字幕文本恢复手型。

## 2. 卡片可点区域与手型区域

视频卡片、库文件夹卡片、Shiori 列表卡片的可点击区域、手型区域与 Hover 判定区域必须完全一致，三者都是卡片的整个矩形区域，包含内容四周的交互内边距与四个角。Hover 的圆角矩形背景只是外观，保持不变，不随判定区域改变。

## 3. 不变项

1. 手型仍只出现在 `docs/human/design/UI Application Rules.md` 指针一节列出的三处。
2. 卡片手型仍需 macOS 15 及以上；更低版本上卡片为箭头，Hover 效果不受影响。
3. 指针的覆盖与冻结规则不变。

# 验收

1. 进入多选模式后，Hover 表格任意行的任意位置均为箭头；退出多选模式后，字幕文本恢复手型。
2. 逐类卡片把指针移到四个角：Hover 背景亮起、指针为手型、点击能打开该卡片，三者边界完全重合。
3. 指针移出卡片后，Hover 效果与手型同时消失。
4. 现有自动化端到端与单元用例全部通过。
5. 指针形状本身由需求方人工验收。
