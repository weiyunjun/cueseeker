# 需求描述

## 1. Library 一级界面排序按钮
1. **位置与对齐**：
   - 位于卡片网格上方的操作行中，高度为 36px（`--height-control`），与下方卡片网格间距 16px（`--spacing-4`）。
   - 排序按钮整体与页面主内容区右边缘（即 Grid 容器右侧基准线）保持右对齐。
2. **按钮形态与内容**：
   - 采用标准 Neutral 按钮样式，包含 Leading 图标与文字。
   - 图标使用 Phosphor 图标库的 `funnel-simple`。
   - 文字内容实时反映当前生效的排序方式名称。
3. **激活状态**：
   - 排序菜单打开期间，排序按钮呈现 Open 状态（浅 Accent 激活底色 `--color-bg-active`）。

## 2. 排序单选菜单
1. **选项列表**：
   - **默认排序**
   - **最晚入库**
   - **最早入库**
2. **菜单交互规范**：
   - 遵循标准 Radio Menu 规范：当前选中项展示勾选标记（`check`），未选中项预留标记槽位。
   - **默认高亮**：菜单打开时，键盘焦点与高亮默认停留在第一项（默认排序）。
   - **键盘与鼠标**：支持方向键上下移动高亮、Enter/空格键确认选择、Esc 键关闭；支持鼠标 Hover 切换高亮、点击项选择并关闭；点击菜单外部区域仅关闭菜单，不触发下层操作。

## 3. 排序规则与持久化
1. **入库时间定义**：
   - 以文件夹下最早被索引的文件时间（首次入库时间）作为该文件夹的入库时间戳。
2. **平局裁决（Tie-breaker）**：
   - 无论是“最晚入库”还是“最早入库”，在入库时间相同的情况下（如同一批次入库），均退化为按文件夹名称升序（A → Z）排列。
3. **持久化**：
   - 用户选定的排序方式持久化保存至偏好设置，重启应用后保持选中的排序。

# 验收标准

1. **界面与布局**：
   - Library 一级界面右上角呈现排序按钮，与第一排卡片最右侧边缘右对齐。
   - 按钮显示 `funnel-simple` 图标和当前排序文案；菜单打开时呈现 Open 背景态。
2. **单选菜单行为**：
   - 点击弹出单选菜单，包含默认排序、最晚入库、最早入库三项。
   - 菜单打开默认高亮首项；支持键盘导航与选择；勾选标记与选中项一致。
3. **数据排序正确性**：
   - 切换排序后，卡片网格即时按照选定规则重排。
   - 最晚入库与最早入库在时间相同的情况下，严格按名称 A-Z 稳定排列。
   - 重启 App 后，排序模式保持不变。
