# 需求描述

## 1. 适用范围

五个菜单：Workbench 表格行右键菜单、Workbench 卡片与封面右键菜单、
视频播放倍速菜单、Playback Overlay 选中文字菜单、Command Panel 选中文字菜单。

菜单被更高层界面覆盖时，按下归更高层，本需求不适用；此时菜单保持显示、
不接受输入，沿用 `20260825-UI-Menu Modality And Layer Input Ownership.md` §3。

## 2. 菜单所在窗口内的按下

1. 左键：该次按下只用于关闭菜单，不传给下层，不触发落点上的控件、选中或
   光标变化。
2. 右键：关闭当前菜单，该次按下继续生效；落点自身有右键菜单时，新菜单立即打开。
3. 中键不关闭菜单。
4. 系统菜单栏按同一规则处理：左键关闭菜单且系统菜单不展开，右键关闭菜单且
   系统菜单展开。

## 3. 其他窗口内的输入

1. 应用的独立窗口（设置窗口）不属于
   `20260825-UI-Menu Modality And Layer Input Ownership.md` §2 的界面层级清单。
2. 用快捷键呼出独立窗口时，菜单不发生任何变化。
3. 独立窗口内的按下不关闭菜单，也不被截留，完整交给该窗口。
4. 焦点回到菜单所在窗口后，菜单继续按 §2 响应。

## 4. 作废的旧规则

1. 作废 `20260825-UI-Menu Modality And Layer Input Ownership.md` §5 第 2 条，
   该文档其余条目继续有效。
2. 作废 `20260824-UI-Menu Placement And Outside Interaction.md` §5.2 与验收第 6 条。

# 验收

1. 菜单打开时在菜单之外按下左键：菜单关闭，落点上的控件不被触发，行或卡片的
   选中不改变。
2. 菜单打开时右键按下另一张卡片或另一行：当前菜单关闭，被右键点中的目标立即
   打开它自己的菜单。
3. 菜单打开时点击左下角设置按钮：该次按下只关闭菜单，设置窗口不打开。
4. 菜单打开时点击系统菜单栏：左键只关闭菜单，系统菜单不展开；右键关闭菜单，
   系统菜单展开。
5. 菜单打开时按 `⌘,` 呼出设置窗口：菜单保持显示不变。
6. 承接第 5 条，在设置窗口内点击：菜单不关闭，该次点击一次生效，不需要点第二次。
7. 承接第 6 条，回到主窗口在菜单之外按下左键：菜单关闭。
8. 中键在菜单之外按下不关闭菜单。
9. 五个菜单的以上行为一致。
