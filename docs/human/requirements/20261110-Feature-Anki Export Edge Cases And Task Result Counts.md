# 需求描述

1. **Anki 导出单张卡片失败判定与独立跳过规则**
   - 同一导出任务内按顺序逐张处理待导出的台词卡片；当某张卡片导出失败时，仅将该张卡片判定为失败并跳过（失败数量 `+1`），继续处理后续台词卡片，不影响同一任务内其余台词卡片的正常导出。
   - **单张卡片判定为失败并跳过的条件**：
     1. **媒体项提取失败**：当卡片正面或背面配置了 `Audio`（音频）或 `Screenshot`（截图）时，若该台词所属视频已不在媒体库中、视频文件不存在或无法读取、无可用音轨或视频画面、音频或画面格式不支持导出、目标时间点无法解码出任何视频画面帧，或最终未能生成非空的音频/图片文件。
     2. **数据库字段缺失**：当卡片正面或背面配置了 `Cue Text`（台词文本）、`Display Title`（显示标题）、`Time Range`（时间范围）或 `Deep Link` 时，若该台词已不在媒体库中或对应字段内容缺失为空。
     3. **台词组文本边界规则**：当卡片配置了 `Cue Group Text`（台词组文本）而该台词无同组其他台词行时，若所在面仍有其他有效内容则正常省略该项并导出卡片；**仅当卡片正面或背面只配置了 `Cue Group Text` 一项且内容为空（导致整面为空）时，才判定该张卡片失败并跳过**。

2. **导出任务最终状态与打包规则**
   - **成功数量 $\ge 1$**：将所有成功卡片打包生成目标 `.apkg` 文件，任务进入 **「已完成（`Completed`）」**。
   - **成功数量 $= 0$（全部卡片均失败）**：不生成空的 `.apkg` 文件，任务进入 **「未完成（`Incomplete`）」**，失败原因显示为：
     - 英文：`All cards failed to export`
     - 简体中文：`全部卡片导出失败`
     - 繁体中文：`全部卡片匯出失敗`

3. **「任务面板」卡片展示规则（`L-06.10 Task Card Layout`）**
   - **排队中（`Queued`）**：维持现状，第 2 行显示排队状态与总卡片数量（如 `Queued  10 cards` / `排队中  10 张卡片` / `排隊中  10 張卡片`）。
   - **正在执行（`In Progress`）**：
     - 第 2 行显示已成功数量、总卡片数量与已失败数量（失败数量为 `0` 时同样常驻显示）：
       - 英文：`%1$d / %2$d cards exported, %3$d unsuccessful`
       - 简体中文：`已导出 %1$d / %2$d 张卡片，%3$d 张失败`
       - 繁体中文：`已匯出 %1$d / %2$d 張卡片，%3$d 張失敗`
     - 第 3 行胶囊进度条维持现有推进规则不变，按 `已处理数量（成功 + 失败）/ 总数量` 计算进度。
   - **已完成（`Completed`）**：第 2 行显示**最终成功导出的卡片数量**与完成时间（如 `8 cards  Just now` / `8 张卡片  刚刚` / `8 張卡片  剛剛`）。
   - **未完成（`Incomplete`）**：维持现状，第 2 行显示**总卡片数量**与终止时间，第 3 行显示失败原因。

4. **「任务详情」弹窗展示规则（`L-06.11 Task Detail Dialog Layout`）**
   - **上方「导出信息（`Export Info`）」分组**：
     - **排队中（`Queued`）**：维持现状，仅展示 `File Name`（文件名）、`Location`（位置）、`Card Count`（卡片数量，显示总数量）。
     - **正在执行（`In Progress`）**、**已完成（`Completed`）**、**未完成（`Incomplete`）**：在 `Card Count`（总数量）下方新增两行纯阿拉伯数字字段：
       - **成功数量**（英文：`Succeeded`；简体中文：`成功数量`；繁体中文：`成功數量`）
       - **失败数量**（英文：`Failed`；简体中文：`失败数量`；繁体中文：`失敗數量`）
     - **各状态下的数值规则**：
       - **正在执行**：随每张卡片处理完成实时更新当前的成功数量与失败数量。
       - **已完成**：显示最终的成功数量与失败数量。
       - **未完成**：无论因全部卡片导出失败，还是因用户取消、应用退出中断或重命名冲突拦截而未完成，成功数量统一显示 `0`，失败数量统一显示总卡片数量。
   - **下方「任务状态（`Task Status`）」分组**：
     - **正在执行**状态下，`Current Stage`（当前阶段）文案与任务卡片第 2 行一致（显示 `%1$d / %2$d cards exported, %3$d unsuccessful` 及其对应简繁文案），`Progress`（进度）胶囊进度条与百分比维持按已处理卡片占比推进。

# 验收标准

1. **单卡失败隔离与部分成功导出验证**
   - 选中多条台词执行 Anki 导出（其中包含视频缺失、无音轨、时间点超出片尾无法截取画面帧、或单面仅配置 `Cue Group Text` 但为单行字幕的台词，以及正常台词）：
     - 失败的台词卡片被自动跳过，不中断其余正常台词的导出；
     - 同一面同时配置了 `Cue Text` 与 `Cue Group Text` 的单行字幕台词正常导出（仅省略空的台词组文本）；
     - 导出完成后正常生成 `.apkg` 文件，导入 Anki 后包含全部成功卡片且内容完整，任务进入 `Completed` 标签页。
2. **全部卡片失败验证**
   - 当待导出的所有台词卡片均导出失败（成功数量为 `0`）时，不生成 `.apkg` 文件，任务进入 `Incomplete` 标签页，卡片第 3 行及任务详情的失败原因显示 `All cards failed to export` / `全部卡片导出失败` / `全部卡片匯出失敗`。
3. **任务面板卡片与任务详情弹窗联动验证**
   - **排队中**：任务卡片显示总卡片数，任务详情 `Export Info` 分组仅展示 `File Name`、`Location`、`Card Count`（总数量）。
   - **正在执行**：任务卡片第 2 行与任务详情 `Current Stage` 实时显示 `xx / yy cards exported, zz unsuccessful`（含 `zz = 0` 时），任务详情 `Export Info` 分组实时更新 `Succeeded` 与 `Failed` 数字，进度条按已处理总数推进。
   - **已完成**：任务卡片第 2 行显示成功导出的卡片数；任务详情 `Export Info` 分组中 `Card Count` 显示总数量，`Succeeded` 与 `Failed` 分别显示最终成功数与失败数。
   - **未完成**：全部失败、中途取消、应用中断或重命名冲突拦截进入 `Incomplete` 的导出任务，任务卡片第 2 行显示总卡片数，任务详情 `Export Info` 分组中 `Card Count` 显示总数量、`Succeeded` 显示 `0`、`Failed` 显示总数量。
