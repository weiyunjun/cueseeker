# 需求描述
1. 在Settings中新增URL Scheme的选项标签页。
2. 这个版本只加一个功能：直接播放URL Scheme的搜索结果。功能名称Play First Search Result，用一个开关控制。
3. 该功能开关默认关闭，开启后，点击链接，会进行搜索并在首屏结果出来以后播放第一个搜索结果，而不需要渲染搜索页。
4. 该功能开关开启，以URL Scheme方式播放视频后，会回到搜索该词的Search界面。
5. 如果没有任何搜索匹配结果，则直接fallback搜索该词的Search界面。
6. 这个版本的新的URL Scheme允许取消旧URL Scheme意图、旧搜索任务，并停止当前播放。

需要讨论：
1. 该选项的英文名。
2. 具体实现延迟是否可以接受。
