# 需求描述

## 1. 移除封面骨架屏（Remove Cover Skeleton Screen）
1. **彻底废除扫光骨架屏**：
   - 移除封面图加载期间的扫光动效（Shimmer）及显眼的骨架屏底色。
   - 废弃原 `20261004-UI-Cover Skeleton Screen With Shimmer.md` 中定义的封面骨架屏方案。

## 2. 封面加载中与兜底交互规范
1. **加载中状态（Loading）**：
   - 处于异步读取或解码中的封面，保持卡片几何尺寸与界面/卡片默认底色一致，**呈静默空白，不展示任何扫光、动画或临时图标**。
   - 解码完成后直接呈现真实图片。
2. **已缓存状态（Cached / Reorder）**：
   - 已经处于内存缓存中的封面，在界面刷新、重排或排序切换时，**直接即时渲染，杜绝任何过渡态或白/灰闪烁**。
3. **静态兜底封面（Fallback）**：
   - 仅在数据源无封面（`coverPath` 为空）或文件损坏加载失败时，显示静态默认封面（保留占位底色与默认视频/列表图标）。
   - 有有效封面的卡片在加载中严禁展示默认图标。

# 验收标准

1. **排序与切换无闪烁**：
   - 在 Library 等界面修改排序或切换筛选时，封面平滑保持或即时就位，无灰色底块闪烁与重新淡入感。
2. **冷启动表现**：
   - 冷启动进入界面时，封面区域平稳就位，无扫光动画，无默认小图标被覆盖的闪现感。
3. **兜底准确**：
   - 仅无封面或加载失败的卡片展示静态默认图标。
