# 需求描述

## 1. 导出弹窗即时弹出（零等待）

1. 在 Search 与 Excerpt 表格中勾选条目并点击 `Export to Anki` 时，配置弹窗即时弹出。
2. 弹窗打开阶段严禁在主线程执行音频轨道查询（`defaultAudioTrackIndex`）或大批量数据库读取，弹窗打开前置耗时压降至百毫秒内（推荐 < 50ms），消除明显卡顿与冻结。

## 2. 音轨解析后置到后台导出任务

1. 选定条目的默认音轨解析推迟至用户点击弹窗中的 `Export`、任务进入后台队列执行阶段处理。
2. 后台任务在实际生成 Anki 卡片音频时按需读取视频默认音轨并执行容错回退，全程在后台异步进行，不阻塞界面交互。

# 验收标准

1. **秒开验收**：
   - 在 Search 或 Excerpt 表格中多选大量结果（如 500~1,500+ 条）并点击 `Export to Anki`：弹窗瞬间呈现，主线程无明显卡顿停顿。
2. **导出结果一致性**：
   - 确认导出后，后台任务正常执行，生成的 Anki 卡片音频轨道与现有逻辑完全一致。
3. **自动化测试**：
