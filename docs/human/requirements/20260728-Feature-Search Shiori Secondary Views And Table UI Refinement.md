# 需求描述
1. 准备修改Search及Shiori界面。如图所示，将现在的2栏改造为3栏：搜索框及其他按钮，筛选条件可视化数据面板，结果表格
2. 可以点击Filter按钮，显示/隐藏筛选条件可视化数据面板。当显示时，Filter按钮的外观和当前弹出菜单时Filter按钮的外观一致。
3. 所有筛选条件，都可以多选。
4. 每次搜索都要进行全量搜索，保证数据面板可以显示正确的数据，这里本质上是一种数据范畴分布的显示。
5. 数据卡片内部多选默认是或的关系，例如选1~3s和3~5s其实就是同时选择这2组。但是数据卡片之间是且的关系，即同时满足这几个数据卡片条件的结果。
6. Shiori后续还会迭代更多的数据卡片，但是这个版本先不做，注意要把数据卡片作为新的筛选项抽象出来，保证不同的位置可以调用它
7. 旧的筛选的相关功能及代码，不用了可以删除
8. 初始化Search页面时默认显示数据面板，默认全部选择All，筛选条件重启App后恢复默认。Command Panel界面的Search那里先维持现状（即按照现在的临时空Filter处理，后续会在界面里支持筛选条件，放到搜索结果列表左侧替代现在的封面），后续再支持，先处理Workbench这里的代码。
9. exact结果出来之前，输入搜索词以后，数据卡片的数字都要显示Calculating，且disable所有选项，禁止修改。
10.搜索条件一，Duration，选择时钟图标，5个选项：All，<1s，1~2.999s，3~4.999s，≥5s。
11.搜索条件二：Character，选择T的图标，5个选项：All，1-10，11-20，21-30，31+。
12.搜索条件三：Language，选择地球图标，选项：All，以及数据库当前所有包含的语言。只需要列出单个语言，如果一个字幕被认为是多语言的，那么可以会被算在多个语言中。换言之，所有选项数字之和可能会大于字幕数量总和。
13. 搜索条件四：Watch Status，选择眼球图标，4个选项：All，Finished，Watching，Unwatched。
14. Filter按钮显示的数字，是选择了非All的筛选条件的数据卡片的数量。
15. Language/Watch Status 卡片取代现有全局语言与观看范围设置。
16. 卡片数字是始终表示搜索词命中的完整分布。

# 修改流程

## Step 1：建立数据卡片筛选语义

定义 Duration、Character、Language、Watch Status 四类筛选项：

- `All` 等于该卡片不限制结果。
- 卡片内多选为 OR。
- 卡片之间为 AND。
- Language 仅列出数据库包含的单个语言及 Unknown；多语言 Cue 可同时归入多个 Language 类别，因此各语言计数之和可能大于 Cue 总数。
- Watching Status 直接读取观看状态，不读取观看进度。

验收：纯逻辑测试覆盖所有组合，不涉及 UI。

## Step 2：建立索引阶段的分布缓存

- index 阶段生成 Duration、Character、Language 的分类与汇总缓存。
- 索引增删改时同步更新。
- Watch Status 在索引关系变化或观看状态变化时更新。
- 空搜索词只读取缓存，不扫描 Cue 表。

验收：

- 缓存数量与数据库直接统计一致。
- 打开 Search 空页面不触发全 Cue 扫描。
- 修改观看状态只更新 Watching Status 分布。

## Step 3：让 Search exact 产出完整分布快照

每次输入搜索词时：

- exact 搜索覆盖完整结果域；
- 同步生成四类分布计数和每条结果的紧凑分类值；
- exact 完成前数据卡片处于 `Calculating`，所有选项 Disabled；
- 新查询自动废弃旧查询的分布快照。

验收：

- exact 数量、结果 ID、分布数量来自同一 generation。
- 旧查询结果不能覆盖新查询。
- 不增加第二次全量搜索。

## Step 4：实现内存筛选投影

- 筛选只作用于 exact 完整结果快照。
- 保留原始搜索排序。
- 点击筛选不访问数据库、不执行 FTS、不创建新的 exact task。
- 只替换表格使用的有序结果 ID 投影。

验收：

- 卡片内 OR、卡片间 AND 正确。
- All、单选、多选、全部清除正确。
- 筛选前后排序不变。
- 在当前完整数据库规模下进行性能测试；若结果不支持即时响应，停止并报告，不继续 UI 步骤。

## Step 6：让 Shiori 接入相同的数据筛选能力

- Shiori 使用相同的数据卡片定义和筛选算法。
- 数据范围限定为当前 Shiori List。
- Search 与 Shiori 分别保存自己的会话筛选状态。
- Shiori 数据、列表或 Watching Status 变化时重建对应快照。
- 本版本不增加 Shiori 专属数据卡片。

验收：
