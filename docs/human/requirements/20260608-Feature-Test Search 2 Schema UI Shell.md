### 需求描述
1. 在CueSeeker主界面顶栏，Test Search UI图标右侧新增一个Test Search 2图标，点击以后显示Test Search 2界面。
2. Test Search 2界面，是在Test Search界面及逻辑基础上，按照Test Search UI修改UI和布局，新增筛选相关UI。
3. 第一阶段：替换或新增，除表格区域的界面的相关组件UI。第二阶段：处理表格相关UI。第三阶段：处理Name字段。
4. 第一阶段，要把Test Search UI中的私有组件提取成可复用组件。并且保证视觉上的一致。
5. 第二阶段，表格部分需要完整保留目前Test Search界面的首屏加载，虚拟化等特性。
6. 第二阶段，Phase 1需要让表头样式和Test Search UI的表头样式对齐。
7. 第二阶段，Phase 2新增Language列。用于显示字幕对应的语言。对于合并了同一时间戳的多个字幕，显示包含的所有语言。
8. 第二阶段，语言列的内容，需要做成通用的tag。语言对应的tag目前包含：zh-hans，zh-hant，zh，en，jp，unknown。这里英文版的显示名和键名一样，后续做其他语言版本时，显示名会和键名不一样。
9. 第二阶段，现在所有的tag统一用默认的蓝色样式，注意样式要和语言本身或者和语言列解耦。后续会做选择tag颜色的功能，类似Notion。其它数据类型是tag的列，例如Speaker，也可以调用不同的tag颜色。
10. 第三阶段：Name字段改为Display Title字段，表头和下面显示的内容，一起修改。
11. 筛选逻辑，这个需求单不做，因为涉及很多后端复杂的规则，需要单独开一个需求单处理。
