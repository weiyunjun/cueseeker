# 需求描述
1. 在Settings - Search中新增开关选项：Prefill with Focused Cue。选项的说明文字是：Automatically fill the Command Panel with the focused cue when opened from Playback Overlay。
2. 功能是：位于Playback Overlay界面（Playback Overlay Current，Playback Overlay Cue Playlist，不包括Collage界面）时，打开Command Panel，会自动填充焦点字幕内容，且输入光标位于文本末尾。
3. 该功能默认关闭。
