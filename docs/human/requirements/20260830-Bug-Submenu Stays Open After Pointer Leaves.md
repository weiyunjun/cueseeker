# 缺陷描述

## 1. 复现

1. 在 Shiori 列表的表格行上右键打开行菜单。
2. 悬停 `Move to…` 或 `Duplicate to…`，二级菜单展开。
3. 指针移出一级与二级菜单区域，停住不动。

## 2. 现象

二级菜单不关闭，一直留在原处。

## 3. 期望

1. 指针移出一级与二级菜单区域后，二级菜单关闭，一级菜单保持打开。
2. 指针朝二级菜单移动的途中，二级菜单保持展开，不得闪断。安全区为：指针当前位置与二级菜单靠一级菜单那条边的两个端点围成的区域，连同两个菜单之间的间隙。
3. 指针位于安全区内时，即使经过一级菜单的其它项，也不关闭二级菜单、不展开其它二级菜单、不移动一级菜单的高亮。
4. 指针离开安全区，且不在一级与二级菜单之上时，二级菜单关闭。

## 4. 不在本单范围内

1. 二级菜单的展开时机、位置、尺寸与视觉不变。
2. 一级菜单的开关时机不变。
3. 菜单模态不变：菜单打开期间，菜单之外仍不出现任何 Hover 变化，指针形状不变。
4. 不判定指针的移动速度与方向意图：只要指针在安全区内就保持展开，不额外要求它朝二级菜单移动得够快。
5. 键盘操作二级菜单的行为不变。

## 5. 设计文档

本需求验收通过后，将第 3 节的关闭规则补入关联设计文档的 Submenu 章节。

# 验收

1. 按第 1 节复现路径操作，指针移出后二级菜单关闭，一级菜单仍然打开。
2. 指针从一级菜单跨入二级菜单的过程中，二级菜单保持展开，不闪断。
3. 从触发项斜向移到二级菜单靠下的项，途中经过一级菜单的其它项：二级菜单不关也不换，一级菜单的高亮仍停在触发项上。
4. 承接第 3 条，途中折返离开安全区，二级菜单关闭。
5. 指针从二级菜单移回一级菜单的其它项，二级菜单关闭，该项高亮。
6. 反复移入移出多次，行为一致，不出现关不掉或关错的情况。
7. 菜单打开期间，菜单之外的表格行、卡片、按钮、滚动条仍不跟随指针。
8. 现有自动化端到端与单元用例全部通过。
9. 关闭时机由需求方人工验收。
