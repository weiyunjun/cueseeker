# 缺陷描述

## 1. 复现

1. 在 Shiori 列表的表格行上右键打开行菜单。
2. 悬停 `Move to…` 或 `Duplicate to…`，二级菜单展开。
3. 指针移出一级与二级菜单区域，停住不动。

## 2. 现象

二级菜单不关闭，一直留在原处。

## 3. 期望

指针移出一级与二级菜单区域后，二级菜单关闭，一级菜单保持打开。指针从一级菜单跨入二级菜单的途中不算移出，二级菜单不得闪断。

## 4. 不在本单范围内

1. 二级菜单的展开时机、位置、尺寸与视觉不变。
2. 一级菜单的开关时机不变。
3. 菜单模态不变：菜单打开期间，菜单之外仍不出现任何 Hover 变化，指针形状不变。

## 5. 设计文档

本需求验收通过后，将第 3 节的关闭规则补入关联设计文档的 Submenu 章节。

# 验收

1. 按第 1 节复现路径操作，指针移出后二级菜单关闭，一级菜单仍然打开。
2. 指针从一级菜单跨入二级菜单的过程中，二级菜单保持展开，不闪断。
3. 指针从二级菜单移回一级菜单的其它项，二级菜单关闭，该项高亮。
4. 反复移入移出多次，行为一致，不出现关不掉或关错的情况。
5. 菜单打开期间，菜单之外的表格行、卡片、按钮、滚动条仍不跟随指针。
6. 现有自动化端到端与单元用例全部通过。
7. 关闭时机由需求方人工验收。
