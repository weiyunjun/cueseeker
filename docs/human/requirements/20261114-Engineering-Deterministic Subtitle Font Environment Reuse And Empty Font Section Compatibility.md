# 需求描述

1. **跨集与连续快速切换时确定性复用已预热字体排版环境**：
   - 应用启动后台静默预热完成后，在跨集打开新视频、同集内手动切换字幕轨以及连续快速切换上下句或上下集期间，有序交接上一字幕会话的释放与新字幕会话的加载，稳定复用已就绪的基础字体排版环境，消除切换并发竞争引发的重复冷启动初始化开销。

2. **系统字库变更同步刷新**：
   - 应用运行期间当系统安装、启用或移除字体时，基础字幕字体排版环境与字体别名映射同步标记失效，并在后续新建字幕会话时自动刷新生效，无需重启应用即可识别新变更的系统字体；系统字库未发生变更时，跨集与切轨全程保持复用。

3. **整文件回退路径空内嵌字体段落兼容**：
   - 未建立位置索引或因外部编辑走整文件回退读取的 ASS / SSA 字幕，若仅包含空的内嵌字体段落标题（含仅带空白或注释行的情形）而无实际内嵌字体数据，按无内嵌字体处理并正常复用共享基础字体排版环境；仅当段落内确有实际内嵌字体数据时才使用独立隔离的排版环境，且关闭后不污染共享环境。

# 验收标准

1. **单次切集与高频连切零重复冷建**：后台预热完成后，执行跨集打开、连续快速跨多集跳过及手动切换普通 ASS / SSA 字幕轨时，全程稳定复用同一套已预热的基础字体排版环境，不产生额外的字体排版环境冷启动初始化或重复扫描系统字库。
2. **字库变更感知与内嵌字体隔离准确**：触发系统字库变更后，已打开的旧会话安全释放、后续新会话自动重建并复用更新后的字体排版环境；仅含空内嵌字体段落标题的整文件回退字幕正常复用共享环境，实含内嵌字体数据的字幕独立隔离渲染且不污染后续字幕。自动化测试全部通过且对 Debug 与 Release 环境零残留。
