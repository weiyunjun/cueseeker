main
### 需求描述
移除视频内的边栏相关代码：
1. App里的视频内边栏UI代码：右侧面板本体，搜索结果 tab，当前字幕 tab，边栏开关按钮，边栏显示状态持久化。
2. 边栏初始化任务：打开视频后自动准备边栏搜索导航数据，打开视频后自动准备当前字幕列表数据，字幕路径变化时重新刷新边栏数据。
3. 边栏播放期联动：播放过程中根据当前时间持续更新“边栏当前项”，当前字幕列表为了高亮/滚动而维护的窗口数据，搜索结果边栏为了高亮/滚动而维护的窗口数据。
4. 边栏虚拟列表：搜索结果列表虚拟滚动，当前字幕列表虚拟滚动，行高计算、文本测量、滚动定位、hover/选中态这些 UI 成本。
### 注意事项
5. 不要误删“搜索结果上一个/下一个”的最小能力。
6. quick search ui的状态机设计将在下一个需求单实现，这一步先把代码删除，看看是否存在性能问题。
### 验收标准
7. 硬解同一个视频时，性能恢复到之前的水准（大致恢复即可，目前存在显著问题）。
