# 需求描述

1. **数据库无损升级与 Index 阶段 HDR 元数据采集（同步覆盖 Debug 与 Release）**：
   - 升级本地数据库结构，全新环境直接创建最新结构，已有旧版数据库（Debug 与 Release 环境）启动时自动无损升级并完整保留既有媒体库、视频、字幕、台词、观看记录与摘录等全部数据；启动升级阶段不扫描外部媒体文件。
   - 在执行 Index（含添加文件夹、`Index All`、`Index Folder`）读取视频信息阶段，对本地与远程视频统一识别并保存完整的结构化原始 HDR 元数据（含片头为普通画面、正片切入 HDR 信号的视频）：涵盖视频包含的全部 HDR 标准（杜比视界、`HDR10+`、`HDR10`、`HLG`）、杜比视界配置号（Profile）、色域、传递曲线、母带显示器色域与最小/最大亮度（`nits`）、最大内容峰值亮度（`MaxCLL`）及最大单帧平均亮度（`MaxFALL`）。
   - 升级后尚未重新执行 Index 的存量视频暂按无 HDR 展示；执行 Index 时，存量视频即使文件大小与修改时间未变也自动补读一次 HDR 元数据，普通 SDR 视频确认无 HDR 后即标记完成，后续未变更时不再重复探测；应用内重命名文件夹或单集文件时完整保留已入库的 HDR 元数据。

2. **`File` 界面视频卡片 HDR 精简展示（`L-04.6 File Card Layout`）**：
   - 在视频卡片第 2 行副标题的**简化分辨率右侧、视频编码左侧**加入 HDR 信息，依次展示为 **`<简化分辨率>  <HDR 信息>  <视频编码>  <时长>  <文件大小>`**（例如 `4K  杜比视界  HEVC  01:58:20  18.42 GB`、英文 `4K  Dolby Vision  HEVC  01:58:20  18.42 GB` 或 `4K  HDR10  HEVC  23:42  1.85 GB`），相邻项统一以 **2 个英文空格** 分隔。
   - **单一最高优先级规则**：视频包含一种或多种兼容 HDR 标准时，卡片仅按 **杜比视界 > `HDR10+` > `HDR10` > `HLG`** 展示最高优先级的 1 项；其中杜比视界随应用语言展示为 **`杜比视界`**（简体中文）、**`杜比視界`**（繁体中文）、**`Dolby Vision`**（英文），其余标准统一展示为 `HDR10+`、`HDR10`、`HLG`。
   - **缺省省略与零特殊实现约束**：普通 SDR 视频或尚未补齐 HDR 信息的视频直接省略该项（不显示占位符，不产生多余空格）；严格沿用 `L-04.6` 与 `UI Text Selection Rules.md` 既有副标题排版、自然折行、基准高度锁定与静态文本划选复制规范，禁止硬编码样式或新增私自特殊实现。

3. **`File Info` 详情弹窗 HDR 完整展示（`L-06.8 File Detail Dialog Layout`）**：
   - 在视频 `File Info` 弹窗的 `Video` 分组卡片内，于 **`Pixel Format` 下方、`Duration` 上方** 依次按需展示以下 **6 项** 属性行：
     1. **`HDR`**（英/简/繁统一为 `HDR`）：按 `杜比视界` → `HDR10+` → `HDR10` → `HLG` 顺序，以 ` / ` 分隔完整列出该视频实际包含的全部 HDR 标准；杜比视界名称随应用语言切换，并在可识别具体配置号时附带括号标注（如 `杜比视界 (Profile 8.1) / HDR10`、`杜比视界 (Profile 8.4) / HLG`、`杜比视界 (Profile 5)`、`HDR10+ / HDR10`；未标记具体配置号时仅展示杜比视界名称）。
     2. **色域**（英文：`Color Primaries`；简体中文：`色域`；繁体中文：`色域`）：如 `BT.2020`、`Display P3`。
     3. **传递曲线**（英文：`Transfer Function`；简体中文：`传递曲线`；繁体中文：`傳遞曲線`）：如 `PQ (SMPTE ST 2084)`、`HLG (ARIB STD-B67)`。
     4. **母带显示**（英文：`Mastering Display`；简体中文：`母带显示`；繁体中文：`母帶顯示`）：同时具备母带色域与最小/最大亮度时合并展示（如 `Display P3, 0.005 - 1000 nits`，亮度数值去除末尾多余 `0`）；仅具备其中一项时单独展示该项。
     5. **`MaxCLL`**（英/简/繁统一为 `MaxCLL`）：最大内容峰值亮度（如 `852 nits`）。
     6. **`MaxFALL`**（英/简/繁统一为 `MaxFALL`）：最大单帧平均亮度（如 `185 nits`）。
   - **按需隐藏与实时语言联动**：普通 SDR 视频或尚未重新执行 Index 的视频，上述 6 行全部隐藏（不显示对应行，也不显示 `-`）；HDR 视频中某项元数据缺失或 `MaxCLL` / `MaxFALL` 数值为 `0` 时，单独隐藏对应行。切换应用语言时，`File` 视频卡片与当前已打开的 `File Info` 弹窗均立即实时刷新为新语言，无需重新执行 Index 或重开弹窗。

4. **设计文档同步安排**：
   - 关联设计文档中的视频元数据字段及 `File` 卡片、`File Info` 布局描述，待本次改动验收完成后再统一提交更新。

# 验收标准

1. **数据库平滑升级与重索引补全**：Debug 与 Release 环境下的旧版数据库启动时均自动无损升级，升级后未重新 Index 前存量视频不显示任何 HDR 占位或异常行；执行 `Index All` 或 `Index Folder`（含本地与远程目录）后，存量与新增 HDR 视频准确写入 HDR 元数据，且确认无 HDR 的普通 SDR 视频与未变更视频在后续 Index 中不再重复耗时探测。
2. **`File` 视频卡片展示与排版零退步**：HDR 视频卡片第 2 行在简化分辨率与视频编码之间准确显示最高优先级单一标准（如 `4K  杜比视界  HEVC  01:58:20  18.42 GB`），普通 SDR 视频直接省略并保持 2 个英文空格分隔；卡片高度、折行、对齐与静态文本划选复制无任何退步。
3. **`File Info` 完整 6 项按需展示**：打开各类 HDR 视频（含 `HDR10`、无静态亮度数据的 `HDR10`、`HDR10+`、`HLG`、片头普通画面正片切入 `HLG` 的视频，以及杜比视界 `Profile 5 / 8.1 / 8.4 / 10.1` 等）的 `File Info`，`Pixel Format` 与 `Duration` 之间准确展示实际具备的 `HDR`（含全部兼容层与 Profile）、`色域`、`传递曲线`、`母带显示`、`MaxCLL`、`MaxFALL`，缺失项或 `0` 值亮度项单独隐藏；普通 SDR 视频完全隐藏上述 6 行。
4. **多语言实时切换与重命名保留**：切换英文、简体中文与繁体中文后，`File` 视频卡片与已打开的 `File Info` 弹窗中的杜比视界名称及属性标题立即实时切换，无需重新 Index；执行应用内文件夹或单集重命名后，HDR 展示信息完整保留。
