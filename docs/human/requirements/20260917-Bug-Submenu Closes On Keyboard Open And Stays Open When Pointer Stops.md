# 缺陷描述

## 1. 范围

所有带二级菜单的菜单：Workbench Search 表格行菜单的 Save to Excerpt List，Workbench Excerpt 表格行菜单的 Move to ... 与 Duplicate to ...，Player More Menu 的 Audio Track 与 Default Audio Track。

## 2. 缺陷一：键盘展开的二级菜单立即关闭

### 2.1 复现

1. 打开带二级菜单的菜单，指针停在二级菜单触发项之外，不再移动。
2. 用上下方向键把高亮移到触发项，按右方向键或回车。

### 2.2 现象

二级菜单展开后立即关闭。指针悬停展开没有该问题。

### 2.3 期望

1. 指针位置没有变化时，二级菜单不因指针而关闭或切换。菜单出现、重新布局引起的悬停变化不算指针移动。
2. 键盘展开的二级菜单，在指针移动之前只由键盘（左方向键、Esc、回车选中）或点击关闭。
3. 指针移动之后，按指针规则处理。

## 3. 缺陷二：指针停下后二级菜单不消失

### 3.1 复现

1. 指针悬停触发项，展开二级菜单。
2. 指针朝右下方移动，经过一级菜单的其它项，在一级菜单内停住。

### 3.2 现象

二级菜单一直不关闭，指针下的项不取得高亮。

### 3.3 期望

1. 安全区只在指针朝二级菜单移动时有效，须同时满足：
   1. 指针位于安全区内：离开触发项时的位置与二级菜单靠一级菜单那条边的两端围成的区域，连同两个菜单之间的间隙。
   2. 指针在水平方向上朝二级菜单一侧移动；只有上下移动时沿用上一次的方向。
   3. 指针停止移动不超过 300 毫秒。
2. 任一条件不满足，安全区立即失效，不需要指针再次移动：
   1. 指针在一级菜单的其它项上：该项取得高亮；该项是触发项时展开它的二级菜单，否则关闭二级菜单。
   2. 指针在一级菜单上但不在任何菜单项上：关闭二级菜单。
   3. 指针不在一级与二级菜单之上：关闭二级菜单。
3. 安全区有效期间，途经的菜单项不取得高亮，也不展开自己的二级菜单。

## 4. 不在本单范围内

1. 二级菜单的展开时机、位置、尺寸与视觉不变。
2. 一级菜单的开关规则与菜单模态不变。
3. 二级菜单内的键盘上下移动、左方向键关闭、回车选中不变。
4. 两个缺陷叠加出的其它问题，本单修复后另行观察、另案处理。

## 5. 设计文档

本需求验收通过后，将第 2.3 与 3.3 节的规则补入关联设计文档的 Submenu 章节，替换其中 Safe Area 的现有描述。

# 验收

1. 四个触发项分别用右方向键与回车展开，指针静止：二级菜单保持展开，直到按左方向键、Esc、回车选中或点击。
2. 承接第 1 条，指针移到一级菜单另一项：二级菜单关闭或切换，该项高亮；指针移出两个菜单：二级菜单关闭。
3. 按第 3.1 节复现路径操作：指针停住约 300 毫秒后二级菜单关闭，指针下的项高亮，期间不再移动指针。
4. 从触发项斜向移入二级菜单靠下的项，途中经过其它项：二级菜单不关不换，一级菜单高亮停在触发项。
5. 途中朝远离二级菜单的方向折返：二级菜单按指针所在位置立即处理。
6. 现有自动化端到端与单元用例全部通过。
7. 需求方人工验收。
