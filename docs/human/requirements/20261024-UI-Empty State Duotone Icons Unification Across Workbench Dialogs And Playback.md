# 需求描述

1. **统一空状态组件排版与视觉结构（`C-09.2 Empty State`）**：
   - 工作台各主页面、弹窗（任务面板、网络文件夹浏览第 2 步）、播放覆盖层（`Current`、`Playlist`）及命令面板二级子页面（`Search Results`、`Recent Videos`、`Recent Excerpt Lists`）的所有空状态与边界失效态，统一复用同一套居中空状态组件。
   - **视觉层级**：顶部居中展示 **`68×68px`**（基于 `256×256` 画布绘制）的系统强调色同色系双色调（Duotone）图标，图标与下方文案垂直间距为 **`14px`**；除「文件页一级界面无根文件夹」保留标题（`15px Semibold` 主文本色，与说明间距 `4px`）+ 说明文案外，其余场景统一采用「顶部图标 + 居中说明文案（`14px Regular` 次要弱化文本色，最大宽度 `380px`）」结构。
   - **命令面板补齐空状态**：命令面板的「搜索结果页」「最近视频页」「最近摘录集页」在无数据时不再留白，统一居中展示对应的空状态图标与提示文案。

2. **10 枚同色系双色调空状态图标规范**：
   - 所有空状态图标随当前主题强调色（浅色/深色模式自动适配）动态着色，通过同色系不同透明度区分层次：
     1. **搜索提示（Search Hint）**：圆角文档卡片底板 + 5 段水平文本线，右下角叠加带镂空遮罩的放大镜。
     2. **搜索/筛选无结果（Search No Results）**：与「搜索提示」共用相同的圆角卡片底板与右下角镂空放大镜，卡片左上区域替换为 `100%` 实心强调色圆头 `✕` 号。
     3. **视频（Video）**：复用圆角视频框底板 + 居中实心播放三角图标。
     4. **摘录书签（Excerpt Bookmark）**：单层圆角燕尾书签底板（不带内部横线与多层背板）。
     5. **文件夹（Folder）**：复用顶部深色页签 + 浅色主体的文件夹双色调图标。
     6. **文件夹 + 圆环 `?`（Folder + Question）**：在「文件夹」图标右下角通过圆形镂空遮罩叠加实心描边圆环与等比缩放的圆头 `?` 角标。
     7. **视频 + 圆环 `?`（Video + Question）**：在「视频」图标右下角叠加同款镂空圆环 `?` 角标。
     8. **摘录书签 + 圆环 `?`（Excerpt + Question）**：在「摘录书签」图标右下角（略微右移以保留底部燕尾缺口可见）叠加同款镂空圆环 `?` 角标。
     9. **字幕 + 圆环 `?`（Subtitle + Question）**：在双色调「字幕」图标（圆角矩形底板 + 两排圆头实心字幕横条）右下角叠加同款镂空圆环 `?` 角标。
     10. **任务托盘（Task Tray）**：上下统一底色的圆角矩形托盘底板 + 中下部内凹折线实心托盘分割线。

3. **全界面 22 个空状态与边界失效场景映射**：
   - **搜索页（Search）**：
     - 未输入搜索词（`输入搜索词以显示台词。`） $\rightarrow$ **搜索提示**
     - 搜索或筛选无结果（`未找到匹配的台词。`） $\rightarrow$ **搜索/筛选无结果**
   - **最近页（Recent）**：
     - 视频标签页为空（`还没有最近观看。`） $\rightarrow$ **视频**
     - 摘录集标签页为空（`还没有最近的摘录集。`） $\rightarrow$ **摘录书签**
   - **媒体库页（Library）**：
     - 一级总览页为空（`还没有媒体库视频。`） $\rightarrow$ **视频**
     - 二级详情页所属文件夹已移出媒体库（`该文件夹已不在媒体库中。`） $\rightarrow$ **视频 + 圆环 `?`**
   - **文件页（File）**：
     - 一级页无任何根文件夹（`没有字幕文件夹` + `选择一个包含字幕文件的本地文件夹。`） $\rightarrow$ **文件夹**
     - 二级页根文件夹仍在库中但无已入库内容（`此文件夹中没有仍在媒体库中的项目。`） $\rightarrow$ **文件夹**
     - 二级/三级页所属根文件夹已移出媒体库（`该文件夹已不在媒体库中。`） $\rightarrow$ **文件夹 + 圆环 `?`**
     - 三级页子文件夹因内部文件清空并重新索引而失效变空（`此文件夹中没有仍在媒体库中的项目。`） $\rightarrow$ **文件夹 + 圆环 `?`**
   - **摘录页（Excerpt）**：
     - 二级详情页列表无任何摘录（`从搜索结果中或在播放时保存台词，即可收集摘录。`） $\rightarrow$ **摘录书签**
     - 二级详情页搜索或筛选无匹配结果（`未找到匹配的摘录。`，含列表中仅有已失效行且触发搜索/筛选导致结果为 0 条的情况） $\rightarrow$ **搜索/筛选无结果**
     - 二级详情页当前摘录列表已被删除（`该列表已不在媒体库中。`） $\rightarrow$ **摘录书签 + 圆环 `?`**
   - **弹窗（Dialogs）**：
     - 任务面板「进行中 / 已完成 / 未完成」三个标签页为空（`没有进行中的任务。` / `没有已完成的任务。` / `没有未完成的任务。`） $\rightarrow$ **任务托盘**
     - 网络文件夹弹窗（`WebDav / SMB / FTP / NFS Folder` 第 2 步）正常浏览空子目录（`此文件夹中没有文件夹、视频或字幕文件。`） $\rightarrow$ **文件夹**
     - 网络文件夹弹窗（第 2 步）浏览中途子目录加载失败/失效（显示对应错误提示，底部 `Add` 按钮禁用） $\rightarrow$ **文件夹 + 圆环 `?`**
   - **播放覆盖层（Playback Overlay）**：
     - `Current`（当前字幕流）字幕已不在媒体库中（`此字幕已不在媒体库中。`） $\rightarrow$ **字幕 + 圆环 `?`**
     - `Playlist`（字幕播放列表）全部条目已不在媒体库中（`此播放列表中没有仍在媒体库中的项目。`） $\rightarrow$ **字幕 + 圆环 `?`**
     - `Playlist`（视频播放列表）全部视频已不在媒体库中（`此播放列表中没有仍在媒体库中的项目。`） $\rightarrow$ **视频 + 圆环 `?`**
   - **命令面板（Command Panel 二级子页面）**：
     - `Search Results` 搜索或筛选无结果（`未找到匹配的台词。`） $\rightarrow$ **搜索/筛选无结果**
     - `Recent Videos` 为空（`还没有最近观看。`） $\rightarrow$ **视频**
     - `Recent Excerpt Lists` 为空（`还没有最近的摘录集。`） $\rightarrow$ **摘录书签**

# 验收标准

1. 工作台各页面、任务面板、网络文件夹浏览第 2 步、播放覆盖层及命令面板二级子页面的全部 22 个空状态与边界失效场景，均居中显示 `68×68px` 系统强调色双色调图标与对应文案，图标与文案间距统一为 `14px`。
2. 10 枚双色调图标的造型、透明度层次及右下角镂空圆环 `?` 角标在浅色与深色模式下均随系统强调色准确渲染，无底色穿透或线条重叠瑕疵。
3. 文件页三级子文件夹因内容清空重索引变空、网络文件夹第 2 步加载子目录失败、播放覆盖层当前字幕/字幕播放列表/视频播放列表失效、以及命令面板 3 个二级子页面为空时，均能准确显示各自对应的空状态图标与多语言文案。
