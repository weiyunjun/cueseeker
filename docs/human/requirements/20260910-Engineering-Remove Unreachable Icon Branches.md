# 需求描述

1. 现状：以下界面分支在代码中定义，但运行时永远无法到达，其图标、尺寸与文案不会出现在界面上。
2. Playback Overlay 模块图标：模块切换只渲染文字标签，模块枚举的图标属性在全仓库没有任何读取点。移除该属性及其 Current、Playlist、Search、Library、Shiori 五个分支的图标定义。
3. Workbench 的 library 模式：Sidebar 只呈现 Search、Recent、Library、File、Shiori 五项，其中 Library 由 testLibrary 模式承担；页面路由不会进入 library 模式，旧版本保存的该模式在启动时落到 Search。移除 library 模式。
4. Search 页的 Library 面板：该面板在全仓库没有任何引用，从不显示，其中的信息页状态组件（九个状态）与文件夹分组视图随之从不显示。移除该面板及只被它使用的组件、状态、文案与图标。
5. 旧版搜索栏与筛选栏：Search 与 Shiori 页只使用新版搜索栏，旧版搜索栏、旧版筛选栏及只被它们使用的工具栏按钮从不显示。移除。
6. 从不使用的组件：从未被调用的带图标操作按钮，其加号图标没有其它引用；从未被使用的 Shiori 卡片分组视图及其分组标题；播放控制按钮中从未被使用的主播放样式及其图标尺寸。移除。
7. 移除后，图标登记与线宽表只保留 Icon Registry 列出的图标与尺寸。
8. 只移除上述不可达部分，不改动任何仍在显示的界面、文案与图标。移除后失去引用的本地化条目，以及只覆盖被移除内容的测试，一并移除。控件中新旧两套样式并存的分支不在本需求范围。
9. 整份不再使用的文件由所有者手动删除。

# 验收

1. 构建通过，无新增告警。

3. Icon Registry 列出的图标全部正常显示。
4. 视觉人工验收。不为本需求新增 E2E 能力。
