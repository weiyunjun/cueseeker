# 需求描述

1. **动态特效字幕首帧一帧内微差容忍同帧直出**：
   - 打开视频、拖动进度或点击字幕跳转时，字幕预备槽按请求目标时间并行预渲染首帧；当视频首帧解码就绪后的实际对齐画面时间与已预备（或正在预备完成）的字幕时间存在视频单帧级微小偏差（不超过 50 毫秒），且两者处于完全相同的生效字幕集合区间（期间无任何字幕事件开始或结束）时，直接采纳该预备字幕帧与首帧视频画面及音频同帧同步直出，不再因动态渐变、位移、卡拉 OK 等逐帧动画标签阻塞首帧门控等待二次重绘。

2. **同帧直出后静默无闪烁微调与稳态逐帧动画保持**：
   - 采用微差容忍同帧直出的动态特效字幕帧上屏后，后台静默补齐当前实际画面时间的精确渲染并原位替换字幕图层，全程不产生空帧闪烁，也不重复计入首帧同步遥测；进入正常播放后，动态特效字幕继续保持原有的逐帧平滑动画更新频率。

3. **跨句边界与超阈值偏差严格拦截及单句循环对齐兼容**：
   - 一旦视频实际首帧时间与预备字幕时间跨越任意字幕事件的起止边界（如从上一句落入下一句、从空白落入新字幕、或中途新增/结束叠加特效事件），或时间偏差超过 50 毫秒，或目标视频分辨率发生变化，严禁复用偏差预备帧，必须等待精确目标帧渲染就绪（或受限于既有首帧门控超时上限）后再上屏；既有单句循环与精准跳句在句首前 2 毫秒内的时间对齐规则保持不变，确保句首动态字幕不发生回退错句。

# 验收标准

1. **动态特效字幕同帧直出零二次阻塞**：打开或跳转至含渐变、位移、卡拉 OK 等动态特效的字幕位置时，若视频首帧实际画面时间与预渲染目标时间相差不超过 50 毫秒且未跨越任何字幕事件起止边界，首帧字幕随视频首帧同帧同步显示，不触发开闸前的二次阻塞重绘，且上屏后静默完成精确时间微调、无空帧闪烁。
2. **边界安全与单句循环零回退**：跨字幕事件起止边界或偏差超过 50 毫秒的场景绝不错显相邻句或空白帧；句首含动态特效的单句循环在首帧轻微早到（2 毫秒内）时仍稳定对齐目标句首并同帧直出。自动化测试全部通过且对 Debug 与 Release 环境零残留。
