# 需求描述

1. **通用间距**：以下 Workbench 各界面顶部操作栏/工具栏统一改为**左对齐**布局，栏内相邻元素的水平间距统一使用 `--spacing-3`（`12px`）。

2. **Search 界面（`L-05.4`）**：
   - 第二栏改为左对齐：默认态从左到右依次为「筛选按钮、结果数量」；批量选择态从左到右依次为「`退出选择` 按钮、批量选择说明文字」（第一栏搜索框维持禁用态）。

3. **Library 一级界面（`L-04.1`）**：
   - 第一栏改为左对齐，从左到右依次为「排序按钮、文件夹数量」；排序下拉菜单改为与排序按钮左边缘对齐弹出。

4. **File 全部层级界面（`L-04.5`）**：
   - 第一栏改为左对齐，从左到右依次为「`Add Folder` 按钮、`Index Now` 按钮、Index 状态信息」。
   - 第一栏与第二栏（二、三级界面的面包屑）改为顶部冻结：出现垂直滚动条向下滚动时，第一栏与第二栏固定在顶部，仅下方列表内容垂直滚动（出现横向滚动条时与下方内容同步横向滚动，同 Search 界面）。

5. **Excerpt 一级界面（`L-05.1`）**：
   - 第一栏改为左对齐，从左到右依次为「`New List` 按钮、Excerpt 数据文字」。

6. **Excerpt 二级界面（`L-05.3` / `L-05.4`）**：
   - 合并搜索栏与下方操作栏为单栏（高度 `--height-control`），随表头保持吸顶冻结。
   - 默认态左对齐，从左到右依次为「搜索框、筛选按钮、摘录台词数量」；默认铺满宽度，当可用宽度减小时，筛选按钮与摘录台词数量保持自身宽度，优先缩减搜索框宽度。
   - 批量选择态整栏切换（覆盖搜索框、筛选按钮与数量），左对齐从左到右依次为「`退出选择` 按钮、批量选择说明文字」。

# 验收标准

1. Search、Library 一级、File 各级、Excerpt 一级及 Excerpt 二级界面的操作栏/工具栏均按上述从左到右顺序左对齐排列，相邻元素间距为 `--spacing-3`（`12px`）。
2. Search 第二栏与 Excerpt 二级合并栏在批量选择模式下均左对齐展示「`退出选择` 按钮、批量选择说明文字」，Excerpt 二级界面在批量选择时覆盖原搜索框区域并在退出后恢复。
3. Excerpt 二级界面合并后的单栏默认铺满宽度，缩窄窗口时优先缩减搜索框宽度，且与下方表头吸顶高度计算准确、无遮挡或留白异常。
4. File 一、二、三级界面垂直滚动时，第一栏与第二栏（面包屑）保持顶部冻结，菜单弹出位置准确。
