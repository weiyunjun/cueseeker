# 需求描述

本需求取代此前所有关于播放页 Player UI 与指针显隐的规则，包括 20260715 需求中"播放页初始化时隐藏 Pointer"一条。

## 1. 定义

1. Player UI：播放页顶栏、底部进度条与按钮区，以及它们弹出的菜单。Player UI 隐藏时，弹出的菜单一并关闭。
2. 可交互区域：Player UI 中能被点击或能被键盘焦点到达的控件，禁用状态也算：红绿灯、返回按钮、Task 入口、Settings 入口、进度条命中区、底栏各按钮、音量控件、倍速菜单项。标题、时间显示、顶栏与底栏的空白、视频画面不算。
3. 焦点在视频播放窗口：App 在前台且主窗口是当前窗口。Playback Overlay、Command Panel 与窗口内对话框打开时焦点仍在视频播放窗口；Settings 等独立窗口、系统对话框与其它 App 取得焦点时不在。
4. 指针移动：指针位置的真实变化，含按住鼠标拖动。滚轮、点击、键盘都不算移动。

## 2. 不变量

1. 指针隐藏时 Player UI 一定隐藏；指针显示时 Player UI 可以显示或隐藏。
2. 所有规则与视频播放或暂停状态无关。

## 3. 显示

1. 进入播放页：指针与 Player UI 都显示，并开始计时。
2. Player UI 隐藏后，只有窗口内的指针移动使它重新显示。

## 4. 自动隐藏

1. 以下条件全部成立，且 3 秒内指针没有移动，指针与 Player UI 一起隐藏：
   1. 焦点在视频播放窗口。
   2. 指针在窗口内且不在可交互区域。
   3. 没有正在拖动进度条或音量滑块。
   4. 键盘焦点不在 Player UI 的任何控件上。
2. 任一条件中断，计时清零；再次全部成立时从头计 3 秒。点击不重置计时。
3. 键盘焦点一条当前没有触发路径（按钮不获得焦点，Player UI 没有输入框），只记录规则，本次不实现。

## 5. 立即隐藏

1. 指针移出窗口：Player UI 隐藏，指针保持显示。
2. 焦点离开视频播放窗口：Player UI 隐藏，指针显示。
3. 进入全屏：指针与 Player UI 都隐藏。

## 6. 同窗口上层界面

1. Playback Overlay、Command Panel 与窗口内对话框打开时，指针显示，Player UI 的状态与计时冻结。
2. 关闭时按当时的条件重新判定：条件全部成立则从头计 3 秒；指针已在窗口外或焦点已离开则 Player UI 隐藏。

## 7. Token

`docs/human/design/UI Design System.md` 1.6 动效新增：

- `--duration-player-ui-idle-hide`: `3s`

代码读取该值，不再硬编码。

# 验收

1. 从 Workbench 进入播放页：指针与 Player UI 都显示，不动鼠标 3 秒后一起隐藏。
2. 指针停在任一底栏按钮、进度条或红绿灯上不动：Player UI 与指针一直显示。
3. 指针停在标题、时间显示或视频画面上不动：3 秒后一起隐藏。
4. 打开倍速菜单，指针移到视频画面上停下：3 秒后指针、Player UI 与倍速菜单一起隐藏。
5. 打开倍速菜单，指针移出窗口：Player UI 与倍速菜单立即隐藏，指针保持显示。
6. 拖动进度条或音量滑块时指针滑出它并按住不动 3 秒：Player UI 不隐藏。
7. Player UI 显示、指针停在视频画面上 2 秒后按 K 打开 Command Panel：指针显示，Player UI 不隐藏；按 Esc 关闭后不动鼠标，再过 3 秒才隐藏。
8. 指针与 Player UI 都已隐藏时按 K 打开 Command Panel：指针显示；关闭后 Player UI 保持隐藏，不动鼠标 3 秒后指针再次隐藏。
9. 点击顶栏 Task 入口打开任务界面：指针显示，Player UI 不隐藏；关闭后不动鼠标，再过 3 秒才隐藏。
10. 点击顶栏 Settings 入口：指针显示，Player UI 立即隐藏。
11. 两者都隐藏时切到其它 App 再马上切回：指针显示，Player UI 隐藏，不动鼠标 3 秒后指针再次隐藏。
12. 点击视频画面播放或暂停：不重置计时。
13. 进入全屏：指针与 Player UI 立即隐藏；移动鼠标后都显示。
14. 以上各条在视频播放与暂停两种状态下表现一致。
