# 需求描述

## 1. 现状

指针悬停在二级菜单的触发项上后，需要等待约 300 毫秒二级菜单才展开，主观上明显延迟。

## 2. 目标

指针悬停在二级菜单触发项上时，二级菜单立即展开，不设任何等待。

## 3. 规则

1. 指针进入二级菜单触发项，二级菜单立即展开。
2. 指针从一个触发项移到另一个触发项，前一个立即收起，后一个立即展开。
3. 点击触发项与键盘右方向键的展开行为不变，仍为立即展开。

## 4. 不在本单范围内

1. 指针移出一级与二级菜单区域后二级菜单不消失的缺陷，另案处理。
2. 二级菜单的位置、尺寸与视觉不变。

## 5. 设计文档

本需求验收通过后，将第 3 节规则补入关联设计文档的 Submenu 章节。

# 验收

1. 指针滑到 `Move to…` 或 `Duplicate to…` 上，二级菜单随即出现，无可感知等待。
2. 在两个触发项之间来回移动，二级菜单跟随切换，不残留上一个。
3. 点击触发项、键盘右方向键展开二级菜单的行为与之前一致。
4. 现有自动化端到端与单元用例全部通过。
5. 展开的即时程度由需求方人工验收。
