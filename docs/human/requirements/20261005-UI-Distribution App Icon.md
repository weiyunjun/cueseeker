# 需求描述

## 1. 目标
为正式打包发布的 macOS 应用程序（Distribution App）配置应用图标。本地开发及 Debug 构建保持现状（不设置自定义图标/使用系统默认），以便于直观区分开发环境与正式打包产物。

## 2. 图标设计规格
1. **核心图形**：
   - 采用标准内聚式“放大镜（Seek） + 双行长短字幕条（Cue）”组合造型。
   - 放大镜为厚实圆环与 45° 饱满短柄，两行字幕条居中内嵌于镜框内。
2. **底板规范**：
   - 遵循 macOS 规范，主体居中置于标准圆角矩形（Squircle）底板之上。
3. **输出规格**：
   - 提供标准 `AppIcon.icns`，完整覆盖 16×16 至 1024×1024 各级分辨率（含 @1x 与 @2x Retina）。

## 3. 应用生效范围
1. **打包产物**：
   - 打包脚本生成的 `CueSeeker.app` 包含该应用图标，在 Dock、Finder、调度中心及关于面板正常显示。
2. **Debug 构建**：
   - 本地开发/Debug 运行保持原样，不注入自定义应用图标。
