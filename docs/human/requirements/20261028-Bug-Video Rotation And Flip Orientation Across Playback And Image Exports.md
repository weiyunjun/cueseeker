# 需求描述

1. **播放页视频画面与字幕画布按方向标记自动转正**：
   - 对携带旋转角度（90° / 180° / 270°）与镜像翻转（水平 / 垂直翻转）方向标记的本地及远程视频（如手机竖拍或倒拍视频），在硬件加速解码与软件解码下均按方向标记将视频画面自动旋转、翻转至正确朝向展示（若同时含非 `1:1` 像素拉伸比，先按像素拉伸比还原比例，再应用旋转与翻转变换并对调宽高），避免竖拍视频横躺或倒拍视频上下颠倒。
   - 播放页字幕图层（含 SRT 与 ASS 字幕）统一按方向标记转正后的实际显示画幅计算画布区域、边距、字号缩放与定位坐标，确保字幕排版在竖屏或翻转后的视频画面上准确对齐。

2. **封面、预览缩略图与各类截图导出统一按转正后方向输出**：
   - 对携带旋转或翻转方向标记的本地及远程视频，以下图像生成与导出均统一输出按方向标记转正后的画面：
     - Library 与 Recent 剧集自动封面生成；
     - 播放页进度条悬停/拖拽预览缩略图（预览缩略图尺寸与宽高比同步按转正后的画幅比例展示）；
     - 播放页当前画面截图（含无字幕与带字幕截图，带字幕截图的字幕排版与播放页转正画面一致）；
     - 台词截图与长图拼接（Collage）预览、复制及导出；
     - Export to Anki 导出的卡片配图。

3. **视频「文件详情」分辨率按旋转方向修正宽高展示**：
   - 在 File 页面打开视频文件的「文件详情」弹窗（`L-06.8 File Detail Dialog Layout`）时，若视频携带 90° 或 270° 旋转方向标记，`File Details -> Resolution`（视频分辨率）一栏将存储宽高对调后展示（如存储为 `1920×1080` 且带 90° 旋转标记的手机竖拍视频展示为 `1080 × 1920`）；其余未发生宽高对调的视频保持展示原始存储分辨率。

# 验收标准

1. 播放携带旋转（90° / 180° / 270°）或镜像翻转标记的本地及远程视频（涵盖硬件加速解码与软件解码）时，播放页视频画面均自动转正展示，SRT 与 ASS 字幕的画布范围、字号比例及位置均与转正后的画面严格对齐。
2. 上述带方向标记的视频所生成的剧集封面、播放进度条预览缩略图、播放器当前画面截图（无字幕与带字幕）、台词截图与长图拼接（Collage）以及 Anki 导出配图，画面方向与宽高比均转正无误。
3. 在 File 页面查看携带 90° 或 270° 旋转标记的视频「文件详情」时，`Resolution` 一栏准确展示宽高对调后的竖屏分辨率（如 `1080 × 1920`）。
