# 需求描述

1. **音画字首帧同步呈现（消除先出画面与人声、后闪出字幕的割裂感）**：
   - 在打开新视频（挂载可见字幕时）、切换至上/下一条台词或在同一视频内执行进度跳转时，顶栏标题与左上角导航反馈仍立即响应；播放画面保持上一帧平滑过渡，待目标视频首帧、音频与目标时间点的首帧字幕（含 ASS / SSA 与 SRT；目标时间点本身处于无台词空白段时以完成空白段判定为准）同时准备就绪后，在同一帧同步上屏并起播音频。
   - 当播放无外挂字幕的视频或用户已隐藏字幕时，不引入任何字幕等待；在播放页内手动切换可见字幕轨时，待目标字幕首帧就绪后平滑替换当前字幕显示。
   - 首帧字幕匹配与进度结算须与现有的 `Repeat` 帧对齐规则兼容：当解码首帧时间戳略早于跳转目标时间但处于 `2ms` 帧对齐容差范围内时，首帧字幕按对齐后的目标时间点匹配展示，不得引发 `Repeat` 倒回上一句或首帧短暂漏字。

2. **字幕直接读取失败与等待超时的严格区分**：
   - **字幕读取失败**（文件缺失、无读取权限、远程字幕无法读取或内容损坏）：立即结束字幕等待，放行视频画面与音频正常播放，不渲染该字幕，并在播放窗口左上角弹出既有红色报错横幅（保持既有文案与消失规则不变）。
   - **字幕准备等待超时**：超时计时**严格从目标视频首帧已解码就绪的时刻开始起算**（远程视频缓冲等视频侧耗时不计入字幕超时），上限为 `1` 秒（`1000ms`）。若视频首帧就绪后满 `1` 秒目标首帧字幕仍未就绪，立即放行视频与音频正常起播且**不弹出红色报错横幅**，待后台字幕准备完成后自动补上显示（若后台最终确认为读取失败，再按失败规则弹出红色报错横幅）。连续快速切换目标时，旧请求的等待与超时立即作废，仅对最新目标生效。

3. **按需局部加载已索引 ASS / SSA 字幕与未索引回退（播放期纯只读）**：
   - 播放已建立有效位置索引且文件指纹校验通过的本地或已缓存远程 ASS / SSA 字幕时，无需读取整份字幕文件，按目标时间窗口局部读取所需事件内容完成首帧及后续连续播放渲染（完整保留同一时间戳多语种台词及跨样式特效顺序）；同一集内跳转或连续切换台词时复用已校验索引，不重复做整表校验或全量读取。
   - 当存量字幕尚未执行过 Index、标记为不适用局部加载，或外部编辑修改了字幕文件导致指纹失效时，自动无缝回退为整文件读取并正常完成渲染；播放全流程对数据库严格保持纯只读，严禁在非 Index 流程写入或更新数据库。

4. **字幕字体环境启动静默预热与跨集复用**：
   - 应用启动后在后台静默预热字幕字体排版环境（不阻塞主界面启动与交互），并在跨集连续播放及切换字幕时复用已就绪的基础字体环境，消除冷启动首次播放与跨集切换时重复扫描系统字库造成的额外首帧等待。

# 验收标准

1. **音画字同帧齐出且切换无回归**：冷启动首次打开视频、在搜索结果或摘录集队列中连续切换上下句（含短促台词、双语同轴台词及数万行超大特效 ASS / SRT 字幕）、以及同集跳转与连续触发 `Repeat` 时，新画面、人声与对应首帧字幕同步出现，无“先出画面与语音、后闪出字幕”的二次跳变，且 `Repeat` 稳定重播当前台词不倒回上一句。
2. **局部加载、外部改动回退与纯只读合规**：已执行 Index 的本地与远程缓存 ASS / SSA 字幕按需局部加载且字体、样式与特效渲染准确无缺失；未执行 Index 的存量字幕或外部修改后的字幕自动回退并正常渲染；播放全过程对数据库零写入。
3. **超时放行与读取失败报错准确区分**：慢速远程视频缓冲期间不会误触发字幕超时；视频首帧就绪后若极端情况下字幕准备超过 `1` 秒，视频与音频按时放行且不误弹红色报错横幅，后续字幕就绪后自动显示；字幕文件缺失、无权限或损坏时，视频照常播放并在左上角准确弹出红色报错横幅。诊断日志耗时统计准确，自动化测试全部通过且对 Debug 与 Release 环境零残留。
