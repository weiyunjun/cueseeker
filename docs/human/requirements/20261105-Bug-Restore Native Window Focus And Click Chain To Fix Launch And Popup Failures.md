# 需求描述

1. **恢复启动即显示主窗口与原生焦点激活**：
   - 应用启动时第一时间创建并弹出主窗口，不在主窗口显示前阻塞执行视频播放器等非首屏重资源初始化。
   - 主窗口与独立设置窗口的显示、前置及焦点状态完全交由系统原生机制管理，移除人为伪造窗口焦点状态、篡改屏幕外鼠标坐标、在鼠标按下半途插队重激活窗口及注入假鼠标事件等特殊拦截逻辑。

2. **保证全界面按钮点击、弹出菜单与独立窗口正常响应**：
   - 点击 File 页面“添加文件夹”按钮、顶部栏“设置”按钮及各界面按钮/右键入口时，正常弹出对应的下拉菜单、右键菜单或独立设置窗口，不得出现点击无反应或被中途打断的情况。
   - 保持白名单按钮“左键按下呈现 `Pressed`、按住移出热区退回未按下外观、在热区外松开不触发”的既有交互表现。

3. **保持窗口失焦清空并抑制 `Hover` 的表现**：
   - 当切换应用或窗口失去系统焦点（如打开独立设置窗口覆盖在主窗口之上）时，失焦窗口立即清除活跃的 `Hover` 高亮（因上层菜单或弹窗打开而冻结保持的下层高亮及 `Select` 状态除外）并将指针恢复为默认箭头；窗口处于后台失焦期间鼠标滑过不产生 `Hover`；窗口重获系统焦点时按当前指针位置恢复 `Hover`。

# 验收标准

1. **跨设备每次启动正常显示并聚焦主窗口**：将打包后的应用放置在任意目标 Mac 上，每次双击启动均立即显示主窗口并正常获得系统焦点（左上角红绿灯亮起彩色），无需等待或再次点击 Dock 栏图标。
2. **核心按钮与弹出界面正常可用**：启动进入应用后，点击 File 页面的“添加文件夹”按钮立即弹出下拉菜单，点击顶部栏“设置”按钮立即弹出独立设置窗口，所有二级菜单与弹窗交互正常。
3. **按下移出取消与后台失焦无 `Hover` 正常生效**：
   - 在任意按钮上按下鼠标左键后拖出按钮区域再松开，按钮不触发点击动作。
   - 切换到其他应用或打开设置窗口使下层窗口失焦（红绿灯变灰）时，失焦窗口内原有的 `Hover` 高亮立即清除，且鼠标在失焦窗口上移动时不出现任何 `Hover` 高亮或手型指针。
