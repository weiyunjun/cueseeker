# 需求描述

1. **常规左键点击统一为「按下不限时 + 在原目标内松开生效」**：
   - 所有按钮、卡片、列表行、复选框及画面点击动作，左键按住期间不设时长上限；松开左键时若指针仍位于按下时的同一目标热区内则触发动作，若按住期间移出该目标热区再松开则取消触发。
   - 统一修正以下此前存在「按住片刻再松开不生效」或「按下瞬间立即生效」的位置：
     - **视频卡片**：Recent 页面、Library 二级页面、Playback Overlay 播放列表、Command Panel 最近视频中的视频剧集卡片；
     - **File 页面卡片**：File 列表中的文件夹卡片点击进入子目录；
     - **播放页舞台区域**：点击视频画面及黑边切换播放/暂停；
     - **远程目录选择弹窗（WebDAV / SMB / FTP / NFS）**：目录列表行的单击选中与双击进入子目录（双击仅限制两次点击间隔，不限制单次按住时长）；
     - **设置页字幕颜色控件**：颜色预览块的点击打开取色面板；
     - **Search 与 Excerpt 表格行勾选**：点击行首勾选框、批量选择模式下点击整行切换勾选、以及 Shift 连续勾选（非批量选择模式下按住左键拖拽仍正常划选字幕文字）；
     - **长截图编辑器（Collage Editor）右侧字幕列表**：点击右侧字幕行或勾选框切换勾选状态。

2. **保持「按下瞬间立即生效」的交互场景不变**：
   - **右键菜单**：遵循 macOS 原生规范，右键按下瞬间立即弹出菜单（含菜单打开期间右键点击其他带菜单目标时立即切换菜单）。
   - **消极关闭与清除动作**：菜单或下拉面板打开时在外部按下左键立即关闭、表格有文字选区时按下左键立即清除选区、快捷键录制时在外部按下左键立即结束录制。
   - **连续追踪与聚焦动作**：播放进度条与音量条按下并拖拽、字幕文本划词选择、输入框按下获取光标焦点、窗口顶栏按下拖拽移动窗口。

# 验收标准

1. 在上述所有卡片、远程目录行、播放页画面、设置页颜色块上按住左键停留任意时长后在原目标内松开，动作均正常生效；按住期间将指针移出目标后再松开，动作取消不触发。
2. 在 Search / Excerpt 表格中点击行勾选框或批量选择下点击整行，以及在长截图编辑器右侧点击字幕行勾选时，按下左键期间状态不变，松开左键后才切换勾选；按住移出目标后再松开不触发勾选变化。
3. 右键按下立即弹出菜单、点击外部按下立即关闭菜单/清除选区、进度条/音量条拖拽与文字划选等既有行为保持不变。
