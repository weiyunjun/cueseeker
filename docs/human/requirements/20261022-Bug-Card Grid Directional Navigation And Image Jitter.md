# 需求描述

1. **卡片网格方向键（及手柄方向键）导航规则**：
   - 在 Command Panel「最近视频」「最近摘录」及播放页「播放列表」的卡片网格中，严格按当前界面实际排布的每一排与每一列位置进行导航。
   - **左 / 右方向键**：仅在当前排内向左或向右移动一格；若当前已处于该排最左侧或最右侧，保持当前选中卡片不变，不跨排移动。
   - **上 / 下方向键**：向紧邻的上一排或下一排移动，优先选中相邻排同一列位置的卡片；若相邻排卡片数量较少、同一列位置没有卡片，则选中相邻排最右侧（即左侧最近）的卡片；若当前已处于第一排按上键、或已处于最后一排按下键，保持当前选中卡片不变。

2. **卡片网格布局与滚动的视觉稳定表现**：
   - 在不同窗口宽度（含窄窗口少列布局）及列表滚动场景下，卡片的封面图、选中背景框与文字标题始终保持完整对齐，不出现封面或背景框错位漂移。
   - 连续按方向键导航时，若目标卡片已在当前可视区域内完整显示，列表保持静止不滚动；若目标卡片超出可视区域触发列表滚动，画面平滑定位，不出现图片跳动或画面闪烁。

# 验收标准

1. 在 Command Panel「最近视频」或「最近摘录」中，当上一时间分组的最后一排不足整排列数（如第 2 排仅有第 1 个卡片），从下一分组第一排（第 3 排）的第 2、3、4 个卡片按方向「上」键时，选中焦点均准确落到第 2 排第 1 个卡片，不会跳过第 2 排直接跳到第 1 排。
2. 在卡片网格中，处于任意一排最左侧按「左」键、最右侧按「右」键、第一排按「上」键、最后一排按「下」键时，焦点均保持在原卡片不动，不会跨排或跳向同行其他卡片。
3. 在较窄窗口宽度（如每排显示 2 列或 1 列卡片）或调整窗口宽度后打开、浏览、滚动卡片网格时，所有卡片的封面图、选中底框与标题文字位置完全对齐，不出现封面或选中底框脱离卡片漂移的现象。
4. 在 Command Panel「最近视频」「最近摘录」及播放页「播放列表」中连续按方向「上 / 下」键往返导航并触发列表滚动时，卡片与封面图片保持稳定，不出现图片明显跳动或画面闪一下的现象；回到第一排时顶部分组标题完整展示不被截断。
