# 需求描述

1. **摘录集两类数量展示口径**：
   - **完整有效摘录总数 `xx`（不受摘录集内搜索关键词、筛选条件、排序方式影响）**：
     - 各处摘录集封面卡片左下角角标（`xx cues`，含 `Excerpt` 一级总览、工作台 `Recent -> Excerpt Lists`、播放页 `Command Panel -> Recent Excerpt Lists`）及 `Excerpt` 一级总览顶部汇总统计；
     - `Excerpt` 二级界面顶部 `Cover Summary` 标题下方第 1 行（`xx excerpts  Created yyyy-MM-dd`）。
   - **当前过滤后可见有效摘录数 `yy`（随该摘录集当前的搜索关键词与筛选条件实时变化）**：
     - `Excerpt` 二级界面工具栏下方统计（`yy excerpts`）；
     - `Excerpt` 二级界面顶部 `Cover Summary` 进度区域分母（`#x / yy` 中的 `yy`），两者始终严格相等。已展示页面处于后台资料库变更冻结状态时，顶部进度与数量随下方表格一起维持冻结；页内删除/移走有效摘录或解冻刷新时同步更新。

2. **「目标摘录」记录与生命周期**：
   - 每个摘录集仅在发生**实际播放行为**时写入或更新其目标摘录记录与最近播放时间；保存新摘录、切换排序、修改搜索/筛选或界面回退展示均不改写目标摘录记录。
   - **删除/移走或资料库失效即永久清空（不可自动恢复）**：当已记录的目标摘录从该摘录集中被手动删除/移走，或因所属文件夹移出媒体库、重新索引导致原台词失效时，**立即永久清空该摘录集的目标摘录记录**（不再自动改写绑定到第 1 条有效摘录；该摘录集在 `Recent` 中所属的历史播放时间分组维持不变；即便后续未播放其它摘录又将该文件夹重新加回媒体库，也保持清空状态不自动恢复）。
   - **搜索或筛选排除为临时回退（可自动恢复）**：当目标摘录在媒体库中仍有效，仅因当前表内搜索关键词或筛选条件未命中而不在结果中时，保留原目标摘录记录；清空搜索词或放宽筛选使其重新命中（且期间未实际播放其它摘录覆盖）后，立即恢复指向原目标摘录。

3. **`Excerpt` 二级界面顶部 `Cover Summary` 三态规则（禁止硬编码与私自特殊实现）**：
   - 设该摘录集在当前搜索关键词与筛选条件下的可见有效摘录数为 `yy`：
     - **`Resume` 态**：`yy > 0`，且存在未清空的有效目标摘录并在当前搜索与筛选结果中命中 → 显示进度区域 **`#x / yy  <目标台词内容>`**（进度条比例为 `x / yy`，`x` 为该条在当前搜索、筛选、排序下的 1-based 有效序号）+ 主按钮 **`Resume`**。
     - **`Play` 态**：`yy > 0`，但当前无命中的目标摘录（统一覆盖**从未播放过**、**原目标摘录因删除/移走或失效已被清空**、**原目标摘录被当前搜索词或筛选条件临时排除**）→ 统一显示进度区域 **`#1 / yy  <当前第 1 条有效台词内容>`**（进度条比例为 `1 / yy`，随排序、搜索、筛选变化实时对应当前第 1 条有效摘录）+ 主按钮 **`Play`**。
     - **`Disabled` 态**：**`yy = 0`**（含空列表、全部摘录失效，或列表虽有完整有效摘录 `xx > 0` 但被当前搜索词/筛选条件过滤为 `0` 条）→ **隐藏进度区域** + 主按钮显示为禁用（`Disabled`）状态的 **`Play`**。
   - `Library` 二级界面（文件夹详情页）在文件夹从未观看过时，维持隐藏进度区域 + `Play` 按钮的既有表现不变。

4. **多入口打开摘录集播放行为完全一致**：
   - 各摘录集独立维护其持久化的筛选条件、排序方式，以及应用运行期间按摘录集保留的表内搜索词（重启清空）；播放页内维持不提供修改摘录集搜索/筛选/排序且不支持删除摘录的既有规则。
   - 无论从工作台 `Recent -> Excerpt Lists` 点击卡片、从播放页 `Command Panel -> Recent Excerpt Lists` 点击卡片，还是从 `Excerpt` 二级界面点击 `Cover Summary` 的 `Play` / `Resume` 按钮打开某摘录集，均严格基于该摘录集当前生效的**「搜索关键词 + 筛选条件 + 排序方式」**解析有效播放序列（共 `yy` 条）：
     - **`yy = 0`**：拦截播放、不进入播放页（播放页 `Command Panel` 保持打开）、不记录或刷新最近播放时间，在界面右下角弹出 3 秒 `No Available Excerpts` / `没有可用的摘录` / `沒有可用的摘錄` 警告 Toast（含未刷新的冻结态二级界面点击按钮时后台已无匹配有效项的场景）。
     - **`yy > 0`**：存在命中的有效目标摘录则从该条（`#x`）继续播放，否则从当前第 1 条有效摘录（`#1`）开始播放；进入播放页后的播放列表（`Playlist`）内容、顺序及上/下一条切集范围，与在 `Excerpt` 二级界面直接点击下方表格行进入播放完全一致；实际触发播放后将该条记为新的目标摘录并更新最近播放时间。

5. **设计文档同步安排**：
   - 关联数据、业务与 UI 设计文档待本次改动验收完成后再统一提交更新。

# 验收标准

1. **两类数量口径与实时联动**：摘录集含 `100` 条有效摘录时，输入搜索词或设置筛选使表格仅剩 `20` 条有效摘录——各处封面卡片角标与 `Excerpt` 二级界面标题下方仍显示 `100 cues` / `100 excerpts`，而工具栏显示 `20 excerpts`、顶部进度分母显示 `/ 20`；页内删除 `1` 条有效摘录后，两类计数同步变为 `99` 与 `19`。
2. **`Cover Summary` 三态与目标摘录回退/恢复**：
   - 新建或从未播放但含有效摘录的摘录集，二级界面顶部显示 `#1 / yy  <第 1 条台词>`、进度条 `1 / yy` 与 `Play` 按钮；未点击播放时切换排序，`#1` 台词内容随之实时更新，按钮保持 `Play`。
   - 播放到第 `10` 条（显示 `#10 / 100` + `Resume`）后：
     - 输入搜索词或设置筛选将该条排除（剩余 `20` 条有效项），顶部回退为 `#1 / 20  <当前第 1 条台词>` + `Play`；清空搜索词或放宽筛选后，自动恢复为 `#10 / 100  <原第 10 条台词>` + `Resume`；切换排序时 `#x` 实时更新为新位置。
     - 手动删除或移走第 `10` 条后，顶部立即变为 `#1 / 99  <第 1 条台词>` + `Play`（不再显示 `Resume`）。
     - 将第 `10` 条所属文件夹移出媒体库使其失效后，顶部变为 `#1 / yy` + `Play`；期间未播放其它摘录又将该文件夹重新加回媒体库，仍保持 `#1 / 100` + `Play` 不自动恢复，且该摘录集在 `Recent` 中的历史播放时间分组不变。
   - 当列表无有效摘录，或虽有 `100` 条有效摘录但被当前搜索词/筛选条件过滤为 `0` 条时，二级界面标题下方仍显示完整有效数（如 `100 excerpts`），进度区域隐藏，主按钮为禁用的 `Play`；`Library` 二级界面未观看文件夹维持隐藏进度区域 + `Play` 按钮不变。
3. **三处播放入口行为一致性**：为某摘录集设置搜索词、筛选条件与非默认排序后，分别从工作台 `Recent -> Excerpt Lists`、播放页 `Command Panel -> Recent Excerpt Lists` 以及 `Excerpt` 二级界面 `Play` / `Resume` 按钮打开该摘录集：
   - 当过滤后有效摘录 `yy > 0` 时，三处起播条目一致（目标摘录命中则播 `#x`，未命中则播 `#1` 并在起播后更新目标摘录使二级界面变为 `Resume`），且播放页 `Playlist` 与上/下一条切集顺序完全符合该列表当前的搜索、筛选与排序；
   - 当过滤后有效摘录 `yy = 0`（即使卡片角标显示 `100 cues`）时，在两处 `Recent Excerpt Lists` 点击卡片（或在未刷新冻结态二级界面点击按钮）均不进入播放（播放页 `Command Panel` 保持打开）、不更新最近播放时间，并在右下角弹出 3 秒 `No Available Excerpts` / `没有可用的摘录` / `沒有可用的摘錄` Toast。
