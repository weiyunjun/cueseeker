# 需求描述

1. **`Open` 态的表现绑定与状态退出规则**：
   - 挂载菜单的控件（如 `...` 按钮、排序按钮等）在菜单打开时进入 `Open` 态，“弹出的菜单界面”与“控件的灰色底高亮”共同构成 `Open` 态的表现。
   - 当控件的状态从 `Open` 切换为关闭（`Close`）时，属于 `Open` 态的所有表现（菜单界面与控件灰色底）必须同步消失并退回默认状态（仅当此时界面未处于菜单冻结且鼠标实际仍停留在该控件上时，才进入 `Hover` 态），严禁在退出 `Open` 态后残留灰色底样式。

2. **同一层级弹出新菜单时的 `Open` 态互斥转换**：
   - 同一界面层级内同一时刻最多只能存在一个处于 `Open` 态的菜单。
   - 当在同一层级通过右键（或点击）打开新菜单时，会将同一层级已有的 `Open` 态切换为关闭（`Close`），原控件随之退出 `Open` 态（收起旧菜单并清除原控件灰色底），随后新菜单进入 `Open` 态。

# 验收标准

1. 在 Excerpt 二级界面点击封面摘要区 `...` 按钮或工具栏排序按钮打开菜单后，在下方字幕表格区域点击鼠标右键弹出表格右键菜单：原菜单立即关闭，且 `...` 按钮或排序按钮的灰色底同步消失。
2. 在 Search 界面（及 Command Panel 搜索结果页）点击工具栏排序按钮打开菜单后，在下方字幕表格区域点击鼠标右键弹出表格右键菜单：原排序菜单立即关闭，且排序按钮的灰色底同步消失。
3. 在各界面通过点击菜单外部、按 `Esc` 键或触发同层其他菜单使已打开的菜单变为关闭时，原触发按钮的菜单与灰色底均同步消失（仅在无新菜单冻结且鼠标当前仍停留在原按钮上时显示 `Hover` 态）。
