# 需求描述

1. **停留期间保持冻结**：
   - 在执行 `Remove Folder`、`Index` 或 `Add Folder` 期间及任务完成时，若当前正停留在 Search 界面，保持当前搜索结果不变，不主动刷新、不闪烁。

2. **Search 界面再次出现时以数据库实际变更结果区分更新**：
   - 当离开 Search 界面后再次进入（包括点击后退/前进导航、跨左侧栏标签页切回、或从播放页返回）且当前存在搜索结果/搜索词时，以期间数据库索引内容是否发生实质性变化及变更结果为准：
     - **数据库无实质性变化**（如执行 `Index` 但文件均未改动、添加空文件夹或移除空文件夹）：保持当前搜索结果不变，不重新发起搜索。
     - **仅发生过内容移除（`Remove Folder` 实际移除了已入库内容）**：不重新发起搜索，仅从当前已有搜索结果、结果总数与 Filter 筛选项计数中直接剔除已不在资料库中的失效条目，保留原有排序与滚动位置。
     - **发生过 `Index` 或 `Add Folder` 且产生数据库内容变化（无论期间是否同时移除过文件夹）**：按当前搜索词与已选 Filter 筛选条件重新执行搜索，使新增命中的台词、被修改后不再命中的台词以及文字更新后的台词均同步为最新状态。

# 验收标准

1. **停留不刷新**：搜索出结果后，去 File 页触发 `Remove Folder`、`Index` 或 `Add Folder` 并立即切回 Search 页等待任务完成，停留在 Search 页期间列表不发生刷新或闪烁。
2. **无实质变更再次出现不重搜**：搜索出结果后，在未改动任何文件的情况下执行 `Index`（或添加/移除空文件夹），完成后离开再回到 Search 页，保持原有结果不变，不触发重新搜索。
3. **仅移除内容后再次出现**：搜索词命中多个文件夹的结果（如共 4 条），移除其中一个文件夹（含 2 条结果）并切回 Search 页等待完成，随后点击后退再前进（或切 Tab 再切回），搜索结果不重搜而直接剔除失效项，更新为剩余 2 条，结果总数与 Filter 计数同步更新。
4. **执行 Index 或 Add Folder 产生变更后再次出现**：搜索出结果后，修改字幕文件（产生新命中或修改已命中台词文字）执行 `Index`，或执行 `Add Folder` 导入有有效字幕的新文件夹，待任务完成后通过后退再前进（或切 Tab 再切回、从播放页返回）回到 Search 页，自动重新执行搜索并展示最新命中结果与台词内容。
