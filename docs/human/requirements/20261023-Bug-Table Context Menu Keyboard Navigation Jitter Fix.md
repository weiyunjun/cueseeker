# 需求描述

1. **消除弹出菜单在打开与键盘/手柄导航时的画面抖动**：
   - 在 Search 界面与 Excerpt 二级界面等表格中打开行操作菜单（右键菜单或 `...` 按钮菜单）及二级子菜单时，菜单外框与内部各选项行位置必须一次性稳定落位，不得出现亚像素偏移或连续跳变。
   - 当菜单处于完整展开（无滚动条）状态时，使用键盘方向键（`↑` / `↓`）或手柄快速切换高亮选项期间，菜单外框与所有选项行必须保持绝对静止，不得触发无效滚动或产生抖动。
   - 当菜单因窗口可用空间受限而出现滚动条时，仅在切换高亮选项需要保持目标项可见时平滑滚动列表，已处于可视区域内的选项间来回切换时不得产生额外抖动。

# 验收标准

1. 在 Search 界面与 Excerpt 二级界面的字幕表格任意位置点击右键打开菜单，不动鼠标，使用键盘 `↑` / `↓` 方向键在相邻选项间快速交替按键导航：菜单外框、文字、快捷键与高亮底色均保持稳定，无任何上下或左右抖动。
2. 打开带有二级子菜单的选项（如“保存到…”、“移动到…”、“复制到…”）并在主菜单与子菜单中使用方向键快速切换选项时，主菜单与子菜单均无抖动。
3. 缩小窗口高度使表格右键菜单或子菜单出现滚动条：打开瞬间菜单稳定无跳变；使用 `↑` / `↓` 方向键在可视区域内切换选项时画面完全静止，超出可视区域时正常滚动将高亮项带入视野。
