# 缺陷描述

## 1. 复现与现象

**症状一**

1. 在工作台表格中点击字幕文本进入播放页。
2. 播放期间移动指针，关闭视频回到工作台，把指针停在 Sidebar 上。

指针全程保持手型。只有指针回到工作台内容区（封面卡片、搜索栏、表格所在的那块区域）时，才恢复箭头。

**症状二**

1. 指针停在表格的非 Cue 列上，此时指针正常。
2. 滚动滚轮。

指针变成手型。

## 2. 期望

1. 手型只在指针位于表格内可播放字幕文本上时出现。
2. 指针以任何方式离开可播放字幕文本后恢复箭头，包括移动、滚动、被更高层覆盖、切换页面。
3. 工作台被播放页或对话框覆盖时，指针恢复箭头。

## 3. 不在本单范围内

1. 三处手型区域的位置与生效条件不变。
2. 卡片手型的 macOS 版本差异不变。
3. 播放页无操作三秒后隐藏指针的行为不变。
4. 菜单打开期间指针保持箭头的行为不变。

## 4. 设计文档

本单不新增视觉规则，`docs/human/design/UI Application Rules.md`「指针」章节的现有规则不变。

# 验收

1. 点击字幕文本进入播放页，指针立即为箭头。
2. 承接第 1 条，在视频上移动指针，仍为箭头。
3. 承接第 1 条，关闭视频回到工作台，指针停在 Sidebar 上为箭头。
4. 指针停在表格的非 Cue 列上滚动滚轮，指针不变成手型。
5. 字幕文本上仍为手型，指针移出后恢复箭头。
6. 表格可选文本仍为 I 型指针，滚动条仍为箭头。
7. 现有自动化端到端与单元用例全部通过。
8. 指针形状由需求方人工验收。
