# 需求描述

1. **深度诊断埋点的工程级收集开关**：
   - 提供统一的工程级配置开关，支持设置为“仅 Debug 收集”或“Debug 与 Release 均收集”（不在用户界面暴露开关）。
   - 当开关设为“仅 Debug 收集”时，Release 构建仅输出常驻日志；当开关设为“Debug 与 Release 均收集”时，Release 构建同步收集深度诊断埋点（含界面跳转与详情页加载耗时拆解、弹窗打开耗时与动画指标、播放区间汇总指标、搜索翻页加载耗时、常规路由与进度跳转记录），并按既有目录隔离规则写入 `logs/release/` 下的按日日志文件。

2. **刷屏与冗余日志清理**：
   - **移除单张静态图正常渲染日志**：进度条缩略图预览、媒体库封面、当前帧截图、长截图与 Anki 导出图片渲染时，不再逐张记录正常渲染日志；仅当单张图解码与渲染总耗时达到或超过 `200ms` 时记录慢渲染警告。
   - **修复主线程卡顿误报并上调阈值**：主线程卡顿监控剔除事件循环轮次退出至下一轮进入之间的空闲等待间隔（`exit -> entry`），并将卡顿记录阈值由 `32ms` 调整为 `200ms`。
   - **播放心跳改为区间汇总与限流警告**：取消视频播放期间每秒一次的周期性心跳日志，改为在暂停、跳转或停止播放时输出一次该播放区间的平均/最大解码耗时、渲染耗时、包等待耗时、音画同步偏差与掉帧数汇总；单帧过慢或音画偏差超标警告增加 `5s` 限流防抖。
   - **精简菜单流水账与重复日志**：弹出菜单与浮层面板打开、菜单项点击在 Release 下仅于打开耗时达到或超过 `100ms` 时记录慢响应警告；修复摘录集简介浮层打开时重复记录两条日志的问题，并将所有弹窗打开日志中的随机 UUID 标识替换为可读的弹窗类型名称；移除与上层播放请求重复的底层属性赋值及同会话跳转资格判断日志。

3. **Release 日志观感优化与高价值诊断提级**：
   - **Release 隐去搜索词与台词原文**：在 Release 构建中，主界面搜索、摘录集内搜索、命令面板预填与搜索、以及 URL Scheme 搜索日志不再记录搜索词或台词原文，改为记录字符长度（`query_len`）；Debug 构建保留原文记录。
   - **关键技术诊断提级至 Release 常驻**：视频色彩空间与 HDR 色调映射状态切换、WebDAV 播放地址重定向解析结果与耗时、大列表释放后的内存回收触发，以及达到 `200ms` 阈值的主线程卡顿，在 Release 构建中常驻记录。

4. **排障日志盲区补齐（Debug 与 Release 常驻记录）**：
   - **启动硬件环境信息**：应用启动日志补充记录设备芯片型号/架构、物理内存容量，以及当前主显示器是否支持 HDR 与最大 EDR 余量。
   - **硬件解码自动降级警告**：当视频播放因编码不支持、首包硬解失败或首帧输出软解像素而由硬件解码自动降级为软件解码时，写入本地警告日志并记录视频文件名与降级原因。
   - **视频打开与跳转底层阶段耗时**：将底层打开媒体准备阶段耗时（停止旧会话、打开容器、流信息探测、解码器与音频初始化、初始定位）、首帧上屏阶段耗时（首包读取、首帧视频解码与跳帧统计、音频预缓冲等待、主线程上屏）及会话内跳转底层准备耗时接入本地日志系统（正常拆解数据随深度诊断开关收集，慢操作或失败常驻记录）。
   - **Anki 导出单卡失败明细**：Anki 导出过程中单张卡片发生音频截取失败、视频抽帧失败或文件写入失败时，记录具体失败环节、对应媒体文件名与错误原因。

# 验收标准

1. **工程开关切换生效**：将工程配置开关分别设为“仅 Debug 收集”和“Debug 与 Release 均收集”时，Release 构建能按配置切换是否输出深度诊断埋点，且单元测试与集成测试（`swift test`）全程零磁盘日志残留。
2. **刷屏消除与标识规范**：拖动播放进度条预览缩略图、正常播放视频及日常静止等待时，不再产生逐张缩略图渲染日志、每秒播放心跳日志及 `exit -> entry` 假性主线程卡顿日志；展开简介浮层仅记录单次日志，所有弹窗日志均显示可读弹窗名称而非随机 UUID。
3. **Release 观感与常驻诊断完整**：在 Release 日志中执行搜索或唤起命令面板时仅记录 `query_len` 而不出现搜索词或台词原文；启动硬件信息、HDR 色彩映射状态、硬件解码降级警告、WebDAV 重定向耗时、视频底层阶段耗时及 Anki 单卡导出失败明细均按规范写入本地日志文件。
