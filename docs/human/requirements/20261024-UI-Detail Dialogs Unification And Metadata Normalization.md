# 需求描述

1. **详情弹窗容器与组件统一（`L-06.8 File Detail Dialog Layout`、`L-06.11 Task Detail Dialog Layout`）**：
   - 文件夹详情、视频详情、字幕详情与任务详情统一复用同一套详情弹窗布局结构：顶部固定标题栏与关闭按钮、中间可滚动内容区（高度受窗口安全高度约束且自适应内容）、统一的标头行、分组卡片、键值行、`#1` 序号列表行及胶囊进度条。
   - 弹窗容器完全遵循 `C-10.1 Dialog` 通用圆角、外侧轮廓线与内侧高光规则，移除弹窗内部多余的分割线外框描边，并保持弹窗打开期间屏蔽底层表格文字划选。
   - **标头行（Header Row）**：左侧 `40×40px`（`--size-detail-file-icon-container`）同色深浅大图标与右侧名称的水平间距统一为 `--spacing-4`（`16px`）。
   - **任务详情进度条**：正在执行任务「进度」行右侧胶囊进度条复用 `C-09.3 Progress Indicator / Bar`，进度条宽度定义为 `--width-task-detail-progress-bar`（`140px`），右侧间隔 `--spacing-3`（`12px`）展示百分比。

2. **数据展示与空值兜底规则统一**：
   - **文件大小**：视频详情与字幕详情的「文件大小」与 File 列表卡片保持一致，统一采用 `1024` 进位并保留 `2` 位小数（如 `1.43 GB`、`102.35 KB`）。
   - **音频卡片按需展示**：视频详情中仅当存在有效音轨（且包含至少一项可展示的有效属性）时才展示 `Audio #1`、`Audio #2`... 卡片；无音轨或音轨无任何有效属性时不展示音频卡片。
   - **空列表与回退占位**：`#1` 序号列表（关联字幕、关联视频、修改前/后文件名、目标文件夹）为空时，统一展示 `#1` 与 `无`（英：`None` / 繁：`無`）；未入库字幕无法获取字符编码时展示 `-`。
   - **数量字段纯数字化**：字幕详情的「原始行数」「有效行数」与文件夹详情、任务详情的所有数量字段一致，仅展示纯阿拉伯数字（不带单位后缀）。

3. **多语言文案统一与实时响应**：
   - **菜单入口**：File 界面与 Task 界面卡片菜单中的详情入口统一为 `查看详情`（英：`Get Info` / 繁：`查看詳情`）。
   - **位置字段**：File 详情与 Task 详情中的 `Path` 与 `Location` 中文统一为 `位置`（繁：`位置`）。
   - **数量字段名称**：文件夹详情与任务详情中的 `Folder Count`、`Video Count`、`Subtitle Count` 中文统一为 `文件夹数量`、`视频数量`、`字幕数量`（繁：`資料夾數量`、`影片數量`、`字幕數量`），与 `卡片数量`、`文件数量` 对齐。
   - 切换界面语言时，已打开的详情弹窗文案实时同步更新。

4. **设计文档一致性约束**：
   - 严禁硬编码或私自特殊实现，所有视觉与交互均须可体现在 UI 设计文档体系中；待实际 UI 验收定稿后同步更新 `docs/human/design/ui/` 与 `docs/human/design/workbench/` 下对应文档。

# 验收标准

1. 文件夹详情、视频详情、字幕详情与任务详情的弹窗外框、内部滚动、标头行图标与名称 `16px` 间距、键值行、`#1` 序号列表行及 `140px` 胶囊进度条样式完全统一，且弹窗内鼠标拖拽不会穿透选中底层表格文字。
2. 视频与字幕详情中的「文件大小」按 `1024` 进位保留 2 位小数展示，与 File 列表卡片完全一致。
3. 无音轨视频的详情弹窗中不展示 `Audio #1` 卡片；序号列表为空时统一显示 `#1  无`（`None`）；字幕详情的「原始行数」「有效行数」显示为纯阿拉伯数字。
4. File 与 Task 菜单入口均显示「查看详情」，各详情弹窗中的「位置」「文件夹数量」「视频数量」「字幕数量」等文案在简/繁/英三语下准确统一，切换语言时实时刷新。
