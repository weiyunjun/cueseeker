# 需求描述

1. **首帧画面与前导音频不对齐、以及正片延后起步视频的起播时钟对齐（对齐 IINA，本地与远程）**：
   - **音频起点早于首个可解码视频关键帧**：当广播流或传输流（如 `.ts`）中音频流起始时间点早于首个可解码视频关键帧（如音频从 `0.0s` 起步，而首个视频关键帧在 `1.12s`）时，打开视频后直接将起播时钟锚定在首帧视频画面时间点，丢弃早于首帧视频画面的前导音频，使画面与声音从首帧视频时间点起立即同步播放，严禁出现前导黑屏等待或画面冻结在首帧等待音频追赶的现象。
   - **正片音视频延后起步而字幕从零起步**：当容器内音视频流均从非零时间点（如第 `10.0s`）才开始有数据、而字幕从 `0.0s` 起步时，保持容器原始总时长与原始时间轴不变（不人为平移抹除起始偏移），打开视频后直接从首个有效音视频帧所在的时间点（如 `00:10`）开始同步播放至视频总时长结束，避免尾部出现无数据无限加载。

2. **中途时间戳归零回绕与正向大跳变的时钟重锚定（对齐 IINA，本地与远程）**：
   - **中途时间戳归零回绕**：当节目流或 DVD 视频（如 `.VOB`）在播放中途（如第 `36.45s` 章节交界处）发生内部时间戳归零回绕时，保持文件原始时间戳不人为叠加偏移；跨过回绕点时自动重锚定音画同步时钟，使进度条跳回 `00:00` 后音画按正常帧率继续同步播放；且当用户先拖动跳转至回绕点之前的位置（如 `00:30`）再继续播放跨过回绕点时，回绕后的音视频帧正常解码播放，严禁被跳转前帧过滤逻辑误判丢弃而导致黑屏。
   - **中途时间戳正向大跳变**：当传输流（如 `.ts`）在播放中途（如第 `00:10` 处）发生内部时间戳正向大跳变（如突增 600 秒至 `10:10`）时，保持文件原始时间戳不人为扣减抹除空白；遇到正向大跳变时自动重锚定音画同步时钟，使进度条直接跳至跳变后的时间点（如从 `00:10` 跳至 `10:10`）并无缝继续播放，严禁画面在跳变前原地冻结等待。

3. **蓝光 `.m2ts` 与传输流 `.ts` 打开及跳转时的硬件解码保持与快速出画（本地与远程）**：
   - 打开视频位于起点（`0.0s`）时直接从文件起始位置读取数据包，避免因多余的起点跳转操作漏掉位于文件首包的 IDR 关键帧；
   - 在打开视频或拖动跳转后，自动跳过首个关键帧之前的前导非关键帧数据包，避免硬件解码器因前导非关键帧或局部坏包报错而被误降级为软件解码，确保 H.264 等支持硬解的视频稳定保持硬件加速解码并立即出画。

4. **未标记声道布局（Unknown Channel Layout）音轨的重采样兼容与防死锁（本地与远程）**：
   - 当视频容器（如含 24-bit / 16-bit LPCM `pcm_s24le` 等音轨的 MKV 文件）中的音频流与解码音频帧具有有效声道数（`> 0`），但未写入具体的声道布局标记（`unknown` 状态）时，自动根据声道数补齐默认标准声道布局（如 1 声道对应单声道、2 声道对应立体声等）完成重采样转换，消除因重采样失败导致音频无法完成预热、进而使播放器死锁卡在第 1 帧（`00:00`）的问题。

5. **分片视频流与无完整关键帧索引流的进度条预览缩略图恢复（本地与远程）**：
   - **分片关键帧完整解码**：针对将单帧视频画面拆分为多个同时间戳数据包存储的容器（如 `.rmvb` RealVideo），缩略图预览解码时连续送入后续分片数据包直至拼装解码出完整画面，消除仅送入首个分片即清空缓冲导致缩略图始终为空的问题。
   - **进度条内连续滑动实时更新缩略图**：针对打开时容器内关键帧索引记录不足的流式文件（如 `.ts`、`.m2ts`、`.vob` 仅记录片头 1 个关键帧索引），消除因复用残缺关键帧索引缓存拦截后续请求、导致鼠标在进度条内连续移动时缩略图停滞不更新的问题；并优化预览解码跳过非关键帧与冗余探测，使鼠标在进度条内滑动时预览缩略图实时跟随更新。

# 验收标准

1. **前导音频早于首帧及延后起步视频正常起播**：
   - 打开音频早于首个视频关键帧约 1.12 秒的 `.ts` 视频时，画面与声音直接从首帧画面时间点（约 `00:01`）立即同步正常播放，无前导黑屏或首帧画面卡顿等待；
   - 打开总时长 `01:00`、正片音视频从 `00:10` 起步的 `.mkv` 视频时，进度条总时长保持 `01:00`，打开后直接从 `00:10` 同步播放至 `01:00` 正常结束，尾部不卡加载。
2. **中途时间戳归零回绕与正向大跳变表现对齐 IINA**：
   - 从头或从 `00:30` 跳转后播放第 `36.45s` 处时间戳归零回绕的 `.VOB` 视频时，跨过 `00:36` 后进度条跳回 `00:00` 并按正常速度继续同步播放音画，且任意位置跳转与顺序播放的时间点完全一致；
   - 播放第 `00:10` 处时间戳正向跳变 600 秒的 `.ts` 视频时，到 `00:10` 后进度条直接跳至 `10:10` 并无缝继续播放至 `10:24` 结束，画面不冻结。
3. **蓝光 `.m2ts` 与 `.ts` 稳定保持硬件解码**：打开及拖动跳转 `1080p` H.264 蓝光 `.m2ts` 与含局部坏包的 `.ts` 视频时，始终保持硬件加速解码并立即出画，不被误降级为软件解码。
4. **未定义声道布局的 `pcm_s24le` 视频流畅播放**：打开含 `unknown` 声道布局 `pcm_s24le` 音轨的 MKV 视频时，声音正常输出且音画流畅播放，不再死锁卡在第 1 帧。
5. **进度条缩略图预览实时更新**：在 `.rmvb`、`.ts`、`.m2ts`、`.vob` 视频播放页将鼠标移入进度条并在进度条内连续左右移动时，预览缩略图均能正常显示并随鼠标位置实时更新。
