# 版本

main

# 关联设计

- 无。本需求仅补充播放字幕首帧延迟诊断日志埋点，不改变任何播放或字幕呈现行为。

# 需求描述

1. **纯诊断埋点与零行为变更约束**：
   - 仅补充字幕加载与首帧呈现延迟的诊断日志，不改变任何现有的视频打开、进度跳转、字幕加载时机、排版渲染逻辑或画面呈现行为。

2. **切换节点的字幕首帧诊断记录**：
   - 在打开新视频（挂载字幕时）、同一视频内跳转、以及播放页内手动切换字幕轨这三类场景完成目标时间点首帧字幕上屏时，记录单次汇总诊断日志；正常连续播放期间的逐帧或逐句字幕刷新不产生日志，被后续快速连续切换中途取代或因停止播放取消的未完成请求不输出完成日志。
   - 诊断记录须包含：字幕文件名、字幕格式（ASS / SRT）、触发场景（新视频打开 / 同视频跳转 / 手动切换字幕轨）、字幕源准备耗时（完成读取、字体信息获取与初始化排版的耗时；复用已就绪字幕源时记为 `0`）、首帧字幕生成与上屏耗时，以及相对视频首帧上屏的滞后时差（从视频首帧画面提交显示到对应目标时间点首帧字幕实际更新至屏幕图层的时间差；若视频首帧提交时目标首帧字幕已同步就绪上屏则记为 `0`）。

3. **播放提交就绪标记与慢滞后警告分级**：
   - 在播放呈现提交日志中补充当前批次提交时刻目标字幕首帧是否已同步就绪的状态信息（无字幕或隐藏字幕时明确区分）。
   - 常规耗时的字幕首帧拆解日志归入深度诊断埋点（随工程级诊断收集开关控制）；当相对视频首帧上屏滞后时差超过 `33ms`，或单次字幕准备与首帧生成总耗时达到或超过 `200ms` 时，提级输出常驻警告日志（`WARN`）。

# 验收标准

1. **各切换场景计时准确且无刷屏**：播放搜索结果队列、摘录集队列、普通视频内跳转及手动切换 ASS / SRT 字幕轨时，日志准确反映字幕源准备耗时、首帧生成耗时及相对视频首帧实际贴上屏幕的滞后时差；连续正常播放期间无逐句字幕刷新日志，连续快速切换仅记录最终生效批次。
2. **日志开关与测试隔离合规**：深度诊断日志与常驻警告日志遵循工程级诊断开关及 Debug / Release 目录隔离规范，且运行自动化测试全程零磁盘日志残留。
3. **播放与字幕表现零变更**：视频打开、跳转、跨分辨率切换、自动暂停及字幕渲染视觉效果与改动前完全一致。
