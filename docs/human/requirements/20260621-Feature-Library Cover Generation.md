# 需求描述
## 概述
1. 在index阶段处理好封面图，注意这里，仍然要保持和字幕数据库一致的原则，即只处理有对应字幕的视频的封面图。
2. 文件夹本身需要有一个封面图，这个版本先引用第一个有对应字幕的视频的封面图。这里没有逻辑问题，因为如果不存在任何这种视频，那么文件夹本身也不会显示出来。
## 封面图处理
1. 首先处理视频的候选时间点：20% / 30% / 40% / 50% / 60%，分别截对应时间的截图。
2. 根据算法选出质量最佳的图片作为封面图。
## 数据处理
以下特征会在index时触发生成封面图：
1. 该视频有对应字幕，但是不存在或丢失了封面图。
以下特征会在index时触发重新生成封面图：
1. 视频文件的大小或时长变化。
注意，算法版本的变化不应该触发重新生成封面图，后续会添加重新生成封面图的按钮的功能。index是中频静默操作，你不能要求用户因为你改了算法就强制改封面图。
## 其它
1. 处理封面图的并发数为32。
2. 保存视频原始分辨率截图。
3. 筛选后，用不到的截图不需要保留。
