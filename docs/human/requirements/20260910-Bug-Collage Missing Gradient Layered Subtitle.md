# 需求描述

1. 部分字幕用多条内容相同、各自 `\clip` 一个横条的事件叠出一句渐变字，索引时这些事件被去重为一个 Cue。Collage 只渲染该 Cue 记录的那一条事件，画面上只剩一个横条，看上去像没有字幕。
2. Collage 渲染选中 Cue 时，必须把索引时被去重掉的同源事件一并渲染，使该句还原为完整外观。
3. 同一时刻未被选中的字幕（其他台词、招牌、注释）仍不出现在 Collage 中。
4. 未使用该写法的字幕，Collage 结果不变。

# 验收

1. 《少女乐队的呐喊》第 6 集 `.scjp.ass`，Cue 8515265（0:22:17.20）加入 Collage：中日双语歌词完整显示，与播放界面截图一致。
2. 该文件 ED 段 0:22:17.20 之后的其余歌词 Cue 同样完整显示。
3. 同文件正片台词 Cue 的 Collage 结果与修复前一致。
4. Collage 中不出现未选中的字幕内容。
5. 以 Collage 导出图片人工比对验收，不为本需求新增 E2E 能力。
