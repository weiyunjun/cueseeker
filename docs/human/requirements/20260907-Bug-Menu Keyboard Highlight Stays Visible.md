# 需求描述

## 1. 适用范围

所有菜单及其二级菜单：Workbench 表格行菜单、筛选菜单、Shiori 目标菜单（Save to Shiori、Move to ...、Duplicate to ...，以及 Playback Overlay 与 Command Panel 的 Save to Shiori 按钮菜单）、封面卡片右键菜单、选中文字菜单。

## 2. 高亮可见性

1. 菜单打开的瞬间，默认高亮项不在可见范围内时，菜单滚动使其可见。
2. 键盘导航之后，新的高亮项不在可见范围内时，菜单滚动使其可见。
3. 滚动为最小滚动：滚到该项刚好完整可见为止，不居中。
4. 滚动不带动画，瞬时到位。
5. 该行为属于菜单本身，不由各个菜单各自实现；新增菜单与新增菜单项自动具备。

## 3. 保持不变

1. 滚轮滚动与拖拽滚动条不改变高亮，也不触发本需求的滚动。
2. 指针移动与 Hover 采纳、回车与 Esc、菜单内外交互、菜单方向、高度、宽度、滚动条外观与位置均不变。
3. 内容不足以滚动时菜单没有任何变化。
4. 不新增、不修改任何 Token。

# 验收

1. Shiori 列表多到 Save to Shiori 菜单出现滚动条：打开瞬间最近保存的那个列表完整可见。
2. 同一菜单按方向下键一路到底：每一步的高亮项都完整可见，到末项停住。
3. 同一菜单按方向上键一路到顶：每一步的高亮项都完整可见，到首项停住。
4. 表格行菜单的 Move to ... 与 Duplicate to ... 二级菜单满足第 1 至 3 条。
5. 菜单出现滚动条时滚动滚轮：高亮不动，菜单也不跳回高亮项。
6. 筛选菜单的打开高亮与键盘导航没有回归。
7. 压低窗口高度使表格行菜单与封面卡片右键菜单出现滚动条：键盘导航时高亮项保持完整可见。
8. 第 1 至 6 条使用现有 Debug E2E 控制器覆盖；第 7 条需要改变窗口高度，控制器没有窗口高度命令，走人工验收。不为本需求新增 E2E 能力。
