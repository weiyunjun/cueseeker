# 需求描述

1. **Command Panel 搜索与工作台 Search 即搜即得链路对齐**：
   - Command Panel 搜索框与工作台 Search 页面直接共用同一份搜索词状态与同一条输入触发搜索链路，不再单独维护面板搜索词副本及专属的防抖与复用判定状态。
   - 在 Command Panel 一级菜单输入搜索词（或打开面板自动填入当前聚焦台词）时，仅触发与工作台 Search 一致的实时搜索，不在打字过程中额外执行筛选项重算或偏好设置写入。
   - 一级菜单 `Search <搜索词>` 右侧的结果数量与二级结果页底部状态栏的总数展示，直接复用工作台 Search 的精确总数完成状态判定。

2. **一级菜单进入二级搜索结果页直接切换，不打断或清空已有搜索**：
   - 在一级菜单按回车或点击 `Search <搜索词>` 进入二级搜索结果页时，仅执行面板界面切换，直接展示当前正在进行或已完成的搜索结果，不取消重搜，也不因首尾空白字符差异清空已搜出的结果。

3. **消除搜索与播放过程中的冗余同步及后台无效计算**：
   - Command Panel 二级搜索结果页在首屏 100 条产出及全量统计完成时只执行单次同步；全量统计完成但前 100 条结果未变化时，仅更新底部状态栏总条数，不重复重建结果列表。
   - 播放页覆盖在工作台上方期间，底部被遮挡的工作台 Search 页面暂停响应搜索词与结果变化，待返回工作台时再同步刷新。
   - 仅当搜索结果产生后媒体库实际发生增删变动时，才执行失效台词过滤校验；刚从数据库检索出的新鲜搜索结果不再重复查库校验。

# 验收标准

1. **即搜即得与计数一致**：打开 Command Panel 输入搜索词（或自动填入聚焦台词），一级菜单 `Search <搜索词>` 右侧在精确统计完成后显示 `xx results`，退出播放页切回工作台 Search 页面时搜索框内容、结果列表及计数完全一致。
2. **进入二级结果页流畅不重搜**：在一级菜单输入搜索词后（无论是在输入后立即按回车、还是等待计数显示后按回车，或输入内容含首尾空格），进入二级搜索结果页均直接复用当前搜索并在首屏 100 条产出后立即展示，不发生结果被清空或重复发起搜索的情况。
3. **无冗余卡顿与后台重搜**：在播放页使用 Command Panel 搜索、切入二级结果页、点选搜索结果播放，或打开空的 Command Panel 从 `Recent Videos` 切换视频时，主线程响应流畅，后台不再静默重跑无关的旧搜索或重复执行数据库校验。
