# 需求描述

1. **`File` 界面文件卡片副标题展示规则（`L-04.6 File Card Layout`）**：
   - **视频卡片**：第 2 行由仅显示文件大小调整为依次展示 **`<简化分辨率>  <视频编码>  <时长>  <文件大小>`**（例如 `1080P  HEVC  23:42  831.65 MB`）。
   - **字幕卡片**：第 2 行由仅显示文件大小调整为依次展示 **`<原始台词数>  <有效台词数>  <文件大小>`**，随当前界面语言显示（数量为 `1` 时英文使用单数 `cue`）：
     - 简体中文：`520 条原始台词  486 条有效台词`
     - 繁体中文：`520 條原始台詞  486 條有效台詞`
     - 英文：`520 raw cues  486 valid cues`
   - **分隔与缺失兜底**：同一行内相邻信息之间统一以 **2 个英文空格** 分隔；若个别元数据尚未就绪或读取失败，直接省略该项不展示（不显示占位符，且未知文件大小不得误显示为 `0 B`；真实 `0` 字节文件正常显示 `0 B`），其余已有信息仍按顺序以 2 个英文空格连接；后台补充元数据完成后界面同步更新。
   - **排版、折行与文本选择（零特殊实现约束）**：严格沿用 `L-04.6 File Card Layout` 与 `UI Text Selection Rules.md` 既有规范——所有信息完整展示、不截断，随卡片中间文本列可用宽度自然折行，严禁硬编码样式参数或新增私有断行特殊实现，保持卡片基准高度、多行向下延展、图标/按钮锁定对齐及静态文本划选复制行为不变。

2. **视频卡片简化分辨率规则（共 10 档）**：
   - 按视频经旋转矫正后的宽高提取长边与短边，统一映射为以下 **10 种全大写简洁标识**，不附带额外后缀：
     - **`8K`**：4320 线 / 7680 宽级（含更高分辨率）
     - **`4K`**：2160 线 / 3840 宽级
     - **`2K`**：短边达到 1440 线级（如 `2560×1440`、`2560×1600`、`3440×1440`、`1440×2560`；超宽 `2560×1080` 因短边为 1080 归入 `1080P`）
     - **`1080P`**：1080 线 / 1920 宽级（含宽银幕去黑边如 `1920×800`、`1916×1076`、4:3 如 `1440×1080`、竖屏如 `1080×1920`）
     - **`720P`**：720 线 / 1280 宽级
     - **`576P`**：576 线 / 1024 宽级（含 PAL `720×576` 及竖裁如 `607×1080`）
     - **`480P`**：480 线 / 854 宽级（含 NTSC `720×480`、`640×480`）
     - **`360P`**：360 线 / 640 宽级
     - **`240P`**：240 线 / 426 宽级
     - **`144P`**：低于 `240P` 的所有有效低分辨率视频（如 `160×120`、`176×144`、`256×144`）
   - 横屏电影与压制片保留约 5% 去黑边微裁切容差，竖屏及极狭长异常裁切画面受短边门槛约束以防误判或虚高定档。

3. **视频卡片编码格式简写规则（仅作用于文件卡片）**：
   - `File` 视频卡片统一采用简洁编码名称，**`File Info` 详情弹窗原有写法保持不变**：
     - 常见现代编码：`HEVC`、`AVC`、`AV1`、`VP9`、`VP8`、`VVC`
     - 传统/专业编码：`MPEG-4`、`MPEG-2`、`MPEG-1`、`ProRes`、`WMV`、`VC-1`、`Theora`、`RealVideo`、`H.263`、`FLV1`
     - 其余已识别编码取编码简称全大写展示。

4. **全应用时长与进度时间前导零统一**：
   - 全应用内所有视频时长及播放进度时间统一为 **小时与分钟均补两位前导零**：不足 1 小时显示 `MM:SS`（如 `03:05`），达到或超过 1 小时显示 `HH:MM:SS`（如 `01:05:30`）。
   - 覆盖范围包括：`File` 视频卡片、`Recent` 与 `Library` 封面时长角标、`Cover Summary` 进度时间、播放器底栏当前/剩余时间、进度条时间胶囊，并与已采用该格式的 `File Info` 详情弹窗及台词时间轴保持完全一致。

5. **设计文档同步安排**：
   - 关联 UI 设计文档中对应布局与时间展示描述，待本次改动验收完成后再统一提交更新。

# 验收标准

1. **文件卡片信息与语言切换验收**：`File` 界面中视频卡片第 2 行依次显示 `<简化分辨率>  <视频编码>  <时长>  <文件大小>`，字幕卡片第 2 行依次显示 `<原始台词数>  <有效台词数>  <文件大小>`，各项间均以 2 个英文空格分隔；切换 `EN`、简体中文与繁体中文后，字幕台词数文案立即按规范更新（英文单数 `1 raw cue` / `1 valid cue`）；缺省或未就绪字段直接省略，不显示占位符或误显示 `0 B`。
2. **卡片排版与文本复制零退步验收**：常规与最窄窗口（`600px`）下，卡片第 2 行按中间文本列完整可用宽度正常单行展示，无异常提前折行或文字贴边溢出；卡片基准高度、左侧图标与右侧更多按钮对齐、静态文本划选与复制行为均无退步。
3. **分辨率与编码准确度验收**：标准 16:9、宽银幕去黑边（`1920×800`、`3840×1600`）、微裁切 BDRip（`1916×1076`）、`2K`（`2560×1440`、`3440×1440` 且区分 `2560×1080` 为 `1080P`）、竖屏（`1080×1920` 为 `1080P`、`607×1080` 为 `576P`）以及 `720×576`、`160×120` 等均按 10 档规则准确显示；`H.264` / `H.265` 在卡片上显示为 `AVC` / `HEVC`，而 `File Info` 详情弹窗仍保持原有完整写法与原始像素分辨率不变。
4. **全局时长补零一致性验收**：对于不足 1 小时及超过 1 小时的视频，`File` 视频卡片、`Recent` / `Library` 封面角标、`Cover Summary` 进度文本、播放器底栏当前与剩余时间、进度条拖拽时间胶囊及 `File Info` 详情弹窗均统一展示为两位补零格式（如 `03:05`、`01:05:30`）。
