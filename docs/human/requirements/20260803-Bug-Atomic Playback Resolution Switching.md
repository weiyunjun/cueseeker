# 关联设计
- 无。本需求只修复既有播放呈现问题，不改变播放交互或数据定义。

# 需求描述
1. 现状：播放搜索结果并切换到前一个或后一个结果时，如果前后视频分辨率或宽高比不同，例如 4K、标准 1080P 与非标准分辨率之间切换，可能短暂显示画面拉伸、位置跳动或字幕闪烁。
2. 原因范围：新视频首帧、视频尺寸、显示布局和字幕画面目前可能分阶段提交，从而暴露属于不同播放 Presentation 的中间状态。
3. 目标：视频首帧、视频尺寸、显示布局和字幕画面必须以同一个 Presentation Generation 一致提交。
4. 在新 Presentation 完整可显示之前，保留旧 Presentation 的完整画面；不得混合显示新视频帧与旧尺寸、旧视频帧与新尺寸，或尺寸不匹配的字幕画面。
5. 新 Presentation 的第一帧必须直接使用正确的宽高比和显示区域，不得先按旧视频尺寸显示后再调整。
6. ASS 和 SRT 字幕必须与对应视频 Presentation 同步切换，不得因视频尺寸更新和字幕源更新而出现可见的重复清空、错位或闪烁。
7. 快速连续切换时，只允许最新的 Presentation Generation 提交；过期的视频帧、尺寸信息和字幕结果必须被拒绝。
8. 不新增过渡动画、占位界面或额外设置，不改变字幕编码、索引、播放控制及自动暂停语义。

# 验收标准
1. 搜索结果前后切换至少覆盖以下组合：
   - 3840×2160 与 1920×1080；
   - 相同宽高比但不同像素尺寸；
   - 标准 16:9 与非标准分辨率或不同宽高比。
2. 每种组合的第一帧均直接以正确尺寸显示，不出现拉伸、缩放跳变、位置跳动或黑帧闪烁。
3. ASS、SRT 及隐藏字幕三种状态下均不得出现尺寸错位或字幕闪烁。
4. 快速连续切换多个结果时，只显示最终目标，不得回闪到中间结果。
5. 同一视频内 Seek、相同分辨率视频切换、首帧冻结、自动暂停及播放控制行为不得回归。
6. 自动化测试必须验证视频帧、视频尺寸和字幕状态属于同一个 Presentation Generation，并拒绝过期提交。
