# 需求描述

1. **入口与弹窗整体布局（`L-04.6 File Card Layout`、`L-06.8 File Detail Dialog Layout`）**：
   - 在 File 界面**一级文件夹卡片**和**二级文件夹卡片**右侧 `...` 弹出菜单最顶部（第一项），新增 **「显示简介」（英：`Get Info` / 繁：`顯示簡介`）**（Neutral，图标 `info`）。
   - 与视频、字幕的「显示简介」一致，后台有索引、重命名等任务或数据库压缩进行期间，该菜单项保持可点击。
   - 点击后弹出详情对话框，弹窗尺寸、四边等距、内部滚动、分组卡片与键值行排版、长路径多行折行后内部左对齐以及数字等宽对齐规则完全复用现有「文件详情」对话框：
     - **顶部标题栏**：左侧主标题为 **「文件夹详情」（英：`Folder Info` / 繁：`資料夾詳情`）**，右上角为关闭按钮。
     - **文件夹标头行（Header Row）**：左侧为 `40×40px` 的文件夹类型专属同色深浅大图标（匹配本地、WebDAV、SMB、FTP、NFS 文件夹图标），右侧（间距 `16px`）展示当前文件夹卡片的名称（最多 2 行，超出尾部省略）。

2. **卡片分组与展示字段**：
   - 自上而下分为 **2 个分组卡片**，所有数量字段均显示为纯阿拉伯数字，时间格式统一为 `yyyy-MM-dd HH:mm:ss`：
   - **第 1 块 —「文件夹信息」（英：`Folder Info` / 繁：`資料夾資訊`）**：
     1. **`位置`（英：`Path` / 繁：`位置`）**：文件夹的完整路径。
     2. **`文件夹数`（英：`Folder Count` / 繁：`資料夾數`）**：
        - **二级文件夹**：固定为 `1`。
        - **一级文件夹（根文件夹）**：统计其下属包含有效配对（视频 + 字幕）的子文件夹数量；若根文件夹自身直属目录下也存在有效配对的视频和字幕，则根文件夹自身也计为 `1`（累加 `+1`）；不包含任何有效配对的空根文件夹显示为 `0`。
     3. **`视频数`（英：`Video Count` / 繁：`影片數`）**：当前文件夹统计范围内已有效配对的视频总数（一级文件夹统计其下属全部有效配对视频；二级文件夹仅统计该分组自身直属的有效配对视频）。
     4. **`字幕数`（英：`Subtitle Count` / 繁：`字幕數`）**：当前文件夹统计范围内已有效配对的字幕总数。
   - **第 2 块 —「索引信息」（英：`Index Info` / 繁：`索引資訊`）**：
     1. **`添加时间`（英：`Added` / 繁：`加入時間`）**：一级文件夹被添加到媒体库的时间，或二级文件夹首次索引入库生成的时间。
     2. **`更新时间`（英：`Updated` / 繁：`更新時間`）**：该文件夹最后一次索引成功完成的时间。

3. **时间维护、嵌套联动、墓碑与历史兼容规则**：
   - **App 内重命名保持时间不变**：通过 App 内「重命名此文件夹」修改一级或二级文件夹名称后，文件夹的 `位置` 更新为新路径，`添加时间` 与 `更新时间` 保持不变。
   - **父子包含关系的一级文件夹「更新时间」联动**：
     - 当执行「索引全部」或对父级根文件夹执行「索引此文件夹」时，父级根文件夹及其覆盖范围内的子级根文件夹、下属二级文件夹的 `更新时间` 同步刷新。
     - 当仅对子级根文件夹执行「索引此文件夹」时，仅刷新该子级根文件夹及其下属二级文件夹的 `更新时间`，父级根文件夹的 `更新时间` 保持不变。
   - **「添加时间」不进入墓碑**：
     - 墓碑仅保留用户记忆数据（观看状态、播放进度、自定义封面、默认音轨及台词摘录绑定），**文件夹的 `添加时间` 不进入墓碑**。
     - 当一级文件夹被移除后重新添加，或二级文件夹因无有效配对离开媒体库后再次配对入库时，均按新入库生成全新的 `添加时间`。
   - **已有媒体库免重新索引兼容**：
     - 升级后对已有的一级与二级文件夹自动利用现有入库与索引历史补齐初始 `添加时间` 与 `更新时间`，无需重新执行索引即可直接查看完整文件夹详情。

# 验收标准

1. File 界面一级与二级文件夹卡片 `...` 菜单首项均为带 `info` 图标的「显示简介」，任务运行期间仍可点击打开。
2. 弹窗顶部标题显示为「文件夹详情」，标头行正确展示对应协议的文件夹大图标与文件夹名称，下方按「文件夹信息」（`位置`、`文件夹数`、`视频数`、`字幕数`）与「索引信息」（`添加时间`、`更新时间`）两块卡片顺序展示。
3. 二级文件夹的 `文件夹数` 恒为 `1`；一级文件夹在空文件夹、仅子文件夹有配对、根目录直属与子文件夹均有配对三种场景下，`文件夹数`、`视频数`、`字幕数` 均统计准确。
4. 存在父子包含关系的两个一级文件夹：对父文件夹执行索引或执行「索引全部」时两者 `更新时间` 均刷新；仅对子文件夹执行「索引此文件夹」时，仅子文件夹 `更新时间` 刷新，父文件夹 `更新时间` 不变。
5. 文件夹离开媒体库（移除文件夹或删除配对文件后索引）并再次加回或恢复配对入库时，自定义封面与观看进度等墓碑数据正常恢复，而文件夹的 `添加时间` 重新生成为最新入库时间。
6. 旧版本已有数据的媒体库升级后，无需重新执行 Index，直接打开任意一级或二级文件夹的「显示简介」即可正常显示完整的数量与时间信息。
