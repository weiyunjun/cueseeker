# 需求描述

1. **输入框基础交互与组件变体规则**：
   - **单行输入框（`C-01.1 Text Field`、密码输入框、`C-01.3 Search Field`、`C-01.4 Number Field`、`C-02.3 Color Well`）**：
     - 禁止换行，输入或粘贴中的换行符默认替换为空格；按下回车键不插入换行、不全选文字、不触发对话框确认（仅 `Command Panel` 搜索框保持回车执行动作）。
     - 聚焦前后容器尺寸、圆角、内边距及文本/占位符绘制起点保持一致，不显示外发光焦点环（仅边框变为聚焦色）。
     - 各变体叠加自身规则：
       - `C-01.1 Text Field`：远程文件夹 `Address` 输入框在输入或粘贴百分号编码链接时即时还原为可读字符。
       - `C-01.3 Search Field`：有文字时右侧显示清空按钮（`✕`），点击清空文字并使该搜索框获得或保持焦点。
       - `C-01.4 Number Field`：文字右对齐、等宽数字，仅允许输入 `0-9`，输入或粘贴遇到换行符或 `.` 时在首个位置截断；超出上限时立即钳制为上限值，为空或低于下限时在失焦时恢复原值或钳制为下限值。
       - `C-02.3 Color Well`：固定 `#` 前缀，仅允许输入 `0-9`、`A-F`（自动转大写，最多 6 位），粘贴自动剥离 `#` 并在首个换行符或 `.` 处截断；失焦时 `4~5` 位截断取前 3 位，`0~2` 位恢复原值；聚焦或点击时展开下方 `6×2` 预设色板。
   - **多行文本框（`C-01.2 Text Area`）**：
     - 允许换行，按下回车键在光标处插入换行，粘贴保留多行文本；支持内部垂直滚动条。

2. **文本框内部与外部鼠标点击焦点规则**：
   - **文本框容器内部点击**：
     - 在单行输入框、搜索框（除清空按钮外）、多行文本框圆角容器内部按下鼠标左键时聚焦该文本框，并将光标直接置于鼠标点击的字符位置（不触发全选，也不发生横向滚动位置跳变）；支持双击选词、三击全选、按住左键拖拽划选文字（从框内按下左键拖选文字滑出容器边界并在外部松开时，保持焦点与已选中的文字）。
     - 在文本框容器内部按下鼠标右键时获得或保持焦点，不取消焦点。
     - 点击或拖拽多行文本框内部的垂直滚动条、或点击 `C-02.3 Color Well` 展开的预设色板内部时，保持对应输入框焦点不变。
   - **文本框容器外部点击取消焦点**：
     - 当任意单行输入框或多行文本框处于聚焦状态时，鼠标左键或右键在该文本框容器（及 `C-02.3 Color Well` 已展开的预设色板）以外的区域按下时，立即取消该文本框的焦点（收起输入光标、清除框内文字选区、容器边框恢复非聚焦状态，颜色输入框同步收起预设色板），且不影响外部落点原本的点击或右键菜单行为。

3. **默认焦点与有文字时自动全选**：
   - 界面出现时默认不自动获得焦点，仅以下 4 处例外在界面出现时自动赋予默认焦点：
     1. `Confirmation` 对话框打开时：焦点在 `Cancel` 按钮。
     2. `Workbench Search` 页面进入时（切换到 `Search` 一级页面，不含 `Excerpt` 二级详情页）：顶部搜索框默认获得焦点；若搜索框内已有文字，自动将该文字全部选中。关闭上层对话框或菜单回到 `Search` 页面、或退出表格批量选择模式时不重新自动聚焦。
     3. `Rename` 对话框打开时：新名称输入框默认获得焦点，并将预填的名称全部选中。
     4. `Command Panel` 一级界面出现时（含首次打开及从二级界面返回一级界面）：搜索框默认获得焦点；若搜索框内已有文字（含已输入的搜索词或开启「Prefill with Focused Cue」自动填入的字幕文本），自动将该文字全部选中。

# 验收标准

1. 用鼠标左键点击已有文字（含长度超出输入框宽度的长文本）的任意单行输入框或多行文本框内部时，直接聚焦并将光标准确落在所点击的字符位置，不会出现“先全选一闪再取消全选”或横向滚动位置跳变导致的定位错乱；双击选词、三击全选及拖选文字（含拖出框外松开）均正常保持焦点与选区。
2. 聚焦任意单行输入框或多行文本框后，用鼠标左键或右键在文本框容器外（如空白处、表格、卡片、按钮）按下时，文本框立即取消焦点、光标与文字选区消失，且外部按钮点击或右键菜单正常响应。
3. 在聚焦的多行文本框中点击或拖拽内部滚动条、在搜索框中点击右侧 `✕` 清空按钮、或在颜色输入框展开的预设色板中点击选色时，输入框焦点均保持不丢失；数字框与颜色框的字符过滤、范围钳制及失焦恢复行为符合规范。
4. 切换到 `Workbench Search` 页面时，搜索框自动聚焦且已有搜索词处于全选状态；取消搜索框焦点后打开并关闭弹窗/菜单或进出批量选择模式，搜索框保持无焦点；进入 `Excerpt` 二级详情页时搜索框不自动聚焦。
5. 打开 `Rename Folder` 或 `Rename Files` 弹窗时，新名称输入框稳定自动聚焦且预填名称处于全选状态；打开 `Command Panel` 一级界面（含首次打开、开启「Prefill with Focused Cue」自动填入字幕、从二级界面返回一级界面）时，搜索框稳定自动聚焦且已有文字处于全选状态。
