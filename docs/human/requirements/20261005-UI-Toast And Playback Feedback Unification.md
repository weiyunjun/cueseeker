# 需求：Toast 与播放反馈（Playback Feedback）样式统一与颜色修正

## 1. 需求背景与目标

前序 Dark Mode 改动引入了以下视觉错乱：
1. **图标异常变紫**：常规操作（如复制台词、复制 Deep Link 等）的 Toast 图标被错误赋予系统 Accent Color，在当前系统下显示为紫色。
2. **表面材质割裂与反向漂移**：Workbench Toast 采用实色 `#2A2A2E` 显得生硬；播放反馈采用系统原生材质，在视频上呈现 Light 偏亮/Dark 死黑的倒错现象；Playback Overlay 下的反馈因黑色正片叠底呈现发黑凹陷，违反“Dark 下越上层越亮”法则。

**目标**：恢复全场景图标纯白单色规范，统一 Workbench Toast 与 Playback Feedback 的表面材质与层级亮度，消除视觉割裂。

---

## 2. 图标颜色规范

- **全场景图标统一纯白**：Toast 与 Playback Feedback 中的**所有图标一律使用纯白色**（`#FFFFFF`，与主文字完全一致），不区分场景，不设置任何彩色分支。
- **严禁使用彩色**：严禁使用 Accent Color，严禁在深色胶囊上使用红、黄、绿等状态语义色，保持纯白单色 HUD 质感。

---

## 3. 表面材质与底色规范（Toast & Playback Feedback 统一）

Workbench Toast 与播放界面的 Playback Feedback 统一视觉标准，消除两套实现割裂：

### 3.1 Light Mode
- **背景色**：深色半透明基底（`rgba(31, 31, 31, 0.90)`），叠加毛玻璃效果。
- **边框**：四周均匀 1px 微光描边（`rgba(255, 255, 255, 0.15)`）。
- **文本与图标**：纯白色（`#FFFFFF`）。

### 3.2 Dark Mode
- **背景色**：遵循“Dark 下越上层越亮”原则，采用半透明提亮底色（`rgba(45, 45, 50, 0.92)` / `#2D2D32` 级微透），叠加毛玻璃效果：
  - 在 Workbench 页面底色（`#1C1C1F`）上自然浮起；
  - 在 Playback Overlay 底色（`#242426`）上亮度明显高于底层，彻底消除死黑凹陷。
- **边框**：四周均匀 1px 微光描边（`rgba(255, 255, 255, 0.15)`）。
- **文本与图标**：文本使用 `--color-text-primary`（`#E4E4E4`），常规图标使用纯白（`#FFFFFF`）。

### 3.3 视频播放界面一致性
- 播放视频界面始终为纯黑背景。
- 反馈胶囊摆脱系统级 `.ultraThinMaterial` 随 Light/Dark 模式产生的反常雾化漂移，在 Light 和 Dark 模式下均保持稳定、清晰的深色微透 HUD 胶囊质感。

---

## 4. 验收标准

1. **图标颜色**：无论复制台词、保存摘录、还是“已存在该摘录”/“不在库中”等报错警示，所有弹出的胶囊图标一律为纯白色，无任何 Accent 紫色或暗黄/红绿杂色。
2. **Dark 模式浮层对比度**：
   - Workbench 弹出 Toast 时，底色呈现微透浮起感，不再是生硬的灰色实色块。
   - Playback Overlay 弹出反馈时，胶囊底色明显亮于 `#242426` 抽屉底色，无发黑融色。
3. **播放视频界面稳定性**：在视频播放过程中触发快进/快退/音量反馈，无论系统切换为 Light 还是 Dark 模式，反馈背景均呈现一致的深色 HUD 质感，不再出现 Light 发灰白、Dark 变死黑的现象。
