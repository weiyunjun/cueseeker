# 需求描述

1. 本需求适用于 Search 与 Shiori 两个表格界面的表头。

2. 删除表头的排序功能与全部排序相关 UI：表头右侧的排序指示图标（未排序 / 升序 / 降序）、点击表头弹出的排序菜单，以及「升序排序 / 降序排序」菜单项及其本地化文案。不得因此删除表格行右键菜单共用的菜单与弹层基础设施。

3. 表头单元格改为纯文本标签，不再是可交互控件：不再有 Hover 背景、指针手型光标、按下反馈、焦点环与键盘 Tab 焦点。标题文本的字号、字重、颜色与左右内边距保持不变。

4. 列宽、列顺序、列显示与隐藏规则、表头高度、表头吸顶与横向同步滚动行为保持不变。

5. 选择模式下的表头 Checkbox 列不受影响。

6. 表格数据的现有默认顺序保持不变。

# UI 文档同步

视觉验收完成后，由人类维护者更新并提交 `docs/human/design/UI Design System.md`，删除 Table Header Cell 的 Sortable 变体及其排序状态定义，并同步 Search / Shiori Table Layout 的组件清单。
