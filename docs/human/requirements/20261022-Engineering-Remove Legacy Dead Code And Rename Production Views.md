# 需求描述

1. **移除已停用的历史遗留代码与废弃分支**：
   - 移除早期缩略图生成缓存、旧版表格组件、早期搜索列表辅助逻辑、旧版媒体库卡片、旧版表格整行数据拼接路径、旧版单张与批量截图导出等在当前正式功能中已完全停用的历史代码及仅针对这些废弃逻辑的单元测试。
   - 移除播放页台词浮层（Playback Overlay）中已迁入 Command Panel 的搜索、媒体库、摘录集旧模块分支，以及从未启用的虚拟窗口分页请求逻辑与废弃播放器属性。

2. **移除旧版视觉样式兼容开关**：
   - 通用控件、搜索栏、滚动条及台词表格统一保留当前正式使用的新版视觉样式，移除不再使用的旧版样式兼容开关及旧版字体、配色与布局分支。

3. **正式页面目录与文件正名**：
   - 将原沙盒/测试命名下的正式业务页面（Search、Recent、Library、Excerpt 详情表格）及主界面与播放页顶层切换视图，按其实际正式职责重命名并归位到对应业务目录。

4. **清理本地历史构建缓存残留**：
   - 清理本地未纳入版本管理的早期跨平台实验构建缓存、历史归档构建缓存及脚本运行缓存。

# 验收标准

1. 项目编译构建与全量单元测试通过，无新增编译告警。
2. 主界面（Search、Recent、Library、File、Excerpt）与播放页（视频播放、台词浮层、Command Panel、拼图预览与导出）的所有视觉样式与交互行为与改动前完全一致。
