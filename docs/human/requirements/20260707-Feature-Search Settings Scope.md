# 需求描述
1. Settings界面，在左侧新增Search标签，放在Appearance标签下面。
2. Search标签图标用放大镜图标。
3. 将Primary Search Language的选项放到Search标签页下。
4. 新增Search Scope选项，有一个下拉选择框，可以选择：All，Only Finished，Watching + Finished。默认选择All。
5. 顾名思义，All代表不筛选，Only Finished代表只筛选匹配到的视频为Finished的字幕，Watching + Finished代表只筛选匹配到的视频为Finished或Watching的字幕。
6. Search Scope选项只对Search标签页的常规Search行为有效，对Shiori的搜索或者Context的搜索是无效的。
