# 需求描述

1. **远程目录浏览卡片（WebDav / SMB / FTP / NFS 第二步）左侧复选框与点击交互**：
   - **视觉排布**：文件夹卡片最左侧增加圆形复选框（Checkbox），右侧依次为文件夹图标、文件夹名称与右侧 `>` 箭头；视频与字幕文件卡片不显示复选框，维持不可点击、无悬停效果。
   - **左侧勾选矩形热区**：从文件夹卡片左边缘至文件夹图标左边缘、贯穿卡片上下全高的矩形区域作为复选框点击热区，左键单击该矩形区域内任意位置即可切换勾选或取消勾选。
   - **单击进入子文件夹**：左键单击文件夹卡片除左侧勾选区以外的主体区域，直接进入下一层子文件夹（不再使用双击），并自动清空上一层级已勾选的文件夹。
   - **卡片外观与悬停**：勾选状态仅由左侧复选框表达；未禁用的文件夹卡片在勾选前后均保持默认背景与默认边框，鼠标悬停在卡片上时统一显示常规 Hover 背景。

2. **已添加文件夹的禁用状态与复选框 Disabled 样式修复**：
   - **复选框 Disabled 样式**：未勾选且禁用（Unchecked + Disabled）保持灰色空心圆环；已勾选或半选且禁用（Checked / Indeterminate + Disabled）显示为灰色实心圆配白色勾号/横线。
   - **已添加文件夹禁用规则**：若某个文件夹本身已添加在 File 列表中，或位于已添加文件夹的路径之下（子目录），该文件夹卡片处于禁用状态：左侧复选框固定显示为灰色「已勾选 + 禁用」样式，右侧隐藏 `caret-right` 箭头并显示绿底白字「已添加 / Added / 已加入」胶囊标签（复用封面卡片「已观看」标签样式），不可取消勾选，卡片主体也不可点击进入下一层，且无 Hover 变色效果。

3. **右下角「添加」按钮可用性与添加规则**：
   - 支持在同一层级勾选多个未禁用的文件夹，点击「添加」按从上到下顺序依次入队添加。
   - 当未勾选任何文件夹时：
     - 若当前所在目录自身已被添加（或位于已添加目录之下），或当前目录下存在子文件夹但全部子文件夹均已处于禁用不可勾选状态，或处于 SMB 主机顶层共享列表 / NFS 主机顶层导出列表，「添加」按钮为 `Disabled`；
     - 其余情况下「添加」按钮可用，点击直接添加当前所在的目录本身。

# 验收标准

1. 连接 WebDav / SMB / FTP / NFS 进入目录浏览界面后，文件夹卡片左侧显示复选框，文件卡片不显示复选框；单击文件夹卡片左侧矩形区域可切换勾选/取消勾选，勾选后卡片背景与边框保持默认且仍有 Hover 效果；单击卡片其余区域直接进入下一层级并清空此前勾选。
2. 已添加的文件夹及其子文件夹在浏览列表中左侧复选框显示为灰色实心圆配白色勾号（Checked + Disabled），右侧替代箭头显示绿底白字「已添加 / Added / 已加入」标签，既不可取消勾选，也不可点击卡片进入下一层，且无 Hover 效果。
3. 未勾选任何文件夹时，若当前目录已添加或当前层级所有文件夹均不可勾选，右下角「添加」按钮为 `Disabled`；存在可添加项时行为与原多选/添加当前目录逻辑一致。
