# 需求描述

1. **支持含组合字符（如日文浊音假名）的文件夹正常移除与重扫清理**：
   - 当文件夹或文件路径中包含日文浊音假名等组合字符时，移除该文件夹、重新索引清理已删除文件、更新失效摘录原因与清理变更提示均能准确匹配该路径下的全部字幕、视频及摘录记录，不再因路径前缀截取长度偏差导致移除文件夹报错或残留旧记录。

2. **统一含组合字符的子文件夹路径匹配规则**：
   - 当媒体库根目录下包含带组合字符的子文件夹时，子文件夹相对路径保持与根路径一致的字符形态，在 File 页面查看「文件夹详情」、生成自动封面或设置自定义封面、以及在 App 内重命名该子文件夹时均能准确匹配并保持封面关联。

3. **支持在 App 内将本地文件夹或文件重命名为含组合字符的新名称**：
   - 在 App 内对本地根文件夹、子文件夹或视频/字幕文件组执行重命名并输入含日文浊音假名等组合字符的新名称时，更新后的新路径统一规范化为本地磁盘标准字符形态，重命名后在 Library 与 File 页面正常显示，且后续可继续正常执行再次重命名、重新索引与移除。

# 验收标准

1. 添加路径含日文浊音假名等组合字符的根文件夹，完成索引并观看视频后，执行移除文件夹操作，任务正常完成且无报错，相关索引数据被完整清理。
2. 媒体库根目录下存在含日文浊音假名等组合字符的子文件夹时，File 页面「文件夹详情」能正常显示该子文件夹记录，自动封面与自定义封面在 App 内重命名该子文件夹后依然保持关联。
3. 在 App 内将已索引的本地文件夹或视频/字幕文件重命名为包含键盘输入的日文浊音假名（如 `ガ`、`ダ`）的新名称后，重命名任务正常迅速完成，Library 与 File 页面列表正常展示，再次重命名、重新索引或移除该文件夹均正常无报错。
