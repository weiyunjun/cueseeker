# 需求描述

## 1. 搜索框高度与聚焦优化
1. **高度统一**：Workbench 搜索页与 Command Panel 的搜索框高度由 40px 收敛为 **36px**（统一使用 `--height-control`）。
2. **比例与对齐**：保持 14px 字号（占高度约 40%），图标与占位符垂直居中对齐。
3. **移除焦点光晕**：移除获得焦点时的外圈透明度光晕，聚焦时仅保留 1px 边框切换为 Accent 颜色。
4. **Command Panel 焦点可用性**：确保 Command Panel 打开时光标正常聚焦在搜索框中且接受键盘输入，不被播放页覆盖逻辑拦截。

## 2. 工具栏第二排与批量选择极简重构
1. **容器高度**：第二行整体高度统一为 **36px**（`--height-control`）。
2. **文字垂直下对齐**：第二行左侧文本（常规状态下的结果数、批量选择状态下的提示文案）在垂直方向改为**下对齐**，与右侧按钮底部保持齐平。
3. **取消横幅容器**：彻底移除批量选择时的有色背景卡片与边框。
4. **内容平替**：
   - 常规状态：左侧展示结果数（`xx results/excerpts`），右侧为筛选按钮；
   - 批量选择状态：左侧展示提示文案（`Batch selection active: click any row to select, Shift+click for range`，样式同结果数），右侧为 Neutral 按钮「退出选择」。

## 3. 布局间距与吸顶高度
1. **行间距**：第一排（搜索框）与第二排（操作行）的间距为 **8px**（`--spacing-2`）。
2. **表格间距**：第二排与下方表格的间距调整为 **8px**（`--spacing-2`）。
3. **吸顶高度对齐**：Excerpt 详情页吸顶高度同步更新为 **88px**（`36 + 8 + 36 + 8`）。

# 验收标准

1. 搜索框在 Workbench 和 Command Panel 中高度均为 36px，无外圈光晕，在 Command Panel 打开后光标自动聚焦且键盘可正常输入。
2. 第二行高度为 36px，左侧结果数及批量选择提示文本底部与右侧按钮底部对齐。
3. 进入批量选择状态无背景色块横幅，退出选择恢复原有结果数与筛选按钮。
4. 第一排与第二排间距为 8px，第二排与下方表格间距为 8px。
