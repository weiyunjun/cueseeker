# 需求描述

1. **长图拼接（Collage）兼容各类视频封装格式与伪装后缀视频（本地与远程）**：
   - 长图拼接提取视频画面时，对本地及远程（WebDAV、SMB、FTP、NFS）视频均根据文件内部实际封装格式（而非文件名后缀）决定是否启用 MKV / WebM 内封字幕与附件跳过加速，避免将 MKV / WebM 视频改名为其他后缀时丢失加速，或将非 MKV / WebM 视频改名为 `.mkv` / `.webm` 后缀时因参数不兼容而报错。
   - 提取视频画面时兼容全部受支持视频格式（含容器头未直接记录画面尺寸、带时间轴起点偏移，以及后缀名与内部实际封装不一致的视频），确保预览、复制与导出均正常生成画面且不报错中断。

2. **视频「文件详情」按内部真实封装格式展示文件格式（本地与远程）**：
   - 在 File 页面打开本地或远程视频文件的「文件详情」弹窗（`L-06.8 File Detail Dialog Layout`）时，`File Details -> Format`（文件格式）一栏根据视频文件内部实际封装格式展示对应的标准格式名称（格式为 `<标准格式名称> (.<对应小写后缀>)`）；若文件原后缀本身已属于其内部实际封装家族（如共用同一容器家族的 `.mpg` / `.mpeg` / `.vob`、`.ts` / `.m2ts` / `.mts`、`.wmv` / `.asf`、`.rm` / `.rmvb` 或通用 ISO 容器下的 `.mp4` / `.mov` / `.m4v` 等），则保持原后缀对应的标准格式名称不变；仅在文件不可读时回退按文件名后缀展示；弹窗顶部的文件名、文件列表卡片名称及文件路径均保持原文件名不变。

# 验收标准

1. 本地及远程文件夹中所有受支持的 20 种视频格式（含无文件头宽高参数、带时间轴起点偏移或后缀名与内部真实封装格式不一致的视频），均能正常执行 Collage 长截图预览、复制及导出。
2. 对含大量内封字幕与字体附件的 MKV / WebM 视频（含被改名为其他视频后缀的情况），Collage 抽帧依然保持跳过内封字幕与附件的加速效果；将非 MKV / WebM 视频改名为 `.mkv` / `.webm` 后缀时，Collage 长截图同样正常生成且不报错。
3. 在 File 页面查看本地或远程视频的「文件详情」时，弹窗顶部与列表文件名保持原文件名不变；当文件后缀与内部实际封装跨族不一致时，`Format` 一栏准确显示内部真实封装对应的标准格式名称；当文件后缀与其内部封装家族一致时，准确保持原后缀对应的标准格式名称。
