# 需求描述

1. **剥离播放器模块中的媒体库业务与直连数据库行为**：
   - 将媒体库封面候选抽帧打分、多尺寸封面生成入库、视频时长回填，以及截图/拼图默认文件命名与导出条数校验等产品业务规则收口至核心业务层，播放器模块仅保留纯粹的媒体帧提取、字幕合成与播放能力。
   - 移除播放器内部直接持有数据库文件路径并自行打开数据库连接的行为，改为通过只读数据提供接口获取所需的预计算字幕渲染数据。

2. **消除只读查询写库副作用与统一路径规范化逻辑**：
   - 移除读取最近播放摘录集摘要查询中夹带的隐式数据库修改操作，确保只读查询不产生写库副作用。
   - 将分散在多个模块中重复实现的文件夹路径前缀匹配与规范化逻辑统一收口至核心数据层。

3. **消除主窗口顶层与滚动状态的无效界面刷新**：
   - 移除主窗口顶部栏中声明但未使用的状态订阅，并将主窗口根视图中的弹窗层状态订阅隔离至独立子视图，避免后台任务进度或局部数据更新触发整个主窗口根视图重算。
   - 优化滚动期间的指针悬停抑制广播机制，避免列表滚动开始或结束时唤醒窗口内未处于悬停状态的按钮控件。

# 验收标准

1. 项目编译构建与全量单元测试通过，无新增编译告警。
2. 媒体库自动封面生成、视频时长解析、ASS 字幕分段渲染、截图与拼图导出、最近摘录集展示，以及主界面与播放页各控件的悬停、滚动与弹窗交互表现与改动前完全一致。
