# 需求描述

1. **现状问题**：
   - 单行文本输入框（包括工作台主搜索框、播放页 Command Panel 搜索框、新建与编辑摘录集名称输入框、改名输入框、Anki 导出输入框等）在显示默认填充文字（Placeholder）时，使用中文输入法输入拼音（未上屏组合态）时填充文字不会消失，导致拼音与填充文字重叠。

2. **修复要求**：
   - 文本输入框在用户开始输入任何内容（包括中文输入法未上屏的组合拼音）时，默认填充文字必须立即消失，严禁与输入字符重叠。
   - 输入内容完全清空且无未上屏字符时，默认填充文字正常恢复显示。

# 验收标准

1. 打开工作台主搜索框、播放页 Command Panel 搜索框，或新建/编辑摘录集名称输入框。
2. 切换至中文输入法，在输入框中键入拼音字母（未按空格/回车上屏）。
3. 验证输入框的默认填充文字在开始键入拼音的第一刻立即隐藏，界面无任何重叠文字。
4. 候选词上屏、以及将输入框内容退格完全清空后，填充文字的表现正常。
