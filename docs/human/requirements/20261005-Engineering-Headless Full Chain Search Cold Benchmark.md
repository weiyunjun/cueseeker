main

# 需求目标

建立无界面（Headless）的全链路搜索基准测试（Benchmark）标准与工具，无需启动 App 图形窗口，直接运行包含媒体库范围、SearchStore 分批收集、主线程状态提交及全量 Facet 聚合在内的真实完整链路，测量真实的冷搜索首屏时间与完整结果时间，并完成基准建档。

# 需求

1. **无界面全链路覆盖**：
   - 测试必须在无需启动 App 图形窗口（Headless）的环境下运行。
   - 必须覆盖完整真实搜索链路：包含实际媒体库目录范围过滤（`selectedFolders`）、后台分批数据收集、`SearchStore` 主线程首屏与完整状态提交、以及全量 Facet 聚合计算。
2. **测试词与独立冷采样**：
   - 固定使用 3 个关键测试词：`大丈夫`、`今日`、`の`。
   - 每个搜索词必须严格进行 **5 次独立冷搜索测试**，每次测试隔离连接与缓存，杜绝热缓存污染。
3. **两项核心指标采集**：
   - **首屏渲染就绪时间**：从触发搜索到首屏结果（前 100 条）在主线程提交并就绪的时间。
   - **完整结果就绪时间**：从触发搜索到全量结果扫描完毕、完成全量 Facet 聚合计算与数据源快照就绪的时间。
4. **基准建档与工具化**：
   - 提供可复现该测试的自动化基准工具，输出 5 次采样的原始数据（Raw）、中位数（Median）及极值范围，写入工程文档作为性能基线。

# 验收

1. 提供无需启动 App 的基准测试命令，针对 `大丈夫`、`今日`、`の` 均完成 5 次独立冷测试。
2. 实测数据真实反映全链路端到端耗时（其中 `の` 完整结果时间真实体现包含全量 Facet 等开销的约 3 秒水平），产出完整的原始数据与中位数。
3. 基准测试标准与当前版本的 Baseline 正式录入工程文档。
4. 既有自动化测试保持全绿通过。
