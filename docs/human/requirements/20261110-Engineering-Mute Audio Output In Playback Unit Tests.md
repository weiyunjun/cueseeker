# 需求描述

1. **播放相关单元测试全程静音运行**：
   - 在所有拉起真实播放引擎进行音视频播放验证的单元测试中，将测试播放器的输出音量统一设为静音（`0`），消除测试运行期间向系统扬声器或耳机输出高频正弦波蜂鸣音的问题。
   - 保持音频解码、重采样、缓冲队列调度、音画时钟同步、音轨切换、单句自动暂停与音频耗尽自然结束等完整测试链路不变，不影响正式应用的默认播放音量与任何产品行为。

# 验收标准

1. **单元测试零噪音输出**：开启系统声音运行完整单元测试套件时，全程不再发出任何蜂鸣音或刺耳噪音。
2. **测试覆盖与断言保持完整**：所有音视频播放、时钟对齐、音轨切换、自动暂停与自然结束相关的单元测试均完整执行并全部通过。
