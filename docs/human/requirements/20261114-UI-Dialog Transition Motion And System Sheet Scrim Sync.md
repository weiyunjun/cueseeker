# 需求描述

1. **统一对齐 `C-10.1 Dialog` 进出场动效规范与 Token 表达（`UI Tokens.md`、`C-10.1 Dialog`）**：
   - 所有主窗口与设置窗口内由 App 绘制的对话框（覆盖 `L-06.1` ~ `L-06.9`、`L-06.11` 与 `C-10.2 Confirmation Dialog`）统一共用同一套 `C-10.1 Dialog` 动效与遮罩规范，严禁在代码中硬编码参数或为单个弹窗编写私自特殊实现，所需调整须全部可表达于 `UI Tokens.md`（`Dialog Motion` 与 Scrim 相关 Token）与 `C-10.1 Dialog` 规则条目中。
   - 对话框入场与退场的位移曲线、内容淡入淡出节拍及背景压暗（Scrim）淡入淡出曲线按 macOS 原生弹出窗口表现对齐（退场不再强制倒放同一曲线，可在 `Dialog Motion` Token 组内区分进场、退场与 Scrim 动效参数）；系统开启「减弱动态效果」时，取消垂直位移动画并改用统一的纯透明度平滑过渡。

2. **消除弹窗动画起止闪动与视觉跳变（`C-10.1 Dialog`）**：
   - 对话框容器（含背景、圆角、外描边、内高光、阴影）及其内部全部内容（标题、可选中文本、输入框、滚动区域、按钮等）在入场、静止、被上层覆盖及退场全过程中保持一致的整体视觉呈现，动画开始或结束最后一帧不发生整体闪动、明暗跳变或残影切换。

3. **规范叠加系统文件选择框 / 系统警告框时的 Scrim 交接表现**：
   - 各系统文件选择框（如 `Export to Anki` 选择导出目录、`Edit Cover` 选择封面图片等）与系统警告框保持 macOS 原生弹出与系统规范不变；同时保证窗口顶部拖动与双击缩放响应区独立于 Scrim 变化，不随遮罩淡入淡出引发闪烁。
   - **系统面板打开阶段**：任一主窗口内对话框之上弹出系统文件选择框或系统警告框时，自绘 Scrim 按统一规格平滑淡出让位给系统原生遮罩（Light / Dark 模式按对应 Token 衔接），消除打开瞬间的突兀闪屏。
   - **系统面板关闭/取消阶段**：用户点击系统面板的 `Cancel` 或确认按钮、系统面板开始退出且系统遮罩开始同步淡出的同一时间，自绘 Scrim 必须立即同步淡入衔接，避免等到系统面板彻底离屏、背景完全变亮之后才重新恢复灰色遮罩。

4. **保持既有窗口关闭与退出交互规则不变（零退步约束）**：
   - 除 `Confirmation` 位于最上层以外的主窗口内对话框打开期间，主窗口左上角红灯保持可用，点击红灯、`Cmd+Q` 与 Dock 栏“退出”照常直接关闭 App；仅 `Confirmation` 位于最上层时维持阻止关闭/退出（系统关机、重启、注销除外）。
   - 系统文件选择框或系统警告框处于打开期间的红灯与关闭表现维持系统原生规范，关闭系统面板返回原业务弹窗后立即恢复该业务弹窗原本的可关闭状态。

5. **设计文档同步安排**：
   - 关联 UI 设计文档中对应的 `Dialog Motion` / Scrim Token 及 `C-10.1 Dialog` 规则变更，待本次改动验收与视觉微调完成后再统一提交更新。

# 验收标准

1. **弹窗进出场过渡与无闪烁验收（Light & Dark）**：打开与关闭 `Edit Cover`、`Excerpt List Editor`、`Rename`、`Export to Anki`、`Task Panel` 与 `Confirmation`（含弹窗上叠加 `Confirmation`）时，滑入滑出与背景压暗过渡自然贴近 macOS 原生弹出窗口；动画最后一帧结束以及开启/关闭快速打断时均无闪动或明暗跳变；系统开启「减弱动态效果」后无垂直位移，仅平稳淡入淡出。
2. **叠加系统文件选择框衔接验收（Light & Dark）**：在 `Export to Anki` 点击文件夹图标、在 `Edit Cover` 触发选图时，打开系统面板瞬间背景无突兀闪屏；点击 `Cancel` 或确认返回后，背景平稳衔接保持压暗状态，不再出现先彻底取消灰色蒙版变全亮、随后又重新变暗的断层现象。
3. **关闭/退出与既有交互零退步验收**：上述任意非 `Confirmation` 对话框单独打开时，红灯可用，点击关闭窗口、按 `Cmd+Q` 及 Dock 栏“退出”均可直接关闭 App；从系统文件选择框点 `Cancel` 回到 `Export to Anki` / `Edit Cover` 后红灯立即恢复可用；`Confirmation` 打开时红灯变灰并拦截 `Cmd+Q` / Dock 退出；窗口顶栏高度内拖动/双击缩放、下层冻结及弹窗内键盘/Tab/文本选择均保持正常。
