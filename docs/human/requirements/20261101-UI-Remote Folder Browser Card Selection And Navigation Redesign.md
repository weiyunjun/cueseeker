# 需求描述

1. **远程文件夹浏览列表（Step 2）行结构与交互重构**：
   - **移除左侧勾选框**：取消远程文件夹浏览列表（WebDAV / SMB / FTP / NFS）中文件夹卡片内部的左侧 `Checkbox`，将每个文件夹行拆分为**左侧文件夹主卡片**与**右侧独立的 `>` 进入按钮**（水平间距 `--spacing-3`）。
   - **左侧文件夹主卡片与文件卡片**：
     - 卡片左边缘与顶部面包屑及底部 `Back` 按钮左边缘对齐。
     - **未添加的文件夹卡片**：单击卡片本体切换选中状态（支持同层级多选）。未选中时使用标准卡片默认、Hover 与 Pressed 样式；选中时复用 `Filter Chip` 选中态视觉样式（系统强调色浅底与系统强调色边框，并具备对应的选中态 Hover 与 Pressed 底色反馈）。
     - **已添加的文件夹卡片**（含已被已添加根目录覆盖的子目录）：卡片内部右侧展示 `Added` / `已添加` / `已加入` 胶囊标签（复用 `Watch Status Badge` 的 `Finished` 样式）；卡片本体不可被选中，无 Hover 与 Pressed 反馈。
     - **视频与字幕文件卡片**：不可点击且无 Hover 与 Pressed 反馈；卡片右边框与上方文件夹主卡片的右边框垂直对齐（右侧留空，保持所有主卡片等宽）。
   - **右侧独立 `>` 进入按钮**：
     - 位于所有文件夹主卡片（包含未添加与已添加的文件夹）右侧，高度与主卡片一致，水平内边距为 `--padding-control-x`，居中展示 `caret-right` 图标（`--size-card-chevron`），具备独立的默认、Hover 与 Pressed 样式；按钮右外边缘与底部主操作按钮右外边缘对齐。
     - 点击右侧 `>` 按钮进入对应子目录查看下一级内容（已添加的文件夹同样允许点击右侧 `>` 按钮进入下一级浏览）。

2. **底部主操作按钮动态文案**：
   - **未选中子文件夹（`0` 个）**：文案显示 `Add Current Folder` / `添加当前文件夹` / `加入目前資料夾`，启用与禁用条件保持现有逻辑不变。
   - **选中 `1` 个子文件夹**：文案显示 `Add 1 Folder` / `添加 1 个文件夹` / `加入 1 個資料夾`，按钮启用。
   - **选中 `N`（`N > 1`）个子文件夹**：文案显示 `Add N Folders` / `添加 N 个文件夹` / `加入 N 個資料夾`，按钮启用。

# 验收标准

1. WebDAV、SMB、FTP、NFS 弹窗进入第二步目录浏览后，文件夹行均由左侧主卡片与右侧独立 `>` 按钮组成，不再出现左侧勾选框；右侧 `>` 按钮右边缘与底部主按钮右边缘对齐，下方视频与字幕文件卡片的右边缘与上方文件夹主卡片右边缘对齐。
2. 单击未添加的文件夹主卡片可正常切换选中态并呈现系统强调色底色与边框（含 Hover 与 Pressed 状态变化）；已添加的文件夹主卡片内部右侧显示 `已添加` 胶囊标签且点击主卡片不会选中；无论文件夹是否已添加，点击右侧独立的 `>` 按钮均可进入下一级目录。
3. 底部主按钮在未选中、选中 1 个、选中多个文件夹时，简/繁/英三语文案均按 `添加当前文件夹`、`添加 1 个文件夹`、`添加 N 个文件夹` 动态切换，且添加行为与启用状态准确无误。
