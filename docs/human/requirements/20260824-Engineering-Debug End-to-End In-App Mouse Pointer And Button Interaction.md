# 版本

main

# 需求描述

扩展现有 CueSeeker Debug E2E 控制器，增加应用内鼠标指针移动、右键点击和可分离拖拽事件，并允许查询当前鼠标指针可见状态，使自动化端到端测试能够覆盖依赖 hover、右键菜单和文字拖选的界面行为。

# 需求要求

1. 新增鼠标移动命令，参数包含目标坐标和当前 `sceneID`，向该坐标下最前方的可见 CueSeeker 窗口发送移动事件，并触发对应的进入、移动和离开行为。
2. 新增右键点击命令，参数包含目标坐标和当前 `sceneID`。
3. 新增可分离的拖拽能力：按下、拖动、抬起作为独立命令按顺序发送，用于文字拖选等需要中间过程的交互。
4. `inspect` 结果新增当前鼠标指针可见状态。
5. 坐标系沿用现有完整界面坐标；截图规则不变，截图仍不包含鼠标指针。
6. 所有事件通过正常 AppKit 事件路径发送，不直接调用控件操作或修改业务状态。
7. 不移动真实鼠标，不发送系统级全局事件，不申请 Accessibility 或 Input Monitoring 权限。
8. `sceneID` 过期、坐标越界、目标窗口不存在、拖拽顺序不合法或事件创建失败时必须明确失败，且不得发送事件。
9. 本需求不包含触控板手势、惯性滚动、双击、点击修饰键和横向滚动。
10. 该能力只在显式启用的 Debug E2E 流程中存在，Release App 不得包含或启用。
11. 更新 `docs/engineering/08_end_to_end_testing.md`，记录新增命令格式、参数语义、使用示例和失败条件。
12. 自动化测试覆盖命令解析、参数校验、前方窗口命中、拖拽顺序校验和现有 E2E 命令回归。

# 验收标准

1. 移动到视频卡片或列表行后，截图可确认 hover 效果出现；移开后消失。
2. 移动到视频卡片后发送右键点击，可打开封面右键菜单；在列表行发送右键点击，可打开行右键菜单。
3. 按下、拖动、抬起顺序发送后，可在 Playback Overlay 完成文字拖选并弹出选中文字菜单。
4. 在播放界面执行键盘操作后 `inspect` 返回指针不可见，鼠标移动后返回指针可见。
5. 无效命令不改变界面状态。
6. 现有 `inspect`、`capture`、`click`、`scroll`、`keyPress`、`setWidth` 功能保持正常。
7. Release 隔离检查通过。
