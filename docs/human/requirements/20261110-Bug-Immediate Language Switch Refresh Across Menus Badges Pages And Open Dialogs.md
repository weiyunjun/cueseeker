# 需求描述

在独立设置窗口切换界面语言（跟随系统 / 简体中文 / 繁体中文 / English）后，全应用所有可见页面、控件、卡片、菜单、弹窗、悬停提示与播放浮层必须立即刷新为新语言文案，不得残留旧语言：

1. **设置页内部分段选择控件与输入控件实时跟随当前语言**：
   - 设置页（Settings）中所有分段选择控件（包括 General 页的「外观模式（浅色 / 深色 / 自动）」、Play 页的「解码器（硬件解码 / 软件解码 / 自动）」、Subtitle 页的「水平位置 / 垂直位置 / 边框类型」）在切换语言后，各分段选项文字与等宽布局立即刷新为新语言。
   - Shortcuts 页处于正在录制快捷键状态时，输入框占位提示语与清空按钮悬停提示实时跟随当前语言。

2. **卡片右键菜单与封面设置弹窗文案实时跟随当前语言**：
   - 视频卡片与剧集文件夹卡片右键菜单中的「更换封面（Change Cover）」选项，每次打开菜单时均按当前界面语言显示。
   - 「更换封面」弹窗与「新建 / 编辑摘录列表」弹窗中的弹窗标题、选择图片按钮、图片格式支持提示语及底部取消/保存按钮，每次展示及在打开状态下切换语言时均按当前界面语言显示。

3. **主界面常驻卡片、页面与工具栏在切换语言后立即刷新**：
   - Recent 页面、Library 剧集详情页及播放页 Command Panel 中，视频卡片上的观看状态徽章（观看中 / 已看完 / 未观看）在切换语言后立即更新为新语言。
   - 摘录列表详情页（Excerpt 详情页）在当前停留状态下切换语言时，顶部封面摘要卡的摘录数量与创建日期说明、主操作按钮、搜索框占位提示、工具栏按钮（筛选 / 排序）、字幕表格各列标题及空状态提示（含“未找到该摘录列表”提示）立即刷新为新语言。
   - 搜索页与摘录详情页处于批量多选模式或打开排序菜单 / 保存到摘录菜单时切换语言，顶部多选提示条、「退出多选」按钮及已打开菜单中的选项文案立即更新为新语言。
   - Library 剧集详情页与 Excerpt 详情页顶部封面摘要卡的主操作按钮（播放 / 继续播放）及顶部栏各入口图标按钮、搜索框清空按钮的悬停提示（Tooltip）与无障碍标签在切换语言后立即更新为新语言。

4. **主窗口已打开的弹窗在切换语言后实时刷新**：
   - 当主窗口处于打开弹窗状态、同时在设置窗口切换语言时，当前已打开的弹窗内容（包括筛选弹窗、Anki 导出弹窗、添加远程文件夹弹窗、重命名弹窗、新建/编辑摘录列表弹窗、删除确认弹窗、任务详情弹窗及文件详情弹窗中的空值占位文字、右上角关闭按钮悬停提示，以及各弹窗内已触发的表单校验提示）均实时更新为新语言。

5. **播放页与播放浮层细节在切换语言后实时刷新**：
   - 播放页顶部栏左上角返回按钮、底栏播放/暂停、音量静音、倍速、自动切换间隔步进器（`- / +`）的悬停提示（Tooltip）与无障碍标签、已打开的「更多（音轨）/ 字幕」菜单、默认未选中视频标题及左上角播放报错提示横幅，在切换语言后实时更新为新语言。
   - 播放页悬浮面板（Playback Overlay）处于播放列表（Playlist）或字幕拼图（Collage）标签页时切换语言，底部栏的数量统计文字与操作按钮立即刷新为新语言。

# 验收标准

1. 在设置窗口 General 页切换语言后，当前页面的「Appearance Mode（浅色 / 深色 / 自动）」分段按钮文字与宽度立即变为新语言；切换到 Play 与 Subtitle 页时，其中的分段选择控件同样显示为新语言。
2. 启动应用后在设置中切换语言，在 Recent 或 Library 页面右键点击任意视频卡片或剧集卡片，菜单中的「更换封面」及全部菜单项均显示为新语言；卡片上的「观看中 / 已看完 / 未观看」状态徽章立即变为新语言。
3. 停留在 Excerpt 详情页、Library 剧集详情页或 Search 页面（含批量多选模式及打开排序/摘录目标菜单状态）时切换语言，顶部封面摘要卡的统计信息、「播放 / 继续播放」按钮、搜索栏、工具栏按钮、多选提示条、表格表头列名及空状态提示全部立即更新为新语言，无需切换页面或重新进入。
4. 在主窗口打开「更换封面」、筛选（Filter）、Anki 导出、添加远程文件夹、重命名、新建/编辑摘录列表、删除确认、任务详情或文件详情等任一弹窗（含已触发输入校验错误提示的状态）时，在设置窗口切换语言，已打开的弹窗标题、表单标签、选项、校验提示与按钮文字均立即更新为新语言。
5. 在播放页及播放页悬浮面板（Current / Playlist / Collage）打开状态下切换语言，顶部返回按钮、底栏各控制按钮与间隔步进器悬停提示、已打开的音轨/字幕菜单、错误提示横幅及底部栏的统计文字与操作按钮均立即显示为新语言。
