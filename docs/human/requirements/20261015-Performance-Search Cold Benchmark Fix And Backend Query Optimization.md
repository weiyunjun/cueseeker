main

# 需求描述

1. **搜索基准测试（Benchmark）真冷搜与指标修正**：
   - 修复冷搜索测试中后续轮次命中系统缓存导致耗时偏低的问题，确保每次搜索测试均在完全无缓存（物理冷读）的状态下独立执行。
   - 保持对 `大丈夫`、`今日`、`の` 三个标准测试词进行 5 轮测试，统计结果以 **5 轮平均值（Average）** 作为主指标，同时输出每轮原始数据（Raw）。
   - 输出指标需完整覆盖：**首屏时间（含防抖）**、**完整结果时间（含防抖与主线程状态提交）**、**纯后端首屏时间**、**纯后端完整时间（含数据库查询与主线程提交拆分）**。

2. **搜索后端全链路性能优化**：
   - 优化搜索数据库查询、索引结构、内存行匹配及主线程状态提交链路，降低中高频词在冷搜索下的首屏与全量完成耗时，且不影响现有搜索排序、高亮、语言过滤及分面统计结果的准确性。

# 验收标准

1. 先基于修正后的真冷搜 Benchmark 采集修改前基线数据，每轮测试之间无缓存加速现象。
2. 完成搜索后端优化后，输出修改前后的真冷搜 Benchmark 对比数据，高频词（`の`）与中频词（`大丈夫`、`今日`）的纯后端及完整搜索平均耗时显著下降。
3. 搜索结果数量、排序、分面计数及既有自动化测试全部保持通过。
