# 需求描述

1. **播放运行时 CPU 与子系统负载埋点日志**：
   - 在视频播放期间按固定周期（如每 10 秒）及停止/满 60 秒时，向控制台输出单行汇总性能日志。
   - 埋点指标需覆盖：**墙钟与媒体推进时长**、**进程累计 CPU 时间差分（User / System 秒数及折算占比）**、**硬件退役指令数差分（`ri_instructions`）与线程唤醒次数差分（`task_interrupt_wakeups`）**，以及**视频解码/像素转换、音频缓冲调度、字幕采样与重绘次数**等核心子系统计数与耗时。

2. **底层播放与字幕管线 CPU 性能优化**：
   - 消除字幕渲染管线在静默区间与静止区间的无差别高频轮询，优化位图合成与内存复用。
   - 优化视频软解像素格式输出（支持 8-bit `NV12` 与 10-bit `P010` 直转）与帧上屏提交链路，消除每帧固定派发主线程上屏及逐帧构造截图快照对象的开销，改为后台线程直接入队上屏、仅在首帧回调时通知主线程，并按需惰性构造截图快照。
   - 消除播放稳态下无条件高频运行的饥饿看门狗定时器唤醒，仅在实际等待解码包时按需检测。
   - 优化音频播放管线在常速下的节点旁路、缓冲合并调度与平面音频样本内存拷贝（`memcpy`），降低高频回调与对象分配开销。
   - 所有优化不得影响现有的播放画质、音画同步精度、字幕样式还原、Seek 响应及截图功能。

# 验收标准

1. 先基于埋点日志采集同一视频播放 1 分钟的修改前基准数据。
2. 完成底层播放与字幕优化后，播放同一视频 1 分钟并对比埋点日志，累计 CPU 时间、指令数、唤醒次数及各子系统无效调用显著下降。
3. 与参考播放器播放同一视频进行系统活动监视器直观对比，CPU 占用大幅改善且符合预期，既有自动化测试全部通过。
