# 需求描述

1. **封面卡片统一遵循全局 `Hover` 与指针样式重判规则**：
   - 全应用各封面卡片界面（`Library` 一/二级、`Recent`、`Excerpt` 一级、`Playback Overlay` 播放列表、`Command Panel`）的 `C-11.5 Media Card` 统一遵循与其余交互控件一致的层级冻结/解冻、滚动防抖及窗口焦点状态机，不保留独立的局部例外判定：
     1. 当通过右键点击封面卡片或点击封面右下角 `dots-three` 按钮弹出菜单，或打开上层浮层/对话框使卡片所在层级进入冻结，随后关闭菜单或上层界面解除冻结时，无需再次移动鼠标，立即按当前指针实时落点重判卡片 `Hover` 与鼠标指针样式：
        - 若指针当前位于非卡片空白区域或其它非 `Grab` 区域，立即清除原关联卡片的 `Hover` 背景与 `dots-three` 按钮，鼠标指针同步呈现当前落点对应的样式（如空白区域保持默认箭头、可选/可输入文本区域为 `I-beam`），不得残留原卡片 `Hover` 或错误切换为 `Grab` 抓手样式；
        - 若菜单或上层界面打开期间指针已移至同层另一张可用封面卡片上，解除冻结时立即清除原卡片 `Hover`，同步点亮当前落点下的新卡片 `Hover` 并切换指针样式（卡片主体为 `Grab`，`dots-three` 按钮上为默认箭头）；
        - 若指针仍停留在原可用封面卡片上，解除冻结后继续保持该卡片 `Hover`，指针样式按当前位于卡片主体或 `dots-three` 按钮同步为 `Grab` 或默认箭头。
     2. 滚轮停止满 `300ms` 防抖结束、窗口失焦与重获焦点、以及键盘/手柄导航抑制期间与恢复后，封面卡片 `Hover` 与指针样式继续严格遵循统一交互规则，且不影响窗口原生焦点与单击响应。

# 验收标准

1. **右键或 `dots-three` 打开卡片菜单后在空白区关闭**：在封面卡片上右键（或点击右下角 `dots-three` 按钮）打开菜单，将鼠标移至非卡片空白区域后左键点击或按 `Esc` 关闭菜单，原卡片的 `Hover` 高亮与 `dots-three` 按钮立即消失，鼠标指针保持默认箭头样式，不变成 `Grab` 抓手。
2. **菜单打开期间移至另一张卡片后关闭**：在封面卡片 A 上打开菜单，将鼠标移至另一张可用封面卡片 B 上并左键点击或按 `Esc` 关闭菜单，卡片 A 的 `Hover` 立即清除、卡片 B 立即进入 `Hover` 状态，鼠标指针在卡片主体上同步变为 `Grab` 抓手（在 `dots-three` 按钮上为默认箭头）。
3. **从卡片菜单打开对话框再关闭**：通过卡片菜单打开对话框（如更换封面或查看文件信息），在非原卡片位置关闭对话框后，下层解除冻结时原卡片 `Hover` 立即清除，指针样式与当前落点一致。
4. **跨界面与既有状态联动一致**：在 `Library` 一/二级、`Recent`、`Excerpt` 一级、`Playback Overlay` 与 `Command Panel` 中，右键跨卡片接力切换菜单、滚轮滚动停止满 `300ms`、切换应用或独立设置窗口导致主窗口失焦与重获焦点时，封面卡片 `Hover` 与鼠标指针样式均实时准确同步。
