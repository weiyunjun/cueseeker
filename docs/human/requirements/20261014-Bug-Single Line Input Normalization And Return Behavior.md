# 需求描述

## 1. 单行输入与多行输入的边界

1. 除明确定义为多行文本域（`Text Area`，如 `New List` / `Edit List` 的 `Description`）的控件外，全应用所有搜索框、普通文本输入框、密码框与数字输入框均为单行输入框，严禁出现多行输入或换行显示。
2. **搜索框与单行文本输入框**：
   1. 按下 `Enter`、`Shift+Enter`、`Option+Enter`、`Ctrl+Enter` 均不插入换行符。
   2. 粘贴或输入包含换行符的文本时，在输入瞬间直接将换行符替换为空格并单行显示，光标停在插入内容末尾，无先显示多行再跳变的延迟，也无需再按方向键才变为单行。
3. **Settings 数字输入框**：
   1. 禁止换行输入；输入或粘贴包含换行符、非数字字符或超出立即限制范围的内容时，在输入瞬间直接过滤并单行显示，无闪烁或延迟跳变。

## 2. 按下回车键的交互行为

1. **`WebDav Folder` 对话框**：按下回车键（或切换焦点）不触发 `Add` 按钮。
2. **单行输入框、数字输入框与 Workbench 搜索框**：非输入法组合态下按下回车键时，不换行、不触发对话框确定按钮，且**不将框内文字全选，光标保持在原位置不动**（数字输入框越界时按原有规则修正为边界值且不全选文字）。
3. **输入法组合态**：存在未上屏字符时，按下回车键正常执行字符上屏。
4. **播放页 `Command Panel` 搜索框**：保持非输入法组合态下按回车键执行当前选中项操作的既有行为。

## 3. 输入框点击聚焦与指针区域

1. 搜索框与单行输入框的整个边框容器内部（搜索框右侧的清除按钮除外）均显示 `I-beam` 指针，左键点击容器内任意位置均可直接聚焦输入框。

# 验收标准

1. 在所有搜索框与对话框单行输入框中粘贴多行文本或按 `Option+Enter` / `Ctrl+Enter`：输入瞬间直接单行显示（换行转空格），无多行折行、无闪烁延迟。
2. 在 Settings 各数字输入框中粘贴含换行或非数字字符的文本：输入瞬间直接过滤显示，无延迟跳变。
3. 在 `WebDav Folder` 对话框内按回车或切换输入框焦点，均不会触发 `Add`。
4. 在 Workbench 搜索框、对话框单行输入框、Settings 数字输入框中按回车：文字不会被全选，光标保持在原位置。
5. 鼠标移入搜索框和单行输入框边框内任意非按钮区域均保持 `I-beam` 指针，点击边缘区域可正常聚焦且文字排版不与图标或边缘重叠。
