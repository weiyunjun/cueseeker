# 需求描述

## 1. 单行输入与多行输入的边界

1. 除明确定义为多行文本域（`Text Area`，如 `New List` / `Edit List` 的 `Description`）的控件外，全应用所有搜索框、普通文本输入框、密码框与数字输入框均为单行输入框，严禁出现多行输入或换行显示。
2. **搜索框与单行文本输入框**：
   1. 按下 `Enter`、`Shift+Enter`、`Option+Enter`、`Ctrl+Enter` 均不插入换行符。
   2. 粘贴或输入包含换行符的文本时，在输入瞬间直接将换行符替换为空格并单行显示，光标停在插入内容末尾，无先显示多行再跳变的延迟，也无需再按方向键才变为单行。
3. **Settings 数字输入框**：
   1. 禁止换行输入；只允许输入十进制数字字符，禁止输入小数点 `.`、负号 `-` 及任何其它非数字字符，输入或粘贴时在输入瞬间直接过滤并单行显示，无闪烁或延迟跳变。
   2. `Settings - Play` 的 `Auto Switch Gap` 取值范围为 `0 ~ 10000` 的整数，输入或粘贴超出 `10000`（含超长数字串）时在输入瞬间直接截断为 `10000`。
   3. `Settings - Subtitle` 的 `Size` 为正整数（`≥ 1`，不设上限），`Letter Spacing`、`Line Spacing`、`Outline Width`、`Blur`、`Shadow Offset`、`Margin X`、`Margin Y` 为非负整数（`≥ 0`，不设上限）。
   4. 数字输入框为空或处于未生效状态时，失焦或按下回车键自动恢复为上一次的有效数字（`Size` 小于 `1` 时修正为 `1`）；选中已有数字后输入纯非法字符时直接拦截，不清空原有数字。
4. **聚焦态字体与排版一致性**：当输入框为空时粘贴或输入触发单行净化/字符过滤的内容，框内文字字号、颜色与对齐方式保持不变，不得出现聚焦态字号变小。

## 2. 按下回车键的交互行为

1. **`WebDav Folder` 对话框**：按下回车键（或切换焦点）不触发 `Add` 按钮。
2. **单行输入框、数字输入框与 Workbench 搜索框**：非输入法组合态下按下回车键时，不换行、不触发对话框确定按钮，且**不将框内文字全选，光标保持在原位置不动**（数字输入框越界或为空时修正为边界值/恢复旧值且不全选文字）。
3. **输入法组合态**：存在未上屏字符时，按下回车键正常执行字符上屏。
4. **播放页 `Command Panel` 搜索框**：保持非输入法组合态下按回车键执行当前选中项操作的既有行为。

## 3. 输入框点击聚焦与指针区域

1. 搜索框与单行输入框的整个边框容器内部（搜索框右侧的清除按钮除外）均显示 `I-beam` 指针，左键点击容器内任意位置均可直接聚焦输入框。

# 验收标准

1. 在所有搜索框与对话框单行输入框中粘贴多行文本或按 `Option+Enter` / `Ctrl+Enter`：输入瞬间直接单行显示（换行转空格），无多行折行、无闪烁延迟，且空框输入时字号不缩小。
2. 在 Settings 各数字输入框中输入或粘贴小数点 `.`、负号 `-`、换行符或其它非数字字符：输入瞬间直接过滤，空框输入时字号不缩小；`Auto Switch Gap` 输入超长数字立即截断为 `10000`；清空或输入非法内容后失焦/按回车自动恢复旧数字。
3. 在 `WebDav Folder` 对话框内按回车或切换输入框焦点，均不会触发 `Add`。
4. 在 Workbench 搜索框、对话框单行输入框、Settings 数字输入框中按回车：文字不会被全选，光标保持在原位置。
5. 鼠标移入搜索框和单行输入框边框内任意非按钮区域均保持 `I-beam` 指针，点击边缘区域可正常聚焦且文字排版不与图标或边缘重叠。
