### 版本
main
### 需求描述
优化边栏的搜索结果列表和当前视频字幕列表的前端渲染，采用和测试的Search界面的表格视图类似的处理：虚拟化，按需加载，解耦内容区域和滚动条等。
### 验收标注
1. **Search 播放上一条/下一条**
   搜索 `の` 后，从任意搜索入口进入播放，点击上一条/下一条不应等待全量搜索结果重建。
2. **边栏搜索结果列表**
   只加载当前播放结果附近窗口；快速切换结果时旧加载任务要取消，不能阻塞新结果。
3. **当前视频字幕列表**
   打开视频时不应把完整字幕内容一次性塞进 UI 数据源；滚动条和可见内容解耦，快速滚动不卡顿。
4. **UI 不变**
   不改变现有播放页边栏样式、交互位置、按钮和视觉层级。
5. **生命周期**
   切换搜索、切换视频、快速点下一条时，旧任务不能回写新界面。
