# 需求描述

1. **索引阶段补齐保存字幕字符编码，升级数据库支持完整快照**：
   - 升级数据库，在字幕索引记录中新增保存字符编码（`Encoding`，如 `UTF-8`、`UTF-8 (BOM)`、`UTF-16 LE` 等）；
   - 新添加或重新索引字幕时，在解析字幕阶段直接将识别出的字符编码存入数据库；
   - 对升级前已入库但尚未记录字符编码的旧字幕，在下次执行 `Index All` 或 `Index This Folder` 时，即使字幕文件未发生修改，也自动补齐写入字符编码（仅补齐该元数据且无台词增删改时，不触发任务末尾的数据库压缩）。

2. **查看详情（`Get Info`）100% 纯读索引快照，消除点击瞬间的文件访问与主线程阻塞**：
   - 在 `File` 页面点击文件夹、视频或字幕的 `Get Info` 打开详情弹窗（含预加载同集配对文件列表与各自详情）时，全部数据 100% 直接从数据库索引快照读取，不再访问本地磁盘文件属性，也不再读取和全文解码任何本地或远程字幕源文件；
   - 若升级前已入库的旧字幕尚未重新执行索引，其 `Encoding` 字段与其他缺失元数据一致展示占位符 `-`。

3. **消除详情弹窗入场动画掉帧，保证弹出过程流畅**：
   - 从右键菜单或操作菜单点击 `Get Info` 打开详情弹窗时，菜单收起与弹窗出现之间的界面遮挡冻结状态无缝交接，避免底层 `File` 页面文件列表在弹窗滑入期间发生「先解冻再重新冻结」的连带全量刷新；
   - 隔离详情弹窗开关状态与底层文件列表，消除弹窗首帧挂载时的冗余尺寸状态回写与重复布局测量，确保弹窗 270ms 入场动画全程流畅无卡顿。

# 验收标准

1. **索引编码持久化与增量回填正常**：新索引字幕或对已有文件夹执行 `Index All` / `Index This Folder` 后，字幕详情中的 `Encoding` 准确展示真实编码名称；升级后未重新索引的旧字幕默认展示 `-` 且不触发磁盘或网络读取。
2. **点击 `Get Info` 即时响应无卡顿**：在 `File` 页面对任意视频（含配对多条大体积特效字幕的剧集）或字幕点击 `Get Info` 时，不再发生磁盘文件读取与全文解码，点击瞬间无主线程阻塞，即使源文件离线或不可读仍可正常查看已索引快照详情。
3. **弹窗入场动画流畅无掉帧**：打开视频、字幕或文件夹详情弹窗时，270ms 入场动画平滑顺畅，弹窗内切换同集配对文件、关闭弹窗及各项视觉与交互表现均无回退，自动化测试全部通过。
