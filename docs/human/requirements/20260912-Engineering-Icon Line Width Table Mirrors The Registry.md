# 需求描述

## 1. 目标

代码中的图标线宽表是 `Icon Registry.md` 尺寸与线宽表的镜像，目前缺少 20px 一行。补齐它，使镜像与文档逐行一致。

## 2. 要求

1. 线宽表补入 20px 对应 1.30px。
2. 表的尺寸集合与 `Icon Registry.md` 完全一致，不多不少。
3. 以一条单元用例固定该尺寸集合与对应线宽；文档的表变动时该用例一并更新。
4. 本次不改变任何界面正在使用的图标尺寸，也不新增 20px 图标的使用点。

## 3. 不变的部分

图标的制作规格、母版线宽、Fill 变体规则与图标名录保持现状。

# 验收

1. 线宽表的尺寸集合为 14 / 16 / 18 / 20 / 21 / 23 / 31 / 42 / 47 / 57，各自线宽与 `Icon Registry.md` 相同。
2. Debug 构建下以表中任一尺寸绘制描边图标，不触发「无文档线宽」断言。
3. 现有自动化端到端与单元用例全部通过。
