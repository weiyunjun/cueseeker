# 需求描述

1. **字幕改绑到新视频时，彻底清理不再匹配任何有效字幕的旧视频及其关联状态**：
   - 当目录中的字幕文件保持不变（或同时发生修改），但因视频替换或扩展名优先级变化而改绑到另一个视频文件时（例如目录中原有 `非自然死亡01.Chs.srt` + `非自然死亡01.mp4`，将 `非自然死亡01.mp4` 替换为 `非自然死亡01.mkv` 后执行 Index）：
     - 若原先配对的旧视频（如 `非自然死亡01.mp4`）不再匹配任何有效字幕，必须将该旧视频及其关联的观看状态、观看进度、播放历史等数据彻底移除，不得在后台残留失效记录。
2. **后续同名同路径视频重新入库时按全新视频初始化**：
   - 当上述已脱离匹配并被清理的视频文件名后续再次出现在同一路径下并重新配对入库时（例如之后再将 `非自然死亡01.mkv` 换回一个新的 `非自然死亡01.mp4` 并执行 Index），必须将其视为全新视频文件，观看状态初始化为 `Unwatched`、观看进度初始化为 `0`，不得复用此前已脱离匹配时的旧观看状态或观看进度。

# 验收标准

1. 目录中存在字幕与 `非自然死亡01.mp4`，完成 Index 后播放 `非自然死亡01.mp4` 产生观看进度或修改观看状态（如 `Watching` 或 `Finished`）。
2. 将磁盘上的 `非自然死亡01.mp4` 替换为 `非自然死亡01.mkv` 并执行 Index，`非自然死亡01.mkv` 作为新视频入库，观看状态为 `Unwatched`、观看进度为 `0`，且旧 `非自然死亡01.mp4` 的记录与观看状态、进度被彻底清理。
3. 再将磁盘上的 `非自然死亡01.mkv` 删掉、放回 `非自然死亡01.mp4` 并执行 Index，新入库的 `非自然死亡01.mp4` 观看状态重置为 `Unwatched`、观看进度重置为 `0`，Recent 界面中也不再残留其旧的观看记录。
