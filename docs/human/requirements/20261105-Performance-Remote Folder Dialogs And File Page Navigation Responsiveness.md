# 需求描述

1. **消除远程目录弹窗（`WebDAV` / `SMB` / `FTP` / `NFS`）打开与切步时的掉帧**：
   - 从 `File` 页面 `Add Folder` 菜单点击打开 `WebDAV Folder`、`SMB Folder`、`FTP Folder` 或 `NFS Folder` 弹窗时，菜单收起与弹窗出现之间的下层界面遮挡冻结状态无缝交接，隔离弹窗状态与底层 `File` 页面列表，避免弹窗 270ms 入场动画期间触发底层页面连带整页重绘与主线程卡顿；
   - 从弹窗第 1 步连接进入第 2 步目录浏览，或在目录浏览中进入子目录、点击面包屑切换层级时，目录卡片列表按可视区域按需渲染，消除大量远程文件夹与文件卡片一次性全量挂载造成的主线程阻塞。

2. **远程目录（`WebDAV` / `SMB` / `FTP`）连接与子目录浏览会话复用加速**：
   - 对齐 `NFS` 的连接复用体验，为 `WebDAV`、`SMB` 与 `FTP` 建立活跃连接会话复用机制：在弹窗连接、子目录浏览及后续文件夹扫描读取期间复用已建立的网络连接与认证会话，消除每次点击连接、进入子目录或读取目录时重复建立连接、重复握手与重复认证的等待耗时；
   - 优化 `SMB` 主机地址解析与匿名访问流程：对已解析成功的主机地址进行缓存复用，避免每次访问重复执行多阶段局域网与系统探测；匿名/访客连接直接使用标准匿名凭证握手，消除无效的双重重试等待；
   - 优化 `FTP` 目录读取与 `WebDAV` 路径探测：在单次会话中记忆服务端支持的目录列表方式与已确认的有效服务根路径，避免同一连接下每次浏览子目录重复探测回退。

3. **`File` 页面各级卡片列表按需渲染与无阻塞层级切换**：
   - 在 `File` 页面的一级根目录列表、二级子文件夹列表与单集文件分组列表中，按可视区域按需构建卡片与单集分组，不在进入页面或切换目录首帧一次性全量构建屏幕外的全部卡片；
   - 点击文件夹卡片下钻、点击面包屑或顶栏后退/前进在 `File` 三级目录间切换时，优先复用内存已加载的目录数据直出，未缓存目录的数据读取移出主线程异步完成，并在 Debug 构建下补齐 `File` 页面目录层级切换的交互耗时埋点。

# 验收标准

1. **远程目录弹窗打开与切步流畅无掉帧**：打开 `WebDAV`、`SMB`、`FTP`、`NFS` 弹窗时，270ms 入场动画平滑顺畅，不再触发底层 `File` 页面连带重绘与主线程卡顿告警；进入第 2 步目录列表及切换子目录时界面响应流畅。
2. **远程目录连接与下钻响应显著提速**：`WebDAV`、`SMB`、`FTP` 点击 `Connect` 进入初始目录、点击 `>` 进入下一级子目录、点击面包屑返回上级以及添加远程文件夹扫描时，正确复用连接与解析缓存，等待时间显著缩短，错误提示与断开重连表现正常。
3. **`File` 页面点击卡片切换顺畅无卡顿**：在包含大量子文件夹或大批量剧集视频/字幕的 `File` 目录中点击卡片逐级下钻、点击面包屑或后退/前进切换时，无主线程连续卡顿，Debug 日志准确输出 `File` 目录切换耗时埋点，各项视觉、悬停、按下态、右键与 `...` 菜单交互均无回退，自动化测试全部通过。
