# 需求描述
1. 参考表格那里的虚拟化表格和虚拟化滚动条，优化视频内的字幕焦点窗口。
2. 初始首屏10条字幕，焦点字幕位于第7条，前面有6个，后面有3个。初始10条发布后，后台继续加载并保留当前视频的全部剩余字幕；本需求替代旧需求中的每批10条、最多保留30条、滚动条目标懒加载及禁止完整Cue文本加载规则。
3. 这个版本只处理视频内字幕的字幕焦点窗口，后续再迭代Search或Shiori的聚合字幕焦点窗口。
4. 验收标准：1. 用键盘上下键简单滚动不会有轻微丢帧。2. 用鼠标滚轮滚动，只滚一格时，不会出现滚到一半又回滚的情况，即只要鼠标滚轮动了，哪怕计算的像素不足一个Cue Group，也要滚一个Cue Group。3. 用鼠标滚轮或拖拽滚动条快速滚动，焦点的绝对位置不变，且有一种卷轴滚动的视觉效果。
