# 需求描述

1. **应用启动展示主窗口时确保获得系统前台焦点**：
   - 无论通过打包应用直接启动还是在开发环境下启动，主窗口展示后应用均应切换为前台活跃状态，主窗口成为当前焦点窗口（左上角红绿灯亮起彩色），窗口内 `Hover` 与各项交互立即可用。

2. **打开或唤起独立设置窗口时确保设置窗口获得系统焦点**：
   - 无论主窗口当前已处于聚焦状态，还是在未激活状态下直接点击顶部栏“设置”按钮（或通过菜单/快捷键打开设置），弹出的独立设置窗口均应成为当前前台焦点窗口（设置窗口左上角红绿灯及窗口内开关控件均呈现活跃彩色状态），不得出现主窗口与设置窗口同时处于未激活灰色状态的情况。
   - 关闭独立设置窗口后，若主窗口可见且应用处于前台，焦点正常回到主窗口。

# 验收标准

1. **启动即真实聚焦主窗口**：在开发环境或打包环境下启动应用后，主窗口左上角红绿灯立即亮起彩色，无需额外点击窗口即可直接触发界面元素的 `Hover` 高亮。
2. **启动后直接点击“设置”按钮正常聚焦设置窗口**：应用刚启动（例如停留在 Search 页面）或主窗口处于未激活状态时，直接点击主窗口右上角的“设置”按钮，弹出的设置窗口左上角红绿灯与内部开关（如 `Show Cue Group`、`Prefill with Focused Cue`）立即呈现活跃彩色状态，不会出现两个窗口同时变灰失焦的现象。
