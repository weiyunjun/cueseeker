# 需求描述

1. **Debug 内存与封面缓存监控埋点（长期保留）**：
   - 仅在 **Debug 构建**中启用，在既有界面切换完成日志与对话框打开/切换完成日志中，追加输出与系统活动监视器（Activity Monitor）一致的当前进程物理内存占用（MB）、本次操作前后的内存变化量（MB）、自启动以来的最高内存峰值（MB），以及当前封面内存缓存池实际占用的内存大小（MB）与缓存张数；
   - **Release 构建**不执行上述内存采样与日志输出。

2. **封面内存缓存容量与按需解码优化**：
   - 维持现有 `512 × 288` 封面展示尺寸与并发解码上限不变，将封面内存缓存容量上限调整为 **`64MB` / `100` 张**，并在收到系统内存压力告警时自动清理非当前可见页面的缓存封面；
   - 封面卡片网格仅对当前可视区域及紧邻滚动缓冲区的卡片触发封面加载与解码，屏幕外未滚动到的卡片不提前解码挤占缓存，消除在 `Recent`、`Library` 一/二级、`Excerpt` 及播放页列表之间来回切换或前进/后退时的缓存频繁失效。

3. **复用内存快照直出，消除切页重复查库等待**：
   - 切回已加载过数据的 `Recent`、`Library` 一/二级或 `Excerpt` 页面，以及从播放页快捷命令面板（`Command Panel`）进入 `Recent Videos` / `Recent Excerpt Lists` 时，直接复用内存已同步的列表数据上屏，不再重置就绪状态阻塞切页等待数据库重查；
   - 刷新 `Library` 一级文件夹摘要时，保留未发生变动的二级剧集目录已缓存数据，不作全量清空。

4. **封面卡片网格首帧排版减负**：
   - 封面卡片网格按可视区域按需构建卡片行，不在切页首帧一次性全量构建屏幕外的全部卡片；
   - 移除未处于指针悬停、菜单打开或焦点状态的卡片上常驻的冗余坐标测量与事件监测开销，降低首屏卡片上屏的首帧渲染耗时与主线程卡顿，同时保持既有卡片外观、悬停高亮、右键菜单、`...` 按钮菜单、方向键/手柄导航及无障碍行为不变。

# 验收标准

1. **Debug 内存埋点准确完整**：在 Debug 构建下执行页面切换、进出二级目录、打开快捷命令面板与对话框时，调试日志准确输出当前物理内存、单次操作内存增减量、历史内存峰值及封面缓存池占用（MB 与张数），数值与系统活动监视器一致；可先基于该埋点采集优化前基准数据，再对比验证优化后表现。
2. **跨页切换与前进后退高缓存命中**：在 `Recent`、`Library` 一/二级目录与 `Excerpt` 之间连续来回切换，或在 `Library` 二级剧集页点击后退再立即前进时，已访问页面的首屏封面保持高缓存命中率，不再出现几秒内切换即大面积重新解码的现象。
3. **切页无重复查库阻塞且首帧流畅**：切回已访问过的封面网格页或从快捷命令面板进入 `Recent Videos` / `Recent Excerpt Lists` 时，数据准备阶段无需重复等待数据库读取，首屏 20 张卡片的首帧排版耗时与主线程卡顿显著下降，内存占用平稳受控在合理水位内。
4. **视觉交互零回退与测试通过**：所有封面网格页面的防闪烁直出表现、卡片悬停、右键与 `...` 菜单、键盘/手柄导航及 Release 隔离均保持正常，自动化测试全部通过。
