# 需求描述

1. **卡片与详情文件图标升级为无底框系统强调色（Accent Color）同色深浅大图标**：
   - 覆盖范围：File 界面各级文件夹/视频/字幕卡片、添加远程文件夹弹窗（WebDAV / SMB / FTP / NFS）第 2 步目录浏览列表卡片、任务面板（Task）全部任务卡片（以上均为 `36×36px`），以及文件详情弹窗（`File Info`）顶部的文件图标（`40×40px`）。
   - 移除原有的浅灰色圆角底框与灰色细线条小图标，直接渲染无外边框的同色系深浅层次大图标。
   - **同色浓度层次（`32%` 方案）**：
     - **主体背景层**：`32%` 透明度系统强调色；
     - **中间过渡层**：文件夹左上角半宽顶签为 `52%` 透明度系统强调色，Anki 卡片左上侧横线及改名铅笔为 `59%` 透明度系统强调色；
     - **核心前景层**：`100%` 纯系统强调色。

2. **12 个大图标造型规格**：
   - **文件夹类（7 个：默认本地文件夹、WebDav 文件夹、SMB 文件夹、FTP 文件夹、NFS 文件夹、添加文件夹、移除文件夹）**：左上角为半宽斜切顶签（`52%`），下方为圆角矩形主体（`32%`）；默认文件夹无内部符号，WebDav / SMB / FTP / NFS 文件夹正中央分别为 `100%` 粗体 `DAV` / `SMB` / `FTP` / `NFS`，添加与移除文件夹正中央分别为 `100%` 的 `+` 与 `-` 号。
   - **视频与字幕（2 个）**：同尺寸无边框圆角矩形背景（`32%`）；视频正中央为 `100%` 圆角播放三角（无胶卷打孔与底部横条），字幕下半部为两排 `100%` 圆角台词横条。
   - **Anki（导出到 Anki 任务）**：无边框圆角卡片背景（`32%`），左上侧为 4 排错落卡片横线（`59%`），右下角叠放缩小并带卡片底色留白隔离边的 `100%` 实心 Anki 星星。
   - **Index（索引任务）**：无边框圆形大底（`32%`），正中央为居中小一号、细线条的 `100%` 顺时针旋转箭头。
   - **改名（重命名文件夹 / 文件任务）**：无边框斜向铅笔，右上笔头与左下笔身统一为 `59%` 强调色，笔头与笔身之间保留清晰的斜向留白间隙。

3. **线性小图标同步调整**：
   - File 界面根文件夹卡片菜单中的 `Remove This Folder` 图标由 `minus-circle` 改为 `folder-minus`（文件夹内带减号，与 `folder-plus` 对称；任务卡片 `Remove Task` 菜单项保持 `minus-circle` 不变）。
   - `folder-webdav` 线性小图标（如 `Add Folder` 菜单中的 `WebDav Folder`）下方的协议文字同步改为 `DAV`。

# 验收标准

1. File 界面、远程文件夹浏览列表、任务面板与文件详情弹窗中的上述 12 类图标均已去掉原有的浅灰色底框，按 `32%` 同色深浅方案正确渲染，且随系统强调色与亮/暗模式自动适配。
2. 7 类文件夹大图标（含任务面板中的添加文件夹、移除文件夹）均为左上半宽顶签结构，WebDav 大图标与 `Add Folder` 菜单线性小图标均显示 `DAV`。
3. 视频大图标为无打孔圆角矩形底加居中播放三角；改名大图标的笔头与笔身同色且中间有清晰留白间隙；Anki 与 Index 大图标比例及深浅层次符合规格。
4. File 界面根文件夹卡片菜单中的 `Remove This Folder` 图标已替换为 `folder-minus`。
