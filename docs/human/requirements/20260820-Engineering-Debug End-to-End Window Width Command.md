# 需求目标

为 Debug E2E 控制器增加设置主窗口宽度的命令,使自动化测试能够在不同宽度下验证自适应布局。

# 需求

1. 新增 `setWidth` 命令,参数为目标宽度和当前 `sceneID`。
2. 宽度以场景坐标(逻辑点)为单位;高度和窗口左上角位置保持不变。
3. 目标窗口固定为当前主窗口,不支持指定其他窗口。
4. 目标宽度受窗口自身最小/最大尺寸约束,实际生效宽度以返回的场景信息为准。
5. 成功后返回更新后的完整场景信息和新 `sceneID`。
6. `sceneID` 过期、宽度非正数或非有限值、主窗口不存在、调整后场景不满足现有同屏规则时必须明确失败,且不得改变窗口。
7. 只调整窗口宽度,不修改缩放倍率、显示器配置或业务状态。
8. 该能力只在显式启用的 Debug E2E 流程中存在,Release App 不得包含或启用。
9. 更新 `docs/engineering/08_end_to_end_testing.md`,记录命令格式、宽度语义、使用示例、失败条件及能力边界。
10. 自动化测试覆盖命令解析、参数校验、宽度生效和现有 E2E 命令回归。

# 范围

1. 仅新增窗口宽度调整命令。
2. 不包含高度调整、窗口移动、全屏切换、多窗口批量调整。

# 验收标准

1. 在真实 Debug E2E 流程中可将主窗口设为不同宽度,并通过 `inspect` 与截图确认布局随宽度变化。
2. 无效命令不改变窗口尺寸。
3. 现有 `inspect`、`capture`、`click`、`scroll`、`keyPress` 保持正常。
4. Release 隔离检查通过。
