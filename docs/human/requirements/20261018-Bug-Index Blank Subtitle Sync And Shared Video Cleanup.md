# 需求描述

1. **空白或无有效台词的字幕文件在 Index 时统一不入库、已入库则清理**：
   - 无论是 `.srt` 还是 `.ass` 字幕文件，只要文件内容为空（如 0 字节、仅含空白字符或 BOM）、仅保留 `.ass` 顶部格式说明但无任何台词、或所有台词均不满足入库条件（如时长全部不足 200ms 或去除特效标签后文字全空），均视为“无有效字幕内容”，**不视为文件损坏**：
     - 若为新增字幕文件，Index 后不入库；
     - 若为此前已入库的字幕文件（例如已入库的 `...blank.srt` 被删空全部内容），再次 Index 时将该字幕及其旧台词从 Search、Library、File 界面及播放器字幕列表中移除，不再回退保留清空前的旧数据。
   - 仅当文件发生真正的读取失败、编码无法识别或非空内容格式损坏时，才保留上一次成功 Index 的旧数据。

2. **一集视频配有多个字幕时，移除单个字幕不误删该集视频及观看记录**：
   - 当同一集视频配有多个字幕文件（例如 `EP02.mkv` 同时配有简中、日文、`blank` 三个字幕），删除或清空其中一个字幕并再次 Index 时：
     - 只要该集视频仍有其他有效字幕（即使其余字幕文件未发生修改），**Library 界面中的该集剧集卡片、File 界面中的该集视频与剩余字幕条目、以及 Recent 界面中的观看记录、观看进度与观看状态均完整保留**；
     - 仅当该集视频不再有任何有效字幕时，才将该集视频从软件中移除。

3. **`.srt` 字幕包含单条空文本台词时仅跳过该空台词，正常同步其余修改**：
   - 当 `.srt` 字幕文件中某一条台词仅保留了序号与时间轴（如 `00:01:00,000 --> 00:01:02,000`）而下方台词文字被删空时，与 `.ass` 规则保持一致：**仅跳过该条空台词，正常同步该文件内其余有效台词的修改**，不再因单条空台词判定整份 `.srt` 文件损坏。

# 验收标准

1. 将已入库的字幕文件（`.srt` 或 `.ass`）内容清空或删光所有有效台词后再次执行 Index，该字幕及原有台词从 Search、Library、File 界面及播放器字幕列表中移除，不再回退保留旧数据；新增空白字幕文件执行 Index 同样不入库。
2. 同一集视频配有多个字幕文件时，删除或清空其中一个字幕并再次执行 Index，该集视频在 Library、File 界面中正常保留，Recent 界面中的观看记录与观看进度不丢失。
3. 在 `.srt` 字幕中删空某一条时间轴下的台词文字并修改其他台词后执行 Index，该条空台词被跳过，其余台词修改正常同步生效。
