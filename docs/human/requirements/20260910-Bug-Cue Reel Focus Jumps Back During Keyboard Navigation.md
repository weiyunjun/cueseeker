# 需求描述

1. 现状：在 Playback Overlay 的 Current 或 Collage 编辑的字幕区按方向键后，卷轴滚动完成前按下 S、X、C（Current）或回车（Collage），焦点高亮先回到上一条字幕，滚动结束后才回到目标字幕。
2. 方向键一旦被接受，焦点高亮只能停在目标字幕。卷轴滚动期间发生的任何界面刷新（延后执行的快捷键、勾选变化）都不得把高亮放回上一条。
3. S、X、C 仍延后到滚动结束、焦点提交后执行，作用于目标字幕；回车的勾选立即作用于目标字幕。两者与现状一致。
4. 卷轴位置、滚动时长与曲线、滚轮与滚动条的门控不变。

# 验收

1. Current：按下方向键后立即按 S、X、C，高亮全程停在目标字幕，动作在滚动结束后作用于目标字幕。
2. Collage 编辑：按下方向键后立即按回车，高亮全程停在目标字幕，勾选作用于目标字幕。
3. 连按方向键与按住方向键重复时无回跳。
4. 视觉人工验收；补一条单元回归测试：导航请求进行中再次刷新字幕区状态，显示中的高亮仍为目标字幕。不为本需求新增 E2E 能力。
