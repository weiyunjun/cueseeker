# 需求描述

## 1. 范围与放宽规则

1. 播放快捷键录入全面放宽，支持任意修饰键（⌘、⌥、⌃、⇧）的单修饰或多组合键（例如 ⌘C、⌥→、⌘⇧P）。
2. 允许录入标准编辑组合键（⌘C、⌘V、⌘X、⌘Z、⌘A 等）。
3. 允许录入功能键与页面导航键（F1–F12、Home、End、Page Up、Page Down）。
4. 单键、普通符号、空格、退格（Backspace）与删除（Delete）继续允许录入。

## 2. 明确排除与静默屏蔽

录入以下按键时不写入输入框、不修改原按键、下方不展示任何提示文案，静默忽略并继续保持录制状态：

1. 纯修饰键：仅按下 ⌘、⌥、⌃ 或 ⇧（无具体主键）。
2. 系统与窗口核心操作键：⌘Q（退出）、⌘,（设置）、⌘W（关闭）、⌘H 与 ⌘⌥H（隐藏）、⌘M（最小化）。
3. 全局焦点保留键：Tab。
4. 浮层导航保留键：回车与方向键（用于 Open Command Panel 或 Playback Overlay & Command Panel 分组时）。

## 3. 取消录制

1. 按 Esc 或点击录入栏以外：结束录入，键位不变。
2. 点击录入栏内的 ×：清空该功能的快捷键并结束录入。

## 4. 提示文案与冲突检测简化

1. 移除“含修饰键”、“保留键”、“不支持”等一切非冲突错误提示文案。
2. 仅在录入合法按键且与同生效域内其他功能重复时触发冲突：
   - 录入栏显示 Error 外观。
   - 下方常驻提示行显示冲突文案：Conflicts with “{name}” / 与“{name}”冲突。
   - 冲突期间该按键对冲突各方均不生效，解除冲突后恢复。

# 验收

1. 录入 ⌘C、⌘X、⌘⇧P、⌥→、F11、Home、Page Up 等均可正常生效，输入框正确显示对应的 Keycap。
2. 录入 ⌘Q、⌘,、⌘W、⌘H、⌘M、Tab 或纯修饰键时，输入框无任何变化与报错，录入状态保持不变。
3. Playback Overlay & Command Panel 分组的功能录入回车或方向键时静默屏蔽，不写入。
4. 按 Esc 取消录制，原快捷键不变；点 × 正常清空。
5. 仅在功能冲突时显示红框与冲突文案，不再出现“不支持/保留/含修饰键”等提示。
