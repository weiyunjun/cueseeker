# 需求描述

1. **修复对话框进出场过渡期间内部控件错位跳动与明暗分层（`C-10.1 Dialog`）**：
   - 主窗口与设置窗口内所有共用 `C-10.1 Dialog` 规范的对话框（含各业务对话框、`Task Panel` 与 `C-10.2 Confirmation Dialog`）在入场滑落与退场滑出的整个过渡期间，容器背景、圆角裁切、边线、阴影及内部所有子元素（底部操作按钮、右上角关闭按钮、封面悬停蒙版与图标文字、自动获焦输入框边框等）必须严格保持同一实时位置与透明度整体同步运动，严禁为单个弹窗或单个按钮编写私自特殊实现：
     - **点击底部按钮关闭对话框**：鼠标点击任意底部按钮（如 `Cancel`、`Save`、`Rename`、`Apply`、`Export`、确认框按钮等）触发关闭时，被点击的按钮在松手恢复常态后须继续留在底部原位随整张对话框平滑向上滑出并淡出，不得提前向上跳动窜入内容区。
     - **点击右上角 `✕` 关闭对话框**：鼠标点击任意对话框右上角关闭按钮触发关闭时，`✕` 按钮须留在标题行右侧原位随对话框平滑向上滑出并淡出，不得在松手瞬间向上跳出容器裁切边界而提前消失。
     - **进出场中途悬停或焦点变化**：对话框滑入或滑出半途中，鼠标移入/移出内部可交互区域（如打开 `Edit Cover` 时鼠标快速扫入 `Choose Image` 封面区触发半透明悬停蒙版，或关闭中途鼠标扫过按钮）以及打开对话框自动聚焦输入框（如打开 `Rename` 自动聚焦 `New Name`）时，新触发的悬停蒙版、图标文字、按钮状态或聚焦边框须贴合当前帧的对话框位置与透明度同步过渡，不得提前跳至终点位置导致上下明暗分割或错层。
   - 维持既有 `Dialog Motion` 各曲线、时长、位移距离、系统「减弱动态效果」原位纯淡入淡出表现，以及动画起止最后一帧无整体闪烁的表现不变。

2. **取消叠加系统面板时的自绘 Scrim 退让切换，消除打开与收起阶段的明暗闪烁（`C-10.1 Dialog`）**：
   - 主窗口内有对话框处于打开状态期间，在其上方叠加弹出系统文件选择框或系统警告框（如 `Edit Cover` / `Excerpt List Editor` 点击 `Choose Image`、`Export to Anki` 点击选择导出目录或触发重名替换警告）时，对话框底层的自绘灰色 Scrim 全程保持常驻不变，不再在系统面板打开与收起期间隐藏或切换；系统面板滑入与收起期间由系统原生遮罩在自绘 Scrim 之上自然叠加与淡出（关闭系统面板直接连带关闭下层对话框时，自绘 Scrim 随下层对话框一同淡出），彻底消除点击打开与点击取消收起两个阶段的背景“先亮后暗”闪烁。
   - 无对话框打开时单独触发的系统文件选择框（如 `File` 页添加本地文件夹）保持系统原生单层压暗表现不变。

3. **设计文档同步安排**：
   - 本次新增与修改的设计 Token 均为 0 项；关联 UI 设计文档（`UI Components - Domain.md` 中 `C-10.1 Dialog` 关于系统面板打开期间 Scrim 的描述）待本次改动验收完成后再统一提交更新。

# 验收标准

1. **底部按钮与右上角 `✕` 关闭无跳动验收**：逐一在 `Edit Cover`、`Rename`、`Excerpt List Editor`、`Export to Anki`、搜索筛选对话框、`Confirmation`（含主窗口与 `Settings` 窗口）中用鼠标点击底部 `Cancel` 或主操作按钮关闭对话框，被点击的底部按钮全程贴合对话框底部平滑上移淡出，无向上跳动；在上述对话框及文件/文件夹详情、`Task Panel`、任务详情中用鼠标点击右上角 `✕` 关闭，右上角 `✕` 全程随对话框同步上移淡出，不在第一帧提前消失。
2. **进出场中途悬停与自动聚焦无错层验收**：在 `Library` 打开 `Edit Cover` 的同时快速将鼠标扫入 `Choose Image` 封面区域，封面悬停黑色蒙版与铅笔图标/`Choose Image` 文字居中贴合封面随对话框同步滑入，对话框与封面不出现水平明暗分割线；打开 `Rename` 时 `New Name` 聚焦蓝框随对话框同步滑入；按 `Esc` 关闭对话框中途移动鼠标扫过内部按钮时按钮不发生跳位；动画结束最后一帧及开启「减弱动态效果」时均平稳无闪烁。
3. **系统文件选择框与警告框打开及收起无闪烁验收（Light & Dark）**：在 `Edit Cover` 点击 `Choose Image`、在 `Export to Anki` 点击文件夹图标（含冷启动首次打开与重复打开），从点击瞬间到系统文件选择框滑出全程，以及在系统文件选择框点击 `Cancel` 或确认收起返回原对话框全程，窗口背景均连续平稳过渡，均不再出现“先变亮后变暗”闪烁；在 `Export to Anki` 触发重名替换系统警告框点 `Cancel` 或 `Replace`、以及在 `File` 页直接添加本地文件夹时，遮罩过渡自然且窗口红绿灯与关闭交互保持既有规则零退步。
