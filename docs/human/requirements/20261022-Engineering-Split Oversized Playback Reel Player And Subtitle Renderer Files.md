# 需求描述

1. **播放页台词流滚动组件按职责拆分**：
   - 将播放页台词流滚动组件超长单文件按「虚拟台词流数据契约与适配器」「文字光学边界与多行排版测量」「滚轮惯性物理计算与滚动动画器」「台词画布绘制、时间轴连线与拼图复选框渲染」「滚动容器交互与划词选中菜单」拆分为独立文件。

2. **原生音视频播放器底层内核按职责拆分**：
   - 将原生播放器底层单文件按「硬件解码能力探测与像素格式协商」「进度条拖动关键帧预览解码器」「视频显示图层视图」「播放会话核心（解复用队列、解码时钟同步与音频输出）」「播放器外部协调与生命周期管理」拆分为独立实现单元。

3. **SRT 字幕渲染器拆分与播放器状态通信规范化**：
   - 将 SRT 字幕渲染器单文件按「内联样式标签解析与字体缓存」「字幕排版与位图合成」「字幕叠加图层视图」拆分为独立文件。
   - 移除播放器与播放视图模型之间遗留的旧版字符串属性名轮询接口，统一使用明确的状态与属性接口通信。

# 验收标准

1. 项目编译构建与全量单元测试通过，无新增编译告警。
2. 本地与网络视频播放、音视频同步、进度条拖动预览、SRT/ASS 字幕渲染，以及播放页台词流（Current、Playlist、Command Panel 搜索结果、拼图编辑）的滚动、选中与菜单交互与拆分前完全一致。
