# 需求描述

1. **视频自然播放结束时当前时间对齐至总时长**：
   - 当视频自然播放到底（全部画面与音频播放完毕）时，播放器的当前播放时间必须推进至视频总时长（而非停留在视频最后一帧的起始时间），底部进度条与时间显示同步走满。
2. **Library 或 Recent Videos 入口下最后一个视频播完后的重播与再打开行为**：
   - 从 Library 或 Recent Videos 相关入口进入播放时，若当前视频有下一集，播完后自动切换到下一集播放；若当前没有下一集（如只有 1 集的文件夹，或多集文件夹的最后一集），播完后停留在当前视频片尾总时长处并自动暂停。
   - 当最后一个视频播完停留在片尾总时长处（无下一集且当前进度位于片尾总时长）时：
     - 用户在播放页直接按下播放键（底部播放按钮、空格键或手柄播放键），直接从头（`00:00`）重新开始播放该视频。
     - 无论是在片尾停留还是退出播放页，其已完成的总时长进度均不被回退覆盖；再次从 Library、Recent 或播放页内入口打开该视频时，同样从头（`00:00`）开始播放。

# 验收标准

1. 从 Library 或 Recent Videos 打开仅有 1 集视频的文件夹（或多集文件夹的最后一集）播放至自然结束：播放页底部当前时间与进度条走满至视频总时长并自动暂停；此时直接在播放页按下播放键，视频从 `00:00` 重新开始播放。
2. 最后一个视频自然播放结束停在片尾后，退出播放页（或在片尾停留超过 5 秒后退出）再次打开该视频时，视频正常从 `00:00` 重新开始播放，不会停在片尾不播放。
3. 若当前进度未处于片尾总时长（例如中途暂停，或播完后将进度回退到中间位置），按下播放键或退出后再次打开时，均按当前实际进度位置继续播放。
