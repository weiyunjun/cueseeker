# 需求描述

1. **打包产物剥离本地符号表**：
   - 在应用打包签名前，对主程序可执行文件、内置 `ffmpeg` 工具及打包的动态库执行 `strip -x`，剔除未导出的本地符号表。

2. **FFmpeg 仅裁剪编码器、封装器与滤镜**：
   - 保持现有的全部解复用器（Demuxers）、解码器（Decoders）、解析器（Parsers）与网络协议不变，确保视频与音频播放兼容性零改动。
   - 禁用未使用的编码器（Encoders）、封装器（Muxers）与滤镜（Filters），仅按需开启自动封面生成、进度条缩略图、字幕长截图与 Anki 导出所需的组件。

# 验收标准

1. `CueSeeker.app` 打包总体积从约 `47.0 MB` 降至约 `29.0 MB`。
2. 打包校验与代码签名校验通过。
3. 自动封面生成、进度条缩略图、字幕长截图、Anki 导出及既有自动化测试全部正常通过。
