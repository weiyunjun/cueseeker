# 需求描述

1. **字号（`Size`）计算口径对齐 `libass`**：
   - 以 `1080p`（画布高度 `1080`）为基准，`Size` 定义为包含字体自身上下留白在内的整行高度（与 `libass` 在 `1080p` 下的 `Fontsize` 口径一致），相同数值与字体下渲染出的实际字形大小与 `libass` 一致。

2. **字形填充、描边与模糊视觉对齐 `libass`**：
   - **文字填充不外扩吃边**：关闭系统默认对文字主体的平滑加粗膨胀，文字填充外沿与描边内沿严丝合缝，确保极细描边（如 `1`、`2`）保持设定粗细、不被白色文字向外挤压变薄。
   - **实心描边底座**：`Outline` 模式下，描边层内部填满实心描边色后再向外扩展指定描边宽度；开启 `Blur`（模糊）或半透明描边时，紧贴文字外侧的描边保持浓郁扎实，仅向最外圈柔和羽化，不再因内部镂空而被冲淡发虚。
   - **消除笔画交叉处毛刺与内部重影**：同一字符内交叉重叠的笔画（如“十、木、世”等汉字）先合并外轮廓再向外生成描边，消除交叉夹角处向外的尖刺以及半透明/模糊下的内部十字重影。

3. **伪粗体与行内 `<u>` 下划线对齐 `libass`**：
   - **伪粗体（合成加粗）**：当所选字体（或 SRT 行内 `<b>` 标签）无原生粗体字重时，直接将字形本身向外加粗并同步拉宽字符间距，随后基于加粗后的字形生成描边与阴影，确保开启粗体后黑边同步向外推开、不被文字挤薄。
   - **行内 `<u>` 下划线**：SRT 中的 `<u>` 下划线拥有与文字完全一致的描边、模糊与阴影。

4. **字间距、自动换行、边距与多行碰撞对齐 `libass`**：
   - **字间距（`Letter Spacing`）**：在保留字体自带字偶距微调（Kerning）的基础上叠加设定的字间距；字间距大于 `0` 时关闭英文连字（如 `fi`、`fl`）；单行宽度与水平居中计算不计入行尾最后一个字符后的多余字间距。
   - **智能均衡换行**：单行文本超出最大可用宽度需要自动折行时，自动均衡上下各行的视觉长度（与 `libass` 默认智能换行一致），避免首行塞满、末行过短。
   - **边距（`Margin X` / `Margin Y`）起算基准**：单行最大可用宽度为画布宽度减去左右 `Margin X`；`Margin X` 与 `Margin Y` 直接以文字本身的排版框对齐画布边缘，不因描边粗细、模糊或阴影偏移而推开文字位置。
   - **多条字幕重叠堆叠**：同一时间出现多条字幕上下堆叠时，仅按“文字 + 描边”计算碰撞避让间距，阴影偏移与模糊光晕不额外撑开行距；当 `Vertical` 设为 `Center` 时，发生重叠的后续字幕向下堆叠。

5. **作用范围**：
   - 统一作用于 SRT 字幕的播放画面、Current Frame Screenshot、Subtitle Screenshot 以及 Collage 预览与导出；ASS 字幕渲染行为保持不变。

# 验收标准

1. 在相同 `1080p` 画布、相同字体与相同参数（字号、粗体、描边宽度、颜色、阴影、边距）下，SRT 字幕的实际字形大小、垂直与水平位置与 `libass` 渲染结果一致。
2. 设置细描边（如 `Outline Width = 1` 或 `2`）时，描边粗细均匀扎实，不被亮色文字边缘吃薄；开启 `Blur` 时描边内侧紧贴文字处保持实心浓郁、外侧柔和羽化；汉字交叉笔画处无外凸尖刺与内部重影。
3. 选用无原生粗体的字体（如 `jf-openhuninn-2.0`）开启 `Bold` 时，字形加粗的同时外圈描边同步外扩，保持设定描边厚度不变。
4. SRT 中带 `<u>` 标签的下划线具备与文字一致的描边、模糊和阴影。
5. 长句自动换行时上下行长度均衡；多条字幕同时出现且开启阴影或模糊时，上下堆叠紧凑，不被模糊半径或阴影额外撑大空隙。
