# 需求描述

1. **播放页视频画面与字幕画布按实际显示比例渲染**：
   - 对含非正方形像素（像素拉伸比不为 `1:1`，如 `1440×1080` 变形高清宽屏、`720×480` 变形标清或变形宽屏等）的本地及远程视频，在硬件加速解码与软件解码下均按像素拉伸比换算后的实际显示比例（如 `16:9` 或 `4:3`）渲染视频画面，避免画面被横向挤扁或拉宽。
   - 播放页字幕图层（含 SRT 与 ASS 字幕）统一按视频实际显示尺寸计算画布区域、边距、字号缩放与坐标定位，确保字幕排版比例与实际显示画面完全对齐。

2. **封面、缩略图与各类截图导出统一按实际显示比例输出**：
   - 对含非正方形像素的本地及远程视频，以下图像生成与导出均按像素拉伸比换算后的实际显示尺寸输出正方形像素图片，避免画面变形：
     - Library 与 Recent 剧集自动封面生成；
     - 播放页进度条悬停预览缩略图；
     - 播放页当前画面截图（含无字幕与带字幕截图）；
     - 台词截图与长图拼接（Collage）预览、复制及导出；
     - Export to Anki 导出的卡片配图。
   - 文件详情弹窗（`L-06.8 File Detail Dialog Layout`）中的视频分辨率（`Resolution`）保持展示文件原始存储分辨率不变。

# 验收标准

1. 播放含非正方形像素的视频（涵盖横向拉宽与横向缩窄、硬件加速解码与软件解码）时，播放页视频画面均按实际显示比例正常展示，无横向挤扁或拉长变形。
2. 播放上述变形视频时，播放页 SRT 与 ASS 字幕的画布范围、字号比例及定位坐标均与实际显示的视频画面严格对齐。
3. 上述变形视频生成的剧集封面、进度条预览缩略图、播放器当前画面截图、台词长图拼接（Collage）以及 Anki 导出配图，均按实际显示比例输出且画面无变形；文件详情弹窗中的分辨率继续保持展示文件原始存储分辨率。
