# 需求描述

1. **全窗口开放非焦点悬停反馈与预览（严禁穿透上层遮挡窗口）**：
   - 对 CueSeeker 的所有窗口（主窗口与独立设置窗口），取消“失去窗口焦点时清空 `Hover`、未获焦期间禁止产生 `Hover` 与 `Tooltip`”的限制。
   - 无论当前系统焦点位于外部应用还是应用内另一窗口，只要鼠标指针位于目标窗口**未被其它窗口遮挡的暴露区域**内（且指针未隐藏、当前层未被菜单或上层界面冻结、未处于滚轮滚动 `300ms` 防抖期、未因键盘/手柄导航进入抑制态），窗口内的按钮、导航栏、标签页、分段控件、筛选胶囊、封面卡片、表格（表头 `#` 勾选框、整行高亮、台词下划线与操作按钮）、已打开的弹出菜单项、自定义滚动条、台词长截图预览组、播放进度条时间胶囊与缩略图预览及 `Tooltip` 均正常响应悬停、移出与防抖重判。
   - 当其它应用窗口（如 Finder）或应用内另一独立窗口覆盖在目标窗口上方时，鼠标位于上层遮挡窗口范围内一律不得穿透触发下方被遮挡窗口的悬停或任何交互；仅在鼠标移出上层遮挡窗口、进入下方窗口实际暴露区域时才响应交互。

2. **非焦点窗口支持单次点击直接执行操作**：
   - 当鼠标位于非焦点窗口未被遮挡的暴露区域内时，左键点击、右键菜单或按下拖拽可交互区域（包括播放页的播放/暂停、快退/快进、进度条与音量滑块、画面单击播放/暂停，以及工作台与设置窗口内的各类按钮、封面卡片、表格、滚动条等）在**第 1 次点击/按下时即直接执行对应操作**，同时按系统默认机制自然激活并前置该窗口，无需先点击一次激活窗口再点击第二次触发控件。

3. **播放页 `Player UI` 与鼠标指针显隐规则同步调整**：
   - **唤出与移出**：无论播放窗口是否拥有焦点，只要指针在播放窗口未被遮挡的暴露区域内移动即显示 `Player UI`；当指针移出暴露区域（含移入覆盖在播放窗口上方的其它窗口）时隐藏 `Player UI` 并保持指针显示；切换应用或打开独立窗口导致播放窗口失焦时，若指针仍位于播放窗口未被遮挡的暴露区域内，不再因失焦本身强制隐藏 `Player UI`。
   - **3 秒静止自动隐藏**：当指针位于播放窗口未被遮挡的暴露区域内且不在可点击控件上、未拖拽进度条或音量滑块、无同窗口上层浮层/菜单/对话框且无 `Player UI` 无障碍焦点时，指针静止满 3 秒自动隐藏 `Player UI`；其中**系统鼠标指针仅在播放窗口自身拥有焦点时同步隐藏**，非焦点状态下仅隐藏 `Player UI`、保持鼠标指针显示。

4. **指针形状与焦点专属输入边界**：
   - 当应用处于前台活跃状态时（含焦点位于独立设置窗口、指针移入未遮挡的主窗口区域），主窗口暴露区域按落点实时同步指针形状（`Grab`、`I-beam`、默认箭头）；当焦点位于其它外部应用时，遵循系统前台光标归属。
   - 键盘快捷键、手柄输入、快捷键录入、文本框输入焦点与无障碍状态继续严格绑定聚焦窗口，不在后台抢占输入，且严格遵守复盘红线，不伪造窗口焦点状态或注入假事件。

# 验收标准

1. **非焦点播放播控单次直达**：将焦点置于其它应用（如笔记软件或 Finder）并使播放窗口部分或全部露出，移动鼠标进入播放窗口暴露区域时立即浮现顶底控制栏，悬停进度条正常显示时间胶囊与缩略图预览，悬停按钮正常高亮并显示 `Tooltip`；直接点击第 1 下“播放/暂停”“快退”“快进”或拖拽进度条立即执行对应播控操作并自然激活窗口。
2. **非焦点工作台与设置窗口交互一致**：无论焦点在外部应用还是在主窗口与独立设置窗口之间切换，鼠标滑过未聚焦窗口的暴露区域时，封面卡片、表格表头与行、按钮、滚动条、长截图预览组等均正常呈现悬停效果，第 1 次点击或滚轮滚动均直接生效。
3. **上层窗口遮挡零穿透**：打开 Finder 窗口（或独立设置窗口）覆盖在 CueSeeker 窗口上方，鼠标在上层窗口内部移动、悬停或点击时，下方被遮挡的播放控制栏不会唤出，下方按钮、卡片与表格不会触发悬停或点击；将鼠标移出上层窗口进入 CueSeeker 暴露区域后立即恢复正常交互。
4. **非焦点播放页 3 秒自动隐藏正常**：焦点位于其它应用且鼠标停留在播放窗口未遮挡的画面空白处静止满 3 秒后，`Player UI` 自动隐藏而系统鼠标指针保持显示；移动鼠标后 `Player UI` 再次显示。
5. **启动激活与既有菜单弹窗无回归**：独立打包应用冷启动正常前置聚焦，工作台、播放页与设置窗口的所有按钮、下拉菜单、右键菜单、二级子菜单及对话框点击与键盘快捷键均正常响应。
