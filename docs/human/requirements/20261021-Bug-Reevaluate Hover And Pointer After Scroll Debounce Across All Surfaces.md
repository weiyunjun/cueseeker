# 需求描述

1. **全界面统一滚轮滚动 `300ms` 防抖锁定**：
   - 在任何可滚动区域（包括各界面封面卡片网格、弹出菜单、Command Panel、表格、自定义滚动条等）使用鼠标滚轮或触控板滚动期间，保持滚动开始前的 `Hover` 状态与鼠标指针样式不变，滚动过程中滑过指针下方的元素不触发 `Hover` 切换。
   - 若滚动防抖期间用户主动移动鼠标，立即解除滚动防抖并按当前指针位置实时更新 `Hover` 与指针样式。

2. **停止滚动满 `300ms` 后立即按当前指针位置重判 `Hover` 与指针样式**：
   - 自最后一次滚轮或触控板滚动事件起静止满 `300ms` 后，若当前窗口处于聚焦状态、鼠标未隐藏且当前界面层未被菜单或弹窗冻结，立即清除已滚离指针位置的旧 `Hover`（含已滚出可视区域的条目），并根据鼠标当前实际落点重新判定和恢复落点处元素的 `Hover` 效果及对应指针样式（如落在封面卡片或表格可点击台词上为手型 `Grab`，落在卡片间隙等空白处恢复默认箭头）。
   - Playback 封面卡片与菜单项已有的 `Select` 选中状态不受滚轮防抖重判影响。

# 验收标准

1. **封面卡片网格滚轮防抖与恢复**：在 Library（一级/二级）、Recent、Excerpt 一级、Playback Overlay 视频列表或 Command Panel 中将鼠标悬停在某张封面卡片上（显示 `Hover` 与手型指针），保持鼠标不动并滚动页面使其他卡片或空白区移至指针下方：滚动期间中间经过的卡片不闪烁 `Hover`；停止滚动满 `300ms` 后，原卡片 `Hover` 立即清除（即便原卡片已滚出屏幕外），若指针下为新卡片则新卡片立即显示 `Hover` 且指针保持手型，若指针下为空白区则无卡片 `Hover` 且指针恢复默认箭头。
2. **弹出菜单滚轮防抖与恢复**：在可滚动的弹出菜单中将鼠标悬停在某菜单项上，保持鼠标不动滚动菜单：滚动期间不随划过的菜单项跳动 `Hover`；停止滚动满 `300ms` 后，原菜单项 `Hover` 清除，当前指针所在的新菜单项立即显示 `Hover`（菜单原有的 `Select` 选中项保持不变）。
