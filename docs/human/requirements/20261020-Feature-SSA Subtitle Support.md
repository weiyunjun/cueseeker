# 需求描述

1. **支持 `.ssa`（SubStation Alpha）字幕扫描、配对与默认排序**：
   - 本地、WebDAV 与 SMB 文件夹在执行 Index 时均支持扫描 `.ssa` 字幕文件并与同目录视频配对。
   - 当同一视频匹配到多条去掉最后 1 级后缀名后与视频同名的字幕时，排序优先级更新为 `ass > ssa > srt > vtt`。

2. **SSA 字幕解析、分组与变化检测（与 ASS 字幕适用同一套规则）**：
   - 兼容 SSA 规范的 `[V4 Styles]` 样式区块、样式名前导 `*`、旧版 `Alignment` 对齐编号以及行内 `\a` 对齐标签，使同一时间戳下多条台词构成的 Cue Group 保持正确的上下画面位置顺序。
   - 台词提取、移除 `{...}` 标签、换行转换、去除首尾空白、排除时长小于 200ms 的台词、空文本过滤、完全一致台词去重、按样式识别语言，以及基于「Style + 时间戳 + 文字内容 + 其余 Dialogue 字段」四要素的变化检测，均与 ASS 字幕保持一致。

3. **播放、导出与界面展示**：
   - `.ssa` 字幕在播放页画面渲染、字幕轨切换、截图与 Anki 导出、以及 File 文件详情展示中均正常支持，画面渲染与截图导出保留 SSA 原生样式与排版位置。

# 验收标准

1. 将 `.ssa` 字幕与同名视频放入资料库执行 Index，能够成功配对入库并按样式识别语言，Search 搜索与筛选正常命中；当同目录同时存在同名 `.ass`、`.ssa`、`.srt`、`.vtt` 字幕时，字幕顺序为 `ass > ssa > srt > vtt`。
2. 包含 `[V4 Styles]` 样式对齐或 `{\a...}` 行内对齐的 `.ssa` 双语/顶部注释字幕，入库后台词文本干净，同一时间戳 Cue Group 内的上下台词顺序与画面位置一致；修改局部字段后重新 Index 能按四要素规则复用原 CueID。
3. 播放匹配了 `.ssa` 字幕的视频时，画面字幕样式与位置正常显示，字幕轨切换、台词定位跳转、收藏、截图与 Anki 导出功能正常，File 文件详情正确显示格式名称。
