# 需求描述

## 1. 界面渲染性能埋点日志

1. 记录每次打开 Excerpt List 详情页的端到端耗时日志，覆盖从用户触发打开到前端表格首批可见行渲染完成的全过程。
2. 日志明确输出：列表 ID、列表名称、条目总数、总耗时（毫秒）、以及是否命中内存快照直出（cacheHit）。

## 2. Excerpt List 内存常驻与即时呈现

1. **废除提前清空**：点击进入 Excerpt List 时，严禁预先将表格清空为 0 行，消除白屏与闪烁。
2. **常规场景秒开直出**：
   - 内存已存在该列表数据时，进入详情页直接渲染已有数据，实现首帧瞬出（理想耗时低于 16ms）。
   - 用户在 Excerpt 一级概览与二级详情之间反复切换、或前进/后退返回时，保持零等待体验。
3. **首次冷打开平滑过渡**：初次加载未缓存的列表时，加载完成前保持界面稳定，完成后平滑呈现，不发生剧烈跳动。

## 3. 严格遵循资料库任务惰性刷新规则

1. **停留期间静默不刷**：用户停留在 Excerpt List 界面期间，即使后台资料库任务（Index、Remove Folder 等）完成，界面也绝不触发自动刷新，保持当前画面与操作不受打扰。
2. **离开后再返回轻量对齐**：仅当用户离开该界面后再次重新进入时，才反映条目的失效/恢复状态；且仅针对状态发生变化的条目做局部更新，不得推翻或重载整张表格。

# 验收标准

1. **性能与体验验收**：
   - 使用包含 396 条摘录的基准摘录集《我喜欢的字幕》，在常态（内存命中）下点开，体感完全秒开直出，无空白等待与闪烁。
   - 每次点开 Excerpt List 时，控制台均有准确的耗时性能日志输出。
2. **惰性刷新规则验收**：
   - 资料库任务进行中及刚完成时，停留在 Excerpt List 中无任何自动刷新。
   - 离开后再返回该列表，已失效的条目正确标记，滚动条位置与筛选状态保持不变。
3. **测试覆盖**：
   - 耗时埋点逻辑与数据加载流转均由自动化测试覆盖且全部通过。
