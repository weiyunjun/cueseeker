# 需求描述

## 1. 现状

File 页面在层级流转时（例如从二级 Subfolder 目录列表点击进入三级 Files 文件流），新层级界面未能从顶部开始展示，而是继承了上一层级界面的滚动条位置，存在跨层级滚动污染。

## 2. 要求

1. File 页面一级、二级、三级界面彼此独立，**严禁跨层级共享滚动位置**。
2. 进入任一层级界面时，**该层级界面的滚动条必须从顶部（初始位置）开始展示**。

## 3. 保持不变

1. `20260926-UI-File Page Three Level Card Redesign.md` 需求单中三级卡片布局、数据来源、按钮操作及顶栏历史导航逻辑保持不变。

# 验收

1. 在二级界面滚动到底部后，点击任意文件夹卡片下钻三级界面：三级界面必须从最顶部（第一个文件卡片）开始展示，滚动条位于最顶端。
2. 顶栏 `<` 与 `>` 历史导航在各层级流转时，界面均从顶部开始展示，无滚动位置残留。
3. 不为本需求新增自动化 E2E 能力，由人工验收。
