# 需求描述

## 1. 适用范围

Workbench 表格行菜单（⋯ 按钮与右键）、Workbench 封面右键菜单、
视频播放倍速菜单、Playback Overlay 与 Command Panel 的选中文字菜单。

## 2. 挂靠

1. 由按钮弹出的菜单挂靠在该按钮上。
2. 由右键弹出的菜单挂靠在右键点中的内容位置上。

## 3. 方向

1. 方向只在弹出的瞬间确定一次。
2. 默认朝下；下方空间不足时朝上；仍不足时贴边内移。
3. 弹出之后方向与相对偏移不再重新计算。

## 4. 跟随

1. 挂靠对象因滚动、窗口缩放或布局变化而移动时，菜单随之平移。
2. 菜单自身高度变化时保持已定方向，从同一条基准边生长。
3. 挂靠对象移出可视区时，菜单随之移出，不隐藏也不关闭。

## 5. 菜单之外的交互

1. 菜单打开期间，其余界面保留完整的 Hover、滚动与点击能力。
2. 在菜单之外按下左键或右键时，该次按下只用于关闭菜单，不传给下层。
3. 中键不关闭菜单。

## 6. 菜单之内的交互

1. 指针位于菜单区域内时，滚轮与点击只作用于菜单，不穿透到下层。
2. 菜单内滚动到端点后不再带动下层滚动。

## 7. 高度与滚动条

1. 菜单高度上限 480px，由新增 Token 表达，不得写死数值。
2. 内容超出上限时出现 Vertical Scrollbar。
3. 滚动条出现时占据自身宽度，菜单宽度相应增加；不出现时不占宽度。

## 8. 保持不变

1. 高亮、键盘导航与鼠标规则沿用
   `docs/human/requirements/20260824-UI-Menu Highlight And Single Selection.md`。
2. 界面层级与输入归属沿用
   `docs/human/requirements/20260824-UI-Overlay Layer Priority And Input Ownership.md`。
3. 除高度上限 Token 外，不新增、不修改、不替换任何颜色、尺寸、圆角
   与间距 Token。
4. 菜单自身的配色、圆角、阴影与内边距不变。

# 验收

1. 五个菜单默认朝下弹出；下方空间不足时朝上。
2. 滚动承载菜单的列表或页面，菜单始终贴着挂靠对象移动，方向不变。
3. 缩放窗口使挂靠对象移动，菜单随之移动，方向不变。
4. 挂靠对象滚出可视区后菜单随之移出且不关闭，此时点击任意位置即可关闭。
5. 菜单打开时指针移到菜单之外，下层行、卡片与列表的 Hover 正常出现。
6. 菜单之外按下左键或右键只关闭菜单，下层不响应该次点击。
7. 中键不关闭菜单。
8. 指针停在菜单上滚动滚轮，下层不滚动。
9. Shiori 列表数量足够时二级菜单出现滚动条，菜单宽度相应增加，
   滚动到端点后下层不滚动。
10. 高亮与键盘行为没有回归。
11. 第 5 条依赖 Hover：Workbench 表格行使用现有自动化端到端测试覆盖，
    SwiftUI 卡片与菜单项使用人工验收。其余使用现有自动化端到端测试覆盖，
    不为本需求新增鼠标能力。
