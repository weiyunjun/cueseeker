# 需求描述

1. **全局数字、单位、时间与分隔符规范统一**：
   - **取消千分位逗号**：全应用所有数字与带单位参数（码率、采样率、字幕台词数、文件夹/视频/字幕/文件/卡片数量、设置-开发者词表计数等）均直接展示连续阿拉伯数字，不添加千分位逗号。
   - **文件大小（`1000` 进位）**：File 页面三级文件卡片、视频与字幕详情弹窗、设置-维护页的存储统计与已回收空间，统一按 `1000` 进位计算并保留 2 位小数（如 `831.66 MB`、`60.32 KB`，小于 `1000 B` 时展示整数 `N B`）。
   - **日期时间格式（`yyyy-MM-dd HH:mm:ss`）**：视频与字幕详情的修改时间、文件夹详情的添加/更新时间、任务详情的创建/开始/完成/终止时间、File 页面顶部状态栏「上次更新」、任务面板卡片第 2 行的历史时间、Excerpt 表格「添加日期」列、设置-开发者页词表更新时间，统一采用 `yyyy-MM-dd HH:mm:ss` 格式。
   - **视频时长格式**：视频详情中的「时长」与封面角标、二级页摘要及播放页统一，不足 1 小时省略小时位展示为 `mm:ss`（如 `23:42`），满 1 小时展示为 `HH:mm:ss`。
   - **分隔符与空值占位**：任务面板卡片第 2 行与任务详情「当前阶段」中的多段进度信息统一使用 2 个空格（`  `）分隔；File 页面顶部状态栏从未更新时的占位符与详情弹窗统一为 `-`。
   - **远程路径解码**：视频详情、字幕详情与任务详情中的所有路径及目录列表（`位置`、`原路径`、`新路径`、`目标文件夹`）与文件夹详情一致，将远程网络路径（WebDAV / SMB / FTP / NFS）的百分号编码解码为可读字符展示。

2. **文件详情（视频与字幕）与播放页音轨菜单优化**：
   - **码率位置与单位**：视频详情中的 `码率（Bitrate）` 从 `视频（Video）` 分组移至底部 `详细信息（File Details）` 分组（位于 `文件大小` 下方）；码率大于等于 `1000 kbps` 时换算为 `Mbps`（最多保留 2 位小数并去除末尾多余的 `0`，如 `4.68 Mbps`），低于 `1000 kbps` 时展示为整数 `kbps`。
   - **帧率与采样率格式**：帧率最多保留 3 位小数并去除小数末尾多余的 `0`（如 `23.976 fps`、`29.97 fps`、`24 fps`）；音频采样率换算为 `kHz`（最多保留 2 位小数并去除末尾多余的 `0`，如 `48 kHz`、`44.1 kHz`）。
   - **像素格式可读化**：视频详情中的 `像素格式（Pixel Format）` 简化展示为可读的色彩采样格式（如 `YUV 4:2:0`、`YUV 4:2:2`、`YUV 4:4:4`、`RGB`）。
   - **音视频编码与声道可读化**：
     - 视频详情 `Audio #N` 卡片与播放页 `More -> Audio Track` 菜单中的音频编码统一使用标准友好名称（如 `FLAC`、`AAC`、`Opus`、`PCM`、`AC-3`、`E-AC-3`、`TrueHD`、`DTS`、`Vorbis`、`MP3`、`ALAC`）。
     - 视频详情中的 `声道（Channels）` 展示为可读格式：1 声道为 `单声道 (1.0)` / `單聲道 (1.0)` / `Mono (1.0)`，2 声道为 `立体声 (2.0)` / `立體聲 (2.0)` / `Stereo (2.0)`，6 声道为 `环绕声 (5.1)` / `環繞聲 (5.1)` / `Surround (5.1)`，8 声道为 `环绕声 (7.1)` / `環繞聲 (7.1)` / `Surround (7.1)`。
   - **移除创建时间**：视频详情与字幕详情底部的 `详细信息（File Details）` 分组移除 `创建时间（Created）`，仅保留 `修改时间（Modified）`。

3. **文件夹详情计数与多语言文案统一**：
   - **文件夹详情中的 `文件夹数量（Folder Count）`**：一级文件夹（根文件夹）仅统计其下属包含有效配对的真实子文件夹数量（不将根文件夹自身计入）；二级文件夹（子文件夹）显示为 `0`。
   - **简 / 繁 / 英三语文案修正**：
     - 视频详情关联字幕分组标题：`关联字幕` / `關聯字幕` / `Associated Subtitles`
     - 字幕详情关联视频分组标题：`关联视频` / `關聯影片` / `Associated Video`
     - 字幕详情台词数量标签：`原始台词数` / `原始台詞數` / `Raw Cues`；`有效台词数` / `有效台詞數` / `Valid Cues`
     - 任务详情已索引字幕数量标签：`字幕数量` / `字幕數量` / `Subtitle Count`
     - 任务卡片重命名标题前缀：`重命名文件夹：` / `重新命名資料夾：` / `Rename Folder: `；`重命名文件：` / `重新命名檔案：` / `Rename Files: `

# 验收标准

1. 全应用各详情弹窗、任务卡片、File 状态栏、Excerpt 表格及设置页中不再出现数字千分位逗号与 ` · ` 分隔符；文件大小均按 `1000` 进位保留 2 位小数展示，所有带时分秒的时间戳均统一为 `yyyy-MM-dd HH:mm:ss` 格式，远程网络路径在各详情弹窗中均解码为可读中文路径。
2. 视频详情中 `码率` 位于底部 `详细信息` 分组且以 `Mbps` / `kbps` 展示；`时长` 不足 1 小时省略小时位；`帧率` 与 `采样率`（`kHz`）无多余末尾 `0`；`像素格式` 展示为 `YUV 4:2:0` 等可读格式；`声道` 展示为 `立体声 (2.0)` 等可读格式；音轨编码在视频详情与播放页音轨菜单中均展示为规范名称；视频与字幕详情底部不再展示 `创建时间`。
3. 一级文件夹详情的 `文件夹数量` 仅统计下属有效子文件夹数（不含根目录自身），二级文件夹详情的 `文件夹数量` 为 `0`；关联视频、关联字幕、原始/有效台词数、字幕数量及重命名任务标题在简/繁/英三语下均准确统一。
