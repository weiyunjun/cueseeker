# 需求描述

1. **索引数据库按职责拆分与测试查询剥离**：
   - 将索引数据库超长单文件按「核心字幕解析入库与全文索引更新」「媒体库根路径与文件夹层级管理」「视频墓碑备份与摘录集台词引用恢复」拆分为独立文件。
   - 将片尾演职员表时间推算纯计算逻辑从数据库持久化文件中独立出来。
   - 将原混写在正式索引数据库中、仅供单元测试验证使用的只读检查查询移入测试模块。

2. **数据库初始化与历史版本迁移脚本拆分**：
   - 将数据库初始化文件中的「当前最新表结构定义」与「历史数据库版本逐步升级迁移逻辑」拆分为独立文件。

3. **搜索数据库按职责拆分**：
   - 将搜索数据库文件中的「全文检索与筛选分页核心查询」「上下文邻近台词导航查询」「分词词表诊断查询」拆分为独立文件，并将超长单函数分页查询拆解为清晰的阶段步骤。

# 验收标准

1. 项目编译构建与核心数据层全量单元测试通过，无新增编译告警。
2. 文件夹添加与重索引、嵌套文件夹合并与拆分、墓碑恢复、台词搜索与筛选排序、数据库初始化与旧版本迁移行为与拆分前完全一致。
