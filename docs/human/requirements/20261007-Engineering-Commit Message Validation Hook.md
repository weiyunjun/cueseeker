# 版本

main

# 需求目标

通过轻量级本地 Git Hook 自动化拦截不规范的提交说明，物理杜绝缺少 `docs/human/` 追踪路径或前缀格式错误的 Git 提交。

# 需求

1. **Git Hook 拦截脚本**：
   - 提供极简校验脚本并配置为本地 `.git/hooks/commit-msg`。
2. **强制校验规则**：
   - **首行格式**：必须匹配 `^[A-Z][a-zA-Z0-9 &]*: .+`（首字母大写模块前缀，禁止 `feat:`、小写 `docs:` 等）。
   - **文档追溯**：提交说明中必须包含有效的 `docs/human/` 文档路径。
   - **拦截行为**：校验不通过时直接阻断提交（非零退出码），并输出错误原因与规范示例。

# 验收

1. 提交信息符合 `<Area>: <Summary> (docs/human/...)` 时正常放行。
2. 缺少 `docs/human/` 路径的提交被物理拦截并报错。
3. 使用小写前缀（如 `docs:`）或 Conventional Commits（如 `feat:`）的提交被物理拦截并报错。
