# 需求描述

1. **数据库版本平滑升级（同步覆盖 Debug 与 Release）**：
   - 升级本地数据库版本，全新空白环境启动时直接创建包含新结构的最新版本数据库；已有旧版本数据库（涵盖 Debug 与 Release 环境）启动时自动无损迁移至最新版本，完整保留既有资料库、视频、字幕、台词、摘录与观看记录等全部数据，且迁移阶段不主动扫描外部媒体文件。

2. **Index 阶段统一构建与维护 ASS / SSA 二进制渲染位置索引**：
   - 该预制派生数据严格仅在执行 Index（添加文件夹或更新索引）阶段写入、更新或清理；播放等非 Index 流程保持纯只读，不得向数据库写入。
   - 对所有有效入库的 ASS / SSA 字幕统一处理（不设文件大小阈值）：凡结构支持按时间窗口局部加载的字幕（涵盖 UTF-8、UTF-16 及其他受支持字符编码），均保存公共初始化样式头、字符编码信息，以及按原文件事件先后顺序排列的紧凑二进制位置索引（记录每条事件的起止毫秒时间及在原文件中的起始字节偏移与字节长度），并绑定当时的原文件字节大小、最后修改时间与算法版本；含内嵌字体段等不适用按行局部加载的特殊 ASS / SSA 字幕仅记录当前算法版本的已检查状态标记，避免后续重复执行 Index 时被误判为缺失而反复重扫。
   - 数据库升级后的存量媒体默认维持现状，在后续执行 Index 的数据完整性检查时自动补齐当前算法版本的渲染位置索引；当算法版本有效且原文件大小与修改时间未变时跳过重复生成；当原文件变更重扫、字幕移除或文件夹移除时同步替换或清理对应索引；应用内改名时保持既有索引关联不变。

3. **只读指纹校验与时间窗口位置查询能力**：
   - 提供只读查询能力：基于字幕路径及当前实际文件的字节大小、最后修改时间校验已入库索引的有效性；校验通过时可读取公共初始化样式头、字符编码，并按目标时间窗口返回所有时间重叠事件（含同一时间戳多语种台词及跨样式分块特效）在原文件中的准确字节区间且严格保持原文件行顺序。
   - 当存量字幕尚未执行过 Index、标记为不适用局部加载，或外部字幕文件因编辑修改导致大小或修改时间不匹配时，明确判定索引不可用，绝不使用过期字节偏移。
   - 本需求仅交付数据库升级、Index 期索引构建维护及只读校验查询底座，暂不改变当前播放器的视频与字幕呈现流程。

# 验收标准

1. **Debug 与 Release 数据库升级无损可用**：空白环境首次启动直接创建最新版本数据库；已有旧版数据库启动时平滑升级至最新版本，既有数据零丢失、无阻塞报错。
2. **Index 构建、增量补齐与生命周期一致**：新增导入或存量媒体执行 Index 后，不同大小与编码的标准 ASS / SSA 字幕均正确生成紧凑二进制位置索引，特殊不可切分字幕正确记录已检查状态且重复 Index 不产生冗余重扫；应用内改名保留索引，文件修改或移除时同步更新或清理；非 Index 流程零数据库写入。
3. **同轴多事件保序与外部改动失效保护**：按时间窗口查询返回的重叠事件字节内容与原文件对应行及先后顺序完全一致；当外部字幕文件插入或修改内容后未执行 Index 时，能够准确识别指纹失效而不会返回错位字节区间；完整自动化测试全部通过且对 Debug 与 Release 环境零残留。
