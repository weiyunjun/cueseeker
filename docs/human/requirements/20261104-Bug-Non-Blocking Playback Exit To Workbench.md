# 需求描述

1. **点击返回退出播放页时无主线程阻塞**：
   - 在播放页点击左上角返回按钮（或触发退出播放）回到主界面时，播放页立即收起并切换回目标主界面，保持界面即时响应；
   - 停止播放、释放底层音视频解码与音频输出资源、以及保存当前剧集观看进度的全过程均不在退出瞬间阻塞界面切换。

2. **退出播放回到主界面时按需局部更新，不触发全量重查与无关刷新**：
   - 从播放页返回 `Recent` 或 `Library` 剧集详情页时，直接将刚退出剧集的最新观看进度与时间点同步到对应剧集卡片与列表排序中，不在退出后将整个列表置为加载中或重新全量扫描替换全部卡片，避免返回主界面后的二次卡顿与整页重绘；
   - 退出播放返回 `Recent` 时，若播放期间未发生摘录数据变更，不重复刷新摘录列表概览；若播放仅更新了观看时间点而未改变剧集的“未看 / 在看 / 看完”状态，不触发无关的观看状态联动刷新。

# 验收标准

1. **任意状态下点击返回立即流畅退出**：在播放高码率大体积视频、刚完成进度拖动或刚切换完台词后立即点击左上角返回按钮回到 `Recent`、`Library`、`Search` 或 `Excerpt` 时，播放页立即收起，主界面首帧流畅呈现，退出瞬间与返回后均不发生界面冻结或二次卡顿。
2. **观看记录与卡片进度实时准确**：退出播放回到 `Recent` 或 `Library` 二级目录时，刚观看剧集的进度条、观看状态及在 `Recent` 中的最近观看排序立即准确显示，无旧进度残留或卡片闪烁跳变。
3. **跨页面数据一致性无回退**：若在播放页内新建、修改了摘录或改变了剧集的观看完成状态，退出播放返回主界面后对应列表与状态依然准确同步。
