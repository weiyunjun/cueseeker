# 需求描述

## 1. 现状

1. 打包版中，在 Search 输入关键词（如「の」）搜索，或点击搜索关键词的 Deep Link，应用闪退。
2. 加入 Filter 对话框 Folder 组之前的打包版，同样操作不闪退。

## 2. 要求

1. 打包版中，无论以何种方式发起搜索，都不闪退。
2. 搜索行为保持不变：第一页一找到即显示，完整结果随后显示；Filter 计数与 Deep Link 的处理方式照常。

# 验收

1. 打包版中分别搜索「の」「今」「大丈夫」，均不闪退，并显示完整结果。
2. 打包版中点击搜索关键词的 Deep Link，不闪退，并按设置显示搜索结果或播放第一条结果。
3. 现有自动化端到端与单元用例全部通过；不为本需求新增 E2E 能力。
4. 第 1、2 条在打包后人工验收。
