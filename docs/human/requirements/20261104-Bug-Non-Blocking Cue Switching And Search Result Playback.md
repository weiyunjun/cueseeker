# 需求描述

1. **同一视频内切换台词与跳转进度时不阻塞界面响应**：
   - 在已打开的视频内切换到上一条/下一条台词（或拖动/点击时间轴跳转进度）时，界面与控制栏立即响应，不在跳转发起阶段等待当前帧解码完成或音视频缓冲重置；
   - 当用户连续快速按键切换台词时，中间未完成的跳转请求自动合并，仅定位并呈现最后一次目标台词对应的时间点画面。

2. **海量搜索结果下点击进入播放页保持即时响应**：
   - 在搜索命中数万条结果的大结果集场景下，点击任意搜索结果进入播放页时，直接按需读取目标台词与前后切换信息，不因结果总量的增加而产生进入播放页前的界面卡顿。

3. **播放页内切换台词时不触发底层搜索页重刷与重复资源读取**：
   - 播放页全屏展示期间，切换上一条/下一条台词或更新当前播放台词时，不触发被播放页遮挡的 `Search` 搜索结果列表与筛选栏重绘；
   - 在播放页内切换台词时，直接复用搜索结果已有的显示标题；当切换到同一视频文件的其他台词且字幕文件未变化时，直接复用当前已加载的视频元数据、音轨配置与字幕内容，不重复查询或重新读取。

# 验收标准

1. **同集与跨集切换台词全程流畅无卡顿**：在播放页内通过快捷键或播放列表以常规间隔（1~2 秒）或高频连续按键切换上一条/下一条搜索结果台词与摘录台词（无论切换到同一集视频的其他台词还是跨剧集切换）时，界面始终立即响应，不发生主线程冻结或按键粘滞。
2. **超大搜索结果集点击即开**：搜索高频词产生数万条结果后，点击任意一条结果进入播放页，界面切入速度与小结果集一致，无明显停顿。
3. **状态同步准确无误**：在播放页内多次切换台词后退出播放页返回 `Search` 界面时，当前选中的台词高亮、上下条切换按钮状态及播放进度记录均保持准确一致。
