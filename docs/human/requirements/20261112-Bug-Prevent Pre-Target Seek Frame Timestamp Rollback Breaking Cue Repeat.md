# 需求描述

1. **跳转首帧落在帧对齐容差内时保持目标播放进度不回退**：
   - 在视频内执行时间戳跳转（包括重播当前台词 `Repeat`、从指定台词起播、进度条跳转等）或按指定起始时间打开视频时，若解码命中的首帧画面时间戳略早于跳转目标时间但处于帧对齐容差范围内（不超过 `2ms`），画面与音频保持正常显示和同步起播，但结算与上报的当前播放进度对齐至本次跳转目标时间，不得因首帧时间戳略早 `1~2ms` 而将当前播放进度回退至跳转目标时间之前。
   - 若首帧画面时间戳不早于跳转目标时间，或因跳至片尾最后一帧之后等原因导致首帧早于跳转目标时间超出 `2ms` 容差范围，仍按首帧实际时间戳结算当前播放进度。

# 验收标准

1. **连续触发 `Repeat` 稳定重播当前台词不倒回上一句**：播放任意台词（含台词起点比覆盖该时刻的视频帧起点晚 `1~2ms`、且与前一句台词之间存在无字幕空白段的视频片段）时，以任意间隔连续多次触发 `Repeat`，每次均稳定重播当前台词，不会误跳回前一句台词。
2. **跳转首帧显示时字幕与当前台词定位即时匹配**：跳转至上述台词起点后，首帧画面显示瞬间播放器字幕立即显示当前台词（不出现短暂空白），此时立即打开 `Playback Overlay`（`Current` 模块）默认选中的台词同样为当前台词。
3. **常规跳转与片尾跳转表现无回归**：首帧不早于跳转目标时间的常规跳转，以及跳转目标位于片尾最后一帧之后的边界跳转，当前播放时间展示与音画同步均保持准确正常。
