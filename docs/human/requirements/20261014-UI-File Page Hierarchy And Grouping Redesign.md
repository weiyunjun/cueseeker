# 需求描述

1. **功能栏全层级常驻**：
   - 状态指示器与右侧操作按钮（`Add Folder`、`Index Now`）位于页面第一行，在 File 一、二、三级界面常驻显示。
2. **文件夹类型分组与面包屑演进**：
   - 取消原 `Home`（`首页`）面包屑节点。
   - **一级界面**：按文件夹类型分组展示（`Local Folder`、`WebDAV Folder`），仅当对应类型下存在根目录时显示该分组；类型标题左对齐，使用 `14px`、`600 Semibold`、`--color-text-primary`，下方直接排列该类型的根文件夹卡片。
   - **二、三级界面**：第二行显示以文件夹类型为起点的面包屑（二级为 `[文件夹类型] > [根文件夹名]`，三级为 `[文件夹类型] > [根文件夹名] > [子文件夹名]`），点击文件夹类型返回一级界面。
3. **取消直属内容虚拟文件夹，文件按单集（`Display Title`）分组包裹**：
   - 根目录下的直属文件不再包裹为 `[Folder] (Direct Content)` 虚拟文件夹卡片，而是在二级界面直接展示。若同一根目录下同时存在子文件夹与直属文件，从上到下先显示子文件夹卡片，再显示单集文件分组。
   - 视频与字幕文件按单集（`Display Title`，如 `Ave Mujica - EP01`）分组：
     - `Display Title` 位于所属灰底圆角容器正上方，左边缘与面包屑左边缘对齐，使用 `14px`、`500 Medium`（`--font-weight-control`）、`--color-text-muted`。
     - 下方灰底圆角容器占满页面内容区宽度，内部包裹该集对应的视频与字幕文件卡片。
   - 背景色层级关系：
     - Light Mode：`Display Title` 灰底容器（`#F2F4F7`） > 文件卡片 Hover（`#F9FAFB`） > 文件卡片默认（`#FFFFFF`）。
     - Dark Mode：页面底色（`#1C1C1F`） < `Display Title` 灰底容器（`#242429`） < 文件卡片默认（`#2E2E34`） < 文件卡片 Hover（`#383840`）。
4. **卡片右侧操作按钮与 Chevron 箭头**：
   - **文件夹卡片**（一、二级）：最右侧常驻不可点击的朝右箭头（`caret-right`，`16px`，`--color-text-muted`），提示可点击进入下一层；`...` 按钮位于朝右箭头左侧。
   - **文件卡片**（视频、字幕）：无朝右箭头，最右侧仅保留 `...` 按钮。
   - **卡片 `...` 按钮显隐**：默认隐藏，仅在鼠标 Hover 卡片或该卡片菜单打开时显示；鼠标 Hover 到 `...` 按钮自身（或菜单打开）时显示按钮高亮底色。

# 验收标准

1. File 一、二、三级界面顶部第一行均常驻显示状态指示器与 `Add Folder`、`Index Now` 按钮。
2. 一级界面按 `Local Folder`、`WebDAV Folder` 分组展示根文件夹卡片；点击下钻后第二行正确展示 `文件夹类型 > 根文件夹 > 子文件夹` 面包屑并支持点击返回。
3. 根目录直属文件在二级界面直接按 `Display Title` 灰底容器分组展示，不再出现 `(Direct Content)` 虚拟文件夹；同目录含子文件夹与直属文件时按先文件夹、后文件分组顺序排列。
4. `Display Title` 位于灰底容器正上方且与面包屑左对齐（`14px`、`500 Medium`、`--color-text-muted`），Light / Dark 模式下灰底容器、文件卡片默认态与 Hover 态颜色层次清晰。
5. 文件夹卡片右侧常驻不可点击的 `>` 箭头，文件卡片无 `>` 箭头；所有卡片的 `...` 按钮仅在卡片 Hover 或菜单打开时出现，Hover `...` 按钮自身时呈现底色高亮。
