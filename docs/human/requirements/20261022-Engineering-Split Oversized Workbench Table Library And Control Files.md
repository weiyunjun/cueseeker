# 需求描述

1. **主界面台词虚拟表格按职责拆分**：
   - 将主界面台词虚拟表格超长单文件按「列宽与行高布局计算」「文字与标签排版」「表头视图」「外框与滚动条容器」「单元格内容绘制」「跨单元格划词选中与键鼠交互」「行操作与二级菜单定位」拆分为独立文件。
   - 将原混写在正式表格协调器中的测试专用辅助接口剥离至独立文件，不再与正式渲染及交互逻辑混排。

2. **最近观看与媒体库页面及共用卡片拆分**：
   - 将原混写在同一文件中的「Recent 最近观看页」「Library 媒体库页」「主界面与播放页共用的剧集与文件夹卡片网格」「封面与观看状态徽标组件」「卡片右键菜单事件桥接」拆分为各自独立的组件文件。

3. **通用控件与表单控件按职责拆分**：
   - 将通用控件文件中的「尺寸间距与网格计算参数」「基础按钮与搜索框」「弹出菜单与气泡面板」拆分为独立文件。
   - 将表单控件文件中的「上层表单组件」与「底层原生单行输入框及密码输入框实现」拆分为独立文件。

# 验收标准

1. 项目编译构建与全量单元测试通过，无新增编译告警。
2. 主界面台词虚拟表格（Search 与 Excerpt 详情页）、Recent 页面、Library 页面，以及所有通用按钮、搜索栏、表单输入框和弹出菜单的视觉表现与交互行为与拆分前完全一致。
