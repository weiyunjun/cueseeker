# 需求描述

1. **移除播放页台词队列控制栏间隔时间的千分位逗号**：
   - `C-12.7 Player Cue Queue Control Bar` 右侧 `Gap Stepper` 的间隔时间展示文字与无障碍读屏数值统一展示为连续阿拉伯数字（`<N> ms`，范围 `0 ~ 10000 ms`，如 `1000 ms`、`10000 ms`），不添加英文千分位逗号；尺寸与样式保持现有 Token 不变。

2. **移除数字计数胶囊徽章的千分位逗号**：
   - `C-08.3 Information Badge` 中的 `Task Count Badge`（覆盖主窗口与播放页顶栏任务入口按钮、`Search` / `Excerpt` 及命令面板工具栏筛选按钮、筛选弹窗分组标题右侧计数）统一展示为连续阿拉伯数字（如 `1000`），不添加英文千分位逗号；尺寸与样式保持现有 Token 不变。

3. **边界约束与设计文档安排**：
   - 本次新增与修改的 Token 均为 0 个，禁止硬编码与私自特殊实现；不对不会达到 `1000` 的其他控件（如播放页音量百分比）做多余改动。
   - 关联 UI 设计文档待本次改动验收完成后再统一提交更新。

# 验收标准

1. **播放页间隔时间验收**：播放台词队列时，在 `C-12.7 Player Cue Queue Control Bar` 或 `Settings -> Play` 中将自动切换间隔设为 `1000 ms` ~ `10000 ms` 范围内的任意千位及以上数值，播放页左下角控制栏中的间隔时间均显示为无逗号的连续阿拉伯数字（如 `1000 ms`、`10000 ms`），无障碍读屏数值同步为无逗号格式，步进框宽度与两侧加减按钮位置无抖动或截断。
2. **计数徽章验收**：当 `C-08.3 Task Count Badge` 的计数值达到 `1000` 及以上时（顶栏任务入口按钮、工具栏筛选按钮、筛选弹窗分组标题右侧徽章），徽章内数字均显示为无千分位逗号的连续阿拉伯数字（如 `1000`）。
