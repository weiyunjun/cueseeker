# 需求描述

1. **搜索结果默认排序与 Library 默认排序及字幕排序规则统一**：
   - 搜索结果在 `Default`（默认排序）下，先按所属二级文件夹名称进行自然排序（名称相同时按文件夹完整路径自然排序，与 Library 默认排序一致）；同一二级文件夹内按视频名称自然排序；同一视频配对多个外挂字幕时，按统一字幕优先级排列（与视频同名完全匹配的字幕优先 → 按 `ass > ssa > srt > vtt` 格式优先级 → 同格式按字幕文件名自然排序）；同一字幕文件内部按台词时间轴从早到晚排列。
   - 搜索结果在 `Most Characters`（字数最多）与 `Fewest Characters`（字数最少）排序下，当台词字数相同时，并列项按上述默认排序规则排列。

2. **File 界面二级文件夹排序与筛选弹窗（Filter）文件夹筛选项排序统一**：
   - File 界面一级页面（已添加的根文件夹列表）维持按添加时间从早到晚排列不变；点击根文件夹进入二级文件夹列表时，二级文件夹统一按文件夹名称自然排序（名称相同时按完整路径自然排序，与 Library 默认排序一致）。
   - 搜索与摘录集筛选弹窗（`Filter`）中的 `Folder`（文件夹）筛选项，在无命中计数回退按名称排列时，统一按文件夹名称自然排序（名称相同时按完整路径自然排序）。

3. **File 界面剧集卡片与文件详情弹窗（Get Info）中的配对字幕排序统一**：
   - File 界面二级/三级页面剧集卡片内（视频下方展示的配对字幕列表），以及文件详情弹窗顶部「配对文件」下拉框中的配对字幕列表，统一采用与视频播放页字幕菜单一致的排序规则：与视频同名完全匹配的字幕排在最前 → 其余按 `ass > ssa > srt > vtt` 格式优先级排列 → 同格式按字幕文件名自然排序。

4. **摘录集“最早添加 / 最近添加”排序与批量保存顺序一致**：
   - 批量保存搜索结果到摘录集时，按保存当下列表从上到下的显示顺序依次写入。
   - 在摘录集默认的 `Earliest Date Added`（最早添加，从早到晚）排序下，同一批次保存的内容顺序与保存前的当前排序保持一致；切换到 `Latest Date Added`（最近添加，从晚到早）排序时，同一批次保存的内容顺序与保存前的当前排序严格反向（即 `Earliest Date Added` 与 `Latest Date Added` 严格互为倒序）。

# 验收标准

1. **搜索结果排序**：当媒体库存在带数字编号的二级文件夹（如第 2 季与第 10 季）或同视频配对多个字幕时，搜索结果的默认排序顺序（以及字数排序同字数并列时的顺序）与 Library 默认排序的文件夹顺序、剧集顺序及视频内字幕优先级顺序完全一致。
2. **File 二级文件夹与筛选弹窗文件夹排序**：在 File 界面进入含数字编号子文件夹的根目录，或打开无命中计数的筛选弹窗查看文件夹筛选项时，文件夹均按自然排序（如 `2` 在 `10` 前）排列；File 一级根目录列表仍保持添加时间从早到晚顺序。
3. **File 剧集卡片与详情弹窗配对字幕排序**：同一视频配对多个不同格式或不同后缀的字幕时，File 剧集卡片内视频下方的字幕列表、文件详情弹窗「配对文件」下拉框中的字幕顺序，均与视频播放页字幕菜单顺序完全一致。
4. **摘录集批量保存与添加时间正倒序**：在搜索结果中按任意排序勾选多条台词批量保存到摘录集后，在摘录集 `Earliest Date Added` 排序下显示顺序与保存前完全一致，切换到 `Latest Date Added` 排序后显示顺序完全反转。
