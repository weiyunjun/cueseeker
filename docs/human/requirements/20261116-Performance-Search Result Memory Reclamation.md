# 需求描述

1. **清空搜索词与切换搜索词后回收失效结果内存**：
   - 在工作台 `Search` 或播放页 `Command Panel` 清空搜索词后，凡不再被当前搜索播放列表或已加载摘录集使用的历史搜索结果，及时释放其占用的内存；
   - 连续多次搜索不同关键词（含在工作台 `Search` 完成搜索、在 `Command Panel` 一级界面修改关键词完成结果数统计或进入搜索结果页完成搜索）后，及时淘汰上一轮遗留的无关历史台词，避免多次搜索后内存持续累加。

2. **播放列表与摘录集跨界面生命周期保护**：
   - **搜索播放列表保护与退出/替换补回收**：当用户从搜索结果进入播放页、且当前播放列表仍关联该轮搜索结果时，在播放页打开 `Command Panel` 修改或清空搜索词而未点播新条目的期间，当前播放列表的上一条/下一条切换、自动连播与浮层 `Playlist` 列表展示均保持完整可用；待退出播放页或切换至其他播放来源使该搜索播放列表解绑后，自动补做此前暂缓的旧搜索结果内存回收。
   - **已加载摘录集数据零误伤**：回收失效搜索内存（含清空搜索、切换新搜索词或从播放页返回工作台触发重新搜索）时，已打开过的 `Excerpt` 摘录集详情页及其播放列表所引用的台词保持完整可用，切回任意摘录集时条目展示、表内搜索筛选、排序与播放均不受影响。

3. **输入流畅度与全量搜索能力零回退**：
   - 搜索框连续输入、退格删除或清空高频搜索词时，界面与输入法响应保持流畅，不因旧结果内存释放引发输入卡顿；
   - 同一轮搜索完成后，先收紧再放宽 `Filter` 筛选条件、切换排序方式、任意位置滚动浏览以及全选执行各类批量操作（复制表格、复制深链接、保存至摘录集、导出 Anki）均保持原有的即时响应与完整数据表现。

# 验收标准

1. **无效搜索内存有效回落且不累加**：在未挂载搜索播放列表的场景下（含在工作台 `Search` 直接清空，或在播放媒体库视频时打开 `Command Panel` 清空/改写旧搜索词），搜索产生数万条结果的高频词后再清空搜索框，应用内存占用能够明显回落；连续多次搜索不同高频词再清空后，内存占用不随搜索次数累加增长。
2. **搜索播放列表与已加载摘录集完整可用**：
   - 从搜索结果进入播放后，在播放页打开 `Command Panel` 修改或清空搜索词再按 `Esc` 关闭面板继续播放原视频时，播放页上一条/下一条切换、自动连播及浮层 `Playlist` 内容均正常可用；随后退出播放页或切播其他条目后，已失效的旧搜索内存正常回收；
   - 先打开任意含有效条目的 `Excerpt` 摘录集详情页，再前往 `Search` 搜索高频词并清空搜索框（或在 `Command Panel` 改词后退出播放页返回 `Search`），切回该摘录集时所有有效条目均正常显示与交互，无异常变灰或失效。
3. **交互流畅度与全量功能零回退**：高频词搜索后连续退格、重新输入搜索词无卡顿；同轮搜索内先收紧 `Filter` 再取消恢复全量结果仍即时响应无需重新读盘，大跨度滚动与全选批量操作全部准确无误。
