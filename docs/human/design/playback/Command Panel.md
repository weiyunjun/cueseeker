# 默认条目
1. Recent Videos
2. Recent Excerpt Lists

# 搜索行为
1. 在这个界面，使用Deep Link（URL Scheme）调用搜索或者直接搜索（不论是否自动播放第一个搜索结果），都会视为一次正式搜索。
2. 第1条涉及的2种搜索行为，都会保留当前Filter与排序。
3. 搜索结果界面支持修改Filter与排序，与Workbench的Search界面共用同一套搜索词、Filter、排序与搜索结果。
4. 一级界面输入搜索词（或自动预填聚焦字幕）即开始实时搜索，精确结果数统计完成后在 `Search <搜索词>` 行右侧显示 `xx results`；进入搜索结果界面时直接复用该次搜索。
5. 搜索结果界面最多显示前 100 条结果，首屏 100 条就绪后即刻渲染，无需等待全量搜索完成。
