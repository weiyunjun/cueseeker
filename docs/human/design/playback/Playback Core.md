# 说明
1. 本文档由人类维护，定义视频播放器正常态下的核心播控与字幕渲染业务规则（待逐步补充；边界异常流详见 `Playback Edge Cases.md`）。

# 1. 时间戳跳转（Seek）与帧对齐
1. 播放倍速支持范围为 `0.5×` ~ `3×`。
2. 重播当前台词（Repeat）在任意播放场景下均可用，重播的目标台词与按下回车打开 Playback Overlay（Current 模块）时默认选中的台词一致（当前时间点命中的激活台词；无激活台词时取最近的前一条台词；位于首条台词之前时取首条台词）。
# 2. 播放列表连播与单句自动暂停（Auto Stop）
1. 触发 Repeat 本质是视频内跳转到目标台词起点，不与 Auto Pause 冲突，并会刷新 Auto Switch 的等待倒计时，不弹出提示。
# 3. ASS / SRT 画面字幕渲染与样式覆盖
1. SRT 字幕样式与排版对齐 `libass` 标准（仅作用于 SRT 字幕的播放画面、单帧截图、带字幕截图与台词拼图，ASS 字幕保持原样）：`Size` 以 `1080p` 高度下的完整行高为基准按画面高度等比缩放；`Margin X` / `Margin Y` 以纯文本边缘对齐画布，超宽单行采用上下行长度均衡的自动换行；多条重叠字幕仅按“文字 + 描边（或背景框）”范围避让堆叠（`Bottom` 向上、`Top` 与 `Center` 向下），行内 `<b>` / `<i>` / `<u>` / `<font color>` 标签与描边、模糊、阴影视觉保持一致。
2. 非正方形像素（变形宽屏 / 变形标清）或携带旋转（90° / 180° / 270°）、镜像翻转（水平 / 垂直翻转）方向标记的视频，在硬件加速解码与软件解码下，播放画面、进度条预览缩略图、当前画面截图及 SRT / ASS 字幕画布均统一按转正后的实际显示比例与朝向渲染输出。
# 4. 音轨与字幕轨切换及默认轨道持久化
1. 从 Library 关联入口（剧集卡片、Recent 观看记录、Command Panel Recent Videos、视频播放列表上下集与选集）发起播放时，始终加载该视频的默认字幕与默认音轨；从显式指定字幕的入口（Search 结果、Excerpt List、Deep Link）发起播放时，加载显式指定的字幕与该视频的默认音轨。播放页内通过字幕菜单或音轨菜单切换字幕与音轨仅对当前播放会话临时生效，不持久化修改默认字幕与默认音轨。
