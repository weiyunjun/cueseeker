# 说明
1. 本文档由人类维护，定义视频播放器正常态下的核心播控与字幕渲染业务规则（待逐步补充；边界异常流详见 `Playback Edge Cases.md`）。

# 1. 时间戳跳转（Seek）与帧对齐
1. 播放倍速支持范围为 `0.5×` ~ `3×`。
2. 重播当前台词（Repeat）在任意播放场景下均可用，重播的目标台词与按下回车打开 Playback Overlay（Current 模块）时默认选中的台词一致（当前时间点命中的激活台词；无激活台词时取最近的前一条台词；位于首条台词之前时取首条台词）。
3. 打开新视频或切换到另一部视频时，顶栏标题立即更新为目标视频信息，底部进度条立即归零并处于 `No Duration` 状态（禁用拖拽与悬停预览），播放按钮重置为预期的播放状态并在首帧就绪前忽略播放/暂停切换；画面与字幕保留上一帧平滑过渡，待新视频首帧、音频与首帧字幕同时就绪后同帧更新画面与字幕、起播音频并同步更新当前时间与总时长（无外挂字幕或隐藏字幕时不等待字幕；若视频首帧就绪后满 `1` 秒首帧字幕仍未就绪，则先行放行音画且不报错，待字幕就绪后自动补显）。
4. 在同一视频内触发任意跳转（Seek）时，总时长保持不变，进度条滑块与当前时间立即跳至目标时间点并在等待期间保持、不回跳至旧时间；画面与字幕同样保留上一帧，按第 3 条相同的音画字同步与 `1` 秒超时放行规则切换至目标画面与字幕。
5. 当音频起点早于首帧视频画面，或正片音视频从非零时间点延后起步时，打开视频直接从首帧画面时间点同步起播，并保持容器原始时间轴与总时长；播放中途遇到内部时间戳归零回绕或大幅跳变时，保持文件原始时间戳并直接切换至新时间点继续同步播放。
# 2. 播放列表连播与单句自动暂停（Auto Stop）
1. 触发 Repeat 本质是视频内跳转到目标台词起点，不与 Auto Pause 冲突，并会刷新 Auto Switch 的等待倒计时，不弹出提示。
2. 触发上/下一条切换时，立即更新顶栏标题并弹出对应导航或边界 HUD（完整展示 1 秒）；加载中途连续切换时每次均即时更新标题与 HUD，并取消未完成的旧加载、直接加载最新目标。
# 3. ASS / SRT 画面字幕渲染与样式覆盖
1. SRT 字幕样式与排版对齐 `libass` 标准（仅作用于 SRT 字幕的播放画面、单帧截图、带字幕截图与台词拼图，ASS 字幕保持原样）：`Size` 以 `1080p` 高度下的完整行高为基准按画面高度等比缩放；`Margin X` / `Margin Y` 以纯文本边缘对齐画布，超宽单行采用上下行长度均衡的自动换行；多条重叠字幕仅按“文字 + 描边（或背景框）”范围避让堆叠（`Bottom` 向上、`Top` 与 `Center` 向下），行内 `<b>` / `<i>` / `<u>` / `<font color>` 标签与描边、模糊、阴影视觉保持一致。
2. 非正方形像素（变形宽屏 / 变形标清）或携带旋转（90° / 180° / 270°）、镜像翻转（水平 / 垂直翻转）方向标记的视频，在硬件加速解码与软件解码下，播放画面、进度条预览缩略图、当前画面截图及 SRT / ASS 字幕画布均统一按转正后的实际显示比例与朝向渲染输出。
3. 视频色彩空间与明暗曲线（硬件加速解码与软件解码一致）：支持 `HDR10`、`HDR10+`、`HLG`（含播放中途动态切换）及杜比视界（`Dolby Vision`），在开启系统 HDR 时还原高动态范围与广色域表现，关闭系统 HDR（或处于 SDR 显示环境）时平滑映射至标准动态范围；缺失色彩矩阵或色域标记时按原始分辨率自动推断（宽 `> 1280` 或高 `> 576` 采用 `BT.709`，其余采用 `BT.601`），缺失量化范围标记时默认按有限范围处理；普通 SDR 视频统一按标准 `sRGB`（`Gamma 2.2`）传递曲线渲染；播放页无字幕/带字幕截图、进度条预览缩略图、台词拼图、Anki 导出配图与媒体库自动提取封面共 5 处静态图片，在普通 SDR 视频下与播放画面一致，在 HDR 与杜比视界视频下统一受 `Settings -> General -> Appearance -> HDR Screenshot` 开关控制（开启时对齐开启系统 HDR 的播放画面，关闭时对齐 SDR 模式的播放画面）。
# 4. 音轨与字幕轨切换及默认轨道持久化
1. 从 Library 关联入口（剧集卡片、Recent 观看记录、Command Panel Recent Videos、视频播放列表上下集与选集）发起播放时，始终加载该视频的默认字幕与默认音轨；从显式指定字幕的入口（Search 结果、Excerpt List、Deep Link）发起播放时，加载显式指定的字幕与该视频的默认音轨。播放页内通过字幕菜单或音轨菜单切换字幕与音轨仅对当前播放会话临时生效，不持久化修改默认字幕与默认音轨；切换可见字幕轨时保留当前字幕正常显示，待新字幕首帧就绪后平滑替换。
