# 说明
1. 本文档由人类维护，作为UI/UX的设计补充说明文档。主要设计内容放在/docs/human/design/UI Design System.md。约束AI的工程文档和具体代码实现。

# 界面层级

由低到高：
1. 页面：工作台页面；播放页视频与控制条。
2. 页面内浮层：Selection Action Overlay；Playback Overlay（Current、Playlist、Collage Editor 是它的同层模块）。
3. Command Panel，位于 Playback Overlay 之上。
4. 菜单：属于打开它的那一层，只高于该层自身。
5. 对话框：Edit Cover、Shiori List Editor、任务界面、Confirmation。

Toast 与播放反馈只有视觉，不接受输入，不参与层级。独立窗口与系统菜单栏不属于本清单。红绿灯属于窗口，不参与层级与菜单模态，任何界面状态下可见可用；播放页无 Overlay 时随 Player UI 显隐，Overlay 与 Command Panel 打开时保持显示。红灯关闭主窗口，返回按钮回到来源页。全屏进入与退出的动画期间不显示红绿灯，进入完成后由系统标题栏显示，退出完成后回到页面落位。

# 更高层界面的屏蔽

1. 同一时刻只有最上层的可交互界面接受指针、滚轮与键盘。Selection Action Overlay 例外，它只屏蔽自己覆盖的区域：指针在这块区域内时表格的 Hover 停在进入前的位置，区域之外表格照常接受输入。
2. 更高层界面打开时，下层保持打开前的画面：当前项、高亮与选中都停在原处，不清空，也不跟随指针。
3. 更高层界面不关闭下层已经打开的菜单，视频播放倍速菜单除外：切换到上一个或下一个结果、打开 Command Panel、打开 Playback Overlay 时它都关闭。
4. 更高层界面关闭后，下层恢复接受输入，高亮在指针真实移动之后才改变。
5. 对话框之间允许叠加，上层对话框屏蔽下层对话框。

# 菜单模态

1. 四个方向键、回车与 Esc 归菜单；快捷键不受影响，但打开菜单的那个快捷键归菜单，再按一次关闭它。视频播放倍速菜单例外，左右键照常传给播放页。
2. 在菜单所在窗口内，左键在菜单之外按下只用于关闭菜单，不传给下层；右键在菜单之外按下关闭菜单并继续生效，落点自身有右键菜单时立即换成那个菜单；中键不关闭菜单。
3. 在独立窗口与系统菜单栏上的输入不关闭菜单，也不被截留，它们照常交互。
4. 菜单打开期间，菜单之外不出现任何 Hover 或选中的视觉变化，按钮与滚动条同样不响应指针；菜单的挂靠对象保持打开时的高亮。
5. 指针位于菜单之上时，滚轮只作用于菜单本身。
6. 菜单打开期间对滚动的处理：

| 菜单 | 滚动 |
| --- | --- |
| Workbench 表格行右键菜单 | 整窗口禁止 |
| 筛选菜单 | 整窗口禁止 |
| 卡片与封面右键菜单（Workbench、Command Panel、Playback Overlay） | 整窗口禁止 |
| Playback Overlay 选中文字菜单 | 整窗口禁止 |
| Command Panel 选中文字菜单 | 整窗口禁止 |
| Save to Shiori 菜单（Playback Overlay、Command Panel） | 整窗口禁止 |
| 视频播放倍速菜单 | 不禁止 |

7. 菜单所属的界面关闭，或切换为其它界面时，菜单关闭。
8. 任何菜单打开时，已选中的文字一并清除；选中文字菜单例外，它挂靠的选中文字在它关闭时才清除。
9. 菜单打开时取消当前焦点，包括输入框的聚焦与按钮的焦点环；菜单打开期间不能重新获得焦点，菜单关闭后也不恢复，需要重新点击。

# Hover 与选中

1. 鼠标右键点击 hover 判定区域，Hover 与选中移到指针位置。
2. 鼠标移动只在没有菜单打开时把它们移到指针位置。
3. 鼠标左键只有在非消极功能、且落在 hover 判定区域时才移动它们；关闭已打开的菜单属于消极功能。
4. 键盘方向键把它们移到目标位置。
5. 菜单打开期间被忽略的指针移动，在菜单关闭后不补发。

# 按下

1. 按住鼠标不改变按钮、卡片、菜单项、Sidebar 项与标签的外观。它们在按住期间保持已有的 Default、Hover、Selected、Highlighted、Open 或 Focused 外观，动作在松开时才发生。

# 尺寸过渡

1. 窗口尺寸变化与进出播放页的画面尺寸变化期间，Sidebar、Sidebar Toggle 与返回按钮不接受点击，外观保持进入过渡之前的样子，过渡的开始与结束在它们身上不可见。

# 全屏

1. 全屏以窗口是否处于系统全屏为准，与谁进入无关。播放页在系统全屏中一律使用全屏呈现，包括系统发起的全屏。
2. 窗口已全屏时，绿灯、快捷键 F、Esc、播放器全屏按钮效果一致：CueSeeker 自己退出全屏并恢复全屏前状态，不影响其它 App 的全屏。窗口未全屏时，这些操作进入全屏。
3. 从播放页返回 Workbench：由播放页进入的全屏（含长按绿灯选择的分屏全屏）随之退出；Workbench 先全屏再打开视频的，返回后保持 Workbench 全屏。

# 指针

## 说明
1. 鼠标默认样式：即最常见的箭头样式。鼠标特殊样式：在CueSeeker中包括Grab样式和I-beam样式。
2. 不可用或禁用的内容仍是箭头，不使用禁止指针。
3. 卡片的手型指针需要 macOS 15 及以上；更低版本上卡片为箭头。
4. 本章规则只在主窗口内生效。指针离开主窗口即恢复默认样式；设置窗口等主窗口之外的窗口，指针形状由系统决定。

## 规则
1. 鼠标Grab样式出现场景：1. 表格中，鼠标移动到字幕文字内容上时变为Grab样式。表格包括：Workbench Search界面的表格、Shiori二级界面的表格。2. 鼠标移动到封面卡片组件上，变为Grab。封面卡片组件包括：Library一级界面的封面卡片、Library二级界面的封面卡片、Recent一级界面的视频和Shiori的封面卡片、Recent Videos界面的封面卡片、Recent Shioris界面的封面卡片、Shiori一级界面的封面卡片、Playback Overlay Playlist界面的封面卡片、Command Panel Recent Videos界面的封面卡片、Command Panel Recent Shioris界面的封面卡片。
2. 鼠标I-beam样式出现场景：1. 鼠标移动到任何文字可以按下左键拖拽鼠标选中的、且不变为鼠标Grab样式的区域，变为I-beam样式。2. 鼠标移动到可以输入文本的区域，例如搜索框、编辑列表名称、编辑列表描述等。
3. 界面切换，会将鼠标样式恢复为默认样式。
4. 弹出菜单或Dialog等，会将鼠标样式恢复为默认样式。
5. 当鼠标Grab样式对应的hover/select效果被其他操作改变时，鼠标变回默认样式。

## 规则解释
1. 规则1和规则2描述了：鼠标移动。这意味着除非其他规则影响，否则鼠标自身位置没有变化的情况下，不会主动改变鼠标样式。之所以这么设置，是出于防止鼠标hover和键盘操作冲突的考虑。注意只是滚动鼠标滚轮或按下鼠标左键不会改变鼠标样式。
2. 规则优先级：规则5 > 规则4 > 规则3 > 规则2 = 规则1。 下面会描述。注意这些规则，优先级会低于鼠标位置变化。也就是说，当鼠标移动和5条中的若干条规则发生冲突，会优先判断鼠标移动带来的影响。
3. 规则3界面切换补充说明：Sidebar标签切换；Library一级界面和Library二级界面的Video/File之间切换；Library一级界面/二级界面切换；Shiori一级界面/二级界面切换；进入/退出播放页；进入/退出Playback Overlay；Playback Overlay界面中切换Current/Playlist/Collage；Command Panel 开关及页面切换。

## 具体场景解释
为了帮助理解，描述几个具体场景：
1. 在表格中，鼠标位于某一句很长的字幕的右侧边缘，显示为Grab样式，此时滚动鼠标滚轮，不移动鼠标，虽然新的位置下可能没有字幕文字内容，但根据规则1和规则5，保持为Grab样式，hover效果停留在鼠标滚动前的那一行。
2. 在表格中，鼠标位于某一句很长的字幕的右侧边缘，显示为Grab样式，此时右键弹出菜单，根据规则4，鼠标变为默认样式。
3. 在Playback Overlay Current界面中，鼠标位于某句字幕上，显示为I-beam样式，此时用键盘方向上下键导航，或者滚动鼠标滚轮，根据规则2，鼠标保持为I-beam样式。
4. 在Playback Overlay Current界面中，鼠标位于某句字幕上，显示为I-beam样式，此时选中几个字，弹出了菜单，根据规则4，鼠标变为默认样式。
5. 在Command Panel界面中，鼠标点击Recent Videos，尽管点击后位于某个封面卡片组件上，根据规则3，鼠标变为默认样式，hover效果根据已有实现选中第一个卡片。
6. 在Playback Overlay Current界面中，鼠标位于某句字幕上，显示为I-beam样式，按下Tab切换到Playback Overlay Playlist界面（视频Playlist），尽管鼠标可能位于封面卡片上，但根据规则3，鼠标变为默认样式。
7. 在Playback Overlay Playlist界面（视频Playlist），鼠标移动到某个封面卡片上，显示为Grab样式，此时用键盘方向键将Select切换到其他视频，视觉上hover/select效果已经变化，规则5和规则1有冲突，规则5优先级更高，鼠标变为默认样式。

## 其它说明
1. 鼠标滚轮滚动，不会改变已有的hover效果。在表格、菜单项、滚动封面卡片等位置滚动都会遵循这个规则。该规则和规则5有关联，不过严格来说不属于指针本身的规则，而是关联规则（后续会写更详细的hover/select正式规则）。
