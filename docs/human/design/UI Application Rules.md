# 界面层级

由低到高：
1. 页面：工作台页面；播放页视频与控制条。
2. 页面内浮层：Selection Action Overlay；Playback Overlay（Current、Playlist、
   Collage Editor 是它的同层模块）。
3. Command Panel，位于 Playback Overlay 之上。
4. 菜单：属于打开它的那一层，只高于该层自身。
5. 对话框：Edit Cover、Shiori List Editor、Confirmation。

Toast 与播放反馈只有视觉，不接受输入，不参与层级。Filter Panel 是页面内容，
不是浮层。独立窗口与系统菜单栏不属于本清单。

# 更高层界面的屏蔽

1. 同一时刻只有最上层的可交互界面接受指针、滚轮与键盘。
2. 更高层界面打开时，下层保持打开前的画面：当前项、高亮与选中都停在原处，
   不清空，也不跟随指针。
3. 更高层界面不关闭下层已经打开的菜单。
4. 更高层界面关闭后，下层恢复接受输入，高亮在指针真实移动之后才改变。

# 菜单模态

1. 上下键、回车与 Esc 归菜单；快捷键不受影响。
2. 在菜单所在窗口内，左键在菜单之外按下只用于关闭菜单，不传给下层；右键在菜单
   之外按下关闭菜单并继续生效，落点自身有右键菜单时立即换成那个菜单；中键不
   关闭菜单。
3. 在独立窗口与系统菜单栏上的输入不关闭菜单，也不被截留，它们照常交互。
4. 菜单打开期间，下层不出现任何 Hover 或选中的视觉变化，菜单的挂靠对象
   保持打开时的高亮。
5. 指针位于菜单之上时，滚轮只作用于菜单本身。
6. 菜单打开期间对滚动的处理：

| 菜单 | 滚动 |
| --- | --- |
| Workbench 表格行右键菜单 | 整窗口禁止 |
| Workbench 卡片与封面右键菜单 | 整窗口禁止 |
| Playback Overlay 选中文字菜单 | 整窗口禁止 |
| Command Panel 选中文字菜单 | 整窗口禁止 |
| 视频播放倍速菜单 | 不禁止 |
