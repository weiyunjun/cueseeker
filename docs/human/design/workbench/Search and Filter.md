# 1. 全文检索与字符归一化
1. 字符归一化（不改动原始展示文本）：检索与匹配统一执行 Unicode `NFKC` 兼容归一化与小写转换，并将日文波浪号 `〜` 归一为 `~`、居中省略号 `⋯` 归一为 `...`、弯单双引号 `‘’` / `“”` 归一为直引号 `'` / `"`、连续空白字符（含全角空格、制表符、换行）折叠为单个普通空格，搜索词额外去除首尾空白；保留西文重音符、日文清浊音/半浊音与大小假名、平片假名、中文简繁体及直角引号 `「」` 的区分。
2. 纯字面连续子串匹配：所有文字（含叠字符 `々`、`〇` 等）、字母、数字、标点与特殊符号均作为普通字面字符（无通配符或布尔操作符语法），目标文本归一化后包含搜索词归一化后的完整连续子串（含内部空格）即命中；同时间轴多条独立字幕按单条独立判定，不跨条拼凑。
3. 适用范围：工作台 `Search`、播放页 `Command Panel`（及深链接搜索）、`Excerpt` 表内搜索、`Library` 文件夹搜索、`Excerpt` 列表名搜索与筛选文本条件共用上述归一化与匹配规则。

# 4. 多维筛选（Filter）交并集与计数
1. `Character` 字数计算：字幕文本去除首尾空白后，按东亚字符宽度（East Asian Width）统计，全角与宽字符（`W`/`F`）计 2，其余字符计 1。
2. 参与筛选与排序的属性（时长、字符数、语言、观看状态、文件夹、摘录添加时间等）均在搜索前已确定，搜索、筛选统计与排序直接读取，不临时计算。
