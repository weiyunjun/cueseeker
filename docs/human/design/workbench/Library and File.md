# 3. App 内文件夹与单集联动重命名
1. 重命名前仅校验源是否存在（`Rename Folder` 仅检测目标文件夹本身是否存在；`Rename Files` 仅检测当前这组已知配对的视频与字幕文件是否全部存在，缺一即整体拦截）以及同一父路径下目标名称是否已存在（仅大小写或 Unicode 规范化不同的自身改名除外）。
2. 重命名完成后作为原地替换更新生效：当前停留的 `File` 各级界面直接更新为新名称与新路径；`Search`、`Library`、`Recent` 与 `Excerpt` 同步替换文件夹名、单集显示标题、路径及已选中的文件夹筛选条件，不触发重新搜索。
