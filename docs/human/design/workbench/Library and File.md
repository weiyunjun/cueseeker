# 3. App 内文件夹与单集联动重命名
1. 重命名前仅校验源是否存在（`Rename Folder` 仅检测目标文件夹本身是否存在；`Rename Files` 仅检测当前这组已知配对的视频与字幕文件是否全部存在，缺一即整体拦截）以及同一父路径下目标名称是否已存在（仅大小写或 Unicode 规范化不同的自身改名除外）。
2. 重命名完成后作为原地替换更新生效：当前停留的 `File` 各级界面直接更新为新名称与新路径；`Search`、`Library`、`Recent` 与 `Excerpt` 同步替换文件夹名、单集显示标题、路径及已选中的文件夹筛选条件，不触发重新搜索。
# 4. WebDAV、SMB、FTP 与 NFS 挂载与同步规则
1. 分步添加目录：第一步校验连接并读取初始目录后进入第二步目录浏览；未选中子文件夹直接确认时添加当前所在目录自身（SMB 位于主机顶层共享文件夹列表、或 NFS 位于主机顶层导出目录列表时须至少选中一个共享/导出文件夹），选中同层级一个或多个子文件夹时按界面从上到下的显示顺序添加所选子文件夹。
# 5. 后台任务队列（Task Queue）状态流转与互斥规则
1. 列表排序：`Current` 按发起时间正序（FIFO）排列；`Completed` 与 `Incomplete` 按进入该状态的时间倒序（LIFO）排列，最新结束的任务排在最上方。
2. 多文件夹入库队列：单次添加多个文件夹时，按顺序分别创建独立的 `Add Folder` 任务，首个任务立即进入 `In Progress`，其余任务处于 `Queued` 并依次串行执行。
