# 3. Playback Collage 长截图拼接与导出规则
1. 每个截图组取该组已选字幕公共交集区间的中点时刻截取原始视频画面帧（忽略视频内封字幕、内封字体附件与非视频轨道）；同一 Collage 会话内若分组更新后交集中点时刻不变，直接复用该时刻已截取的原始视频画面。
2. 每组仅在原始视频画面上渲染当前分组选中的外挂字幕台词（含被索引去重的多层渐变同源事件），剔除未选中台词、注释及无关段落；首组保留完整画面，后续分组仅裁切保留含字幕的横向条带并按时间顺序纵向拼接。
