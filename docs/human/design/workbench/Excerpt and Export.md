# 说明
1. 本文档由人类维护，定义摘录管理、台词长截图与 Anki 导出的核心业务规则（待逐步补充）。

# 1. Excerpt 列表增删改与排序
1. 全新初始化时不自动创建默认摘录集（初始数量为 `0`）；允许删除最后一个摘录集。
2. `Recent Excerpt Lists`（Workbench 与 Command Panel）收录全部已存在的摘录集；所属时间分组仅由历史实际播放时间决定（从未播放归入 `Never Played`，曾播放过的摘录集不因列表清空或摘录全部失效而改变分组，尝试播放被拦截时不刷新最近播放时间）。
3. 摘录集仅在实际起播时记录或更新 `Resume` 目标摘录与最近播放时间；目标摘录被删除、移走或因资料库变更失效时立即永久清空（不自动改绑到第 1 条，后续恢复入库也不自动恢复），仅被搜索词或筛选条件临时排除时保留原记录并在重新命中后自动恢复。
4. 从工作台 `Recent -> Excerpt Lists`、播放页 `Command Panel -> Recent Excerpt Lists` 或 `Excerpt` 二级界面 `Play` / `Resume` 打开摘录集时，统一按该列表当前的搜索词、筛选条件与排序方式解析有效播放序列：目标摘录命中时从该条继续播放，未命中但仍有有效项时从当前第 1 条有效摘录播放，过滤后无有效项时拦截并弹出 `No Available Excerpts` Toast。

# 3. Playback Collage 长截图拼接与导出规则
1. 每次进入 Playback Overlay 时，Collage 以打开浮层时的初始焦点字幕作为默认焦点并默认勾选该条字幕；Current 与 Collage 的字幕焦点彼此独立、互不影响。在 Playback Overlay 关闭前，切换顶栏标签页（`Current / Playlist / Collage`）或开关 Command Panel 均保留当前的长截图勾选草稿与焦点位置；关闭 Playback Overlay 返回播放或退出视频时清空。
2. 每个截图组取该组已选字幕公共交集区间的中点时刻截取原始视频画面帧并按转正后的实际显示比例与朝向输出（忽略视频内封字幕、内封字体附件与非视频轨道）；同一 Collage 会话内若分组更新后交集中点时刻不变，直接复用该时刻已截取的原始视频画面。
3. 每组仅在原始视频画面上渲染当前分组选中的外挂字幕台词（含被索引去重的多层渐变同源事件），剔除未选中台词、注释及无关段落；首组保留完整画面，后续分组仅裁切保留含字幕的横向条带并按时间顺序纵向拼接。

# 4. Export to Anki 字段映射与导出生成规则
1. 导出的卡片配图统一按视频转正后的实际显示比例与朝向输出。
2. 单次任务内逐张处理卡片，单张卡片因媒体提取失败、必填字段缺失、或正/背面仅配置 `Cue Group Text` 且内容为空导致整面空白时，仅记为失败并跳过，不影响其余卡片导出（若该面还有其他有效项，空的 `Cue Group Text` 直接省略并正常导出）；至少有 1 张卡片导出成功即生成 `.apkg` 并进入 `Completed`，仅当全部卡片均导出失败时任务进入 `Incomplete` 且不生成空文件。
