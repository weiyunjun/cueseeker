# 1. General 设置规则
1. `Appearance -> HDR Screenshot`（简体中文：`HDR 截图`；繁体中文：`HDR 截圖`）：默认开启，统一控制 HDR 与杜比视界视频在 5 处静态图片（播放页无字幕/带字幕截图、进度条悬停预览缩略图、台词拼图预览与导出、Anki 导出配图、媒体库自动提取封面）的渲染基准（开启时对齐开启系统 HDR 的画面表现，关闭时对齐 SDR 模式的画面表现；普通 SDR 视频不受影响）。切换开关后，实时截图与 Anki 导出立即按新状态输出，进度条预览缩略图与当前已打开的台词拼图预览同步刷新，媒体库自动封面在扫描添加文件夹生成封面时按当前开关状态渲染。
2. `Language -> Application Language`：切换应用语言后立即全局生效，主窗口当前停留的页面、卡片与状态徽章、独立 `Settings` 窗口、系统菜单栏与弹出菜单、已打开的弹窗（含已显示的表单校验提示）以及播放页与播放浮层均实时刷新为新语言，无需重进页面、重开弹窗或重启应用。
# 2. Play 与 Decode 设置规则
1. 解码模式：`Hardware` 与 `Auto` 默认优先使用硬件解码，当设备芯片不支持该编码硬解（如 M1 / M2 播放 AV1）、视频色深或色彩采样超出硬件支持规格（如 12-bit 视频、VP9 / AV1 的非 4:2:0 视频、H.264 的非 8-bit 4:2:0 视频）或硬解失败时，自动回退为软件解码；`Software` 强制使用软件解码。

1. 入口与历史：系统菜单栏应用菜单顶部 `About CueSeeker`（简体中文：`关于字幕求索`；繁体中文：`關於字幕求索`）打开或前置 `Settings` 窗口并定位至 `About` 分类（本次运行首次经该入口打开时以 `About` 为分类历史起点，已打开过则纳入前进/后退历史）；常规入口首次打开默认选中 `General`，运行期间再次打开保持上次停留分类。
2. 手动检查更新：启动应用或进入 `About` 页时不自动联网，仅在手动点击按钮时检查最新正式版 Release（忽略草稿与预发布版本；发现更高版本时支持在默认浏览器打开对应版本页，`Repository` 支持在默认浏览器打开开源仓库主页）。检查状态与结果仅在 App 本次运行期间保留，不持久化，重启后恢复初始态。
