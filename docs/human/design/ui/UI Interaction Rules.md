# 说明

1. 本文档由人类维护，规定 CueSeeker 的全局交互状态机、界面层级与输入屏蔽、菜单模态、Hover/选中/焦点行为、快捷键、全屏、Player UI 与指针显隐、鼠标指针形状优先级及无障碍交互规则。
2. 视觉外观、度量基准与明暗配色约束详见 [`UI Design Rules.md`](UI%20Design%20Rules.md)；组件与布局规格详见 [`UI Index.md`](UI%20Index.md)。

---

# 1. 界面层级

由低到高：
1. 页面：工作台页面；播放页视频与控制条。
2. 页面内浮层：Selection Action Overlay；Playback Overlay（Current、Playlist、Collage Editor 是它的同层模块）。
3. Command Panel，位于 Playback Overlay 之上。
4. 菜单：属于打开它的那一层，只高于该层自身。
5. 对话框：Edit Cover、Excerpt List Editor、Rename、WebDav Folder、SMB Folder、Filter、Export to Anki、任务界面、Confirmation。

Toast、Tooltip、播放反馈与播放页报错条只有视觉，不接受输入，落在其上的点击穿透到下层，不参与层级；Toast 与 Tooltip 画在对话框之上，播放反馈与播放页报错条画在页面内浮层与 Command Panel 之上，报错条也不随 Player UI 隐藏。独立窗口与系统菜单栏不属于本清单。红绿灯属于窗口，不参与层级与菜单模态，任何界面状态下可见可用，只有 Confirmation 位于最上层、或系统文件选择框与系统警告框打开时红灯不可用；播放页无 Overlay 时随 Player UI 显隐，Overlay 与 Command Panel 打开时保持显示。红灯关闭主窗口，返回按钮回到来源页。Confirmation 位于最上层时，Cmd+Q 与 Dock 菜单中的退出同样不生效；系统关机、重启与注销不受影响。全屏进入与退出的动画期间不显示红绿灯，进入完成后由系统标题栏显示，退出完成后回到页面落位。

---

# 2. 更高层界面的屏蔽

1. 同一时刻只有最上层的可交互界面接受指针、滚轮与键盘。Selection Action Overlay 例外，它只屏蔽自己覆盖的区域：指针在这块区域内时表格的 Hover 停在进入前的位置，区域之外表格照常接受输入。
2. 更高层界面打开时，下层保持打开前的画面：当前项、高亮与选中都停在原处，不清空，也不跟随指针。
3. 更高层界面不关闭下层已经打开的菜单。
4. 更高层界面关闭后，下层恢复接受输入，高亮在指针真实移动之后才改变。
5. 对话框之间允许叠加，上层对话框屏蔽下层对话框。
6. 顶栏（Workbench、Player Topbar 显示期间、Playback Overlay 与 Collage，以及对话框打开期间）高度内除红绿灯与可交互控件外的区域属于窗口：拖动移动窗口，双击缩放窗口。
7. 播放页单击视频画面与黑边切换播放/暂停：Player UI 显示期间范围为 Player Topbar 下沿至进度条热区上沿（进度条热区上沿至窗口底边属于底栏，空白区屏蔽下层点击）；Player UI 隐藏期间范围为全窗口。

# 3. 菜单模态

1. 四个方向键、回车与 Esc 归菜单；打开菜单的那个快捷键也归菜单，再按一次关闭它。其余 App 内快捷键与 Tab 不响应，也不传给下层；⌘ 组合键不受影响。
2. 在菜单所在窗口内，左键在菜单之外按下只用于关闭菜单，不传给下层；右键在菜单之外按下关闭菜单并继续生效，落点自身有右键菜单时立即换成那个菜单；中键不关闭菜单。
3. 在独立窗口与系统菜单栏上的输入不关闭菜单，也不被截留，它们照常交互。
4. 菜单打开期间，菜单之外不出现任何 Hover 或选中的视觉变化，按钮与滚动条同样不响应指针；菜单的挂靠对象保持打开时的高亮。
5. 指针位于菜单之上时，滚轮只作用于菜单本身。
6. 任何菜单打开期间，整窗口禁止滚动。
7. 菜单所属的界面关闭，或切换为其它界面时，菜单关闭。
8. 任何菜单打开时，已选中的文字一并清除；选中文字菜单例外，它挂靠的选中文字在它关闭时才清除。
9. 菜单打开时取消当前焦点，包括输入框的聚焦与按钮的焦点环；菜单打开期间不能重新获得焦点，菜单关闭后也不恢复，需要重新点击。

# 4. Hover 与选中

1. 鼠标右键点击 hover 判定区域，Hover 与选中移到指针位置。
2. 鼠标移动只在没有菜单打开时把它们移到指针位置。
3. 鼠标左键只有在非消极功能、且落在 hover 判定区域时才移动它们；关闭已打开的菜单属于消极功能。
4. 键盘方向键把它们移到目标位置。
5. 菜单打开期间被忽略的指针移动，在菜单关闭后不补发。
6. Collage 预览的截图组只有 Hover，没有选中：指针真实移动落在某组上时该组放大，移出时缩回，滚轮不改变它。预览图变化时 Hover 结束，指针再次移动前不放大；指针位置的组从当时的尺寸连续缩回。
7. 左键在截图组上按下并松开，右侧字幕区的焦点跳到该组的第一条字幕，与滚轮到达的表现一致，勾选不变。
8. 表格未处于批量选择时，鼠标悬停到任意行仅该行序号显示 Checkbox（已失效条目除外，不显示 Checkbox 且不可选中），点击 Checkbox 选中该行并进入批量选择，点击其他区域为常规单行点击；悬停到表头 `#` 显示全选 Checkbox，点击全选并进入批量选择。
9. 表格处于批量选择时，点击整行任意区域切换勾选（失效行除外），搜索框、筛选按钮与排序按钮禁用；取消所有勾选、按 Esc 或点击「退出选择」按钮退出批量选择。
10. 指针移入带有 Tooltip 的目标并保持满 `--delay-tooltip-hover` 后显示 Tooltip，同一时刻最多显示 1 个；已显示的 Tooltip 处于显示期间或因指针移出隐藏后的 `--delay-tooltip-skip-window` 内移入新目标时立即显示；指针移出、鼠标按下、滚轮滚动、键盘按键、打开菜单或对话框时立即隐藏，其中除指针移出外的隐藏一并清空免等待时间窗。

# 5. 按下

1. 按住鼠标不改变任何可点击控件或元素（包括按钮、卡片、菜单项、Sidebar 项、标签、面包屑等）的外观。它们在按住期间保持已有的 Default、Hover、Selected、Highlighted、Open 或 Focused 外观，动作在松开时才发生（详见 [`UI Design Rules.md` §1.1](UI%20Design%20Rules.md)）。

---

# 6. 焦点

1. 焦点不受系统「键盘导航」开关影响。
2. 按钮、卡片、标签等控件不获得焦点，鼠标点击也不获得；Tab 与 Shift-Tab 只在输入框之间移动。
3. 界面出现时不自动获得焦点。例外：Confirmation 打开时焦点在 Cancel；Rename 打开时光标在新名称输入框；Command Panel 打开时光标在搜索框。
4. 对话框关闭后，下层不恢复打开前的焦点；切换到其它 App 再切回，焦点保持离开时的状态。

---

# 7. 快捷键

1. Playback、Playback Overlay 与 Command Panel 的快捷键在 Settings / Shortcuts 修改；Esc、Tab，以及 Playback Overlay 与 Command Panel 中的回车与方向键不可修改。
2. 快捷键支持单键，以及 ⌘、⌥、⌃、⇧ 的单修饰或多修饰组合键。纯修饰键、⌘Q、⌘,、⌘W、⌘M、⌘H 与 ⌘⌥H、Tab、浮层回车与方向键静默屏蔽，不录入也不报错。
3. 同一分组内两个功能使用相同的键时，该键对双方都不生效；Edit Collage 与 Collage 分组也会相互比较；Open Command Panel 与全部功能比较。
4. 点击 Shortcut Field 开始录入，它不获得焦点，不参与 Tab 切换。录入期间键盘只归 Shortcut Field，App 菜单的快捷键也不生效；Esc、点击 Shortcut Field 以外或离开 Settings 窗口时结束录入，键位不变。

---

# 8. 尺寸过渡

1. 窗口尺寸变化与进出播放页的画面尺寸变化期间，Sidebar、Sidebar Toggle、后退与前进按钮不接受点击，外观保持进入过渡之前的样子，过渡的开始与结束在它们身上不可见。

---

# 9. 全屏

1. 全屏以窗口是否处于系统全屏为准，与谁进入无关。播放页在系统全屏中一律使用全屏呈现，包括系统发起的全屏。
2. 窗口已全屏时，绿灯、全屏快捷键（默认 F）、Esc、播放器全屏按钮效果一致：CueSeeker 自己退出全屏并恢复全屏前状态，不影响其它 App 的全屏。窗口未全屏时，这些操作进入全屏。
3. 从播放页返回 Workbench：由播放页进入的全屏（含长按绿灯选择的分屏全屏）随之退出；Workbench 先全屏再打开视频的，返回后保持 Workbench 全屏。
4. 播放页与 Playback Overlay 的顶栏在全屏与非全屏一致：播放页顶栏跟随 Player UI 显隐，Overlay 顶栏保持显示；全屏时只有红绿灯改由系统标题栏显示。

---

# 10. Player UI 与指针显隐

1. Player UI 指播放页顶栏、底部进度条与按钮区，以及它们弹出的菜单。Player UI 隐藏时，弹出的菜单一并关闭。
2. 指针隐藏时 Player UI 一定隐藏；指针显示时 Player UI 可以显示或隐藏。显隐与视频播放或暂停状态无关。
3. 进入播放页：指针与 Player UI 都显示，并开始计时。Player UI 隐藏后，只有窗口内的指针移动使它重新显示。
4. 焦点在视频播放窗口、指针在窗口内且不在可点击控件上、没有拖动进度条或音量滑块、键盘焦点不在 Player UI 的控件上，这些同时成立且指针 3 秒没有移动时，指针与 Player UI 一起隐藏。任一条件中断，计时清零；再次全部成立时从头计。只有指针移动算移动，点击、滚轮、键盘都不算，也不重置计时。
5. 可点击控件：红绿灯、返回按钮、Task 与 Settings 入口、进度条、底栏各按钮、音量控件、倍速菜单项、More 菜单及其二级菜单，禁用状态也算。标题、时间显示、顶栏与底栏的空白、视频画面不算。
6. 指针移出窗口：Player UI 隐藏，指针保持显示。焦点离开视频播放窗口，如切到其它 App、打开 Settings 等独立窗口或系统对话框：Player UI 隐藏，指针显示。进入全屏：两者一起隐藏。
7. Playback Overlay、Command Panel 与窗口内对话框打开时，指针显示，Player UI 的状态与计时冻结；关闭时按当时的条件重新判定，成立则从头计时。
8. 键盘焦点一条当前没有触发路径，只作记录。

# 11. 指针

## 11.1 说明
1. 鼠标默认样式：即最常见的箭头样式。鼠标特殊样式：在 CueSeeker 中包括 Grab 样式和 I-beam 样式。
2. 不可用或禁用的内容仍是箭头，不使用禁止指针。
3. 卡片的手型指针需要 macOS 15 及以上；更低版本上卡片为箭头。
4. 本章规则只在主窗口内生效。指针离开主窗口即恢复默认样式；设置窗口等主窗口之外的窗口，指针形状由系统决定。

## 11.2 规则
1. 鼠标 Grab 样式出现场景：1. 表格中，鼠标移动到字幕文字内容上时变为 Grab 样式。表格包括：Workbench Search 界面的表格、Excerpt 二级界面的表格。2. 鼠标移动到封面卡片组件上，变为 Grab。封面卡片组件包括：Library 一级界面的封面卡片、Library 二级界面的封面卡片、Recent 界面 Recent Videos 与 Recent Excerpt Lists 的封面卡片、Excerpt 一级界面的封面卡片、Playback Overlay Playlist 界面的封面卡片、Command Panel Recent Videos 界面的封面卡片、Command Panel Recent Excerpt Lists 界面的封面卡片。
2. 鼠标 I-beam 样式出现场景：1. 鼠标移动到任何文字可以按下左键拖拽鼠标选中的、且不变为鼠标 Grab 样式的区域，变为 I-beam 样式。2. 鼠标移动到可以输入文本的区域，例如搜索框、编辑列表名称、编辑列表描述等。
3. 界面切换，会将鼠标样式恢复为默认样式。
4. 弹出菜单或 Dialog 等，会将鼠标样式恢复为默认样式。
5. 当鼠标 Grab 样式对应的 hover/select 效果被其他操作改变时，鼠标变回默认样式。

## 11.3 规则解释
1. 规则 1 和规则 2 描述了：鼠标移动。这意味着除非其他规则影响，否则鼠标自身位置没有变化的情况下，不会主动改变鼠标样式。之所以这么设置，是出于防止鼠标 hover 和键盘操作冲突的考虑。注意只是滚动鼠标滚轮或按下鼠标左键不会改变鼠标样式。
2. 规则优先级：规则 5 > 规则 4 > 规则 3 > 规则 2 = 规则 1。下面会描述。注意这些规则，优先级会低于鼠标位置变化。也就是说，当鼠标移动和 5 条中的若干条规则发生冲突，会优先判断鼠标移动带来的影响。
3. 规则 3 界面切换补充说明：Sidebar 标签切换；顶栏后退/前进；Recent 的 Recent Videos/Recent Excerpt Lists 之间切换；Library 一级界面/二级界面切换；File 各级界面切换；Excerpt 一级界面/二级界面切换；进入/退出播放页；进入/退出 Playback Overlay；Playback Overlay 界面中切换 Current/Playlist/Collage；Command Panel 开关及页面切换。

## 11.4 具体场景解释
为了帮助理解，描述几个具体场景：
1. 在表格中，鼠标位于某一句很长的字幕的右侧边缘，显示为 Grab 样式，此时滚动鼠标滚轮，不移动鼠标，虽然新的位置下可能没有字幕文字内容，但根据规则 1 和规则 5，保持为 Grab 样式，hover 效果停留在鼠标滚动前的那一行。
2. 在表格中，鼠标位于某一句很长的字幕的右侧边缘，显示为 Grab 样式，此时右键弹出菜单，根据规则 4，鼠标变为默认样式。
3. 在 Playback Overlay Current 界面中，鼠标位于某句字幕上，显示为 I-beam 样式，此时用键盘方向上下键导航，或者滚动鼠标滚轮，根据规则 2，鼠标保持为 I-beam 样式。
4. 在 Playback Overlay Current 界面中，鼠标位于某句字幕上，显示为 I-beam 样式，此时选中几个字，弹出了菜单，根据规则 4，鼠标变为默认样式。
5. 在 Command Panel 界面中，鼠标点击 Recent Videos，尽管点击后位于某个封面卡片组件上，根据规则 3，鼠标变为默认样式，hover 效果根据已有实现选中第一个卡片。
6. 在 Playback Overlay Current 界面中，鼠标位于某句字幕上，显示为 I-beam 样式，按下 Tab 切换到 Playback Overlay Playlist 界面（视频 Playlist），尽管鼠标可能位于封面卡片上，但根据规则 3，鼠标变为默认样式。
7. 在 Playback Overlay Playlist 界面（视频 Playlist），鼠标移动到某个封面卡片上，显示为 Grab 样式，此时用键盘方向键将 Select 切换到其他视频，视觉上 hover/select 效果已经变化，规则 5 和规则 1 有冲突，规则 5 优先级更高，鼠标变为默认样式。

## 11.5 其它说明
1. 鼠标滚轮滚动，不会改变已有的 hover 效果。在表格、菜单项、滚动封面卡片等位置滚动都会遵循这个规则。该规则和规则 5 有关联，不过严格来说不属于指针本身的规则，而是关联规则（详见第 4 章「Hover 与选中」）。

# 12. 无障碍交互（Accessibility，预留扩展）

1. 本章节预留用于后续补充完整的无障碍模式（VoiceOver 屏幕阅读器焦点树、无障碍标签与状态播报、全键盘控制等）交互规则。
