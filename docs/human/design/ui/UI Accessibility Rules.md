# 键盘与手柄无障碍交互规则

---

# 1. 通用规则

## 1.1 核心定义、视觉表现与可选中范围

1. **屏蔽系统自带键盘无障碍**：
   - 全局屏蔽 macOS 系统自带的键盘无障碍（含系统「键盘导航 / Full Keyboard Access」焦点环与系统级 `Tab` 焦点切换），在任何时候均不展示 macOS 系统自身的无障碍光圈；
   - 所有键盘与手柄无障碍行为完全由应用内部统一接管；任何界面打开时初始均不带默认的无障碍光圈。
2. **无障碍的唯一视觉表现（外圈光圈）**：
   - 无障碍选中组件时，仅在目标组件外围绘制带偏移间隙的半透明系统强调色光圈（Focus Ring：颜色 `--color-focus-ring`、线宽 `--focus-ring-width: 2px`、外偏移 `--focus-ring-offset: 2px`），保持组件几何零偏移；
   - **不改变组件自身边框与背景底色**：所有按钮（含 `Neutral`、`Destructive` 等）被无障碍选中时自身边框颜色保持不变；无障碍在任何场合下都不会触发任何组件的鼠标 `Hover` 状态，也不会因无障碍本身改变组件的背景底色（任何背景底色变化均仅来源于组件所属区域的 `Select` 状态）；
   - **无可见外框组件的圆角光圈边界**：
     - 表格普通模式下 `Cues` 列的台词文字（`Interactive Text`）：光圈套在其圆角点击热区框（四周内边距 `--padding-table-cell-hover-x` / `--padding-table-cell-hover-y`，圆角 `--radius-table-cell-hover: 8px`）外围；
     - 面包屑未激活链接节点（`Breadcrumb`）、顶栏与弹窗标签页（`Tab`）、File 页面状态指示器（`Workbench Status Indicator`）：光圈按各自的点击热区矩形配合圆角 `--radius-field`（`6px`）向外偏移 `2px` 绘制。
3. **可选中范围（显式组件类型白名单原则）**：
   - **设计原则与白名单机制**：「鼠标左键点击可产生交互」是划分哪些组件类型纳入无障碍白名单的设计原则；在规则与代码实现上，按**显式指定的组件类型白名单**纳入当前最上层界面的无障碍序列，**不因组件当前处于 `Disabled`（禁用）状态或 `Selected`（已选中）状态而动态跳过**；
   - **禁用态与已选中态组件的表现**：
     - 处于 `Disabled` 状态的白名单组件（含禁用态按钮、禁用态输入框、禁用态复选框/开关、禁用态菜单项、远程目录浏览中已添加置灰的文件夹卡片及其复选框、File 页面处于未索引或进行中状态的状态指示器），以及已处于 `Selected` 状态的单选切换项（含主窗口与设置窗口左侧导航栏 `Sidebar Item` 当前项、标签页 `Tab` 当前项、分段控制器 `Segmented Control` 当前项），**均正常参与无障碍遍历并套上外圈无障碍光圈**；
     - 当无障碍光圈位于处于 `Disabled` 状态的组件或已处于 `Selected` 状态的单选切换项上时，按下触发键（`Space` / `Return` / `✕`）不产生实际动作，无障碍光圈保持在该组件上。
4. **受 `Presence` 控制的按需显现子控件 vs 布局层 `Hidden` vs 结构层 `Collapsed / Closed` 的区分规则**：
   - **受 `Presence` 控制的按需显现子控件（个体按需显现）**：
     - **定义与范围**：所属父组件当前已在界面中展开可见，仅子控件自身受插槽 `Presence` 条件控制、常规下只在鼠标 `Hover` 父组件或打开挂靠菜单期间才显现的子控件。全应用包含以下 4 类：
       1. 封面卡片（`Media Card`：含 `Library` 一级文件夹卡片、`Excerpt` 一级及 `Recent` / `Command Panel` 中的摘录集卡片）右下角的 `dots-three`（`...`）按钮；
       2. File 页面卡片（`File Card`：含一级根目录卡片、二级子文件夹卡片、单集容器内的视频/字幕文件行）右侧的 `dots-three`（`...`）按钮；
       3. 任务面板卡片（`Task Card`）右侧的 `dots-three`（`...`）按钮；
       4. 表格（`Table` 普通模式 `Normal Mode`）表头首列 `#` 槽位的全选 `Checkbox`（当存在有效行时）、有效数据行首列序号槽位的 `Checkbox`、以及数据行 `Cues` 列右侧的 `dots-three`（`...`）按钮。
     - **显现与生命周期**：由于无障碍绝不触发父组件的 `Hover`，当无障碍选中父卡片整体或表格行内其他部位（如台词文字）时，上述子控件**保持不显示**；**仅当无障碍光圈直接移至该子控件自身时（或通过该按钮打开菜单期间），仅该单个子控件自身切换为显示并套上无障碍光圈**（期间即便鼠标不在其上或按 `Cmd + Tab` 窗口失焦，该子控件也保持显示不隐藏）；无障碍一移出该子控件自身即立即恢复不显示。
   - **布局层 `Visible / Hidden` 状态（播放页 `Player UI` 整层唤醒与常驻）**：
     - 播放页主界面的 `Player UI`（顶栏 `L-07.1`、台词队列控制栏与底栏 `L-07.2`）作为当前界面唯一的控制层，即使处于 `Hidden` 状态，其内部白名单控件依然属于当前最上层界面的无障碍序列；
     - 在播放页主界面按下 `Tab` / `Shift + Tab` / `L1` / `R1` 开启无障碍时，**立即将整套 `Player UI` 从 `Hidden` 切换为 `Visible`**（不主动唤出已隐藏的鼠标指针）；且**当无障碍焦点存在于 `Player UI` 上时，「不自动隐藏 `Player UI`」的优先级高于所有自动隐藏条件**（3 秒静止、鼠标移出窗口、`Cmd + Tab` 窗口失焦、进入全屏均不会使其隐藏）；退出无障碍后立即按当前指针与窗口状态重新判定显隐与计时。
   - **结构层 `Collapsed`（已收起）与 `Closed`（已关闭）状态（不参与无障碍）**：
     - 处于 `Collapsed` 状态的容器或部分（如收起态的 `Sidebar`、收起态的音量滑块区域），以及处于 `Closed` 状态的界面层级（未打开的菜单、二级菜单、未展开的 `Color Well` 预设色块面板、对话框、`Playback Overlay`、`Command Panel`），在未通过对应开关动作展开或打开前，其内部组件均不参与无障碍；
     - **窄窗口浮层导航栏（`Overlay Sidebar`）展开时不跳过下层同级组件**：当主窗口处于窄窗口模式且左侧导航栏展开为 `Overlay` 浮层时，被其视觉遮挡的顶栏后退/前进按钮及页面组件仍然正常参与无障碍聚焦与触发，不做特殊跳过处理。
5. **非白名单元素（不参与无障碍）**：
   - **纯展示与仅拖拽元素**：标题、普通文本、各页面数量统计文本（如 `xx folders`、`xx results`、`xx excerpts`、`xx / yy rows selected`）、静态图标、分割线（含 `Menu Divider`）、面包屑导航最右侧不可交互的当前末级节点（`Current Item`）、File 单集容器内的视频/字幕文件行整体、远程目录浏览中的纯视频/字幕文件行、任务卡片整体、表格行（`Table Row`）整体、表格已失效（`Unavailable`）行的首列空白槽位与台词文字、播放页进度条与音量滑块轨道、封面裁剪编辑态下的裁剪框与角点手柄、导出 Anki 数据对象胶囊本体与左侧拖拽手柄、长截图预览组、所有字幕流 `Playback Cue Reel` 及其内部项。
   - **特殊排除项**：系统原生窗口红绿灯（关闭、最小化、全屏）不参与无障碍；设置页快捷键录制框（`Shortcut Field`）本身不参与无障碍，且处于 `Recording` 录制状态期间全局禁用无障碍。

## 1.2 开启、移动、触发与退出

### 1.2.1 键盘与手柄按键映射

| 交互动作 | 键盘按键 | 手柄按键（以 DS5 为准） | 行为说明 |
| --- | --- | --- | --- |
| **正序开启 / 下一个** | `Tab` | `R1` | 未开启时进入无障碍状态并选中第 1 个组件；已开启时移向下一个组件 |
| **逆序开启 / 上一个** | `Shift + Tab` | `L1` | 未开启时进入无障碍状态并选中最后 1 个组件；已开启时移向上一个组件 |
| **触发当前组件** | `Space` 或 `Return` | `✕`（叉键） | 执行当前无障碍选中组件的鼠标左键点击动作 |
| **退出无障碍** | `Esc` | `◯`（圆圈键） | 仅清除无障碍光圈（鼠标左/右键在任意位置点击同样退出） |
| **Select 区域方向导航** | `↑` `↓` `←` `→` | 十字键 / 左摇杆 | 无障碍位于 `Select` 区域内时移动 `Select` 与无障碍光圈；未开启无障碍时仅移动 `Select` |

- **手柄全局生效范围与摇杆规则**：上述手柄按键在全应用所有活动窗口与界面层级（含 Workbench 主窗口各页面、所有弹出菜单与二级菜单、所有模态对话框与任务面板、独立设置窗口、以及播放相关界面）中均全局生效；左摇杆在 `Select` 区域（封面卡片网格、选项列表、弹出菜单與二级菜单）中支持长按像键盘方向键一样连续移动、斜向输入按主轴处理、且需回到死区后才能重新触发。

### 1.2.2 开启时的初始位置
1. **统一首尾规则（与是否存在聚焦输入框无关）**：
   - 只要当前最上层界面处于未开启无障碍状态（无论界面内是否存在默认聚焦或手动点击聚焦的文本输入框）：
     - 按 `Tab` / `R1` 开启无障碍时，**始终选中当前最上层界面的第 1 个无障碍组件**；
     - 按 `Shift + Tab` / `L1` 开启无障碍时，**始终选中当前最上层界面的最后 1 个无障碍组件**；
   - 若开启无障碍时选中的组件不是此前已聚焦的文本输入框，原文本输入框按文本框联动规则立即取消输入焦点（失焦）。

### 1.2.3 触发规则与文本框输入法优先级
1. 只要处于无障碍状态，按下 `Space`、`Return` 或手柄 `✕` **仅响应当前被无障碍光圈选中的组件**（即便界面其他区域仍驻留有 `Select` 高亮，也不会触发该 `Select` 项）。
2. **文本框输入状态联动**：
   - 当无障碍光圈移动至可编辑文本输入框（含 `Color Well` 十六进制输入框）上时，文本框自动获得输入焦点（内边框变为聚焦色并出现光标）；
   - 当无障碍光圈离开文本输入框移向任何其他组件（含搜索框内部的 `✕` 清除按钮、`Color Well` 的预设色块、`Command Panel` 首页下方选项等）时，**原文本输入框立即取消输入焦点（失焦）**；
   - 当无障碍光圈位于文本输入框上时，`Space` 用于输入空格字符，多行文本框（`Text Area`）内 `Return` 用于换行，左右方向键用于移动文本光标。
3. **输入法候选态（IME Marked Text）最高优先级**：
   - 当文本框内存在**未上屏的输入法候选词（如中文输入法已输入拼音但尚未选词上屏）**时，按下 `Esc`、`Space`、`Return`、`Tab` 或方向键均**优先由输入法响应**（例如此时按 `Esc` 仅取消未上屏候选词，不退出无障碍状态）；
   - 仅当文本框内不存在未上屏的输入法候选词时，按键才响应无障碍的退出、移动或触发。

### 1.2.4 退出规则与优先级
1. **按键退出优先级高于界面关闭（`◯` 与 `Esc` 全局严格对应）**：处于无障碍状态（且无未上屏输入法候选词）时，按下第 1 次 `Esc` 或手柄 `◯` **仅退出无障碍状态（清除外圈无障碍光圈；若当前位于文本框上，保留文本框自身的输入焦点；若当前位于已展开的 `Color Well` 色块面板或二级菜单中，不收起色块面板或菜单）**，不关闭当前菜单、Dialog、Command Panel 或 Playback Overlay，也不退出表格批量选择模式或系统全屏；无障碍光圈清除后（或原本未处于无障碍状态时），再次按下 `Esc` 或手柄 `◯` 在全应用所有窗口与层级中具有完全一致的行为，正常执行界面原有的关闭或退出操作（包括关闭 Workbench / 设置页 / 播放页菜单或整套二级菜单、关闭 Dialog 或任务面板、收起 `Color Well` 预设色块面板、关闭 Command Panel 或 Playback Overlay、退出表格批量选择模式或退出系统全屏）。
2. **鼠标点击无条件退出**：在窗口内任意位置按下鼠标左键或右键（**含点击文本输入框内部**），立即退出无障碍状态（清除外圈无障碍光圈；若点击在文本框内部，则仅保持普通文本框输入焦点）。
3. **承载组件消失与界面层级切换自动退出（组件未消失或窗口失焦时保持）**：
   - 无障碍状态严格归属于当前最上层界面中的当前目标组件；
   - **打开更高层界面时清空**：当打开更高层界面（如弹出菜单、展开二级菜单、打开 Dialog、打开 Command Panel）时，下层无障碍清除，且**新打开的上层界面初始处于未开启无障碍状态**；
   - **当前承载光圈的组件自身消失时自动退出**：一旦当前被无障碍光圈选中的组件从界面中消失（不再存在），立即退出无障碍状态。具体包括：
     1. 无障碍所属的界面关闭（如点击右上角关闭按钮或取消按钮关闭 Dialog、收起菜单）；
     2. 在内容区触发卡片进入下级页面/目录导致当前被选中的卡片组件随旧列表销毁；
     3. 触发某个按条件显现的按钮导致该按钮自身从界面移除（如触发搜索框右侧 `✕` 清除按钮清空文字后 `✕` 按钮消失、触发设置页 `Shortcuts` 某行左侧 `✕` 恢复默认按钮后该 `✕` 按钮消失、触发导出 Anki 数据胶囊右侧 `✕` 删除按钮后该胶囊消失）；
   - **承载组件未消失时保持光圈**：当无障碍光圈位于左侧导航栏入口（`App Sidebar` / `Settings Sidebar`）、顶栏或弹窗标签页（`Tab`）、分段控制器选项（`Segmented Control`）或按钮上，按触发键切换了页面/分类/标签页或使该组件变为 `Selected` / `Disabled` 时，由于**当前承载光圈的组件自身并未从界面消失**，无障碍光圈继续保留在该组件上，不退出无障碍状态；
   - **窗口失焦保持原状**：切换应用（如 `Cmd + Tab`）或在主窗口与设置窗口之间切换导致窗口失焦时，**不清除无障碍状态**，无障碍光圈保持在离开前的位置。

## 1.3 移动顺序与视口跟随

1. **当前界面内循环（不穿透）**：按 `Tab` / `Shift + Tab` / `L1` / `R1` 仅在当前最上层可交互界面的无障碍组件之间首尾循环，绝不穿透至下层被屏蔽的界面。
2. **宏观与微观顺序法则**：
   - **从左到右、从上到下**：区域之间与同区域组件之间按视觉排布从上到下、从左到右依次遍历；
   - **先整体、再部分**：当一个可被选中的父组件内部包含独立可被选中的子控件时（如带 `dots-three` 按钮的卡片、带 `✕` 清除按钮的搜索框、带勾选框的远程目录卡片、带预设色块面板的 `Color Well`），无论正序还是逆序进入该父组件，均遵循「先选中父组件整体，再按从上到下、从左到右顺序遍历其内部子控件」的规则。
3. **视口自动滚动露出**：当无障碍移动至未完整显示在当前滚动可视区域内（含被固定顶栏或吸顶表头遮挡）的组件时，所属滚动容器立即最小幅度滚动使其完整可见，不带滚动动画。

## 1.4 与 Hover、Tooltip 及 Select 的关系

### 1.4.1 与鼠标 Hover 及 Tooltip 的关系
1. **非 `Select` 区域独立**：无障碍焦点在非 `Select` 区域内的进入、移动与退出**不触发、不清除、也不抑制**当前鼠标指针所在位置的 `Hover` 状态，**不隐藏**鼠标悬停触发的 `Tooltip`；非 `Select` 区域的同一组件可同时呈现鼠标 `Hover` 样式与外圈无障碍光圈。
2. **进入或在 `Select` 区域内移动时触发 `Select` 联动并抑制鼠标 `Hover`**：当无障碍光圈通过 `Tab` / `Shift + Tab` / `L1` / `R1` 进入任何 `Select` 区域，或在 `Select` 区域内继续移动（含在封面卡片整体与右下角 `dots-three` 按钮之间切换、跨项移动，或通过方向键 / 十字键 / 左摇杆移动）时，都会触发与 `Select` 的联动效果。此时立即取消已有的鼠标 `Hover` 效果（含清除卡片 `Hover` 底色、收起仅因鼠标 `Hover` 才显现的右下角 `dots-three` 按钮、将手型指针恢复为默认箭头指针），并将鼠标的 `Hover` 状态机切换为抑制状态，直至用户再次实际移动鼠标才恢复鼠标 `Hover` 状态机（恢复后若鼠标移至封面卡片上，同一张卡片同时具有 `Select` 与 `Hover` 时只显示 `Select` 底色不叠加，但正常显现手型指针与 `dots-three` 按钮）。
3. **弹出菜单与二级菜单中 `Hover` 与 `Select` 合二为一**：所有弹出菜单与二级菜单维持原有的单一高亮规则，将鼠标悬停（`Hover`）与键盘/手柄/无障碍选中（`Select`）合并为全菜单唯一的单一高亮状态，统一使用菜单原有的 `Hover` 底色（普通项 `--color-bg-hover`、危险项 `--color-danger-bg-hover`、播放页菜单项 `--color-player-menu-item-hover-bg`），并在无障碍模式下于当前无障碍焦点项外围额外绘制无障碍光圈；通过键盘或手柄移动菜单项时立即清除并抑制静止鼠标指针的悬停，直至鼠标再次实际移动；当菜单处于无障碍状态期间用户仅移动鼠标（未点击）指向其他可用菜单项时，菜单唯一的背景高亮底色跟随鼠标移动，而外圈无障碍光圈保持在原无障碍焦点项上。

### 1.4.2 与 Select（选中态）的组合、双向跟随与驻留
1. **Select 区域的定义与职责边界**：
   - 组件背景底色的选中变化完全来源于 `Select` 状态，无障碍自身只负责绘制外圈光圈；
   - **只有本身具备 `Select` 能力的组件所在的集合区域才属于 `Select` 区域**，全应用仅包含以下 3 类：
     1. **封面卡片网格**（`Recent`、`Library` 一/二级、`Excerpt` 一级、`Playback Video Playlist`、`Command Panel` 二级卡片网格）；
     2. **`Command Panel` 一级首页下方的选项列表**；
     3. **所有弹出菜单与二级菜单**（其 `Select` 与鼠标 `Hover` 合二为一）；
   - **非 Select 区域**：顶栏按钮、底栏按钮、工具栏按钮、搜索框（含 `Command Panel` 顶部搜索框）、`File` 页面文件夹卡片、远程目录浏览卡片、任务卡片、表格等组件本身不能被 `Select`，**均不属于 `Select` 区域**，被无障碍选中时仅绘制外圈无障碍光圈，不改变背景底色。
2. **无障碍带动 Select（`Tab` / `Shift + Tab` / `L1` / `R1`）**：
   - 当通过 `Tab` / `Shift + Tab` / `L1` / `R1` 使无障碍从区域外移入 `Select` 区域（如按 `Tab` 移入时选中该区域按顺序的第 1 项），或在 `Select` 区域内移动时，该区域的 `Select` 效果立即同步转移至当前无障碍所在的项，并同步触发取消已有鼠标 `Hover`、将鼠标 `Hover` 状态机置为抑制态的联动效果（弹出菜单中的 `Disabled` 菜单项被无障碍选中时，仅绘制外圈无障碍光圈，不显示高亮底色且清空原菜单高亮底色）。
3. **方向键带动无障碍（`↑` `↓` `←` `→` / 十字键 / 左摇杆）**：
   - **已处于无障碍状态时**：方向键（及手柄十字键/左摇杆）**仅在当前无障碍光圈正位于 `Select` 区域内部时**才对该 `Select` 区域生效：
     - 当无障碍光圈位于 `Select` 区域内部的组件（如封面卡片整体、封面卡片右下角 `dots-three` 按钮、`Command Panel` 首页下方选项、弹出菜单项）上时，按下方向键在该 `Select` 区域内移动 `Select` 项（含在首尾排/列边界继续按键），立即取消已有鼠标 `Hover` 并使鼠标 `Hover` 状态机进入抑制态，无障碍光圈同步跟随并落在该新 `Select` 项的整体（如封面卡片整体）上；
     - 当无障碍光圈位于 `Select` 区域之外的任何组件（如顶栏按钮、底栏按钮、或 `Command Panel` 顶部搜索框）上时，此时无障碍不在 `Select` 区域内，按下方向键**不会移动 `Select` 区域的选中项，无障碍光圈也不会跳入 `Select` 区域**（在可编辑文本框上按左右方向键仅移动文本光标）。
   - **未处于无障碍状态时**：在常驻 `Select` 区域（`Playback` 卡片网格、`Command Panel` 首页选项与二级卡片网格）及弹出菜单中按方向键仅移动 `Select`，不开启无障碍。
4. **离开或退出时的 Select 驻留与清除（Workbench 与 Playback 封面卡片的唯一区别）**：
   - **常驻 Select 区域（Playback 浮层卡片网格、Command Panel 首页选项与二级卡片网格、弹出菜单）**：存在强制的 `Select` 选中（卡片网格与首页选项打开即默认选中一项）；当无障碍通过 `Tab` / `L1` / `R1` 脱离该区域，或按 `Esc` / `◯` 退出无障碍时，外圈无障碍光圈移走或消失，但该区域的 `Select` 效果**继续停留在离开前的最后一项上**；
   - **Workbench 封面卡片区域（`Recent`、`Library` 一/二级、`Excerpt` 一级）**：除无强制常驻 `Select` 外，其余 `Select` 与 `Hover` 状态机规则与 Playback 封面卡片完全一致；仅当无障碍光圈位于卡片网格内部时才联动使对应卡片处于 `Select` 状态，一旦无障碍光圈脱离 Workbench 封面卡片网格或退出无障碍（含按 `Esc` / `◯`、鼠标点击、或打开菜单/对话框清除下层无障碍），选中卡片的 `Select` 状态**立即一并取消**。

# 2. 组件规则

## 2.1 输入框（Inputs：`C-01`）

1. **`C-01.1 Text Field` / `C-01.2 Text Area` / `C-01.4 Number Field`**：
   - 整体可选中（含 `Disabled` 状态；`Disabled` 时仅套无障碍光圈，不进入打字聚焦）；
   - **视觉区分**：仅获得普通输入焦点（非无障碍）时，仅容器内边框变为 `--color-border-focus`（报错态为 `--color-danger-text`）；被无障碍选中时，在聚焦内边框基础上同时在外围绘制无障碍光圈；
   - 可用状态下被无障碍选中时直接进入聚焦可打字状态（若按既有规则需全选则自动全选已有文本）；无障碍移出该输入框时自动取消其输入焦点。
2. **`C-01.3 Search Field`**：
   - 输入框为空（右侧无 `Inline Clear` 按钮）时，仅选中搜索框整体；
   - 输入框内有文字（右侧显现 `Inline Clear` `✕` 按钮）时，按「先整体、再部分」顺序：**先选中搜索框整体（进入可打字状态） → 再选中右侧 `✕` 清除按钮（此时搜索框取消输入焦点，无障碍光圈移至 `✕` 按钮；若按触发键点击 `✕` 清空文字导致 `✕` 按钮消失，则按组件消失规则自动退出无障碍状态）**。
3. **`C-01.5 Shortcut Field`**：
   - 组件自身**不响应无障碍**（移动时直接跳过）；
   - 当任意 `Shortcut Field` 处于 `Recording` 录制状态时，全局禁用无障碍。

## 2.2 选择控件（Selection Controls：`C-02`）

1. **`C-02.1 Checkbox` / `C-02.2 Switch` / `C-02.5 Filter Chip`**：
   - 整体可选中（含 `Disabled` 状态），可用状态下按 `Space` / `Return` / `✕` 切换勾选或开关状态。
2. **`C-02.3 Color Well`**：
   - 严格遵循「先整体、再部分」顺序：无论正序还是逆序进入该组件，均**先选中十六进制输入框整体（进入可编辑状态并同步展开下方 `6×2` 预设色块面板） → 随后按从上到下、从左到右依次遍历面板内的 12 个预设色块**（遍历色块期间输入框取消输入焦点，但预设色块面板保持展开；在色块上按触发键选色后面板保持展开且光圈留在该色块上） → 离开 `Color Well`（从第 12 个色块正序移向下一个组件，或从输入框整体逆序移向上一个组件）时收起预设色块面板。
3. **`C-02.4 Segmented Control`**：
   - 按从左到右顺序依次选中每一个分段选项（**含当前已处于 `Selected` 的分段选项**；在已选分段上按触发键无动作，在未选分段上按触发键切换选中且无障碍光圈留在该分段上）。

## 2.3 按钮（Buttons：`C-03`）

1. **`C-03.1 Button` / `C-03.2 Icon Button` / `C-03.3 Shortcut Action Button`**：
   - 整体可选中（**含 `Disabled` 状态**）；被无障碍选中时仅在外围绘制无障碍光圈，自身边框颜色保持不变；
   - 对于平时默认隐藏、仅在鼠标 `Hover` 父容器时显现的 `Icon Button`（如封面卡片、File 卡片、任务卡片与表格行右侧的 `dots-three` 按钮），**仅当无障碍直接选中该按钮自身时（或通过该按钮打开菜单期间）才显现**，选中其父组件整体时不显现。

## 2.4 菜单（Menus：`C-04`）

1. **`C-04.1 Menu` / `C-04.2 Submenu` / `C-04.3 Menu Item`**：
   - 全应用所有弹出菜单与二级菜单（**含 Workbench 各页面菜单、设置窗口下拉菜单、播放页与 Command Panel 菜单**）在打开期间均同时支持键盘与手柄操作；
   - 菜单打开期间，按从上到下顺序遍历菜单内所有 `Menu Item`（**含 `Disabled` 菜单项**，仅跳过 `Menu Divider` 分割线）；
   - 菜单属于 `Select` 区域，且**维持鼠标 `Hover` 与菜单 `Select` 合二为一的单一高亮状态**（统一使用菜单原有的 `Hover` 底色：普通项 `--color-bg-hover`、危险项 `--color-danger-bg-hover`、播放页菜单项 `--color-player-menu-item-hover-bg`；通过键盘或手柄移动时立即清除并抑制静止鼠标指针的悬停，直至鼠标再次实际移动）：
     - **已处于无障碍状态时**：无障碍选中可用菜单项时，该项同步呈现菜单单一高亮底色与外圈无障碍光圈，并与键盘上下方向键 / 手柄十字键及左摇杆双向同步跟随（`Disabled` 菜单项仅套外圈光圈，不显示高亮底色且清空原菜单高亮底色；无障碍开启期间若用户仅移动鼠标而未点击，菜单唯一高亮底色跟随鼠标位置，外圈无障碍光圈保持在原无障碍焦点项上，按 `Return` / `Space` / `✕` 触发无障碍光圈所在项）；
     - **未处于无障碍状态时**：按键盘上下方向键或手柄十字键 / 左摇杆仅在可用菜单项间移动菜单单一高亮底色（不开启无障碍光圈），按 `Return` / `Space` 或手柄 `✕` 触发当前高亮菜单项，按 `Esc` 或手柄 `◯` 关闭菜单；
   - 通过键盘/手柄选中带二级菜单（`Submenu`）的父菜单项时不自动展开二级菜单，需按 `Space` / `Return` / `✕` 或右方向键 `→`（或手柄十字右键 / 左摇杆右拨）展开；
   - 展开二级菜单后，二级菜单成为当前最上层界面，父菜单触发项保持高亮底色、下层父菜单无障碍光圈清除，**二级菜单内部初始处于未开启无障碍、无默认高亮项状态**（需再按 `Tab` / `R1` 或 `↓` / 十字下键 / 左摇杆下拨等进入选中）；按左方向键 `←`（或手柄十字左键 / 左摇杆左拨）收起二级菜单后高亮底色保持在父菜单触发项上；在菜单或二级菜单处于无障碍状态时，按第 1 次 `Esc` / `◯` 仅清除无障碍光圈（当前可用项高亮底色保留），按第 2 次 `Esc` / `◯` 关闭整套菜单。

## 2.5 导航组件（Navigation：`C-05`）

1. **`C-05.2 Sidebar Toggle`**：作为顶栏图标按钮参与无障碍（含 `Disabled` 态）。
2. **`C-05.3 Sidebar Item`**：仅在 `Sidebar` 处于展开状态时参与无障碍；按从上到下顺序遍历全部导航项（**含当前已处于 `Selected` 的导航项**；触发切换后导航项未消失，无障碍光圈继续留在该导航项上）。
3. **`C-05.4 Tabs` / `C-05.5 Tab`**：按从左到右顺序遍历全部标签页（**含当前已处于 `Selected` 的标签页**；触发切换后标签页未消失，无障碍光圈继续留在该标签页上）。
4. **`C-05.6 Breadcrumb`**：按从左到右顺序仅遍历未激活的上级链接节点（`Link Item`），**跳过最右侧不可交互的当前末级节点（`Current Item`）**。

## 2.6 表格（Tables：`C-06`）

1. **基本原则**：表格行（`Table Row`）整体在任何模式下均不套无障碍光圈，无障碍仅选中表头与数据行内部的以下具体子控件（首列 `Checkbox`、`Cues` 列台词文字、右侧 `dots-three` 按钮）。
2. **`C-06.2 Table Header Cell / Selection`（表头首列 `#`）**：
   - 当表格存在有效行时，表头首列 `#` 槽位的全选 `Checkbox` 参与无障碍；无障碍选中该位置时显现全选 `Checkbox` 并套上无障碍光圈（表头整行不改变底色），触发时切换全选。
3. **`C-06.3 Table Row`（普通模式 `Normal Mode`）**：
   - 整行不改变底色；
   - **有效行（Available Row）**：内部按从左到右依次单独选中 3 个子控件：**① 首列序号槽位的勾选框 `Checkbox`（仅在被无障碍选中时由序号切换显现 `Checkbox` 并套上光圈） → ② `Cues` 列的台词文字（`Interactive Text`，在台词文字圆角点击热区框外围套上光圈，无下划线） → ③ `Cues` 列右侧的 `dots-three` 按钮（仅在被无障碍选中时显现并套上光圈）**；
   - **已失效行（`Unavailable` Row）**：首列无 `Checkbox` 且台词文字已失效不可交互，仅选中 `Cues` 列右侧的 `dots-three` 按钮（被选中时显现并套上光圈）。
4. **`C-06.3 Table Row`（批量选择模式 `Select Mode`）**：
   - **有效行（Available Row）**：按从上到下顺序依次选中每一行首列槽位的 `Checkbox`（在 `Checkbox` 外围套上无障碍光圈，触发时切换该行勾选）；
   - **已失效行（`Unavailable` Row）**：在批量选择模式下无 `Checkbox` 且右侧 `dots-three` 按钮隐藏，无任何可选中子控件，自动跳过。

## 2.7 业务展示与媒体卡片（Domain & Media：`C-08`、`C-11`、`L-04.6`、`L-06.10`）

1. **`C-08.5 Workbench Status Indicator`（File 页面状态指示器）**：
   - File 页面顶部操作栏右侧的状态指示器文字（无论处于已完成、失败、`Last Updated: yy-MM-dd HH:mm`、从未索引 `Last Updated: --` 还是进行中 `In Progress`）均参与无障碍选中（套上无障碍光圈，不显示 Hover 下划线；在不可点击状态下按触发键无动作）；
   - 其他页面（`Library`、`Excerpt`、`Search`）中的纯数量统计文本（如 `xx folders`、`xx results`）不参与无障碍。
2. **`C-11.2 Cover Summary`**：
   - 左下角操作按钮区（`Resume` / `Play` 按钮、`View in File` 按钮、`More` 按钮，含 `Disabled` 状态）按从左到右顺序参与无障碍。
3. **`C-11.3 Cover Crop Editor`**：
   - 未选择新图片时，封面区域中间的选图触发按钮参与无障碍（选中时仅在封面外围套上无障碍光圈，不显示 Hover 态的 `Choose Image` 遮罩）；
   - 已选择图片进入裁剪状态时，裁剪框与四个角点手柄均不参与无障碍（直接跳过）。
4. **`C-11.5 Media Card`（媒体封面卡片）**：
   - **Workbench 与 Playback 封面卡片规则对齐与唯一区别**：Workbench 封面卡片与 Playback 封面卡片共用同一套 `Select` + `Hover` 状态机（无障碍进入或在卡片网格内移动时联动触发 `Select`，立即取消已有鼠标 `Hover` 效果并将鼠标 `Hover` 状态机置为抑制态，直至鼠标再次实际移动；同一卡片同时处于 `Select` 与 `Hover` 时只显示无动画的 `Select` 底色，不叠加 `Hover` 底色）。唯一区别在于 Playback 封面卡片网格强制常驻保持一张卡片处于 `Select`，而 Workbench 封面卡片网格没有强制常驻 `Select`，当无障碍光圈移出网格或退出无障碍后，Workbench 封面卡片的 `Select` 状态立即取消；
   - **Select 承载规则**：在封面卡片网格中，`Select` 状态的最小承载单位为封面卡片整体，卡片内部的 `dots-three` 按钮自身无法被单独 `Select`；
   - **无内部子按钮的封面卡片**（`Recent Videos` 卡片、`Library` 二级剧集卡片、`Playback Video Playlist` 卡片、`Command Panel Recent Videos` 卡片）：直接选中卡片整体（因处于 `Select` 区域，卡片呈现 `Select` 底色，且外围套上无障碍光圈）；
   - **带右下角 `dots-three` 按钮的封面卡片**（`Library` 一级文件夹卡片、`Excerpt` 一级及 `Recent` / `Command Panel` 中的摘录集卡片）：按「先整体、再部分」顺序：
     1. **先选中卡片整体**：卡片呈现 `Select` 底色并套上无障碍光圈（此时因触发 `Select` 联动取消并抑制了鼠标 `Hover`，右下角 `dots-three` 按钮保持隐藏，直至无障碍移至该按钮或鼠标再次实际移动悬停于该卡片）；
     2. **再选中右下角 `dots-three` 按钮**：该 `dots-three` 按钮显现并套上无障碍光圈；同时因无障碍仍处于该卡片网格（`Select` 区域）内且无法单独 `Select` 按钮，`Select` 底色继续挂在该按钮所属的封面卡片上；
   - **方向键默认选中卡片整体**：当无障碍已处于封面卡片网格内（位于某张卡片整体或其 `dots-three` 按钮上）时，按下方向键（或手柄十字键/左摇杆）默认选中目标卡片的**卡片整体**。
5. **`L-04.6 File Card`（File 页面卡片）**：
   - 不属于 `Select` 区域，无障碍选中时不改变卡片或行的背景底色；
   - **一级根目录卡片与二级子文件夹卡片**：先选中文件夹卡片整体（仅卡片外围套上无障碍光圈，右侧 `dots-three` 按钮保持隐藏） → 再选中右侧 `dots-three` 按钮（此时该 `dots-three` 按钮显现并套上无障碍光圈）；
   - **单集容器（`Episode File Group`）内的视频/字幕文件行**：文件行整体不可点击（跳过），直接按从上到下顺序选中每一行右侧的 `dots-three` 按钮（选中时该按钮显现并套上无障碍光圈）。
