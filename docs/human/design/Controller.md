# DS5手柄

## 键位逻辑
下面是键位的逻辑，不代表要按照键盘的方式实现，而是功能上的说明。当描述为相当于键盘的某键时，意思指的是交互和表现，对于用户而言是完全相同的，一些特殊的规则也是完全相同的。

Cross键：在视频播放界面播放/暂停视频，相当于键盘的Space键。在Playback Overlay，Command Panel，Collage界面相当于键盘的Enter键。
Circle键：相当于键盘的Esc，使用场景很多，可以严格一一对应。
Square键：用于Command Panel一级界面删除文字，相当于键盘的Backspace键。用于Playback Overlay，Command Panel Search Result界面复制文字内容，相当于键盘的C键。用于Collage界面的Copy Collage。
Triangle键：视频播放界面，相当于键盘的R键。用于Playback Overlay，Command Panel Search Result界面的收藏字幕，相当于键盘的S键。用于Command Panel一级界面的粘贴。用于Collage界面的Export Collage。

Create键：用于视频播放界面截图和进入/退出Collage界面，相当于键盘的P键。
Touchpad键：用于从视频播放界面进入Playback Overlay界面，按下Touchpad键相当于视频播放界面下的键盘的Enter键。
Options键：相当于键盘的打开Command Panel的按键，相当于键盘的K键。

方向上键：相当于键盘的方向上键。
左摇杆往上拨：相当于键盘的方向上键。
方向下键：相当于键盘的方向下键。
左摇杆往下拨：相当于键盘的方向下键。
方向左键：相当于键盘的方向左键。
左摇杆往左拨：相当于键盘的方向左键。
方向右键：相当于键盘的方向右键。
左摇杆往右拨：相当于键盘的方向右键。

L1：在Playback Overlay界面中，切换到上一个标签。
R1：在Playback Overlay界面中，切换到下一个标签，相当于键盘的Tab键。
L2：在视频播放界面，切换到上一个结果，相当于键盘的A键。
R2：在视频播放界面，切换到下一个结果，相当于键盘的D键。
L3：在视频播放界面，显示/隐藏字幕，相当于键盘的Q键。
R3：在视频播放界面，进入/退出全屏，相当于键盘的F键。

## 额外说明
1. 左摇杆往左拨或往右拨，在视频播放界面，长按像键盘方向键一样连续移动。
2. 左摇杆往左拨或往右拨，在视频播放界面，斜向输入按主轴处理。
3. 左摇杆往左拨或往右拨，在视频播放界面，回到死区后才能重新触发。
4. 左摇杆往上拨或往下拨，在Playback Overlay，Command Panel，Collage界面，长按像键盘方向键一样连续移动。
5. 左摇杆往上拨或往下拨，在Playback Overlay，Command Panel，Collage界面，斜向输入按主轴处理。
6. 左摇杆往上拨或往下拨，在Playback Overlay，Command Panel，Collage界面，回到死区后才能重新触发。
7. L1和R1允许循环切换标签。
