## Summary of Changes
1. **Scoped Continuous Static Text Flow Engine (`WorkbenchStaticTextSelectionCoordinator.swift`, `WorkbenchSelectableText.swift`, `WorkbenchDialogLayer.swift`)**:
   - Split static text selection into single-node selectable text view (`WorkbenchSelectableText.swift`) and continuous flow coordinator (`WorkbenchStaticTextSelectionCoordinator.swift`), eliminating duplicate control/offscreen mouse helpers and redundant view-tree scans.
   - Evolved `WorkbenchStaticTextSelectionCoordinator` from single-node tracking into a reading-order continuous text flow scoped strictly to the topmost active surface (`Description Detail Popover` > topmost uncovered modal dialog > active Main/Settings page).
   - Propagated `isWorkbenchDialogCovered` from `WorkbenchDialogChrome` so covered lower stacked dialogs are excluded from interaction and flow scope.
   - Ordered selectable nodes top-to-bottom by visual row (preserving pinned header ordering ahead of scrolled `NSScrollView` rows) and left-to-right within the same horizontal row, skipping non-selectable controls (icons, progress bars, buttons).
   - Computed visible window clipping in two passes: intersecting outer viewport and scroll clip bounds (`window.contentView`, `NSClipView`, `NSScrollView`, `SubtitleTablePageChromeViewportView`) first (accounting for the 52pt main-window top bar), then subtracting intersecting upper sibling sticky toolbar hosts (`SubtitleTablePageChromeHostingView`) and fixed table headers (`SubtitleVirtualTableHeaderView`) so `Cover Summary` text scrolled behind sticky chrome no longer participates in visible row hit-testing, `\t` horizontal peer merging, or drag-selection activation.
   - Projected the selection anchor strictly from the initial `leftMouseDown` window coordinate without segment intersection or binary search, and enforced strict vertical boundary clamping (`y < firstVisibleRow.minY` clamps to the first visible line start offset with zero top horizontal tolerance band; `y > lastVisibleRow.maxY` clamps to last node end offset).
2. **Blank-Area & Click-Control Drag Entry, Focus Ownership, Native-Drag Exemptions & Mutual Exclusion (`CueSeekerMainWindow.swift`, `SubtitleTableExternalTextSelection.swift`, `SchemaWorkbenchSearchShell.swift`, `LibraryCoverCropEditor.swift`, `AnkiExportDialog.swift`, `PlaybackProgressScrubber.swift`, `PlaybackVolumeControl.swift`)**:
   - Coordinated window-level `leftMouseDown` / `leftMouseDragged` / `leftMouseUp` in `CueSeekerMainWindow.sendEvent` via `WindowMouseEventDisposition` (`.passthrough` / `.consume` / `.redirect`), reusing shared `SubtitleTableTextSelectionHitTesting` helpers (`enclosingEnabledControl`, `cancelOriginatingControlPress`, `offscreenMouseEvent`).
   - Registered selection anchor ownership (`activeScope`, `activeResponderView`, `activeDragSession`, `applyFlowSelection`) before calling `window.makeFirstResponder(anchorPos.view)` on external drag-entry activation so focus switches cleanly to the anchor owner without triggering outside-selection focus-change clearing and stays valid after selection retraction.
   - Unified `.cueSeekerNativeDragRegion(isActive:)` into `SubtitleTableTextSelectionInteractiveRegion` / `SubtitleTableTextSelectionInteractiveRegionView` via `SubtitleTableTextSelectionInteraction.nativeDrag` and resolved it in the single `topmostSemanticInteraction` view-tree pass across `LibraryCoverCropEditor`, `AnkiCardBadgeRow`, `PlaybackProgressScrubber`, `PlaybackVolumeSlider`, `DraggableNSView`, traffic-light buttons, editable text inputs, scrollbars, and sliders.
   - Updated `SubtitleTableExternalTextSelectionSession.drag` to check `isDraggingSelection` and cleared static text selection on entering `Select Mode`, ensuring smooth mutual exclusion between static text flows (such as `Excerpt` `Cover Summary`) and `SubtitleTable` / `PlaybackSubtitleFocusReel`.
3. **Viewport Edge Auto-Scrolling, Clipboard Format & `...` Full Text Extraction (`WorkbenchSelectableText.swift`, `WorkbenchStaticTextSelectionCoordinator.swift`, `CoverSummaryCard.swift`, `WorkbenchExcerptTableView.swift`, `CueSeekerMainWindow.swift`)**:
   - Added 30Hz smooth edge auto-scrolling across `NSScrollView` (`WorkbenchScrollView` / `Description Detail Popover`) and `SubtitleTablePageChromeViewportView` (`Excerpt` detail page), reusing `SubtitleTableTextDragAutoScrollGeometry.nextOrigin` while keeping the initial anchor character pinned even after scrolling offscreen.
   - Serialized multi-node selections with `\t` between horizontal peers on the same visual row (only when both are selected) and `\n` across vertical rows/nodes; mapped pointers on the right half of the tail-truncated glyph / synthesized `...` ellipsis inside the text box or beyond visible line end to `textStorage.length`, restoring the full untruncated underlying string for both TextKit single-line/multi-line tail truncation and pre-truncated `fullCopyText`.
   - Wired `Cmd + C` and `Edit -> Copy` (`validateMenuItem` / `copy(_:)` on both `CueSeekerMainWindow` and `WorkbenchSelectableTextNSView`) without adding a right-click copy context menu.
4. **Unit & Integration Tests (`WorkbenchSelectableTextTests.swift`, `SubtitleTableExternalTextSelectionTests.swift`)**:
   - Covered top-left diagonal drag entry with strict top/bottom vertical clamping, external drag-entry anchor focus ownership & retraction, sticky toolbar & fixed table header occlusion clipping under a 52pt main-window top bar, `Grab` link click vs drag disambiguation, click-control drag entry with press cancellation and unified `.cueSeekerNativeDragRegion` exemptions, `\t` / `\n` clipboard serialization and `Edit -> Copy` menu validation, releasing directly on internal `...` ellipsis to copy full untruncated text, `NSScrollView` viewport edge auto-scrolling + pinned header ordering, dialog scope isolation, and `SubtitleTableExternalTextSelectionSession` mutual exclusion.
