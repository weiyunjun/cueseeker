# CueSeeker UI Collaboration Artifacts

Status: Active

This directory stores source artifacts used to align CueSeeker interface design
before App implementation.

Rules:

- Local HTML prototypes belong under `ui/prototypes/`.
- Visual reference material belongs under `ui/references/`.
- Shared prototype assets belong under `ui/assets/`.
- UI artifacts in this directory are collaboration sources, not stable product
  documentation.
- Stable UI rules, prototype-to-App mappings, and known HTML/App differences
  are documented under `docs/product/`.
